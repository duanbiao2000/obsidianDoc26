| 符号/分类                             | 含义/用途                              | 考察核心或技巧                                | 适用场景/题型                                              | 示例/建议                                            |
| --------------------------------- | ---------------------------------- | -------------------------------------- | ---------------------------------------------------- | ------------------------------------------------ |
| 结构与主旨类 (\|或 M)                    | 标记段落主题句、总起句或段落大意                   | 提取段落主旨；区分主旨与细节；识别段首段尾及转折处              | Matching Headings (段落标题配对)、Choosing a title (选标题)    |                                                  |
| 逻辑关系类 (★ / → / ↔ / +)             | 标记转折(★)、因果(→)、对比(↔)及递进(+)关系        | 精细理解陈述和原文的逻辑关系；定位真正观点所在(转折后)           | TFNG / YNNG 判断题、Matching features (人物观点)             | 在but/however后画★；在therefore前画→；精英考生本能标出转折和因果      |
| 题目相关性标记 (Q / · / ?)               | 标记已确定的出题句(Q)或疑似出题的信息点(· / ?)       | 快速回溯答案来源；识别考点句；事后反思建模                  | 所有题型，尤其是细节定位后的核对                                     | 在用到的句子旁打Q并写上题号；标记包含数字、人名的句子                      |
| 细节信息标记 (○ / 缩写 / ~)               | 圈出数字/年份(○)；缩写人名/机构；标记生词/术语(~)      | 扫读能力(Scanning)；把文字信息对应到图上；定位特定细节       | Matching Information、Diagram Completion、简答题          | Darwin写D；圈出数字旁标n；~代表知道是个概念不纠结意思                  |
| 替换链标记 (≈ / ⇄)                     | 标注题干表达与原文之间的同义改写关系                 | 识别同义改写(Paraphrase Mapping)；建立题干-原文对应关系 | Summary Completion (摘要填空)、Multiple Choice (选择题)      | 例如：workers ≈ employees；这是高分阅读最核心的隐形技能            |
| 段落功能标记 (Def, Ex, Exp, Crit, Sol等) | 识别并简写段落的功能（如定义、举例、实验、批评、解决方案等）     | 识别段落功能而非仅找关键词；建立“文章地图”                 | Matching Headings (标题配对)、Matching Information (信息配对) | Heading常选段落重心(如Crit)而非次要功能(如Def)                 |
| 绝对化警报 (⚠)                         | 警惕题干或原文中出现的绝对词(all, only, always等) | 区分“原文明确说/说反了/没说”；识别TFNG高频陷阱            | TFNG / YNNG 判断题                                      | 看到only/completely等词直接标⚠；注意Some与All的区别            |
| 研究结论标记 (R)                        | 标记研究发现、实验结果或调查结论                   | 精确定位高频出题区；识别作者或研究者态度                   | Matching Features (人物-观点配对)、Multiple Choice          | 在researchers found或results indicate旁标记R，此类句子几乎必考 |
