## 先看中间：Machine Learning 是“总门类”

最中间的方块写的是 **MACHINE LEARNING**。它向四周发散出几大块：

- **Artificial Neural Networks**：各种深度学习网络（CNN、RNN、GAN、Autoencoder 等）。 [github](https://github.com/orgs/community/discussions/163429)
- **Classical Learning**：传统机器学习方法（线性回归、决策树、SVM、kNN 等）。 [facebook](https://www.facebook.com/groups/miaigroup/posts/1813405222764075/)
- **Reinforcement Learning**：和环境交互、靠“奖励/惩罚”学习的算法（Q-Learning, DQN, A3C, SARSA）。 [notes.kodekloud](https://notes.kodekloud.com/docs/AWS-Certified-AI-Practitioner/Fundamentals-of-AI-and-ML/Supervised-Unsupervised-and-Reinforcement-Learning/page)
- **Ensemble Learning**：把多个弱模型组合成强模型的方法（Bagging、Boosting、Stacking）。 [github](https://github.com/orgs/community/discussions/163429)

你可以把它理解成：**机器学习是总学科**，里面有传统方法、神经网络类方法，以及不同学习范式（监督、非监督、强化、集成）。

## Classical Learning：监督 / 非监督 + 典型算法

绿色这块是 **Classical Learning**，下面继续分：

- **Supervised Learning（监督学习）**：  
  模型在“有标签的数据”上学会从输入到输出的映射。典型任务是 **分类** 和 **回归**。 [geeksforgeeks](https://www.geeksforgeeks.org/machine-learning/supervised-vs-reinforcement-vs-unsupervised/)
  - Classification：预测类别  
    - 典型算法：**kNN**, **Logistic Regression**, **Naive Bayes**, **Decision Tree**, **SVM**。  
  - Regression：预测连续数值  
    - 典型算法：**Linear Regression**, **Lasso / Ridge Regression**, **Polynomial Regression**。 [github](https://github.com/orgs/community/discussions/163429)

- **Unsupervised Learning（非监督学习）**：  
  在“无标签的数据”中找模式、结构，比如分组、降维。 [digitalocean](https://www.digitalocean.com/resources/articles/types-of-machine-learning)
  - Clustering：把样本自动分成簇  
    - 典型算法：**k-Means**, **Fuzzy C-Means**, **DBSCAN**, **Mean-Shift**。  
  - Dimensionality Reduction / Visualization：降维、可视化  
    - 典型算法：**PCA**, **LDA**, **SVD**, **ICA**, **t-SNE**, **LLE**, **LSA**。 [github](https://github.com/orgs/community/discussions/163429)

- **Association Rule Mining（关联规则挖掘）**：  
  在交易数据或行为数据中找出 “如果买 X 通常也买 Y” 这类规则。  
  - 算法：**Apriori**, **ECLAT**, **FP-Growth**。 [github](https://github.com/orgs/community/discussions/163429)

如果你只记住一点：**监督 = 有标签；非监督 = 无标签；关联 = 找“共现规则”**，这张图的绿色部分就基本读懂了。 [notes.kodekloud](https://notes.kodekloud.com/docs/AWS-Certified-AI-Practitioner/Fundamentals-of-AI-and-ML/Supervised-Unsupervised-and-Reinforcement-Learning/page)

## Artificial Neural Networks：各种深度网络家族

紫色这块是 **Artificial Neural Networks**，也就是深度学习族谱。 [kudosai](https://www.kudosai.com/Blog/Top-10-Machine-Learning-Algorithms)

图上列了几类：

- **MLP（Multi Layer Perceptron）**：最基础的全连接前馈网络。
- **RNN（Recurrent Neural Networks）**：处理序列数据（文本、时间序列）；下面标了 **LSTM** 和 **GRU** 这两种改良结构。
- **CNN（Convolutional Neural Network）**：处理图像和网格数据；旁边举了 **ResNet, VGG, AlexNet, EfficientNet** 这些知名架构。
- **GAN（Generative Adversarial Networks）**：对抗生成网络，一个生成器、一个判别器相互博弈，用于图像生成等。
- **Autoencoders**：自编码器，用于降维、特征学习、异常检测等。
- **RBFNN（Radial Basis Function Neural Network）**、**Modular Neural Network**：其他类型的网络结构。 [pmc.ncbi.nlm.nih](https://pmc.ncbi.nlm.nih.gov/articles/PMC8703772/)

你可以把这一块理解成：**如果传统算法像“统计工具箱”，这些神经网络就是“可自动提特征的端到端模型”**。

## Reinforcement & Ensemble：两个特殊方向

- **Reinforcement Learning（强化学习）**：  
  不再是“给你一堆样本和标签”，而是一个 **智能体（agent）** 在环境中采取行动，收到奖励或惩罚，逐渐学会策略。 [youtube](https://www.youtube.com/watch?v=Atg-Sl32vOo)
  - 典型算法：**Q-Learning**, **Deep Q-Network (DQN)**, **A3C**, **SARSA**。

- **Ensemble Learning（集成学习）**：  
  用“多个模型的组合”提升性能或鲁棒性。 [facebook](https://www.facebook.com/groups/miaigroup/posts/1813405222764075/)
  - Bagging（如 **Random Forest**）：多棵树投票。  
  - Boosting（如 **AdaBoost, XGBoost, GradientBoost, CatBoost, LightGBM**）：弱模型一层层“纠正”上一层的错误。  
  - Stacking：用一个“高层模型”学习如何加权或组合多个底层模型的输出。

这两块在实践里非常重要：**集成方法是比赛里的常用武器，强化学习是游戏、机器人和决策优化的主力。** [towardsdatascience](https://towardsdatascience.com/15-must-know-machine-learning-algorithms-44faf6bc758e/)

## 第二层：业务导向项目

> Shift from a**NALysis** to de**CIsion-MAKing**.

时间：第 2–3 个月。这里你不再仅仅展示 “I can query data”，而要展示：

> **I can TURN data into a deCIsion.**

“我能把数据变成决策。”

图中给出三个很好的业务问题：

- **Funnel Analysis**：把用户旅程拆为多个阶段，计算各阶段转化率，找最大流失点，并提出优化建议。
- **Cohort Retention Analysis**：按注册月份分组，追踪留存趋势，画留存热力图，解释用户行为。
- **A/B Test Evaluation**：定义假设、计算统计显著性和 p-value，解释结果并给出是否上线的建议。

真正让作品从“数据分析练习”变成“业务分析案例”的，是结论必须落到行动：

> The **BIGgest DROP-off** happens at **PAYment**.  
> We should **TEST** a **SIMpler CHECKout FLOW**.

“最大流失发生在支付环节。我们应测试一个更简洁的结账流程。”

## 把它改造成你的版本

如果你的目标是 **data / analytics + AI 内容工作流**，我会把这张图压缩为三个相互连接的主项目，而非五到八个散项目：

1. **Content Analytics Foundation**：SQL + Python + Power BI  
   分析你自己的视频 / 文章 / 学习内容库：主题、长度、发布时间、产出效率、受众反应。

2. **Audience Funnel & Retention System**：SQL + cohort + dashboard  
   定义“曝光 -> 点击 -> 观看 -> 互动 -> 订阅”漏斗，找不同主题或平台的流失点与高质量受众群。

3. **Knowledge-Content Warehouse**：dbt + star schema + 自动更新  
   将视频元数据、字幕文本特征、发布记录和表现指标转化为稳定的数据模型，最终服务于一个可筛选的选题与表现看板。

最后再选一个强化方向：  

- 想偏 AI：做“内容表现预测”或“字幕文本语义聚类”；  
- 想偏数据工程：做“自动抓取 / 清洗 / 入库 / 更新看板”的管道。  

这三项连在一起，会形成一个清晰定位：

> **I BUILD** data systems for con**TENT** deCIsions, not just **DASHboards**.
