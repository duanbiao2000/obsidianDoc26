需要区分的重点不是“口语词一定错、书面词一定高级”，而是**语域（register）是否符合场景**：日常交流可以自然随意；IELTS Task 2、学术论文和正式报告通常更偏好准确、中性、正式的表达。书面语通常经过修订，信息更密集、结构也更严谨。 

## 常用替换词

| 口语化或较随意 | 书面/正式写法 | 例句 |
|---|---|---|
| a lot of | many / much / a considerable amount of | *Many people rely on cars.* |
| lots of | many / numerous / a wide range of | *A wide range of services is available.* |
| get | receive / obtain / become / achieve | *Students can obtain useful skills.* |
| give | provide / offer | *Schools should provide career guidance.* |
| help | assist / support / enable | *This policy can help families.*（**help** 本身正式写作可用） |
| buy | purchase | *Consumers purchase goods online.* |
| show | demonstrate / indicate / illustrate | *The data indicate a steady increase.* |
| tell | inform / state / explain | *The report states that...* |
| deal with | address / tackle / handle | *Governments must address pollution.* |
| find out | discover / determine / identify | *Researchers identified the cause.* |
| look at | examine / consider / analyse | *This essay examines both views.* |
| think about | consider | *Policymakers should consider the long-term effects.* |
| make sure | ensure | *Authorities should ensure public safety.* |
| start | begin / initiate | *The programme began in 2020.* |
| end | cease / conclude | *The scheme was discontinued.* |
| keep | retain / maintain / preserve | *The city should preserve green spaces.* |
| use | utilise / employ | *People use smartphones daily.*（**use** 常常比 *utilise* 更自然） |
| need | require | *This approach requires substantial funding.* |
| big | large / significant / major | *The policy had a significant impact.* |
| small | limited / minor / slight | *There was a slight decline.* |
| good | beneficial / effective / positive | *Public transport is beneficial for the environment.* |
| bad | harmful / damaging / negative | *Air pollution has harmful effects.* |
| important | essential / crucial / significant | *Education plays a crucial role.* |
| wrong | inappropriate / incorrect / problematic | *This assumption is problematic.* |
| easy | straightforward / accessible | *Online services make information more accessible.* |
| hard | difficult / challenging | *It is challenging to change habits.* |

## 连接与立场

这类口语表达在聊天中很自然，但正式作文中可换成更清楚的逻辑词。

| 较口语化 | 更正式/书面 | 例句 |
|---|---|---|
| so | therefore / consequently / as a result | *Consequently, traffic congestion may decline.* |
| but | however / nevertheless / whereas | *However, the policy may be expensive.* |
| also | in addition / furthermore | *Furthermore, it can improve public health.* |
| anyway | nevertheless / even so | *Nevertheless, the disadvantages remain.* |
| because of | due to / owing to | *The event was cancelled due to heavy rain.* |
| in the end | ultimately / eventually | *Ultimately, individuals must make informed choices.* |
| more and more | an increasing number of / increasingly | *An increasing number of people work remotely.* |
| these days | currently / in recent years | *In recent years, remote work has become more common.* |
| I think | I believe / I would argue / 直接陈述 | *I would argue that public funding is justified.* |
| in my opinion | from my perspective / 直接陈述 | *From my perspective, this is a practical solution.* |
| like | such as / for example | *Outdoor activities, such as cycling, improve health.* |

## 常见“中式口语”改法

下面几组在 IELTS 写作里尤其常见。问题不只是“不高级”，而是表达空泛、逻辑弱或不够地道。

| 尽量少用 | 更好的写法 |
|---|---|
| *With the development of society...* | 直接写具体变化：*As technology advances...* / *As cities expand...* |
| *People’s living standard has improved.* | *Living standards have improved.* |
| *People pay more attention to...* | *People are increasingly concerned about...* |
| *It is convenient for people.* | *It enables people to access services more conveniently.* |
| *It brings many benefits.* | 直接说明利益：*It reduces travel time and lowers transport costs.* |
| *There are pros and cons.* | 明确利弊：*It improves access to education but may widen inequality.* |
| *This phenomenon is serious.* | 说明后果：*This trend can increase housing costs for low-income residents.* |
| *Nowadays, with the rapid development of...* | 直接进入主题：*Online shopping has transformed consumer behaviour.* |
| *We should...* | *Governments / schools / individuals should...* |
| *Everyone knows that...* | 删除，直接陈述并解释 |

## 不要机械替换

最重要的原则是：**正式不等于更长、更生僻。** 有些所谓“书面替换词”反而会让句子不自然。

- 自然：*The policy can help low-income families.*
- 过度：*The policy can facilitate the amelioration of disadvantaged households.*

这里的 *help* 比 *facilitate the amelioration of* 更准确、更好读。

同样：

- *use* 在学术写作中完全可以用；
- *show* 在图表作文中非常常见；
- *buy*、*get* 若语境简单也不一定有问题；
- 不要为了“高级”滥用 *utilise, moreover, nonetheless, facilitate*。

## 可直接使用的句型

- *Governments should **address** this issue by...*
- *This measure may **lead to**...*
- *The policy can **enable** residents to...*
- *The main **drawback** is that...*
- *A major **benefit** is that...*
- *This is particularly **beneficial** for...*
- *The findings **indicate** that...*
- *It is **essential** to consider...*
- *This approach is likely to **reduce / increase**...*
- *The long-term **consequence** may be...*

## 最实用的判断法

写完后看到一个词，依次问：

1. **它是否过于随意？** 如 *kids, a lot of, things, get, stuff*  
2. **它是否足够具体？** 如把 *good* 改为 *beneficial*，更好的是直接说清“有什么益处”。  
3. **替换后是否更自然？** 若只是显得更长，就不要换。  
4. **对象是否明确？** 不写泛泛的 *we*、*people*、*this problem*，而说明具体群体或问题。  

例如，不要只把：

> *A lot of people think it is good.*

机械升级成：

> *Numerous individuals consider it beneficial.*

更好的版本是：

> *Many urban residents support the policy because it reduces commuting time and transport costs.*

这才同时做到了**正式、具体、清楚**。

书面语避免冗余的核心是：**删掉不增加信息的词，把“弱动词 + 名词短语”改为直接动词，并让每句话只承担一个清楚的表达任务。** 简洁不是字数越少越好，而是在不损失必要信息、逻辑和语气的前提下，用最少的词准确传意。 [owl.purdue](https://owl.purdue.edu/owl/general_writing/academic_writing/conciseness/eliminating_words.html)

## 先用一个判断标准

修改一句话时问：

> **删掉或替换这个词后，事实、逻辑、强调程度是否改变？**

- **不改变**：删掉。  
- **改变**：保留，或换成更准确的表达。  

例如：

> *It is important to note that public transport reduces traffic congestion.*

删掉 *It is important to note that* 后，核心信息完全不变：

> *Public transport reduces traffic congestion.*

前一种是“提醒读者这很重要”，后一种是直接给信息。正式写作通常偏好后者。写作中心的建议也包括：删除不必要限定语、冗余搭配及不增加意义的前置短语。 [writingcenter.unc](https://writingcenter.unc.edu/tips-and-tools/conciseness-handout/)

## 删除填充开头

这些开头常拖慢句子，但不增加实质内容。

| 冗余表达 | 简洁改法 |
|---|---|
| *It is important to note that...* | 直接陈述 |
| *It is clear/obvious that...* | 直接陈述 |
| *It should be emphasised that...* | 直接陈述，或用证据强调 |
| *There is no doubt that...* | 直接陈述 |
| *It is widely believed that...* | *Many people believe that...*（若主体重要） |
| *In my personal opinion...* | *In my opinion...* / 直接表达立场 |
| *It can be seen that...* | 图表题可用 *The chart shows...*；多数情况直接说结论 |
| *The fact that...* | 直接使用从句或名词 |

**例子：**

- 冗余：*It is clear that online learning has changed education.*  
- 简洁：*Online learning has changed education.*

- 冗余：*The fact that people live longer has increased healthcare costs.*  
- 简洁：*Longer life expectancy has increased healthcare costs.*

## 避免同义重复

一个概念说一次即可。两个词看似更有力度，往往只是在重复。

| 冗余搭配 | 简洁表达 |
|---|---|
| *each and every* | *each* / *every* |
| *future plans* | *plans* |
| *past history* | *history* |
| *basic fundamentals* | *fundamentals* |
| *final outcome/result* | *outcome/result* |
| *free gift* | *gift* |
| *close proximity* | *proximity* / *near* |
| *true facts* | *facts* |
| *personal opinion* | *opinion* |
| *repeat again* | *repeat* |
| *combine together* | *combine* |
| *return back* | *return* |

例如：

> *Every student should develop their own personal opinion.*

可改为：

> *Every student should develop an opinion.*

学术写作中，还要避免**段落层面的重复**：如果两个主体段都在说“科技使生活方便”，即便换了词，本质上仍是一个观点。应让每段承担不同功能，例如一段谈效率，另一段谈信息获取或社会联系。重复观点会让论证显得不足。 [umanitoba](https://umanitoba.ca/sites/default/files/2020-07/avoiding-redundancy-new.pdf)

## 用直接动词

冗余经常来自“空泛动词 + 名词化结构”。把隐藏在名词里的动作恢复成动词，句子会更短、更有力。Purdue OWL 把这种名词化称为 “hidden verbs”。 [owl.purdue](https://owl.purdue.edu/owl/graduate_writing/documents/IWE-2020-Writing-Concisely.pdf)

| 冗余表达 | 直接表达 |
|---|---|
| *make a decision* | *decide* |
| *give consideration to* | *consider* |
| *conduct an investigation* | *investigate* |
| *make an improvement* | *improve* |
| *provide an explanation of* | *explain* |
| *carry out an analysis* | *analyse* |
| *have an effect on* | *affect* |
| *give support to* | *support* |
| *make a comparison between* | *compare* |
| *be of benefit to* | *benefit* |

**例子：**

> *The government should conduct an investigation into the causes of the problem.*

改为：

> *The government should investigate the causes of the problem.*

> *This policy may have a positive effect on public health.*

改为：

> *This policy may improve public health.*

## 压缩固定短语

许多“看似正式”的短语可以换成一个更普通、更自然的词。过多介词短语也是句子臃肿的常见信号。 [owl.purdue](https://owl.purdue.edu/owl/graduate_writing/documents/IWE-2020-Writing-Concisely.pdf)

| 冗余短语 | 更简洁 |
|---|---|
| *due to the fact that* | *because* |
| *in order to* | *to* |
| *at this point in time* | *now* |
| *for the purpose of* | *to* |
| *in the event that* | *if* |
| *in spite of the fact that* | *although / despite* |
| *a large number of* | *many* |
| *the majority of* | *most* |
| *is able to* | *can* |
| *has the ability to* | *can* |
| *in the vicinity of* | *near* |
| *on a daily basis* | *daily / every day* |
| *with regard to* | *about / regarding* |
| *at the present time* | *currently / now* |

**例子：**

> *In order to reduce pollution, governments should make an investment in public transport.*

改为：

> *To reduce pollution, governments should invest in public transport.*

## 删除无力的程度词

*very, really, quite, rather, extremely, definitely, actually, basically* 常常只拉长句子，而没有提供可验证信息。写作指导资源将它们视为常见的 clutter words（杂乱词）。 [umassd](https://www.umassd.edu/media/umassdartmouth/writing-amp-reading-center/docs-and-pdfs/handouts/effectivesentences.pdf)

| 模糊/无力 | 更具体的表达 |
|---|---|
| *very important* | *essential / crucial*，或说明为什么重要 |
| *very big problem* | *a major problem*，或具体化问题 |
| *really expensive* | *costly / unaffordable* |
| *very good* | *effective / beneficial*，或描述效果 |
| *many people* | 若有依据，给范围、比例或具体群体 |
| *things* | *factors, measures, services, problems* 等具体名词 |

- 冗余：*It is very important for governments to take this issue very seriously.*  
- 简洁：*Governments should address this issue.*  
- 更具体：*Governments should address rising housing costs through affordable-housing programmes.*

## 少用空泛主语与被动结构

*There is/are...*、*It is...* 和过多被动语态，容易把真正的行动者和动作藏起来。并非都错，但能改成具体主语时，通常更清楚、更简洁。 [owl.purdue](https://owl.purdue.edu/owl/subject_specific_writing/professional_technical_writing/revision_in_business_writing/revising_for_clarity.html)

| 绕 | 直接 |
|---|---|
| *There are many people who believe that...* | *Many people believe that...* |
| *It is the responsibility of schools to teach...* | *Schools should teach...* |
| *A decision was made by the government to...* | *The government decided to...* |
| *The implementation of the policy was undertaken by...* | *...implemented the policy.* |
| *There is a need for the government to...* | *The government needs to...* |

## 用肯定表达

双重否定或“否定一个正面词”往往更绕。若含义不变，改为肯定句会更直接。

- 冗余：*It is not uncommon for students to feel stressed.*  
- 简洁：*Students often feel stressed.*

- 冗余：*The policy is not without disadvantages.*  
- 简洁：*The policy has disadvantages.*

- 冗余：*Not many people can afford private healthcare.*  
- 简洁：*Few people can afford private healthcare.*

但要注意语气：*not impossible* 不总等于 *possible*，前者往往意味着“可能性很低”。不能机械替换。

## 雅思写作的精简流程

写完后花 3–5 分钟做一遍“减法编辑”：

1. **圈填充开头**：*It is clear that, It should be noted that, Nowadays, With the development of...*；能删就删。  
2. **圈程度副词**：*very, really, quite, actually, basically*；删掉或换成具体事实。  
3. **找两个词说一个意思**：如 *future plans, personal opinion, repeat again*；只留一个。  
4. **找名词化**：*make a decision, conduct an analysis, have an effect*；改成 *decide, analyse, affect*。  
5. **找长短语**：*due to the fact that, in order to*；压缩为 *because, to*。  
6. **检查段落功能**：每段是否提供了一个新论点，而非反复换词说同一件事。

最有效的检验方式是**朗读**：如果一句话读到中间，你还没找到“谁做什么”，就优先缩短介词短语、明确主语、换成直接动词。对每一个句子，都追求“信息完整，但没有多余负担”。
