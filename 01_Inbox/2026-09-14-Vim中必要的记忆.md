`%:h` 确实不好记，但拆开看其实很有规律。下面给你一套**记忆方法 + 常用符号清单**。

## 一、`%:h` 怎么记

拆成两部分：

- **`%`** = 当前文件名（可以想成“百分比符号代表当前”）
- **`:`** = “接下来是修饰符”
- **`h`** = **h**ead（头部），即去掉尾巴、保留前面的目录

一句话：**当前文件的“头”（目录部分）= `%:h`**

再配合记忆其他修饰符：

| 字母 | 英文 | 含义 | 记忆点 |
|------|------|------|--------|
| `h` | **h**ead | 目录 | 头 |
| `t` | **t**ail | 文件名 | 尾 |
| `r` | **r**oot | 去扩展名 | 根/主干 |
| `e` | **e**xtension | 扩展名 | 扩展 |
| `p` | **p**ath（absolute） | 绝对路径 | path |
| `s` | **s**ubstitute | 替换 | substitute |
| `gs` | **g**lobal **s**ubstitute | 全局替换 | 全局替换 |
| `:~` | 相对 home | 相对 home 路径 | `~` |

## 二、核心记忆口诀

> **h 头 t 尾，r 去尾，e 扩展，p 绝对，s 替换**

`:` 后面可以**链式组合**，从左到右依次处理：

```
%:p:h   先变绝对路径，再取目录
%:t:r   先取文件名，再去扩展名
%:h:t   先取目录，再取最后一段目录名
```

## 三、`:h` / `:t` / `:r` / `:e` 一图理解

以 `/home/user/project/main.py` 为例：

```
/home/user/project/main.py
└───────┬────────┘ └─┬─┘└┬┘
     :h (目录)      :t  :e
                   (文件名)(扩展名)
     :r = 去掉扩展名 = /home/user/project/main
     :t:r = 文件名去扩展名 = main
```

| 写法 | 结果 |
|------|------|
| `%` | `/home/user/project/main.py` |
| `%:h` | `/home/user/project` |
| `%:t` | `main.py` |
| `%:r` | `/home/user/project/main` |
| `%:e` | `py` |
| `%:p` | `/home/user/project/main.py` |
| `%:p:h` | `/home/user/project` |
| `%:t:r` | `main` |

## 四、其他必须记住的关键符号

### 1. 命令行里的特殊寄存器/占位符

| 符号 | 含义 | 例子 |
|------|------|------|
| `%` | 当前文件名 | `:w %` 保存到当前文件 |
| `#` | 上一个编辑的文件 | `:e #` 切回上一个文件 |
| `#n` | 第 n 个 buffer | `:b #2` |
| `.` | 当前行号 | `:.,$d` 删除当前行到末尾 |
| `$` | 最后一行 | `:1,$s/a/b/g` |
| `'<` `'>` | 可视模式选区的起止 | `:'<,'>s/a/b/g` |
| `*` | 系统剪贴板 | `"*y` 复制到系统剪贴板 |
| `+` | 系统剪贴板（同 `*`，X11 下略有别） | `"+p` |
| `0` | 最近一次复制的内容 | `"0p` |
| `"` | 无名寄存器 | `""p` |

### 2. 搜索/替换里的正则符号

| 符号 | 含义 |
|------|------|
| `\v` | very magic（正则更接近常见语法） |
| `\zs` `\ze` | 匹配起止位置 |
| `\<` `\>` | 单词边界 |
| `%(` `%)` | 非捕获分组 |
| `\d` `\w` `\s` | 数字 / 单词字符 / 空白 |

### 3. 快捷跳转/范围符号

| 符号 | 含义 |
|------|------|
| `gg` | 文件开头 |
| `G` | 文件末尾 |
| `0` | 行首 |
| `$` | 行尾 |
| `^` | 行首（非空白） |
| `%` | 匹配的括号间跳转（普通模式） |
| `*` `#` | 向下/向上搜索当前单词 |

### 4. 寄存器前缀 `"`

```
"ay    复制到寄存器 a
"ap    从寄存器 a 粘贴
"+y    复制到系统剪贴板
```

### 5. 宏与标记

| 符号 | 含义 |
|------|------|
| `q` | 录制宏 |
| `@` | 播放宏 |
| `@@` | 重复上一次宏 |
| `m` + 字母 | 设置标记，如 `ma` |
| `` ` `` + 字母 | 跳到标记 |
| `''` | 跳回上次位置 |

## 五、记不住时的救命命令

不用死记，随时在 Neovim 里查：

```vim

:help cmdline-special       " 命令行特殊符号
:help registers            " 寄存器
:help marks                " 标记
```

## 六、最值得先记住的几个

按使用频率排序，先掌握这些就够日常用了：

1. `%` — 当前文件名
2. `%:h` — 当前文件目录
3. `%:t` — 当前文件名
4. `%:r` — 去扩展名的路径
5. `%:e` — 扩展名
6. `.` `$` `'<` `'>` — 行号/范围
7. `#` — 上一个文件
8. `"+` `"*` — 系统剪贴板

记忆核心就一句：**`%` 是当前文件，`:` 后接修饰符，`h` 头 `t` 尾 `r` 去尾 `e` 扩展 `p` 绝对。** 多用几次就自然记住了。

## 十、查找/替换技巧

```vim
:%s/foo/bar/g        全文替换 foo → bar
:%s/foo/bar/gc       带确认

:noh                 取消搜索高亮
```

## 十一、怎么记住

1. **先记 `i a o Esc` 和移动 `hjkl w b 0 $ gg G`** —— 这是生存基础
2. **再记编辑 `dd yy p u .`** —— 效率翻倍
3. **然后记文本对象 `ciw di" ci(`** —— 最优雅的部分
4. **最后记窗口/buffer/tab** —— 管理多文件
5. **不会就 `:help`**，比如 `:help i_CTRL-R` 查插入模式的 Ctrl-R
