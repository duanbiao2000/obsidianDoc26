# ⚖️ 全面身心重塑指南 (Evidence-Based Body Recomposition)

本指南基于 **NSCA-CSCS (美国体能协会注册体能训练专家)** 循证运动科学体系构建，专为降低脑力疲劳、纠正久坐损伤及阶梯式改善身体成分设计。

---

## I. 诊断建模 (The Audit)

### 1. 代谢基准
- **BMR (基础代谢率)**: $1,730 \text{ kcal}$
- **TDEE (每日总消耗量)**: $2,380 \text{ kcal}$ (基于轻度活动系数 $1.375$)
- **重塑靶心摄入 (Recomp Target)**: $2,020 \text{ kcal}$ (每日创造 $360 \text{ kcal}$ 的温和热量赤字)

### 2. 风险识别 (久坐损伤链)
- **上交叉综合征 (圓肩/探颈)**: 胸小肌、上斜方肌过度紧张；深层颈屈肌、前锯肌及中下斜方肌无力。
- **下交叉综合征 (骨盆前倾/腰痛)**: 髂腰肌、竖脊肌长期缩短；臀大肌、腹直肌处于被动拉长且“失活”状态，导致腰椎代偿性受压，引发下腰痛。

### 3. 底层策略
- **策略定义**: **身体重塑 (Body Recomposition)** —— 维持/微增肌肉量，同时阶梯式降低体脂率。

---

## II. 训练系统 (Periodization)

### 1. 4-8周微周期 (Microcycle) 强度规划
- **W1-W2 (募集期)**: 动作轨迹学习，神经肌肉募集激活。靶向 RPE 6-7。
- **W3-W5 (渐进超负荷)**: 增加哑铃负重或动作次数。靶向 RPE 7-8。
- **W6-W7 (突破期)**: 最大限度增加机械张力。靶向 RPE 8-9。
- **W8 (超补偿期/Deload)**: 负荷减半，促进神经系统和关节结缔组织恢复。RPE < 5。

### 2. 特异性热身 (久坐解开算法 - 8分钟)
- **胸椎动员 (Foam Roller Thoracic Extension)**: 15次（解除胸椎僵硬）。
- **库克臀桥 (Cook Hip Bridge)**: 每侧10次（阻断骼腰肌代偿，强制激活臀大肌）。
- **猫狗式 (Cat-Cow)**: 10次（重建脊柱分节段控制能力）。

### 4. 预康复 (Prehab) 每日5分钟修正指令
- **死虫式 (Dead Bug)**: 3组 x 12次/侧（稳定腹内压，直接缓解久坐下腰痛）。
- **WTY 伸展**: 3组 x 每字母保持5秒（强化中下斜方肌，将双肩拉回中立位）。

## III. 燃料管理 (Nutrition & Fueling)

### 1. 宏量营养素克数分配 (总能：2,020 kcal)
- **蛋白质**: $156 \text{ g}$ ($624 \text{ kcal}$, 约占 31%) —— 提供肌肉重塑原料及高饱腹感。
- **碳水化合物**: $210 \text{ g}$ ($840 \text{ kcal}$, 约占 41%) —— 维持高认知工作所需的脑糖原。
- **脂肪**: $62 \text{ g}$ ($558 \text{ kcal}$, 约占 28%) —— 维持内分泌系统与关节健康。

```

```

### 2. 行为策略
- **环境隔离**: 
  - **物理屏蔽**: 视觉范围内（书桌、伸手可及处）严禁存放任何热量密度高于 100kcal/100g 的食物。
  - **低摩擦餐备**: 提前煮好3天份的鸡胸肉/瘦牛肉，高纤维蔬菜（西兰花、生菜）洗净分盒冷藏，确保微波炉加温3分钟内即可获取安全餐。
- **补剂方案**:
  - **一水肌酸 (Creatine Monohydrate)**: 每日 5g（固定时间服用，提升神经元 ATP 代谢，减少脑雾，增强力量）。
  - **维生素 D3**: 每日 5,000 IU（随早餐，弥补居家日照不足，优化血钙平衡及睾酮分泌）。
  - **分离乳清蛋白粉 (Whey)**: 30g（训练后 30 分钟内或下午 3 点低血糖期作为无糖屏障加餐）。

## IV. 办公环境黑客 (Ergonomics)

### 1. 坐姿算法 (90-90-90 检查清单)
- **足底**: 100% 平贴地面，足踝呈 90° 角。
- **膝关节**: 屈膝呈 90° 角，大腿与地面平行。
- **髋骨**: 臀部坐满椅面，躯干与大腿呈 90°-100° 夹角，腰部有靠垫支撑。
- **屏幕视线**: 屏幕上缘与眼睛等高或略低 5 度，拒绝低头。

```
       [屏幕]  <- 视线水平
         ||
    O--  ||    <- 颈部直立
   / \   ||
  /   \________
 O     [ 90°]  <- 肘关节 90°
 |     |
 |     |_______
/ \    [ 90°]  <- 膝关节 90°
| |    |
```

### 2. 代谢零食 (Exercise Snacking) - 每 90 分钟触发
- **120秒代谢激活**: 设定定时器，每专注工作 90 分钟，离开椅子执行：
  - 无负重深蹲 20 次 + 无负重俯卧撑 10 次（或扶墙俯卧撑）。
  - 目的：重新泵血，运送氧气和葡萄糖至大脑，阻断胰岛素敏感度下降。

## V. 迭代追踪 (Feedback Loop)

### 1. 多维 KPI 监控矩阵
- **主观精力 (脑雾指数)**: 记录每日下午 3 点的主观专注力评分（1-10分）。
- **身体围度**: 每周一清晨空腹测定“腰围”（定位脂肪流失）与“大腿围/胸围”（定位肌肉留存）。
- **体能基准**: 记录训练计划中“动作负荷”的 RPE。若相同重量下 RPE 连续两周下降，则代表心肺/神经系统获得实质性重塑。
