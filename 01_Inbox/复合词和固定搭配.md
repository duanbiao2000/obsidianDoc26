英语里的 **compound（复合词/固定搭配）** 范围很大，除了前面说的重叠词和成对词，还有好几类高频又好玩的。下面按构词方式分类整理。 另见: [[2026-09-14-口语构词]]

## 五、不可逆成对词（Irreversible Binomials）

顺序固定，不能随便换。前面提过，这里给更多：

| 例子 | 含义 |
|------|------|
| `fish and chips` | 炸鱼薯条 |
| `salt and pepper` | 盐和胡椒 |
| `bread and butter` | 生计 |
| `black and white` | 黑白分明 |
| `up and down` | 上上下下 |
| `back and forth` | 来来回回 |
| `now and then` | 偶尔 |
| `sick and tired` | 厌烦 |
| `short and sweet` | 简短扼要 |
| `law and order` | 法律与秩序 |
| `peace and quiet` | 安宁 |
| `time and again` | 一次又一次 |
| `more or less` | 或多或少 |
| `sooner or later` | 迟早 |
| `give or take` | 大约 |

**顺序规律**：
- 元音顺序：`i → a → o`，如 `fish and chips`
- 短词在前：`salt and pepper`
- 语义顺序：`law and order`、`up and down`

## 九、记忆与使用建议

1. **写法不确定就查词典**：`notebook` 连写、`ice cream` 分写、`mother-in-law` 连字符，没有绝对规律，靠习惯。
2. **复合形容词作定语时加连字符**：
   - `a well-known writer` ✔
   - `the writer is well known` ✔（作表语不加）
3. **短语动词是口语核心**：`get up`、`put on`、`turn off` 这些必须熟练掌握。
4. **成对词顺序别乱**：`fish and chips` 说反了母语者会觉得别扭。
