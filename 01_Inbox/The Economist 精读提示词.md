对你来说，最好用的不是一句“请精读这篇《The Economist》”，而是把 AI 分成几个角色：理解诊断者、难句解释者、论证分析者、表达教练、写作反馈者。

建议采用 **先练后评**：先留下自己的理解或初稿，再让 AI 定位问题；只有真正卡住时，才直接请求讲解。下面给你一套可复制的提示词，默认中文解释、英文练习，并适合你后续整理到 Obsidian 和 Anki。

## 1. 总控提示词：作为长期精读对话的开场

这是最值得保存的一条。它控制整个对话的目标、证据边界和输出长度，后面再配合专项提示词。

```text
你是我的 The Economist 英语阅读与写作教练。

目标：
帮助我独立理解文章、识别论证结构，并将可复用的表达
迁移到我自己的写作中。不要把训练变成全文翻译或生词堆积。

默认规则：
1. 中文解释，保留关键英文；练习题和写作任务用英文。
2. 以我提供的原文为依据。区分：
   - 原文明确陈述
   - 根据原文作出的推断
   - 理解所需的外部背景
3. 分析作者意图、修辞或隐含前提时，引用具体措辞作为依据；
   不能确定时说明不确定，不要把猜测写成事实。
4. 不杜撰上下文、作者观点、数据或词源。
5. 如果只有文章片段，不要据此声称已经掌握全文主旨。
6. 未经我要求，不逐句翻译全文，不列出所有生词。
7. 我提供摘要或译文时，先诊断我的理解，再进行讲解。
8. 语言建议要区分：
   必须纠正的错误、影响自然度的问题、可选的风格调整。
9. 控制解释范围，只补充解决当前问题所必需的背景。
10. 如果需要外部核验且你能联网，请引用来源；
    不能联网时，明确标注尚未核验。

第一次收到文章后：
- 如果我没有提供自己的理解，先提出 3–4 个理解问题，
  不提前泄露答案，等我回答。
- 如果我已经提供理解，直接开始诊断。
- 如果我明确说“直接讲解”，跳过问答，按我的要求分析。

每次训练结束，只保留：
- 一个重要理解修正
- 最多三个可复用表达
- 一个短小的英文输出任务
```

不要要求每次都输出“翻译、句法、词汇、修辞、背景、论证、练习”全套。总控提示词的作用是建立规则，而不是让每次回答变成报告。

## 2. 阅读理解诊断：检查“我是不是真的读懂了”

适合首遍阅读之后使用。比先看 AI 总结更能暴露自己的误解。

```text
下面是 The Economist 原文片段，以及我的理解。

请先检查我的理解，不要直接给出完整译文。

按以下格式反馈：
1. 我理解正确的部分：简短说明。
2. 最关键的偏差：最多三个，按重要性排序。
3. 对每个偏差：
   - 引用对应原文
   - 说明我遗漏或误读了什么
   - 判断问题属于词义、句法、指代、逻辑还是背景
4. 特别检查我是否：
   - 把可能性写成确定性
   - 把相关关系写成因果关系
   - 忽略否定、让步或条件限制
   - 混淆作者观点与其引用的他人观点
5. 最后给我一道英文复述题，等我重新回答。

原文：
[粘贴原文]

我的理解：
[粘贴自己的中文解释或英文摘要]
```

使用重点：即使你的理解只有三句话，也先交出来。不要等写得“足够好”才让 AI 看。

## 3. 难句解剖：解决长句、指代与逻辑关系

适合你之前问过的那种经济、政策类密集段落。它要求 AI 先解释结构，再解释内容，避免“译文看懂了，但原句仍不会读”。

```text
请帮助我读懂下面这句话。先处理句法，再处理含义。

步骤：
1. 原样列出句子。
2. 找出主句的主语、谓语和主要补语/宾语。
3. 用方括号标记从句、插入语、并列部分和修饰范围。
   标记时保留原词，不要改写原句。
4. 解释代词、指示词和省略成分指向什么；
   如果缺少上下文，说明有哪些合理可能。
5. 解释否定、比较、条件、让步、情态动词及标点
   如何影响句子的逻辑或语气。
6. 给出：
   - 结构更简单但意义不变的英文改写
   - 保留程度和限定条件的自然中文翻译
7. 只讲解两个最关键的语言点。
8. 给出一个同结构、不同主题的英文例句，
   并明确标注“自拟例句”。

如果原句存在歧义，不要强行给出唯一解释。

句子：
[粘贴难句]

必要上下文：
[前后各一句，可选]
```

如果你已经有译文，可以追加：

```text
这是我的译文：[译文]
请先指出最影响准确性的地方，再执行上面的分析。
```

## 4. 论证地图：学习文章怎么“推进观点”

适合读完一篇文章后使用，也适合为写作积累结构。

```text
请分析这篇文章的论证结构，不要逐段翻译，
也不要只把每段内容缩短后重新列一遍。

请输出：
1. 核心问题：文章试图回答什么？
2. 核心主张：一句话说明，并保留重要限定条件。
3. 段落功能表：
   段落编号 | 论证功能 | 核心内容 | 与前后段的关系
4. 关键推理链：
   证据 → 中间推断 → 结论
5. 最多两个重要的隐含前提。
   标注它是原文明确表达，还是你的分析性重构。
6. 作者处理了哪些反对意见？
   哪些限制是作者自己承认的？
7. 如果提出你的批评，单独放在“分析者的质疑”中，
   不要冒充作者观点。
8. 把文章结构抽象成一个可迁移的写作骨架，
   不保留原文具体内容。
9. 给我一个不同主题，让我用同一骨架写一个短段落。

所有重要判断都要指出原文依据。
如果材料不完整，只分析当前片段。

文章：
[粘贴文章]
```

这里最有价值的输出不是“文章有五段”，而是例如：

> 问题 → 常见解释 → 反证 → 替代解释 → 有条件的结论。

这是你能带到自己写作里的东西。

## 5. 语块提取与迁移：避免把精读变成词汇收藏

适合你已有的 Anki 工作流。限制数量，要求每个表达都有实际用途。

```text
请从下面的原文中挑选最多三个值得我主动使用的表达。

筛选标准：
- 能用于多个主题，不只是本文专有名词。
- 能完成明确的表达动作，例如让步、比较、限定、
  因果解释、评价或反驳。
- 优先选择搭配和结构，不优先选择罕见单词。
- 如果没有三个真正值得选的表达，可以少选。

每个表达请提供：
1. 原文中的准确片段。
2. 在当前语境中的意思。
3. 它完成的表达动作。
4. 可替换的结构框架，以及语法、语义或语域限制。
5. 一个容易出现的误用。
6. 一个技术、AI、开源软件或个人学习主题的自拟例句。
7. 一道输出练习：
   给出情境或中文意思，让我自己写英文；
   先不要展示参考答案。

不要把你改写的句子标成原文。
不要在没有检索证据时声称某个表达“非常高频”。

原文：
[粘贴段落]
```

等你答完，再追加：

```text
请检查我的答案是否表达准确、搭配合理。
允许不同的正确表达，不要求我逐字复现参考句。

只把我值得复习的表达整理成 Anki 卡：
正面是表达任务，背面是参考表达、使用限制和我的修订例句。
```

## 6. 写作反馈：让 AI 帮你修改，而不是替你写

这是从阅读转到写作最重要的一条。

```text
下面是原文和我写的英文文本。

任务类型：
[忠实摘要 / 个人短评，选择一个]

请先反馈，不要直接重写全文。

按优先级检查：
1. 内容：
   如果是摘要，是否忠实保留原文观点、条件和程度？
   如果是短评，是否清楚区分作者观点与我的观点？
2. 结构：
   核心主张是否明确？证据与结论是否衔接？
3. 语言：
   是否存在影响意思的词义、搭配或语法问题？
4. 风格：
   是否有冗余、含混或不必要的复杂表达？

最多选择三个最值得修改的问题。
每个问题给出：
- 我的原句
- 问题类型
- 为什么值得修改
- 一个帮助我自行修改的提示

将“错误”与“个人风格偏好”分开。
保留我的意思和语气，不添加我没有提出的论据。

最后等我提交第二稿，不提前给完整范文。

原文：
[粘贴原文]

我的初稿：
[粘贴初稿]
```

第二稿之后再使用：

```text
请比较初稿和第二稿：
1. 哪两个修改真正改善了表达？
2. 还剩哪个最重要的问题？
3. 给出最小修改版，并标明修改位置。
4. 提炼一条我下次能执行的写作规则。

不要为了显得高级而替换所有简单词。
```

## 七、怎样组合，才不会越练越重？

你可以把提示词保存为六条，但每次只调用两三条。

| 当天目标 | 使用顺序 |
|---|---|
| 快速阅读与理解 | 自己读 → 提示词 2 → 英文复述 |
| 解决一个难段 | 提示词 3 → 提示词 5 |
| 阅读带动写作 | 自己读 → 提示词 4 → 自己写 → 提示词 6 |
| 忙碌日最低训练 | 读一段 → 自己写三句摘要 → 提示词 2 |

每次给 AI 的请求，最好都附上这三个字段：

```text
今天目标：[理解 / 难句 / 论证 / 表达 / 写作]
我的尝试：[自己的理解、译文或初稿]
本次边界：[例如：只处理两个问题，10分钟内完成]
```

你最需要长期保留的不是某一条“万能提示词”，而是这个顺序：原文 → 自己尝试 → AI 诊断 → 自己修订。这样每次精读都能留下你的能力变化，而不只是留下 AI 的讲解。
