问题不在一级目录，而在于你当前的“二级目录”混合了**材料类型、训练动作、内容项目、个人品牌和工具名称**。例如 `Shadowing` 是方法，`有声读书` 是材料形态，`SHERO` 是项目/IP，`V0` 是工具或构建方式——它们不能用同一种命名逻辑并列。

解决方法是：让二级目录承担**稳定的能力领域或媒介类型**；而 `SHERO`、`Me and Mine`、`V0` 等具体名称下沉为三级的**系列 / 项目 / 工具实例**。

```
一级：内容处于哪个阶段？
二级：它服务于哪种能力、媒介或工作类型？
三级：具体是哪个系列、项目、素材或工具？
```

```
Input
├── Story & Voice
```

### 命名逻辑

这里避免使用单个、抽象但边界不清的词，例如 `Vision` 或 `Observe` 直接作为二级目录。它们可以保留为三级项目名，但二级层应该说明其收纳原则。

因此：

```
Input | Vision
```

改为：

```
Input
└── Image & Form
    └── Vision
```

而：

```
Input | Observe
```

改为：

```
Input
└── World & Observation
    └── Observe
```

这样以后你遇到一段电影分析、一幅画、一个日常现象或某个创作者的工作流程，不需要重新发明合集，只需要放进已有的“输入媒介”中。

## Internalize：按“如何练成能力”组织

```
Internalize
├── Voice & Fluency
├── Repetition & Familiarity
└── Memory & Retrieval
```

|二级目录|核心目标|当前内容|对应动作|
|---|---|---|---|
|`Voice & Fluency`|让英语的声音、节奏和表达变得自然|Shadowing|听辨、模仿、跟读、录音、复述|
|`Repetition & Familiarity`|以低压力重复建立熟悉感|零摩擦冷静复读|重听、重看、轻声复述、背景回放|
|`Memory & Retrieval`|让知识和表达可以被长期提取|AnkiStudy Log|制卡、复习、回忆、输出检验|

### 三者的关系

这三个目录并不是三个独立的学习系统，而是同一个内化过程中的三个层面：

```
先熟悉
→ 再模仿
→ 最后提取
```

也可以按另一个顺序使用：

```
零摩擦冷静复读
→ Shadowing
→ AnkiStudy Log
```

- `Repetition & Familiarity`：解决“我不想开始、材料还不熟”的问题。
- `Voice & Fluency`：解决“我听得懂但说不出来、不自然”的问题。
- `Memory & Retrieval`：解决“我学过但过几天忘了、需要时想不起来”的问题。

这比把三个方法仅仅并列为三个合集更有 coherence：它们分别对应**熟悉、流利、保持**。

建议使用下面四个二级目录：

```
Output & System
├── Voice & Identity

└── Tools & Leverage
```

- `10xfaster` 和 `V0` 都服务于“以更高杠杆构建东西”，一个偏工作流，一个偏产品原型与实现。

## 统一命名规范

建议让各层级严格承担不同职责。

|层级|命名风格|示例|
|---|---|---|
|一级目录|工作流阶段|`Input`、`Internalize`、`Output & System`|
|二级目录|稳定的能力、媒介或工作领域|`Story & Voice`、`Memory & Retrieval`、`Tools & Leverage`|
|三级目录|具体系列、项目、方法或品牌名称|`有声读书`、`Shadowing`、`SHERO`、`V0`|

以后新建项目时，不应先问“我该不该建一个新合集”，而应依序问：

1. 它是**输入**、**内化**，还是**输出/系统**？
2. 它属于哪个已有能力或媒介领域？
3. 它是否值得成为一个有明确产出、可持续推进的具体项目？

例如，你将来要加入一个“古典绘画与神话”系列：

```
Input
└── Image & Form
    └── 古典绘画与神话
```

如果你进一步把它做成脚本、视频或概念卡，它才进入：

```
Output & System
└── Ideas & Frameworks
    └── 古典绘画与神话
```

同一主题可以跨越多个一级目录，但在每一层承担的任务不同：**Input 是接触它，Internalize 是练会它，Output & System 是用它创造东西。**
