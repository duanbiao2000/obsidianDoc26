- A. **正面：** 什么是 Active Recall？ **背面：** 主动召回。

- D. **正面：** Claude Code 生成卡片时，用于包裹正反面的最安全分隔符是什么？ **背面：** `|` (管道符，避免逗号或制表符在 CSV 导入时解析错乱)。

#### 📌 Q3：主动召回（Active Recall）与生成式学习的本质
根据认知心理学与行为科学，以下哪一种在使用 Anki 卡片时的行为，**最能**产生强固的神经突触连接，从而实现真正的“长期记忆”？
- A. **被动确认：** 看到卡片正面，脑子里大概有个模糊的概念，马上点击“显示答案”，然后自我安慰说“啊，对，我就是这么想的”。
- B. **视觉熟练度：** 因为这张卡片已经看过了 5 遍，仅凭正面排版和第一个单词就条件反射般地背出了答案，而没有真正思考其背后的逻辑。
- C. **物理输出/大声说出：** 在点击“显示答案”之前，强制自己在草稿纸上写下关键词，或者用嘴巴清晰地用英文/中文复述出完整答案。
- D. **快速刷卡：** 追求速度，在 10 分钟内快速刷完 100 张卡片，保持极高的点击频率。

> [!success]- 点击查看答案与解析
> **正确答案：C**
> 
> **解析：** 
> 认知科学表明，“感到费力”的提取（Desirable Difficulty，合意困难）才是记忆编码的黄金期。A 和 B 都是“流利度错觉（Illusion of Competence）”。只有当你强制进行**物理输出**（写下来、说出来、打出来）时，大脑才在真正进行“主动召回”。

#### 📌 Q4：如何避免 Anki 闪卡中的“上下文脱钩（Context Decay）”
你用 Claude Code 自动提取了一张英语高分表达卡片。但在复习时，你发现自己“在 Anki 里一看到提示就能答对，但一到雅思口语考场上就完全想不起来用”。这属于典型的“孤岛记忆”。为了解决这个问题，在利用 AI 生成卡片时，**最应该添加**什么元素？
- A. 在卡片背面增加 5 个同义词，方便替换。
- B. 在卡片背面（或正面提示中）引入 **"Micro-Context"（微场景锚定）**，例如：`[场景：当你被考官问到如何缓解压力时]`。
- C. 增加卡片的重复频率，把间隔时间缩短。
- D. 使用更炫酷的 CSS 样式给关键词加粗标红。

> [!success]- 点击查看答案与解析
> **正确答案：B**
> 
> **解析：** 
> 记忆具有“场景依赖性”。如果你只背孤立的词汇，大脑在现实场景中由于缺乏“线索（Cue）”而无法检索该记忆。通过在卡片正面或背面注入**微场景锚定（Micro-Context）**，相当于给大脑装上了一个触发器。当考场上遇到类似场景时，该表达就会被自动激活。

在“Claude Code + Obsidian + Anki”的闭环学习系统中，为了保证知识库的纯净度与记忆的“高 ROI（投资回报率）”，以下哪一个环节**绝对不能**完全托管给 AI，必须由你本人（人类）亲自把关和决策？

- B. 为 Anki 卡片编写用于排版的美化 CSS 样式代码。
- C. 筛选“哪些知识值得背诵”，以及在复习阶段根据自身痛点对卡片内容进行“个性化语义微调”。
- D. 将 `.csv` 格式的文本文件批量导入到 Anki 具体的 Card Deck 中。

> [!success]- 点击查看答案与解析
> **正确答案：C**
> 
> **解析：**
