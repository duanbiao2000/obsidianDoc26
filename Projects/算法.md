### 1. Matrix Traversal（矩阵遍历）—— 螺旋 / 路径 + 方向示例

**核心思想**：在二维矩阵（grid）中按照特定顺序或规则访问所有元素，常用于螺旋遍历、DFS/BFS 路径搜索、岛屿问题等。

**常见类型**：

- **螺旋遍历（Spiral Order）**：从左上角开始，按顺时针（或逆时针）螺旋向内遍历。
- **多方向路径遍历**：使用方向数组控制上下左右移动。

**方向数组技巧**（最常用）：

```python
directions = [(-1, 0), (0, 1), (1, 0), (0, -1)]  # 上、右、下、左
```

**经典例题**：

- LeetCode 54. Spiral Matrix（螺旋矩阵）
- LeetCode 59. Spiral Matrix II（生成螺旋矩阵）
- LeetCode 212. Word Search II（单词搜索）
- 岛屿数量、太平洋大西洋水流等问题

**螺旋遍历代码模板**（Python）：

```python
def spiralOrder(matrix):
    if not matrix or not matrix[0]:
        return []
    
    result = []
    top, bottom = 0, len(matrix) - 1
    left, right = 0, len(matrix[0]) - 1
    
    while top <= bottom and left <= right:
        # 从左到右
        for col in range(left, right + 1):
            result.append(matrix[top][col])
        top += 1
        
        # 从上到下
        for row in range(top, bottom + 1):
            result.append(matrix[row][right])
        right -= 1
        
        # 从右到左（需要判断是否还有行）
        if top <= bottom:
            for col in range(right, left - 1, -1):
                result.append(matrix[bottom][col])
            bottom -= 1
        
        # 从下到上（需要判断是否还有列）
        if left <= right:
            for row in range(bottom, top - 1, -1):
                result.append(matrix[row][left])
            left += 1
    
    return result
```

**技巧要点**：

- 使用四个边界 `top, bottom, left, right` 收缩范围
- 每次遍历完一条边后收缩边界
- 注意判断条件避免重复访问

### 2. Backtracking（回溯）—— 决策树 + 选择

**核心思想**：通过**试错 + 撤销**的方式枚举所有可能的解，常用于“找所有解”或“找最优解”的问题。

**本质**：在**决策树**的每一层做出一个选择，进入下一层；如果不满足条件就**回退**（撤销选择），尝试其他分支。

**决策树示意**（以组合问题为例）：

```
          []
       /   |   \
     [1]  [2]  [3]
     / \    |
  [1,2] [1,3] [2,3]
```

**回溯三要素**：

1. **选择**（for 循环枚举当前层的选项）
2. **约束**（剪枝条件）
3. **撤销**（backtrack 后恢复状态）

**经典例题**：

- LeetCode 46. Permutations（全排列）
- LeetCode 78. Subsets（子集）
- LeetCode 39/40. Combination Sum（组合总和）
- N-Queens（N 皇后）
- Sudoku Solver（数独）

**通用回溯模板**：

```python
def backtracking(选择列表, 路径, 结果):
    if 满足结束条件:
        result.append(路径.copy())   # 记录答案
        return
    
    for 选择 in 选择列表:           # 遍历当前层所有选择
        if 剪枝条件: continue
        
        做选择（路径.append(选择)）
        backtracking(...)            # 递归进入下一层
        撤销选择（路径.pop()）        # 回溯
```

**示例：子集问题**

```python
def subsets(nums):
    result = []
    def dfs(start, path):
        result.append(path[:])          # 每个节点都是一个解
        for i in range(start, len(nums)):
            path.append(nums[i])
            dfs(i + 1, path)
            path.pop()                  # 回溯
    dfs(0, [])
    return result
```

**关键技巧**：用 `start` 索引避免重复使用同一元素（组合 vs 排列）。

### 3. DP Patterns（动态规划模式）—— 经典 DP 表格（0/1 背包为例）

**核心思想**：把大问题分解成重叠子问题，通过**表格（dp数组）**自底向上存储子问题的最优解，避免重复计算。

**两大特征**：

- 重叠子问题
- 最优子结构

**常见 DP 模式**：

- 0/1 背包
- 完全背包
- 最长递增子序列（LIS）
- 区间 DP
- 状态压缩 DP
- 树形 DP 等

**经典 0/1 背包 DP 表格**：

假设有 `n` 个物品，背包容量 `W`，物品重量 `w[i]`，价值 `v[i]`。

**DP 定义**：
`dp[i][w]` = 前 `i` 个物品，背包容量为 `w` 时的最大价值。

**状态转移**：

```python
dp[i][w] = max( dp[i-1][w],                    # 不选第i个物品
                dp[i-1][w - w[i]] + v[i] )     # 选第i个物品（容量足够）
```

**优化空间**（一维 DP）：

```python
def knapsack(W, w, v):
    n = len(w)
    dp = [0] * (W + 1)
    
    for i in range(n):
        for capacity in range(W, w[i]-1, -1):   # 逆序遍历
            dp[capacity] = max(dp[capacity], 
                             dp[capacity - w[i]] + v[i])
    return dp[W]
```

**其他常见 DP 表格模式**：

- **字符串 DP**：`dp[i][j]` 表示 s[0..i] 和 t[0..j] 的最长公共子序列等
- **股票问题**：`dp[i][k][0/1]`（第i天，交易k次，手上是否有股票）
- **打家劫舍**：`dp[i]` = 到第i家能偷到的最大金额
