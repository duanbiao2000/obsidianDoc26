# 话题：地点与空间（Places & Spaces）

## 话题定位

**两类考试都高频**。Part 1 常问喜欢的地点、常去的地方；Part 2 经典话题卡
"Describe a place you would like to visit / a city you know / a room you like / a quiet place"；
Part 3 讨论旅行、城市发展、公共空间等。

## 考频

★★★★☆

## 核心策略

- **地点素材"五感细节"**：位置、外观、氛围、活动、感受，
  五个维度各给一点，回答自然丰满，不会讲不满。
- **"想去的地方"讲动机**：为什么想去（文化、自然、历史），
  动机 + 期待，比单纯描述更有深度。
- **公共空间类问题用"个人 → 社会"**：从个人体验扩展到社会意义，
  体现论证层次。

## 练习顺序

1. 背 `01-核心词汇与搭配.md`；
2. `02-part1-问题与思路.md` 录音；
3. `03-part2-话题卡素材.md` 准备地点话题卡，限时 2 分钟；
4. `04-part3-论证语料.md` 练城市与公共空间类论证。
