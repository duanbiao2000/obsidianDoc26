# 话题：经历与故事（Experiences & Stories）

## 话题定位

**两类考试都高频**。Part 2 题库中最庞大的一类：Describe a trip / an event /
something you did for the first time / an important decision / a challenge。
Part 1 常问难忘的经历、做过的有趣的事；Part 3 讨论经历的意义、成长等。

## 考频

★★★★★

## 核心策略

- **准备 3–5 个"万能故事"**：一次旅行、一次克服困难、一次帮助他人、一次新体验，
  覆盖绝大多数经历类话题卡（与第 10 课"一材多用"直接对应）。
- **故事四要素**：时间 / 地点 / 事件 / 感受，缺一不可，细节决定长度与分数。
- **意义升华收尾**：每段故事结尾用一句"这教会了我/让我明白…"，
  提升回答深度，契合 7.5 要求。

## 练习顺序

1. 背 `01-核心词汇与搭配.md`；
2. `02-part1-问题与思路.md` 录音；
3. `03-part2-话题卡素材.md` 准备 2 个故事提纲，各限时讲 2 分钟；
4. `04-part3-论证语料.md` 练经历意义类论证。

## 与课程对应

- 第 4 课话题卡结构、第 10 课一材多用（本话题是核心训练场）、第 5 课论证框架。
