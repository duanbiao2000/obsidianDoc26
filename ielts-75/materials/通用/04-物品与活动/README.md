# 话题：物品与活动（Objects & Activities）

## 话题定位

**两类考试都高频**。Part 1 常问礼物、常用的物品、喜欢的活动；Part 2 经典话题卡
"Describe a gift you received / an object you use often / a hobby / an activity you enjoy"；
Part 3 讨论消费、礼物的意义、活动的价值等。

## 考频

★★★★☆

## 核心策略

- **物品素材讲"故事"**：一个物品的价值不在物品本身，而在背后的人与回忆，
  讲故事是得分关键。
- **活动话题讲"意义"**：喜欢什么活动 → 为什么 → 带来什么，
  避免只说"好玩"。
- **消费类问题用"理性态度"**：物尽其用、适度消费，
  折中表态体现成熟度。

## 练习顺序

1. 背 `01-核心词汇与搭配.md`；
2. `02-part1-问题与思路.md` 录音；
3. `03-part2-话题卡素材.md` 准备物品/活动话题卡，限时 2 分钟；
4. `04-part3-论证语料.md` 练礼物、消费类论证。
