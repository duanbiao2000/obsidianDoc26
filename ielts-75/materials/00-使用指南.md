# 雅思口语话题素材库 · 使用指南

> 配套：`ielts-75/` 教学工作区（11 课方法论 + 本素材库）
> 规划：见 `ielts-75/materials-plan.md`

## 一、素材库是什么

- **11 课教你"怎么练"，素材库给你"练什么"**：每课学到的方法，在这里找到对应话题进行实战。
- 共 **16 个话题文件夹**，按三大类组织：
  - **留学**：学业与专业、校园生活与教师、住宿与家乡、兴趣与休闲、出行与旅行、科技与数字生活
  - **移民工作**：工作与职业、职场与同事、移民动机与新生活、社会融入与社区、健康与生活方式、环境与社会议题
  - **通用**（两类考试都考）：人物与关系、经历与故事、地点与空间、物品与活动

## 二、每个话题文件夹的 5 个文件

| 文件 | 内容 | 建议用法 |
| --- | --- | --- |
| `README.md` | 话题定位、考频、核心策略 | 先读，定策略 |
| `01-核心词汇与搭配.md` | 核心词 + 搭配 + 转述，对齐 Anki | 背词，转 Anki 卡片 |
| `02-part1-问题与思路.md` | 高频问题 + A-R-E 示范 | 录音练习 Part 1 |
| `03-part2-话题卡素材.md` | 话题卡 + 素材骨架 + 一材多用 | 写提纲，限时 2 分钟 |
| `04-part3-论证语料.md` | 抽象问题 + 论证框架 + 语料句 | 练论证，录音 5–8 句 |

## 三、三种典型用法

### 用法 A：跟课推进（学方法时）
- 学完第 3 课（Part 1）→ 用各话题的 `02-part1` 文件练 A-R-E；
- 学完第 4、10 课（Part 2）→ 用 `03-part2` 文件练话题卡；
- 学完第 5 课（Part 3）→ 用 `04-part3` 文件练论证。

### 用法 B：话题专项突破（连续刷题期）
1. 选一个话题文件夹，按 README 定策略；
2. 依次过：词汇 → Part 1 → Part 2 → Part 3；
3. 每项都录音，回听检查（是否 3–4 句、有 A-R-E、有论证框架）；
4. 一个文件夹吃透，再下一个；卡点记入 `ielts-75/learning-records/`。

### 用法 C：冲刺期（模考期）
- 只回看：错因对应的词汇语料 + 之前录音暴露的薄弱话题；
- 不再扩展新内容，重点做"一材多用"的临场改编练习。

## 四、与 Anki 的配合

- `01-核心词汇与搭配.md` 中的词与搭配，每词一张卡片：
  - 正面：中文释义；
  - 背面：英文 + 搭配 + 例句。
- 每日固定复习时间，配合间隔重复；
- 同义替换（尤其科技、教育类话题）优先入卡，因为听力也会考。

## 五、与 11 课的对应关系

| 课程 | 对应的素材用法 |
| --- | --- |
| 第 1 课 诊断 | 用话题文件夹的 Part 1 文件测试自己，记录卡点 |
| 第 2 课 连读弱读 | 朗读素材中的示范回答，体会节奏 |
| 第 3 课 Part 1 | 用 `02-part1` 文件练 A-R-E |
| 第 4 课 Part 2 | 用 `03-part2` 文件练话题卡结构 |
| 第 5 课 Part 3 | 用 `04-part3` 文件练论证框架 |
| 第 6–8 课 听力 | 词汇文件与听力考点词汇互通（同义替换） |
| 第 9 课 发音 | 跟读各话题的示范回答 |
| 第 10 课 一材多用 | 用 `03-part2` 中的"一材多用"示范练改编 |
| 第 11 课 模考 | 抽取话题文件夹做完整口语模拟 |

## 六、使用纪律（重要）

1. **方法优先于素材**：先按 11 课的方法练，素材只是练习对象，
   不要跳过方法论直接背素材。
2. **输出优先于输入**：每个话题必须录音，只读不练等于没学。
3. **不贪多**：一个话题吃透再下一个，16 个话题全部过一遍
   远胜每个话题只碰一次。
4. **记录反馈**：每次练习的卡点写进 learning-records，
   冲刺期按记录复习，这是 teach 体系判定 ZPD 的依据。
