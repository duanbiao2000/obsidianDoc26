# 话题：校园生活与教师（Campus Life & Teachers）

## 话题定位

留学类高频话题。Part 1 常问学校生活、同学、老师；Part 2 常考
"Describe a teacher you liked / a memorable class / your school days"；
Part 3 讨论师生关系、教育方式、校园生活利弊等。

## 考频

★★★★☆

## 核心策略

- **写"细节"不写"概念"**：描述老师，要说出他做了什么、说了什么、对你产生了什么具体影响，
  而不是"he was very kind"空泛评价。
- **用具体场景支撑**：一次课堂活动、一次课后帮助、一句让你印象深的话——
  这些细节让回答有长度、有画面感，同时自然带出语法多样性。
- **对比与感受收尾**：结尾用一句感受（It taught me … / I'll always remember …），
  既完整又体现连贯性。

## 练习顺序

1. 背 `01-核心词汇与搭配.md`；
2. `02-part1-问题与思路.md` 录音练习 A-R-E；
3. `03-part2-话题卡素材.md` 做提纲 + 限时 2 分钟讲述；
4. `04-part3-论证语料.md` 练师生关系、教育方式的论证。
