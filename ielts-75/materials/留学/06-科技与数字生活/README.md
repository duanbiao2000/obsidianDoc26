# 话题：科技与数字生活（Technology & Digital Life）

## 话题定位

Part 1/3 的高频抽象话题（手机、网络、社交媒体、AI 等）；Part 2 常考
"Describe a time you used technology / a device you use / an app you like"。
科技类问题抽象度高，是 Part 3 论证的"重灾区"，需要观点+展开的完整框架。

## 考频

★★★★☆（Part 3 极高频）

## 核心策略

- **观点先行，避免只描述**：科技类问题容易答成"描述现象"，要主动表态
  （利大于弊/弊大于利/因使用方式而异），再展开。
- **用"双刃剑"结构**：科技话题天然适合"好处 + 弊端 + 折中"的论证，
  这是 7.5 论证质量的典型结构。
- **保持平衡态度**：不极端赞美也不全盘否定，用"取决于如何使用"收尾，
  体现思维的成熟度。

## 练习顺序

1. 背 `01-核心词汇与搭配.md`；
2. `02-part1-问题与思路.md` 录音（重点：手机、网络使用）；
3. `03-part2-话题卡素材.md` 准备一个"科技相关经历"话题卡；
4. `04-part3-论证语料.md` 重点练双刃剑论证。
