# 学业与专业 · Part 2 话题卡素材

> 核心素材：一个"让你有收获的课程/项目"，可套多个话题卡（一材多用）。
> 结构：开场点题 → 主体 2–3 个内容点（主题句+细节）→ 收尾感受。

## 素材骨架（核心故事）

**主题**：大学里一门让你收获最大的课程（如一个小组项目/实践课）

- **背景**：什么课、什么时候、谁一起做的
- **过程**：遇到什么困难、怎么解决的
- **收获**：学会了什么技能、对你有什么影响

## 话题卡 1：Describe a course you enjoyed

**提纲（1 分钟准备用，只写关键词）**

- 开场：the data visualisation course I took last semester
- 点 1：why enjoyed — hands-on / teamwork
- 点 2：a specific project — built a dashboard for campus traffic
- 收尾：taught me practical skills + confidence

**示范提纲展开**：
I'd like to talk about a course I really enjoyed last semester — a data visualisation course.
First of all, what made it special was that it was very hands-on: instead of sitting through lectures, we spent most of the time working on real projects in teams.
Then, we built a dashboard that showed campus traffic patterns, which was challenging but extremely rewarding.
In the end, the course taught me practical skills and gave me the confidence to work on data projects.

## 话题卡 2：Describe a project you did that was difficult（一材多用）

**改编思路**：同一素材，换开场与重点——
- 开场改为：I'd like to talk about a difficult project I took on last semester.
- 重点从"课程有趣"改为"困难与解决"：时间紧、数据难、与队友分歧如何化解
- 收尾：克服困难后的成就感

## 话题卡 3：Describe something that helped you learn a new skill（一材多用）

**改编思路**：
- 开场：There's a course that helped me learn a completely new skill — data visualisation.
- 重点：从零开始 → 遇到困难 → 通过练习和队友帮助掌握
- 收尾：这个技能对之后学习/生活的影响

## 避免背稿感

- 提纲只写关键词，讲的时候现场用"填充公式"扩展（时间/地点/人物/做了什么/感受）；
- 三个话题卡共享素材，但开场与重点必须按题目重新组织，不要照背同一段。
