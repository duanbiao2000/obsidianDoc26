# 学业与专业 · 核心词汇与搭配

> 用法：每组词掌握"搭配 + 转述"两层。Anki 卡片建议：正面中文，背面英文 + 搭配。

## 一、专业与课程

| 词/表达 | 搭配 | 转述/近义 |
| --- | --- | --- |
| major（专业，名词） | my major is … / major in … | subject, field, course |
| subject（科目） | required / optional subject | course, module |
| course（课程） | take a course, enrol in a course | module, class |
| curriculum（课程体系） | the curriculum covers … | course structure, syllabus |
| lecture（讲座课） | attend a lecture, give a lecture | talk, class |
| seminar（研讨课） | join a seminar | discussion class |
| assignment（作业） | hand in an assignment | task, piece of work |
| dissertation / thesis（论文） | write a dissertation | research paper |

## 二、学习与能力

| 词/表达 | 搭配 | 转述/近义 |
| --- | --- | --- |
| develop skills（培养技能） | develop practical skills | build up, gain |
| critical thinking（批判性思维） | develop critical thinking | think independently |
| academic ability（学术能力） | improve academic ability | study skills, academic skills |
| self-discipline（自律） | require self-discipline | self-control |
| keep up with（跟上） | keep up with the coursework | stay on top of |
| fall behind（落后） | I didn't want to fall behind | get behind |

## 三、感受与评价

| 词/表达 | 搭配 | 转述/近义 |
| --- | --- | --- |
| be interested in（对…感兴趣） | I'm really interested in … | I'm quite into … |
| challenging（有挑战的） | a challenging course | demanding, tough |
| rewarding（有收获的） | a rewarding experience | worthwhile, valuable |
| rewarding（有收获的） | find it rewarding to … | find it worthwhile to … |
| demanding（要求高的） | a demanding major | challenging, rigorous |
| hands-on（动手实践的） | hands-on projects | practical, practical-based |
| lay a solid foundation（打下坚实基础） | lay a solid foundation for … | build a strong base for … |

## 四、高频句型（直接套用）

- My major is …, which focuses on …（我的专业是…，侧重…）
- I chose this major because I've always been fascinated by …（选这个专业是因为我一直对…着迷）
- What I enjoy most about it is …（我最喜欢的是…）
- It's quite challenging, but that's exactly what I like about it.（有挑战，但这正是我喜欢的地方）
- I'm planning to … in the future, because …（我计划未来…，因为…）

## 五、易错提醒

- "major in" 是动词短语，"my major" 是名词，别混用；
- "course" 与 "subject" 近义，可交替使用避免重复；
- 谈未来计划用 will / plan to，避免通篇一般现在时。
