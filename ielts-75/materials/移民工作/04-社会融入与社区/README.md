# 话题：社会融入与社区（Social Integration & Community）

## 话题定位

移民工作类重要话题。Part 1 常问邻居、社区、志愿者活动；Part 2 常考
"Describe a community event / a neighbour who helped you / a voluntary activity"；
Part 3 讨论社区、社会凝聚力、志愿服务等。

## 考频

★★★☆☆

## 核心策略

- **社区话题讲"关系"**：邻里、社区活动的本质是人与人的连接，
  用具体事件（一次帮助、一次活动）支撑，避免空谈概念。
- **志愿者话题用"动机 → 行动 → 收获"结构**：为什么做、做了什么、得到什么，
  结构清晰且有温度。
- **社会性问题用"个人 → 社会"升华**：从个人经历上升到社会价值，
  符合 7.5 论证深度要求。
