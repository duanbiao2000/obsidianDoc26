# 话题：环境与社会议题（Environment & Social Issues）

## 话题定位

移民工作类及通用类都常考的抽象话题。Part 1 常问环保习惯、对环境问题的看法；
Part 2 常考 "Describe an environmental issue / an activity that helps the environment /
a social issue you care about"；
Part 3 大量出现环境、社会议题的论证（污染、气候、城市化、社会问题）。

## 考频

★★★★☆（Part 3 论证强度最高的一类）

## 核心策略

- **环境话题用"个人行动 → 社会意义"结构**：先讲自己做什么，
  再升华到环保需要集体行动，论证自然且有深度。
- **社会议题保持"客观 + 建设性"**：指出问题的同时给出建议，
  不空喊口号，用具体方案体现思维成熟度。
- **观点类问题善用"责任分担"**：个人、政府、企业各负其责，
  多角度论证是 7.5 的典型特征。

## 练习顺序

1. 背 `01-核心词汇与搭配.md`；
2. `02-part1-问题与思路.md` 录音；
3. `03-part2-话题卡素材.md` 准备环保类话题卡，限时 2 分钟；
4. `04-part3-论证语料.md` 重点练多角度责任分担的论证。
