# Learning Record 0001 — 初始状态（2026-11-20）

## 已确认的当前状态

- 英语水平约 **雅思 6.0–6.5**（学习者自述）。
- **口语为短板**，听力未明确但需同步提升至 7.5。
- 目标：**1–2 个月内总分 7.5+**。
- 时间预算：**每天 2 小时以上**。

## 学习者明确表达的目标

- 通过 Matt Pocock 的 teach skill 体系化训练，提升听力与口语到 7.5+。

## 教学决策依据（ZPD 判定）

- 时间仅 1–2 个月，不能从"零基础语音"慢慢讲起，第一课应是**诊断 + 目标校准**：
  让学习者建立 7.5 的评分标准认知，并完成一次自我诊断，暴露当前的具体卡点。
- 口语是短板 → 课程权重向口语倾斜（约 60% 口语 / 40% 听力），但听力每天保持最低训练量。

## 已识别的、可能阻碍 7.5 的常见误解（后续课程验证与纠正）

- 流利 ≠ 语速快。
- 词汇量 ≠ 生僻词，7.5 更看重搭配与灵活转述。
- 听力不需要听懂每个词，抓主旨与关键细节即可。
