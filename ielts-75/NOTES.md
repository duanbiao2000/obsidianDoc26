# NOTES — 教学便签（偏好、节奏、踩过的坑）

## 学习者画像

- 起点约 6.0–6.5；口语是短板；目标 1–2 个月内 7.5+；每天预算 2 小时以上。
- 时间紧：课程必须"高杠杆"——先攻最能涨分的环节（口语流利度与组织、听力同义替换与基础题型准确率）。

## 节奏约定

- 每节课 = 一次可完成的学习单元（约 40–60 分钟），只承诺"学会做一件以前不会的事"。
- 听力与口语课**交叉安排**，不要连续多节只练同一项。
- 每节课后必须做**输出作业**（录音 / 做题 / 复述），否则视为未完成。
- 模考节奏：每周 1 套完整听力模考 + 1 次完整口语模拟（可用与 agent 对话完成）。

## 已知短板（teach 的固有限制，需要外部补充）

1. **没有自动间隔复习** → 用 Anki 承担词汇、同义替换、拼写的间隔检索。
2. **退出标准不明确** → 由本工作区的 plan.md 定义：连续两次模考达标才视为过关。
3. **口语需要真实对话** → 与 agent 的模拟对话 + 自己录音回听，作为课堂教学的补充。
