# 雅思 7.5+ 听力/口语 8 周训练规划（基于 teach skill）

> 依据：MISSION.md（1–2 个月、口语短板、每天 2h+）、RESOURCES.md、GLOSSARY.md。
> 本规划与 teach 的 lessons 配合使用：每节课的"教学"由 lessons/ 里的 HTML 课承担，
> 本规划负责排期、配重、模考与退出标准（弥补 teach 在排期与退出标准上的短板）。

## 总体策略：口语优先，听力保底

- 口语（短板）占约 **60%**，听力占约 **40%**，但**每天两项都要碰**（交叉混合原则）。
- 时间紧，只做高杠杆动作：口语主攻**流利度 + 结构 + 语法多样性**；
  听力主攻**同义替换预判 + 基础题型零失误 + 连读弱读解码**。
- 一切训练以"可量化反馈"收尾：录音回听、错题归因、模考计分。

## 每日 2 小时分配模板（基准）

| 模块 | 时间 | 内容 |
| --- | --- | --- |
| 听力输入 | 35–40 min | 精听一段剑桥真题（听 → 看文本 → 分析错因 → 跟读）或题型专项 |
| 口语输出 | 45–50 min | 与 agent 模拟对话 / 真题录音 / Part 2 话题卡 / 跟读模仿 |
| 复习与记录 | 20–25 min | Anki 间隔复习；把当天卡点写进 learning-records |
| 弹性/复盘 | 10 min | 复盘当日一句话收获，核对是否完成本课作业 |

## 分阶段安排

### 阶段一（第 1 周）：诊断与目标校准
- 第 1 课：**诊断课**——理解 7.5 评分标准，完成自我诊断，记录初始卡点。
- 第 2 课：语音底层（连读/弱读/重音）——为听力解码和口语发音打底。
- 建立 Anki 卡片库（口语语料 + 听力同义替换）。
- 完成 1 次完整听力模考（剑桥真题），记录原始分作为基线。

### 阶段二（第 2–4 周）：口语主攻期 + 听力保底
- 口语线（核心）：
  - Part 1：扩展回答策略（回答 + 原因 + 例子），减少"yes/no"式短答。
  - Part 2：话题卡结构（开场 1 句 + 内容 4–5 句 + 收尾 1 句），练到能稳定讲满 2 分钟。
  - Part 3：观点 + 解释 + 举例的展开模式，练习复杂句式与自我修正的度。
  - 发音：重音、语调、连读在口语中的运用，跟读训练。
- 听力线（保底）：Section 1/2 基础题型（填空、表格、地图）准确率冲到近满分；
  开始积累同义替换笔记。

### 阶段三（第 5–6 周）：综合提升期
- 口语：Part 2 限时与变题训练；Part 3 深度论证；**完整口语模拟**（与 agent 或按考试流程自测）。
- 听力：Section 3/4 学术场景；多选题、配对题等难题型的干扰项识别。
- 每周末：1 套完整听力模考 + 1 次完整口语模拟，记录分数曲线。

### 阶段四（第 7–8 周）：冲刺与模考期
- 每周 **2 次完整模考**（听力全真 + 口语全真），严格计时。
- 错题/录音归因：错误按"知识缺失 / 语音听不懂 / 粗心拼写 / 时间与节奏"分类，逐类攻克。
- 最后 1 周减量，保持手感，重点复习 learning-records 里标记的薄弱项和 Anki 卡片。

## 里程碑与退出标准（明确 teach 缺失的"何时停止"）

| 时间点 | 检查项 | 达标标准 |
| --- | --- | --- |
| 第 2 周末 | 首次完整模考 | 听力原始分记录，口语完成首次全真模拟并记录各维度印象分 |
| 第 4 周末 | 阶段模考 | 听力 ≥ 7.0 水平（约 28–30/40）；口语能稳定讲满 Part 2 且无明显语法硬伤 |
| 第 6 周末 | 冲刺前模考 | 听力接近 7.5；口语 Part 1/2 达到 7+ 表现 |
| 第 8 周（考前） | 最终验收 | **连续两次模考**：听力 32–34/40，口语各维度达到 7.5 描述，方可认定达标 |

- 若某周模考未达标：不新增内容，先回到对应 learning-records 卡点做专项纠错，再继续。

## 与 teach skill 的配合方式

- 每节课由 `lessons/` 下的 HTML 承担，按顺序推进；上完一节再开下一节。
- 每次新会话进入 `ielts-75/` 目录，说"下一课"即可从 learning-records 继续，不重头讲。
- 课堂内的练习关卡在 HTML 内完成；作业（录音、模考）在会话中或线下完成，
  结果写回 learning-records，供下一课判定 ZPD。
- 复习安排由 Anki + 本规划的模考节奏承担，不依赖 agent 的自动提醒。

## 一次性连续学习指南

1. **顺序**：按编号 0001 → 0011 依次学习，每课约 45–50 分钟，一气呵成。
2. **每课内部节奏**：读课 → 做随堂测验（必做，检索练习）→ 做课后作业 →
   （建议）把作业结果或口答答案发给 agent，获取逐句反馈并写入 learning-records。
3. **交叉原则**：口语与听力天然交叉，连续学习时可在 0005 与 0006 之间、
   0008 与 0009 之间各安排一次复习回看，更符合间隔记忆规律。
4. **练习材料**：每课作业所需的剑桥真题、口语题库从 RESOURCES.md 获取；
   Anki 承担词汇、同义替换、易错拼写的间隔复习。
5. **模考节奏**：从第 6 课起每 1–2 周至少 1 次完整听力模考；
   第 11 课后进入冲刺期，按课内流程执行，直到达到退出标准（连续两次达标）。
6. **反馈通道**：连续学习期间，任何一课的作业或口答都可随时发到对话里，
   agent 会按该课的评分框架反馈，并更新 learning-records（这决定后续复习重点）。
