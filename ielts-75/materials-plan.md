# 雅思口语话题素材库 · 规划方案

> 目标：为留学、移民工作两大类语境下的口语话题，设计统一结构的话题素材。
> **一个话题 = 一个文件夹**，学完 11 课后按话题查用、专项突破。

## 一、设计原则

1. **方法对齐**：所有素材与 `lessons/0001–0011` 的方法论对应——
   A-R-E 扩展结构（第 3 课）、话题卡结构（第 4 课）、论证框架（第 5 课）、
   一材多用（第 10 课），不另起一套体系。
2. **高杠杆、不堆砌**：每个话题只放"核心词 + 搭配 + 转述 + 可套用句型"，
   7.5 考的是灵活运用，不是生僻词数量。
3. **结构统一**：每个话题文件夹内部文件数量和命名完全一致，
   学会一个文件夹的用法，所有话题通用，查找方便。
4. **可直接入库**：词汇与搭配文件的格式对齐 Anki，可一键转为间隔复习卡片。
5. **中英结合**：英文语料为主体，中文做策略说明与思路点拨。

## 三、每个话题文件夹的固定结构（5 个文件）

| 文件 | 内容 | 对应课程 |
| --- | --- | --- |
| `README.md` | 话题定位、考频、核心策略、练习顺序建议 | 总纲 |
| `01-核心词汇与搭配.md` | 20–30 个核心词 + 高频搭配 + 转述表达，对齐 Anki 格式 | 第 3 课语料块 |
| `02-part1-问题与思路.md` | 5–8 个高频 Part 1 问题 + A-R-E 示范回答思路 | 第 3 课 |
| `03-part2-话题卡素材.md` | 2–3 张话题卡 + 素材骨架 + "一材多用"示范提纲 | 第 4、10 课 |
| `04-part3-论证语料.md` | 4–6 个抽象问题 + 论证框架 + 可套用语料句 | 第 5 课 |

> 每个话题**约 40–60 分钟可消化**：先读 README 定策略 → 过词汇 →
> 按 Part 1/2/3 顺序各练一轮，录音回听，卡点记入 learning-records。

## 四、生成与使用节奏

1. **生成顺序**（可一次性或分批）：先通用 + 留学（考试出现频率最高），
   再移民工作类；或按你的选择调整。
2. **使用方式**：与 11 课配合——
   - 学课期间：按课程进度用对应文件（如学完第 3 课，用各话题的 part1 文件练 A-R-E）；
   - 连续刷题期：按话题文件夹逐个攻克，一个文件夹吃透再下一个；
   - 冲刺期：只回看错因对应的词汇与语料，不再扩展新内容。
3. **质量标准**：每个话题的示范回答遵循 7.5 档要求（3–4 句扩展、有搭配、
   有从句、有让步），不做"完美范文"式堆砌。
