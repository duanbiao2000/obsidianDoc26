# 法律解释

> 一句话定义：法律解释是确定法律文本含义的活动与方法：文义解释优先，体系解释看上下文，目的解释追问立法意图，历史解释回望立法背景；解释有边界——不能逾越可能的文义去造法。

## 它解决的问题

"公民的通信自由不受侵犯"——电子邮件算通信吗？"个人信息"包括公开信息吗？法律永远落后于词汇的演化，文本总有模糊、漏洞与矛盾。解释方法给裁判者一套可辩护的工具，也给当事人一套预测裁判的思路。

解释不是"想怎么读就怎么读"：文义是边界，体系与目的是校正，解释结果要能经得起反对方的检验——这与代码评审中"语义要可辩护"如出一辙。

## 它反对或区别于

- **[[法律推理]]：解释确定大前提，推理完成三段论
- **[[法律规则]]：规则的模糊性呼唤解释
- **[[法律渊源]]：解释的对象来自渊源
- **[[语言]]（哲学集）：意义的哲学底座
- **常见误解：**"按字面读就够"；字面常有歧义，而法官/执法者实际使用的解释方法决定结果——所以"法律风险"要按解释惯例评估

## 一个代表人物／传统

- **萨维尼：**解释四要素（文义、逻辑、历史、体系）
- **法律实证主义与目的论：**耶林"目的法学"
- **中国的解释体制：**立法解释、司法解释（两高）、行政解释分工
- **法教义学：**以解释为核心的法律适用技艺

## 技术或生活案例

**场景：**旧法写"窃取、收买、非法提供公民个人信息"，如今 API 接口被批量爬取——算不算"窃取"？

**分析：**文义解释会卡壳，目的解释（保护个人信息自决）则给出答案：行为实质等同窃取。你在评估"打擦边球是否违规"时，真正的风险不是字面，而是执法者会用的解释方法——把字面通过当作安全，是最大的合规幻觉。
