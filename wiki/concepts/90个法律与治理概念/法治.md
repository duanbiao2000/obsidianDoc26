# 法治

> 一句话定义：法治是"法律至上"的治理状态：任何权力（包括政府自身）都受公开、稳定、事先公布的法律约束，人人平等适用法律，纠纷由独立公正的裁判解决——它的反面是人治与恣意。

## 它解决的问题

为什么"明君"治理仍不可靠？因为人治的好坏取决于掌权者的偶然品质，且无从预测。法治用规则约束权力：公民知道边界，官员知道权限，投资者敢投入——"制度的确定性"本身是经济增长与创新的基础设施。

法治不等于"有法律"：恶法也可以有法条。法治还要求法律本身良好（不溯及、明确、稳定）、执行平等、司法独立、政府守法。

## 它反对或区别于

- **[[法律]]：法律是规则集合；法治是规则的统治地位
- **[[权力分立]]与[[司法独立]]：法治的制度支柱
- **[[正当程序]]：法治的运行规则
- **[[权力]]（哲学集）：法治就是驯服权力
- **常见误解：**"法治=依法管理老百姓"；法治的关键是**治权**——约束掌权者与约束公民同等重要

## 一个代表人物／传统

- **亚里士多德：**法治优于一人之治（已立法律获普遍服从＋所服从之法本身优良）
- **戴雪：**法治三要素（法律至上、法律面前平等、权利由法院保障）
- **韦伯：**形式理性法律与现代科层制的亲和性
- **中国实践：**"依法治国"与法律体系建设的语境

## 技术或生活案例

**场景：**公司 API 突然封禁你的调用，投诉无门，条款随时可改。

**分析：**你体验到的正是"规则不治理"：单方随时变更、无稳定程序、无中立救济。法治化的契约则相反——变更须通知与宽限期、争议有管辖与仲裁、规则可预期。把法治思维用于产品条款设计，就是给用户"确定性"。
