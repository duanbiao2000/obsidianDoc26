## 上期（01–30）：法的地基：规则、推理与公法

| # | 概念 | 一句话定义 |
| ---: | --- | --- |
| 01 | [[法律]] | 法律是由国家制定或认可、以国家强制力为后盾、向社会公开的规范性体系：它设定权利义务、规定违反的后果，并用权威机关的执行让规则可预测——现代法律追求公开、一般、稳定与不溯及既往。 |
| 02 | [[法治]] | 法治是"法律至上"的治理状态：任何权力（包括政府自身）都受公开、稳定、事先公布的法律约束，人人平等适用法律，纠纷由独立公正的裁判解决——它的反面是人治与恣意。 |
| 03 | [[法律渊源]] | 法律渊源回答"法律从哪里来、到哪里找"：宪法、法律、行政法规、地方性法规、规章、习惯、判例与学说都是可能的渊源，并按效力位阶排列——上位法优于下位法，特别法优于一般法，新法优于旧法。 |
| 04 | [[法律解释]] | 法律解释是确定法律文本含义的活动与方法：文义解释优先，体系解释看上下文，目的解释追问立法意图，历史解释回望立法背景；解释有边界——不能逾越可能的文义去造法。 |
| 05 | [[法律推理]] | 法律推理是把规则（大前提）与事实（小前提）结合得出裁判结论的三段论式思维，辅以类比推理处理相似案件、后果考量权衡社会效果；它是"像律师一样思考"的核心技艺。 |
| 06 | [[法律规则]] | 法律规则是由假定条件、行为模式与法律后果构成的"如果—那么"指令：授权、命令或禁止某种行为，并规定遵守的收益与违反的代价——它是法律体系的基本指令单元。 |
| 07 | [[法律原则]] | 法律原则是法律体系中的基础价值与方针（诚实信用、平等、公平、公序良俗、罪刑法定等）：它不给出"如果—那么"的精确指令，而是以分量的方式被权衡，用来解释规则、填补漏洞与矫正极端结果。 |
| 08 | [[法律关系]] | 法律关系是法律在主体之间建立的权利义务联系，由主体、内容（权利义务）与客体三要素构成；它由法律事实（事件或行为）引发，是"法律作用于生活"的最小分析单元。 |
| 09 | [[法律主体]] | 法律主体是法律承认能够享有权利、承担义务的"人"：自然人当然具有权利能力，法人（公司、机关、事业单位等）由法律拟制为独立主体，非法人组织介于其间——主体资格决定谁能自己上场参与法律关系。 |
| 10 | [[法律责任]] | 法律责任是因违反法律义务或造成法定损害而必须承受的不利后果，分为民事责任（赔偿、恢复）、行政责任（处罚、处分）与刑事责任（刑罚）三大类——归责讲原则（过错责任为基、无过错为例外），构成要讲要件。 |
| 11 | [[法律权利]] | 法律权利是法律承认并保护的主体利益与行动资格：权利人有"可以做什么、要求他人做什么或不做什么"的法律地位，并能在受侵害时请求国家救济——它与道德权利（哲学意义上的"应得"）的区别在于可主张、可诉、有强制保障。 |
| 12 | [[法律义务]] | 法律义务是法律课加于主体的应为或不为（作为义务与不作为义务），对应他人的权利或公共利益，并以责任与制裁为后盾——义务不同于道德义务之处在于：内容法定、对象明确、违反可被强制追责。 |
| 13 | [[法律制裁]] | 法律制裁是国家对违法者施加的强制性不利后果：刑事制裁（刑罚）、行政处罚（罚款、拘留、吊销许可）、民事制裁（赔偿、返还、继续履行）与违宪制裁；它使法律从"纸面规范"变成"有效率的威慑"。 |
| 14 | [[正当程序]] | 正当程序要求公权力在作出不利决定前履行公平程序：告知理由、听取陈述申辩、回避利害关系、说明依据、提供救济——"程序正义是看得见的正义"，结果对错难断时，程序公正赋予决定可接受性。 |
| 15 | [[司法独立]] | 司法独立是法院依法独立行使审判权、不受行政机关、社会团体与个人干涉的原则：裁判者中立、只服从法律、身份有保障；它让纠纷解决不取决于权力、关系与舆论的强弱，而取决于规则与证据。 |
| 16 | [[诉讼]] | 诉讼是当事人把争议提交法院、由中立裁判者按法定程序作出有强制力判决的纠纷解决机制：民事诉讼解决平等主体之争，行政诉讼审查行政行为，刑事诉讼追究犯罪，另有公益诉讼守护公共利益。 |
| 17 | [[证据法]] | 证据法规定什么材料能被法庭采信（可采性）、有多大说服力（证明力）、由谁举证（举证责任）与达到什么标准才算证明成功（证明标准）——法律上的"事实"是被证据支撑的结论，而非客观真相本身。 |
| 18 | [[判例]] | 判例是法院先前判决形成的裁判规范：在普通法系，遵循先例原则使判例成为正式法律渊源；在大陆法系，判例虽非法源却事实上约束下级法院，中国则以指导性案例制度让"类似案件类似处理"获得制度通道。 |
| 19 | [[立法]] | 立法是有权机关按照法定权限与程序，制定、修改、废止规范性法律文件的活动：它把社会需求转化为一般、公开、稳定的规则文本，程序上讲究民主参与（人大审议、公开征求意见）与科学立法（评估、论证）。 |
| 20 | [[宪法]] | 宪法是国家的根本法：它组织国家权力（谁有权、如何产生、如何分工），并宣告公民基本权利（自由、平等、财产、人格尊严等）；一切法律、法规与行政行为不得与宪法抵触——宪法是法律体系的顶层约束。 |
| 21 | [[权力分立]] | 权力分立是把国家权力划分为立法、行政、司法三支、交由不同机关行使并相互制衡的宪制安排：立法者不能既当运动员又当裁判，行政者不能自定规则又自行执行——"权力必须用权力来约束"。 |
| 22 | [[司法审查]] | 司法审查是法院对立法或行政行为是否合法的复核机制：行政诉讼让公民可以告行政机关，违宪审查让法院（或专门机关）判断法律是否与宪法抵触——它是"权力受规则约束"的最后一道闸门。 |
| 23 | [[比例原则]] | 比例原则要求限制权利的措施必须经受三问：适当（措施有助于达成目的）、必要（没有侵害更小的替代手段）、均衡（收益与代价相称）——它是公法上审查权力行使的"元标尺"，也是权衡一切规则成本的思维工具。 |
| 24 | [[行政法]] | 行政法是规范行政权如何行使的法律部门：它规定行政机关的职权边界（职权法定）、行为方式（许可、处罚、强制、合同）、程序要求与监督救济——它的核心命题是"把政府关进法律的笼子"，同时让政府高效办事。 |
| 25 | [[行政行为]] | 行政行为是行政机关行使职权作出的、对相对人权利义务产生影响的举动：抽象行政行为制定普遍规则（规章、规范性文件），具体行政行为针对个案（许可、处罚、强制、确认）——具体行政行为可直接被复议与诉讼。 |
| 26 | [[行政许可]] | 行政许可（审批）是行政机关根据申请，准许相对人从事特定活动的行为——凡是涉及公共安全、市场秩序、有限资源的事项（牌照、资质、备案），未经许可不得从事；许可的设定须有法律依据，实施遵循公开、便民与信赖保护。 |
| 27 | [[政府信息公开]] | 政府信息公开是"以公开为原则、以不公开为例外"的制度：行政机关主动公开履职信息，公民、法人也可依申请获取与其相关的政府信息——不公开的例外（国家秘密、商业秘密、个人隐私、内部事务）必须法定且说明理由。 |
| 28 | [[国家赔偿]] | 国家赔偿是国家机关及其工作人员违法行使职权侵犯公民、法人合法权益时，由国家承担的赔偿责任，分为行政赔偿与司法赔偿；它以国家财政为后盾，让"公权力犯错"不再由受害人自认倒霉。 |
| 29 | [[法律与道德]] | 法律与道德是两套重叠却不重合的规范体系：道德靠内心信念与社会舆论约束，法律靠国家强制；法律常吸收最低限度的道德共识，但"合法"不等于"合德"，"合德"也不等于"可强制"——界限划在哪里，是法理学最古老的争论之一。 |
| 30 | [[法律与科技]] | 法律与科技研究技术变迁与法律规则之间的互动：技术跑得快、法律改得慢造成"规制时差"，于是出现软法先行、标准治理、技术内嵌规制（"代码即法律"）等应对——法律的难题在于既不放任风险，又不扼杀创新。 |

## 中期（31–60）：部门法：民事、商事、刑事与公共利益

| # | 概念 | 一句话定义 |
| ---: | --- | --- |
| 31 | [[民法]] | 民法是调整平等主体之间人身关系与财产关系的法律部门，以意思自治为核心、以民法典为集大成：自然人、法人与其他组织在交易、家庭与日常交往中的权利义务，主要由民法确立。 |
| 32 | [[物权]] | 物权是权利人对特定物享有的直接支配与排他权利：所有权（自物权）、用益物权与担保物权（他物权）为其主干；物权法定、一物一权、公示公信是三大原则——它回答"这东西是谁的、能怎么用、能不能当担保"。 |
| 33 | [[合同]] | 合同是平等主体之间设立、变更、终止民事权利义务的协议：要约与承诺达成合意即成立，依法成立的合同对双方有法律约束力——它是把"口头信任"升级为"可执行承诺"的装置，也是市场经济最基本的法律工具。 |
| 34 | [[侵权责任]] | 侵权责任是行为人因过错侵害他人民事权益、或无过错但依法应担责时承担的民事责任：以过错责任为原则（有过错才赔）、无过错责任为例外（高风险活动不问过错）、损害填补为核心，赔偿是主要救济方式。 |
| 35 | [[人格权]] | 人格权是民事主体对其人格利益享有的、不可转让的固有权利：生命权、身体权、健康权、姓名权、肖像权、名誉权、荣誉权、隐私权及个人信息受保护（中国民法典人格权编）——它守护"作为人而被尊重"的最低底线。 |
| 36 | [[消费者权益]] | 消费者权益保护是以倾斜保护矫正"强卖弱买"的立法：知情权、自主选择权、公平交易权、安全保障权、求偿权等九项权利，配以七天无理由退货、惩罚性赔偿、格式条款限制等武器——承认消费者在信息与实力上的弱势，用法律拉平差距。 |
| 37 | [[公司法]] | 公司法是规范公司的设立、组织、运营与解散的法律：它确立有限责任与独立法人人格两大基石，安排股东会、董事会、监事（会）、经理的治理结构，并规定股东权利与董事、监事、高级管理人员的忠实勤勉义务。 |
| 38 | [[破产]] | 破产是债务人不能清偿到期债务时，依法律程序对其财产进行集体清偿与公平分配的制度：清算（消灭主体）、重整（拯救企业）、和解（协商减债）三种程序并立——破产法既是"退出法"，也是"拯救法"。 |
| 39 | [[刑法]] | 刑法是规定犯罪与刑罚的法律，以罪刑法定、罪责刑相适应、适用刑法人人平等为基本原则：它用国家最严厉的制裁保护法益，也因此要求最严格的正当性——"刑法是其他部门法的保障法"。 |
| 40 | [[罪刑法定]] | 罪刑法定即"法无明文规定不为罪、法无明文规定不处罚"：禁止类推解释入罪、禁止溯及既往（从旧兼从轻）、要求刑罚法规明确——它是刑法乃至整个法治的基石，保护公民不被"事后立法"偷袭。 |
| 41 | [[正当防卫]] | 正当防卫是对正在进行的不法侵害采取的制止行为，造成损害的，不负刑事责任；明显超过必要限度造成重大损害的属防卫过当应负刑责——面对不法侵害，法律不要求公民"打不还手"。 |
| 42 | [[刑罚]] | 刑罚是犯罪的法律后果，由国家依法科处：主刑（管制、拘役、有期徒刑、无期徒刑、死刑）与附加刑（罚金、剥夺政治权利、没收财产、驱逐出境）；其正当性来自报应与预防的统一——既让罪行得到清算，也威慑与改造，防止再犯。 |
| 43 | [[劳动法]] | 劳动法调整劳动者与用人单位之间的劳动关系：劳动合同的订立、履行、解除与终止，工时休假、工资报酬、社会保险、工伤认定，以及对劳动者的倾斜保护——它的底色是"劳动者在组织面前是弱者"，所以法律给弱者加buff。 |
| 44 | [[税法]] | 税法规定国家向谁、就什么、按多少征税：以税收法定为原则，增值税、企业所得税、个人所得税、关税等构成主体税种，纳税人须依法申报纳税——逃税是违法，避税是钻空子，节税是合法安排，三者边界决定风险等级。 |
| 45 | [[专利]] | 专利是以公开换保护的排他权：对具备新颖性、创造性与实用性的发明创造（发明、实用新型、外观设计），国家授予一定期限（发明 20 年）的独占实施权——专利制度用"暂时的垄断"换取技术的公开与社会的进步。 |
| 46 | [[著作权]] | 著作权（版权）保护文学、艺术与科学作品：作者享有署名、修改、保护作品完整等精神权利与复制、发行、信息网络传播等财产权利；其核心结构是"思想表达二分"——只保护表达、不保护思想，作品一经完成自动产生（无需登记）。 |
| 47 | [[商标]] | 商标是用于区分商品或服务来源的标志：文字、图形、字母、颜色组合乃至声音均可注册；中国实行注册取得制，注册后享有排他使用权（每 10 年续展），显著性是其灵魂——商标保护的是消费者心中的"来源信任"。 |
| 48 | [[商业秘密]] | 商业秘密是不为公众所知悉、具有商业价值并经权利人采取相应保密措施的技术信息与经营信息：秘密性、价值性、保密性三要件缺一不可；他人以不正当手段获取、披露、使用即构成侵权——它是无需公开的"隐形专利"。 |
| 49 | [[反不正当竞争]] | 反不正当竞争法禁止经营者以不正当手段争夺交易机会：混淆仿冒、虚假宣传、商业诋毁、侵犯商业秘密、不正当有奖销售，以及互联网领域特有的流量劫持、干扰、恶意不兼容、数据抓取等行为——并设"诚实信用与商业道德"一般条款兜底。 |
| 50 | [[经济法]] | 经济法是调整国家干预经济活动之关系的法律部门家族：一面是市场规制（反垄断、反不正当竞争、消费者保护、产品质量与食品安全监管），一面是宏观调控与市场监管（财税、金融、产业政策的法律化）——它回答"市场失灵时，国家的手伸多长、怎么伸"。 |
| 51 | [[金融监管]] | 金融监管是监管机构对金融机构与金融活动的规则约束：牌照准入、资本与流动性要求（审慎监管）、投资者与消费者保护（行为监管）、系统性风险防范（宏观审慎）——金融业的负外部性与信息不对称决定了它不可能"完全自由"。 |
| 52 | [[行政处罚]] | 行政处罚是行政机关对违反行政管理秩序行为的制裁：警告、通报批评、罚款、没收、暂扣吊销许可证、限制从业、行政拘留等种类；处罚法定、过罚相当、一事不再罚、处罚与教育相结合——它是企业最常直接面对的法律后果形态。 |
| 53 | [[举证责任]] | 举证责任是"事实真伪不明时谁承担败诉风险"的分配规则：民事诉讼一般"谁主张谁举证"，特殊情形倒置；劳动争议中用人单位对解除、工时等事实举证；行政诉讼由被告行政机关证明其行为合法；刑事诉讼由公诉方证明被告有罪。 |
| 54 | [[环境法]] | 环境法以可持续发展为目标，规制污染排放与生态破坏：环境影响评价、排污许可、总量控制、按日连续处罚、环境公益诉讼与生态损害赔偿构成制度骨架——"污染者付费、损害者担责"，绿色原则正在向技术产品渗透。 |
| 55 | [[产品责任]] | 产品责任是因产品缺陷造成人身、财产损害时，生产者、销售者承担的无过错责任：缺陷包括设计缺陷、制造缺陷与警示缺陷；"发展风险"（依当时科技水平不能发现）是生产者抗辩事由——产品一旦流通，责任随产品走。 |
| 56 | [[国际法]] | 国际法主要是国家之间的法律：以条约、习惯国际法与一般法律原则为渊源，以国家与国际组织为主体，确立主权平等、不干涉内政、禁止使用武力等基本原则——它没有世界政府，靠互惠、声誉与对等制裁维持效力。 |
| 57 | [[仲裁]] | 仲裁是当事人依仲裁协议将争议提交仲裁机构、由仲裁庭作出终局裁决的制度：协议仲裁、一裁终局、程序灵活、保密性强；跨境裁决依《纽约公约》在 170 多个国家承认与执行——国际商事争议的首选通道。 |
| 58 | [[比较法]] | 比较法是对不同法律体系进行比较研究的学问：大陆法系（成文法、法典化）与普通法系（判例法、法官造法）为两大主干，另有混合法域与区域法（欧盟法）——比较不是为了猎奇，而是为了理解"法律为什么长成这样"并预判规则走向。 |
| 59 | [[法律职业]] | 法律职业是以法律知识与技能为业的共同体：法官、检察官、律师、公司法务、合规官、公证员与法学研究者——共同伦理是独立、保密、利益冲突回避与勤勉尽责；"法律人思维"（规则敏感、程序意识、证据习惯）正是这套职业训练的产物。 |
| 60 | [[法律经济学]] | 法律经济学用经济学的成本收益框架分析法律制度：产权如何配置（科斯定理）、侵权如何归责（汉德公式：预防成本小于损失概率乘损失额即有过失）、刑罚如何威慑（贝克尔模型）、救济选财产规则还是责任规则——效率成为评价法律的重要标尺，但绝非唯一标尺。 |

## 下期（61–90）：治理、规制与数字时代

| # | 概念 | 一句话定义 |
| ---: | --- | --- |
| 61 | [[治理]] | 治理是为共同事务制定规则并执行、监督规则的系统安排，覆盖公司、平台、国家与全球等多个层次：它强调多主体参与（政府、市场、社会组织、用户）与过程品质（参与、透明、问责、效能），而不只是"自上而下的统治"。 |
| 62 | [[问责]] | 问责是让权力行使者就其决策与行为向有关方面说明理由并承担后果的机制：谁对谁负责（选举、上级、法院、公众）、就什么负责（结果、程序、说明义务）、通过什么机制（选举、审计、诉讼、举报、公开）——没有问责链条的权力必然走向滥权。 |
| 63 | [[透明度]] | 透明度是决策的依据、过程与结果可以被外部看见与核查的程度：政府信息公开、监管规则公开、企业信息披露、算法规则与数据使用披露——透明是信任与问责的燃料，但"可见"不等于"可理解"，且须与隐私、商业秘密平衡。 |
| 64 | [[规制]] | 规制是公共权威为纠正市场失灵或实现公共目标而对私人行为进行的持续性控制：工具谱系从命令控制（禁令、标准、许可）到市场工具（税收、补贴、交易许可）再到信息工具（披露、标签）与自我规制、共同规制——选择哪种工具，决定规制的成本与效果。 |
| 65 | [[规制俘获]] | 规制俘获是规制者被被规制产业俘获、让规制服务于产业利益而非公共利益的现象：通过信息垄断、旋转门、游说与"规制筑墙"，在位企业把监管变成排挤新进入者的护城河——"规制失灵"与市场失灵同样真实。 |
| 66 | [[风险规制]] | 风险规制是对新技术与社会活动之风险的公共管理：风险评估（科学事实）—风险管理（工具选择）—风险沟通（公众理解）三环节；面对不确定性，规制者要在预防原则（宁可严）与成本收益分析（宁可准）之间取平衡——包括警惕"规制风险本身"。 |
| 67 | [[标准]] | 标准是经协商一致制定、由公认机构批准、供重复使用的技术规范：强制性标准具有法律约束力，推荐性标准通过合同与监管引用获得效力；国家标准、行业标准、团体标准、企业标准构成层级——标准是工程语言与法律规则之间的桥梁。 |
| 68 | [[合规]] | 合规是企业使其经营符合法律法规、监管规定、行业准则与内部制度的系统性管理：从风险识别、制度设计、培训宣贯到监测审计与违规应对——现代合规早已不是"法务查条款"，而是嵌入业务流程的治理能力，并享受"合规整改从宽"的制度激励。 |
| 69 | [[吹哨人]] | 吹哨人机制是让组织内部知情者能够揭露违法与危害行为的制度通道：内部举报（向合规部门）、外部举报（向监管机构）与公开披露（向媒体与公众）三级递进，配套反报复保护、保密与激励——没有安全的举报通道，组织内部的违法往往永不见光。 |
| 70 | [[反腐败]] | 反腐败是预防与惩治公权力与商业活动中腐败行为的制度体系：贪污、受贿、行贿、挪用与商业贿赂各有构成要件；治理端依靠监督（监察、审计）、透明（公开）、问责与教育——腐败的本质是公共权力被私人利益捕获，反腐败即"保护制度的免疫系统"。 |
| 71 | [[数字治理]] | 数字治理有两条线：用数字技术改造公共治理（电子政务、一网通办、数字身份、开放数据、算法行政），以及为数字空间建立规则（网络内容、平台、数据、AI 的公共规制）——它的核心课题是：技术让治理更高效的同时，如何不损害权利、公平与问责。 |
| 72 | [[数据保护]] | 数据保护法规范个人信息的收集、存储、使用、加工、传输与删除（个人信息保护法、GDPR）：知情同意、目的限制、数据最小化、安全义务、主体权利（查阅、复制、更正、删除、可携带）与跨境规则构成框架——违反者面临高额罚款甚至刑事责任。 |
| 73 | [[隐私权]] | 隐私权是个人对其私密空间、私密活动与私密信息不被窥探、侵扰与滥用的权利：宪法上的基本权利属性与民法上的人格权保护叠加；数字时代它扩展为"个人信息自决"——对围绕自己的信息流保持知情与控制的能力。 |
| 74 | [[网络安全]] | 网络安全法律体系（网络安全法、数据安全法、关键信息基础设施保护条例）规定网络运营者的安全义务：等级保护（等保 2.0）、数据分类分级、关键信息基础设施（CII）重点保护、漏洞管理、应急处置与报告——安全不再只是技术问题，而是法定义务体系。 |
| 75 | [[人工智能治理]] | 人工智能治理是为 AI 系统的全生命周期（数据、训练、部署、使用、退出）确立规则与机制：风险分级监管、透明度与可解释、人类监督、公平与非歧视、安全评估、责任分配与标识义务——全球正从伦理倡议走向有牙齿的立法（欧盟 AI 法、生成式 AI 管理办法）。 |
| 76 | [[算法治理]] | 算法治理是对自动化决策系统（推荐、排序、评分、定价、风控、用工调度）的专门规制：算法备案与评估、禁止利用算法实施不正当竞争与歧视（含大数据杀熟）、提供用户关闭个性化与便捷退出、保护算法影响下的劳动者与消费者——它把"算法权力"纳入问责轨道。 |
| 77 | [[平台责任]] | 平台责任是平台对其上内容、交易与行为承担的法律义务体系：避风港原则（"通知—删除"后免责）与红旗原则（明知侵权仍须负责）、电商平台对消费者的安全保障责任、内容审核义务、算法推荐的责任加重——平台既是"通道"又是"守门人"，责任随控制力而增长。 |
| 78 | [[网络犯罪]] | 网络犯罪是以网络为对象或工具的犯罪：破坏计算机信息系统罪、非法获取计算机信息系统数据罪、侵犯公民个人信息罪、帮助信息网络犯罪活动罪（帮信罪）等罪名构成技术行为的刑事红线——网络黑产（养号、接码、洗钱、外挂）的每一环都可能单独入罪。 |
| 79 | [[开源许可]] | 开源许可是著作权人主动授权他人使用、修改、分发软件的合同：宽松型许可（MIT、Apache-2.0）几乎不设限，Copyleft 许可（GPL）要求衍生作品同样开源——许可是有法律效力的契约，违反它（如闭源分发 GPL 代码）就是违约与侵权。 |
| 80 | [[智能合约]] | 智能合约是部署在区块链上、条件满足即自动执行的程序化协议：它把履约变成代码（自动执行、不可篡改、公开可查），但"代码即合同"带来法律难题——智能合约的效力认定、错误代码的责任、自动执行与法定救济（撤销、违约）的衔接，仍是法律与代码之间的翻译问题。 |
| 81 | [[数据主权]] | 数据主权是国家对其境内数据及数据处理活动主张管辖与规制的权力主张：数据出境安全评估、数据本地化要求、域外效力（长臂管辖）与多边数据流动规则（CPTPP、DEPA）之间的张力，构成出海企业必须处理的地缘法律问题——数据流到哪，法律就追到哪。 |
| 82 | [[全球治理]] | 全球治理是民族国家之上应对跨国问题的规则与机制体系：联合国与国际组织（WTO、WHO、国际法院）、条约与软法（G20、OECD 准则）、多利益相关方安排（ICANN 式的网络治理）——没有世界政府，全球治理靠规则、机制与协商解决气候、网络、AI、流行病等跨国问题。 |
| 83 | [[紧急状态]] | 紧急状态是面对战争、重大灾害与公共卫生事件等非常情形，国家依法采取超越常规措施的宪制状态：紧急权力须有法律依据、受比例原则约束、有期限与监督，且基本人权的核心（生命、不受酷刑等）不可克减——法治在例外中不缺席，否则例外会成为常态。 |
| 84 | [[陪审制度]] | 陪审制度是让未经法律职业训练的普通公民参与审判的制度：英美陪审团负责事实认定（有罪/无罪由陪审团裁决），大陆法系参审制（如中国的人民陪审员）由公民与法官共同组成合议庭——它的价值在于把社区常识与民主正当性带进法庭，防止司法成为封闭的"法官俱乐部"。 |
| 85 | [[自然法]] | 自然法主张存在超越实证制定法的、源于人性与理性的更高法则：不正义的法律不是真正的法律（"恶法非法"）——从阿奎那到洛克，从纽伦堡审判到当代人权话语，自然法为"反抗恶法"与"人权不可剥夺"提供思想根基。 |
| 86 | [[法律实证主义]] | 法律实证主义主张"法律是什么"与"法律应当是什么"分离：法律的效力取决于其来源（被有权机关制定）而非道德品质——恶法亦法，对恶法的批评属于道德而非法律领域；哈特的"承认规则"与凯尔森的"基础规范"为法律的识别提供了社会事实标准。 |
| 87 | [[法律现实主义]] | 法律现实主义主张法律不是纸面上的规则，而是"法官实际上会怎么做"：规则总有模糊与冲突，裁判受法官的个人特质、直觉与政策判断影响——霍姆斯"法律的生命不是逻辑而是经验"为其宣言，它把法律研究从概念推演拉回行为预测与效果考察。 |
| 88 | [[公共利益]] | 公共利益是法律与规制中为限制权利、动用公共权力提供正当性的概念：指不特定多数人共享的利益（安全、健康、环境、市场秩序、公共资源）；它的危险在于被空洞援引——"以公共利益之名"行部门利益或寻租之实，所以现代法治要求公共利益经由程序（听证、评估、司法审查）被具体化与检验。 |
| 89 | [[法律的边界]] | 法律的边界指法律能做什么与不能做什么：它以强制为后盾却管不了内心与私德，它滞后于技术却仍需回应，它依赖执行却受制于成本与社会共识——"法律万能论"与"法律无用论"同样错误；法律与市场、代码、社会规范各自分工，共同维系秩序。 |
| 90 | [[法律思维]] | 法律思维是法律人共有的思维习惯，也是非法律人可以习得的通识能力：规则思维（把问题要件化）、权利思维（问谁有权、如何救济）、证据思维（凡主张皆须可证明）、程序思维（过程正义先于结果）、衡平思维（在冲突价值间权衡并说明理由）——它是本套 90 卡的收束站。 |
