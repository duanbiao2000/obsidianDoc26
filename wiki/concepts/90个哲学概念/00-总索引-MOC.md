## 上期（01–30）：概念起步 · 逻辑与认识基础

| # | 概念 | 一句话定义 |
| ---: | --- | --- |
| 01 | [[哲学]] | 哲学是对存在、知识、真理、价值、心灵、自由与社会等根本问题进行概念澄清、理由审查和系统反思的活动。 |
| 02 | [[概念]] | 概念是我们用来识别、分类、理解和推理事物的思想工具；它决定什么能被看作同一类问题，以及什么会被忽略。 |
| 03 | [[定义]] | 定义是用较清楚的语言说明一个概念指什么、适用于哪些对象，以及它与相近概念如何区分的表达。 |
| 04 | [[命题]] | 命题是能够被判断为真或假的内容，通常由一个陈述句表达，但不等同于某个具体句子本身。 |
| 05 | [[论证]] | 论证是用一个或多个前提，为某个结论提供理由的结构；它不是争吵，而是可被检验的理由链条。 |
| 06 | [[前提]] | 前提是论证中被用来支持结论的主张；它可以明确说出，也可以隐藏在语言、指标、制度或习惯中。 |
| 07 | [[结论]] | 结论是论证试图让我们接受的主张；它应由前提支持，而不是仅靠说话者的身份、语气或愿望成立。 |
| 08 | [[理由与原因]] | 原因说明一件事为何发生；理由说明一个人为何应当相信某事、选择某事或采取行动。 |
| 09 | [[事实判断]] | 事实判断是关于世界实际上如何的主张，原则上可以通过观察、数据、证据、推理或调查得到支持、修正或反驳。 |
| 10 | [[价值判断]] | 价值判断是关于什么是好、坏、值得、正当、可取或应当做的主张；它不能只由事实数据决定，但必须能够给出理由并接受讨论。 |
| 11 | [[演绎推理]] | 演绎推理是从一般规则、定义或前提出发，推出一个在前提为真时必然成立的结论的推理方式。 |
| 12 | [[归纳推理]] | 归纳推理是从有限观察、样本或案例出发，推断更一般的规律、趋势或未来结果的推理方式。 |
| 13 | [[有效性]] | 有效性是指一个论证的结构是否保证：只要前提为真，结论就不可能为假。 |
| 14 | [[健全性]] | 健全性是指一个演绎论证既具有有效的推理形式，且其前提都真实或可接受。 |
| 15 | [[必要条件]] | 必要条件是某件事要成立就必须具备的条件；没有它，那件事便不可能成立。 |
| 16 | [[充分条件]] | 充分条件是只要具备它，就足以保证某件事成立的条件；但结果也可能由其他条件产生。 |
| 17 | [[反例]] | 反例是一个满足某个主张前提或范围、却不符合其结论的具体案例，用来推翻或限制过强断言。 |
| 18 | [[谬误]] | 谬误是看似能够支持结论、实际在逻辑结构、证据使用、概念转换或讨论相关性上存在问题的推理错误。 |
| 19 | [[循环论证]] | 循环论证是指一个论证把本应证明的结论，直接或以换句话说的方式作为前提使用，因此没有提供独立支持。 |
| 20 | [[稻草人谬误]] | 稻草人谬误是把对方原本较复杂、较有限或较准确的观点歪曲成更弱、更极端或更容易攻击的版本，再反驳那个被歪曲的版本。 |
| 21 | [[真理]] | 真理通常指一个命题以恰当方式符合世界、事实、逻辑或合理信念体系，但“何谓符合”本身仍是哲学争论的问题。 |
| 22 | [[信念]] | 信念是一个主体把某个命题当作真实或大致真实而接受的认知态度。 |
| 23 | [[知识]] | 知识通常被理解为不仅相信某件事，而且该事为真，并且拥有足够理由或可靠方式来相信它；但这一传统定义仍存在重要争议。 |
| 24 | [[证成]] | 证成是一个信念拥有足够认识理由而值得被接受的状态或过程，即说明“我为什么有资格相信它”。 |
| 25 | [[证据]] | 证据是能够支持或削弱某个命题的材料，包括观察、实验、数据、文献、记录、证词、推理结果与可复现过程。 |
| 26 | [[怀疑论]] | 怀疑论是对我们能否获得某类可靠知识、或现有理由是否足够支持知识主张提出根本质疑的哲学立场或方法。 |
| 27 | [[经验主义]] | 经验主义是强调知识主要建立在感知、观察、实验和经验材料之上的认识论传统。 |
| 28 | [[理性主义]] | 理性主义是强调理性、逻辑、先天结构或可由思维把握的原则，在知识形成中具有基础性作用的认识论传统。 |
| 29 | [[实在论]] | 实在论大体主张，世界或某些对象、结构、事实独立于我们的信念、语言、文化或理论而存在。 |
| 30 | [[相对主义]] | 相对主义主张，某些真理、知识、价值或合理性判断，至少部分依赖于特定文化、语言、历史、理论框架或立场，而非完全脱离语境地固定。 |

## 中期（31–60）：主体、伦理与社会

| # | 概念 | 一句话定义 |
| ---: | --- | --- |
| 31 | [[主体]] | 主体是能够经验世界、形成信念、作出行动、给出理由，并可能承担责任的存在者。 |
| 32 | [[客体]] | 客体是被认识、观察、测量、使用、管理或处理的对象。 |
| 33 | [[自我]] | 自我是人对“我是谁”、我的经验是否连续、我的行动是否属于我，以及我如何与他人区分的理解。 |
| 34 | [[他者]] | 他者是与“我”不同、拥有自身经验、目的和尊严，不能被我完全理解、占有或化约为工具的人。 |
| 35 | [[意识]] | 意识通常指一个存在者具有主观体验、觉知或“某种感觉是怎样的”的状态。 |
| 36 | [[意向性]] | 意向性是心灵状态具有“关于某物”的特征，即信念、希望、恐惧和判断总是指向某个对象、情境或可能状态。 |
| 37 | [[语言]] | 语言是人们表达、沟通、分类、承诺、解释和行动的符号实践；它不只传递既有思想，也参与塑造我们能如何理解世界。 |
| 38 | [[解释]] | 解释是说明一个现象、行为或结果为何发生、如何发生，或为何具有某种意义的活动。 |
| 39 | [[理解]] | 理解是把握一个人、文本、行动或处境对当事人意味着什么，并将局部内容放入更完整的语境和关联中。 |
| 40 | [[诠释学]] | 诠释学是研究人如何理解文本、行动、历史和世界，以及理解如何受语言、处境、传统和预先判断影响的哲学传统。 |
| 41 | [[自由]] | 自由是人能够在不受不正当强制、操控或支配的条件下行动、选择、表达和发展自身生活的状态。 |
| 42 | [[意志]] | 意志是主体形成目的、作出选择、维持承诺并推动行动的能力。 |
| 43 | [[自主]] | 自主是一个人能够理解处境、考虑理由，并依据自己能够认可的原则和目标进行自我决定的能力与状态。 |
| 44 | [[责任]] | 责任是个人或组织对其行动、角色、决定及其后果能够被要求说明、回应、修复或承担后果的关系。 |
| 45 | [[权利]] | 权利是个人或群体可以正当地要求他人、组织或制度尊重、保护或提供某种自由、利益、程序或资源的主张。 |
| 46 | [[义务]] | 义务是一个人即使不愿意、不方便或不获利，也有理由或规则要求其应当履行的行动责任。 |
| 47 | [[功利主义]] | 功利主义是一类以行动后果为主要标准、主张应尽量增加总体福祉并减少总体痛苦的伦理学理论。 |
| 48 | [[义务论]] | 义务论是一类认为行动是否正当不仅取决于结果，还取决于是否遵守应当尊重的原则、权利和义务的伦理学理论。 |
| 49 | [[德性伦理]] | 德性伦理关注行动者应培养何种稳定而优秀的品格，以及人在具体情境中如何以实践智慧做出恰当行动。 |
| 50 | [[正义]] | 正义是关于权利、机会、资源、负担、程序和社会认可应如何被公平安排的原则与实践。 |
| 51 | [[社会]] | 社会是由人际关系、分工、制度、规范、权力、文化和共同实践构成的持续协作与冲突网络。 |
| 52 | [[制度]] | 制度是稳定地组织行为、角色、权利、资源、奖励与惩罚的规则、程序和实践体系。 |
| 53 | [[规范]] | 规范是关于人们应当如何行动、判断或相互对待的标准、规则和期待。 |
| 54 | [[权力]] | 权力是影响他人行动、机会、资源、知识可见性或规则边界的能力。 |
| 55 | [[支配]] | 支配是某人或某机构能够任意干预他人的选择、生活或机会，而被影响者缺乏有效反制、申诉或退出能力的状态。 |
| 56 | [[意识形态]] | 意识形态是一套使特定社会关系、利益安排和价值优先级显得自然、合理、唯一或不可改变的观念框架。 |
| 57 | [[异化]] | 异化是人同自己的劳动、成果、他人、共同世界或生活意义发生疏离，以至于原本应服务于人的活动反过来支配人。 |
| 58 | [[承认]] | 承认是把他人视为具有尊严、能力、权利、声音和社会地位的主体，并在关系与制度中给予相应对待。 |
| 59 | [[现代性]] | 现代性是围绕科学、工业、市场、国家、官僚制、个人权利、城市化与持续创新形成的一组历史条件、制度结构和生活经验。 |
| 60 | [[公共性]] | 公共性是人们能够以公开、可理解、可质疑和可共同判断的方式讨论共同事务，并对影响公共利益的权力进行监督的条件与能力。 |

## 下期（61–90）：科学、技术与意义

| # | 概念 | 一句话定义 |
| ---: | --- | --- |
| 61 | [[科学解释]] | 科学解释是借助规律、机制、因果关系、模型或结构，说明某种现象为什么发生、如何发生的活动。 |
| 62 | [[因果关系]] | 因果关系是一个因素、事件或过程以某种方式产生、维持、改变或阻止另一个结果的关系。 |
| 63 | [[相关关系]] | 相关关系是两个变量在数据中呈现共同变化的模式，但这种共同变化本身不证明任何一方导致另一方。 |
| 64 | [[模型]] | 模型是为了理解、预测、模拟、解释或控制某个对象而构建的选择性简化表征。 |
| 65 | [[理论]] | 理论是由概念、假设、规律、解释和推断关系构成的系统框架，用来理解某类现象并指导研究或行动。 |
| 66 | [[假设]] | 假设是为解释、预测或指导研究而暂时提出，并应接受检验、修正或放弃的具体主张。 |
| 67 | [[可证伪性]] | 可证伪性是指一个主张必须允许某些可能的观察、实验或证据将其判定为错误，才具有明确的经验可检验性。 |
| 68 | [[范式]] | 范式是一个共同体在某个时期共享的问题、概念、方法、标准、工具和典型解法，它规定什么算重要问题和好答案。 |
| 69 | [[科学实在论]] | 科学实在论认为，成熟科学理论中关于不可直接观察对象和结构的许多主张，大致对应独立于人类信念而存在的真实世界。 |
| 70 | [[工具主义]] | 工具主义认为，科学理论和模型首先是预测、解释、控制或计算的工具，不必要求其所描述的实体完全真实存在。 |
| 71 | [[技术]] | 技术不是单一工具，而是由工具、知识、基础设施、组织、规则、劳动和使用实践共同构成的行动系统。 |
| 72 | [[技术中立性]] | 技术中立性是“技术本身没有价值倾向，善恶完全取决于使用者”的常见主张。 |
| 73 | [[工具理性]] | 工具理性是以最有效率的方式实现既定目标的思考方式，但它可能不追问目标本身是否值得追求。 |
| 74 | [[目的与手段]] | 目的是行动想实现的价值或状态；手段是为实现该目标而采用的方法、工具、资源和步骤。 |
| 75 | [[效率]] | 效率是在较少时间、资源、能量或成本消耗下，实现某个既定目标的能力。 |
| 76 | [[优化]] | 优化是在给定目标、约束和评价标准下，寻找表现更优方案的过程。 |
| 77 | [[外部性]] | 外部性是某项行动、交易或系统带来的成本或收益，没有完全由作出决策的一方承担或获得，而落在第三方身上。 |
| 78 | [[风险]] | 风险是在不确定条件下，某种损害发生的可能性及其严重程度。 |
| 79 | [[预防原则]] | 预防原则主张，当潜在伤害可能重大、不可逆或难以补救时，即使证据尚未完全确定，也应采取合理的预防和保护措施。 |
| 80 | [[可解释性]] | 可解释性是人能够理解一个系统的依据、行为逻辑、结果原因、限制条件和可采取后续行动的程度。 |
| 81 | [[存在]] | 存在是关于“什么以何种方式存在”，以及人如何处于世界、时间、关系和意义之中的根本问题。 |
| 82 | [[本体论]] | 本体论是研究什么存在、不同事物以何种方式存在，以及它们之间最基本关系和类别结构的哲学分支。 |
| 83 | [[世界]] | 世界不只是全部物理对象的总和，也是在其中人们行动、理解、关切、协作并赋予事物意义的整体场域。 |
| 84 | [[时间性]] | 时间性是指人的经验、身份、计划与行动总是在过去记忆、当下处境和未来可能性之间展开的结构。 |
| 85 | [[身体性]] | 身体性是指人的经验、行动、认知和脆弱性并非发生在抽象头脑中，而是始终通过具体身体、感官、动作、空间和生理状态展开。 |
| 86 | [[具身认知]] | 具身认知认为，认知并非只发生在大脑内部，而与身体、感知、行动、环境和外部工具持续耦合。 |
| 87 | [[注意力]] | 注意力是人将有限认知资源选择性投入某些对象、任务、信号或关系的能力，也是技术系统能够引导、争夺和商业化的资源。 |
| 88 | [[数据化]] | 数据化是将人的行为、关系、经验、物件或过程转译为可记录、分类、计算、比较、预测和管理的数据形式。 |
| 89 | [[自动化]] | 自动化是将原本需要人执行的流程、判断、操作或决策，部分或全部交由技术系统持续完成的过程。 |
| 90 | [[技术伦理]] | 技术伦理是对技术的设计、训练、部署、使用和治理中涉及的价值、权利、风险、责任、权力和社会后果进行系统判断的实践。 |
