# 学习迁移

> 一句话定义：学习迁移是把在一个情境中学到的知识或技能应用到新情境的能力；它分近迁移（相似情境）与远迁移（结构不同），是"学会"与"背会"的真正分水岭。

## 它解决的问题

考试会做、实战不会，是迁移失败。迁移依赖的不是记忆量，而是理解的抽象程度：学到具体步骤只能近迁移，学到背后的原理与结构才能远迁移。

促进迁移的教学策略：多情境练习、变式练习、强调"何时何地为何用"的条件化知识、先学原理再遇案例。

## 它反对或区别于

- **[[记忆]]：记得住不等于能迁移
- **[[主动回忆]]：提取练习强化记忆，迁移还要变化情境
- **[[专家技能]]：专家迁移能力强因知识按深层结构组织
- **[[情境学习]]：知识在情境中被学会也在情境中受限
- **常见误解：**练习量越大迁移越好；同质化的大量练习只巩固原情境

## 一个代表人物／传统

- **爱德华·桑代克：**形式训练说批判与共同要素论
- **查尔斯·贾德：**概括化理论（水下折射实验）
- **现代教育研究：**变式与深层结构的迁移机制
- **编程教育：**语言切换、框架迁移的实践讨论

## 技术或生活案例

**场景：**会写 Python 的人学 Rust 为何仍吃力？

**分析：**语法近迁移容易，但所有权模型、并发思维是深层结构差异——需要远迁移，即重新组织心智模型。高效学习法：明确指出新旧领域的结构异同、在多个小项目里用新范式、警惕"用 Rust 写 Python"。

## 我自己的反问

- 我学的东西能迁移到哪些场景？
- 我的练习是否足够多样（变式）？
- 我学的是步骤还是原理？
- 我的教学/文档帮助读者建立条件化知识了吗？
- 哪些经验实现了远迁移？当时条件是什么？
