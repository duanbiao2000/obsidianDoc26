## 上期（01–30）：认知、学习与自我提升

| # | 概念 | 一句话定义 |
| ---: | --- | --- |
| 01 | [[心理学]] | 心理学是用科学方法研究行为与心理过程（感知、注意、记忆、情绪、动机、社会互动）的学科；它区别于内省与常识，要求可检验的证据。 |
| 02 | [[信度与效度]] | 信度是测量结果的一致性与可重复性；效度是测量是否真的测到了它声称要测的东西——效度比信度更重要，但两者都不可或缺。 |
| 03 | [[行为主义]] | 行为主义主张心理学只研究可观察的行为及其环境前因后果，拒绝把不可观察的"内心"当作科学对象；它奠定了学习与行为矫正的实证基础。 |
| 04 | [[认知革命]] | 认知革命是 20 世纪中叶心理学从"只研究行为"转向"把心智当作信息加工系统"的范式转变；它把人脑类比为接收、编码、存储与提取信息的计算装置。 |
| 05 | [[知觉]] | 知觉是大脑对感觉信息进行组织与解释、从而"看出"一个有意义的世界的主动过程；它受自上而下的预期强烈影响，因此看见不等于如实反映。 |
| 06 | [[注意]] | 注意是对大量感觉与思维输入进行选择、聚焦与分配的认知机制；它的容量有限，因此把注意投向哪里，决定了人能处理什么。 |
| 07 | [[记忆]] | 记忆不是单一仓库，而是编码、存储与提取三个过程构成的系统，包含感觉记忆、工作记忆与长时记忆等不同子系统。 |
| 08 | [[工作记忆]] | 工作记忆是当前正在被操作、加工与保持的少量信息——它是思考的工作台，容量只有大约 4 个组块，超载时思维立即劣化。 |
| 09 | [[遗忘]] | 遗忘是记忆随时间与环境而消退或无法提取的现象；艾宾浩斯曲线显示它先快后慢，而遗忘并非纯粹缺陷——它是系统为相关性做的"缓存清理"。 |
| 10 | [[条件反射]] | 条件反射是学习的基本形式：经典条件反射让中性刺激因与重要事件配对而获得意义（巴甫洛夫的铃声），操作性条件反射让行为因后果而被加强或减弱（斯金纳）。 |
| 11 | [[强化]] | 强化是行为之后出现、使该行为未来更可能发生的后果；正强化给予奖励，负强化移除厌恶刺激，而强化程式的安排方式决定行为建立的模式与持久性。 |
| 12 | [[观察学习]] | 观察学习是通过观看他人行为及其后果而获得新行为与信念的学习方式；它不需要亲身尝试，也不需要直接强化——班杜拉的波波娃娃实验是经典证明。 |
| 13 | [[问题解决]] | 问题解决是从当前状态到达目标状态、且没有现成路径的认知过程；它依赖问题表征、启发式搜索与领域知识，也常被功能固着与心理定势绊住。 |
| 14 | [[创造力]] | 创造力是产生新颖且有用的想法或作品的能力；它不是神秘天赋，而是发散思维与收敛思维交替、知识积累与打破定势并存的认知过程。 |
| 15 | [[智力]] | 智力是个体学习、推理、解决问题与适应环境的能力集合；心理测量学用测验将其操作化，但智力是单一因素还是多元结构、受遗传与环境如何影响，争论持续至今。 |
| 16 | [[认知偏差]] | 认知偏差是思维在特定情境下系统偏离理性基准的模式——它们不是随机错误，而是启发式（快捷方式）在复杂世界的可预测副产品。 |
| 17 | [[情绪]] | 情绪是涉及主观感受、生理唤醒、表情表达与行为倾向的快速适应反应；它并非理性的敌人，而是决策与记忆的重要信号系统。 |
| 18 | [[动机]] | 动机是驱动、维持并引导行为朝向目标的内部力量；它分内在动机（为活动本身）与外在动机（为外部结果），两者的来源与可持续性截然不同。 |
| 19 | [[压力与应对]] | 压力是当环境要求超出个人评估的应对资源时产生的身心反应；其关键在于"评估"——同一件事对人是威胁还是挑战，取决于认知评价与可用资源。 |
| 20 | [[心流]] | 心流是当技能与挑战恰好匹配、目标清晰且反馈即时时出现的全神贯注、时间感扭曲、自我意识消失的高投入状态；它是内在动机的巅峰体验。 |
| 21 | [[自我效能]] | 自我效能是对自己"能否完成特定任务"的信念；它决定人们选择什么、努力多久、在困难面前坚持还是放弃，且比实际能力更能预测行为启动。 |
| 22 | [[归因]] | 归因是人们解释行为原因的过程——归因于内（能力、性格）还是外（情境、运气），稳定还是可变，直接决定随之而来的情绪、责任判断与后续行为。 |
| 23 | [[积极心理学]] | 积极心理学研究使人与组织繁荣的因素——积极情绪、投入、关系、意义与成就（PERMA）——而不仅是修复心理疾病；它主张幸福是可以被科学研究的。 |
| 24 | [[睡眠]] | 睡眠是主动的、周期性的生理心理状态，包含深睡与快速眼动等阶段；它对记忆巩固、情绪调节、免疫与代谢至关重要，睡眠剥夺则迅速损害认知。 |
| 25 | [[语言习得]] | 语言习得研究儿童如何在缺乏系统教学的情况下、在几年内掌握复杂语法系统；核心争论是天生机制（乔姆斯基）与统计学习（输入驱动）各占多少。 |
| 26 | [[认知负荷]] | 认知负荷是任务对有限的工作记忆资源提出的要求总量；当固有负荷、无关负荷与有效负荷之和超出容量，学习与表现就会崩溃。 |
| 27 | [[双系统理论]] | 双系统理论把思维分为快速自动的系统 1（直觉、联想、情绪）与缓慢费力的系统 2（推理、计算、自我控制）；多数判断由系统 1 完成，系统 2 负责监督却常常偷懒。 |
| 28 | [[学习迁移]] | 学习迁移是把在一个情境中学到的知识或技能应用到新情境的能力；它分近迁移（相似情境）与远迁移（结构不同），是"学会"与"背会"的真正分水岭。 |
| 29 | [[元认知]] | 元认知是对自己认知过程的认知与调控——知道什么、不知道什么、学得如何、该用什么策略；它是"学习如何学习"的核心机制。 |
| 30 | [[刻意练习]] | 刻意练习是为提升特定能力而设计、处于能力边缘、伴随即时反馈与重复修正的高度专注练习；它与"熟练后的自动重复"有本质区别。 |

## 中期（31–60）：社会、发展、人格与临床

| # | 概念 | 一句话定义 |
| ---: | --- | --- |
| 31 | [[印象形成]] | 印象形成是人们根据有限信息快速构建对他人整体评价的过程；它高效但充满捷径——首因效应、晕轮效应与负面信息权重都会系统塑造判断。 |
| 32 | [[从众]] | 从众是当个人判断与群体不一致时，改变自己的行为或信念以趋同群体的现象；它分信息性影响（群体提供了信息）与规范性影响（群体施加了压力）。 |
| 33 | [[服从]] | 服从是个人在权威指令下改变行为、执行违背自身判断要求的现象；米尔格拉姆实验震惊地显示，情境压力足以让普通人做出伤害性行为。 |
| 34 | [[群体思维]] | 群体思维是高度内聚的群体为追求一致而压制异议、高估自身、忽视风险与替代方案的决策缺陷；它让聪明人组成的团队做出灾难性决定。 |
| 35 | [[旁观者效应]] | 旁观者效应是紧急事件中在场人数越多、单个人施救可能性反而越小的现象；原因包括责任分散、多元无知与评价恐惧。 |
| 36 | [[社会认同]] | 社会认同是"我是谁"中来自群体成员资格的部分：我们不仅作为个体存在，也作为某些群体的成员而行动，群体的成败会被体验为自身的成败。 |
| 37 | [[刻板印象]] | 刻板印象是对某群体成员的概括性信念——它有认知上的省力功能，却会系统扭曲个体判断，并在"刻板威胁"下通过预期自我实现影响被标签者的表现。 |
| 38 | [[助人行为]] | 助人行为是使他人受益的自愿行动；从紧急施救到日常互助，它受情境（时间压力、在场人数）、认知（是否注意到并判断为紧急）与个体（共情、人格）多重因素调节。 |
| 39 | [[依恋]] | 依恋是婴儿与主要照护者之间形成的情感纽带，其质量（安全型、回避型、矛盾型、混乱型）通过"内部工作模型"影响一生的亲密关系、信任风格与压力应对。 |
| 40 | [[认知发展]] | 认知发展研究儿童与青少年的思维如何随年龄质变——皮亚杰的阶段论（感知运动、前运算、具体运算、形式运算）与维果茨基的"最近发展区"是两大经典框架。 |
| 41 | [[道德发展]] | 道德发展研究人的道德推理与道德行为如何随年龄变化——科尔伯格提出从"避罚服从"经"好孩子/法律秩序"到"普遍原则"的阶段序列，而现代研究更强调道德直觉与社会学习。 |
| 42 | [[大五人格]] | 大五人格是经过词汇与因子分析收敛出的五个人格维度——开放性、尽责性、外向性、宜人性、神经质（OCEAN）；它在跨文化研究中可重复，是现代人格测量的主流框架。 |
| 43 | [[需要层次]] | 马斯洛需要层次把人的动机从生理、安全、归属、尊重排到自我实现；现代观点放弃严格的"逐级满足"顺序，但保留核心洞见：低层需要受威胁时，高层动机让位。 |
| 44 | [[情绪智力]] | 情绪智力是感知、理解、运用与调节自己及他人情绪的能力，通常包括自我觉察、自我管理、社会觉察与关系管理四个分支。 |
| 45 | [[自尊]] | 自尊是对自我整体价值的评价与感受；它分"我不错"的状态自尊与稳定的特质自尊，过高与过低都可能带来问题，健康的自尊建立在真实能力与关系接纳之上。 |
| 46 | [[防御机制]] | 防御机制是心理为缓冲焦虑、维护自我形象而自动启动的无意识策略——压抑、否认、投射、合理化、理智化等；它们短期止痛，长期可能扭曲现实感。 |
| 47 | [[心理障碍]] | 心理障碍是显著偏离常态、伴随痛苦或功能损害的心理行为综合征；它由生物、心理与社会因素共同促成，诊断体系（DSM/ICD）是描述性分类而非终极真理。 |
| 48 | [[抑郁]] | 抑郁（重性抑郁障碍）是持续两周以上、几乎每天存在的低落或兴趣丧失，伴随睡眠食欲变化、精力下降、自责与注意困难等症状群，并显著损害功能。 |
| 49 | [[成瘾]] | 成瘾是明知有害仍持续、强迫性地使用物质或从事行为，其特征是耐受（需更多才满足）、戒断与失控；多巴胺驱动的"想要"与"喜欢"的分离是其神经机制的核心。 |
| 50 | [[创伤]] | 创伤指超出寻常应对能力的严重事件及其心理后果；许多人会自然恢复，部分人发展出创伤后应激障碍（PTSD）——闯入性回忆、回避、负性认知改变与过度警觉。 |
| 51 | [[心理治疗]] | 心理治疗是受过训练的专业人员通过谈话与关系，帮助来访者缓解痛苦、改善功能的循证过程；主流取向包括认知行为、人本、心理动力学与系统式治疗。 |
| 52 | [[认知行为疗法]] | 认知行为疗法（CBT）认为情绪困扰源于对事件的解释（认知）与应对（行为），通过识别并检验自动思维、做行为实验来改变恶性循环；它是证据最强的心理治疗取向之一。 |
| 53 | [[正念]] | 正念是对当下经验不加评判的、有意的觉察——注意到思绪来了又走而不被卷走；它源自佛教冥想传统，已被去宗教化为有实证支持的注意力与情绪调节训练。 |
| 54 | [[心理韧性]] | 心理韧性是面对逆境、创伤或持续压力时良好适应并恢复的能力；它不是固定人格特质，而是可被保护因素（关系、意义、调节策略）培养的动态过程。 |
| 55 | [[神经可塑性]] | 神经可塑性是大脑根据经验持续重组自身的能力——突触加强或削弱、神经回路迁移功能；它终生存在，是学习、记忆与康复的神经基础。 |
| 56 | [[神经科学]] | 神经科学研究神经系统如何产生行为与心理——从神经元、突触与神经递质，到脑区网络与意识；它给心理学提供机制层，但"脑区激活"不等于"心理原因"。 |
| 57 | [[认知老化]] | 认知老化是成年后期流体智力（加工速度、工作记忆、新异问题解决）的逐步下降，而晶体智力（知识、词汇、经验判断）常保持甚至增长；下降轨迹高度个体化且受生活方式调节。 |
| 58 | [[拖延]] | 拖延是明知该做却推迟开始，常伴随即时安慰与后续痛苦的行为模式；它的核心不是时间管理差，而是情绪调节问题——任务引发的焦虑被"现在不做"暂时缓解。 |
| 59 | [[安慰剂效应]] | 安慰剂效应是仅因"相信接受了有效治疗"而产生的真实身心改善；它并非"想象出来的"，而有真实神经机制（期望改变疼痛与奖励加工），是治疗效果的组成部分。 |
| 60 | [[社会支持]] | 社会支持是来自他人的情感关心、实际帮助与信息建议；它是压力与健康之间最重要的缓冲变量——感知到的支持比"实际收到的支持"更能预测健康。 |

## 下期（61–90）：学习科学、人因与数字时代

| # | 概念 | 一句话定义 |
| ---: | --- | --- |
| 61 | [[学习科学]] | 学习科学是融合认知心理学、神经科学、教育学与计算机科学的交叉领域，研究人如何真实地学习，并把证据转化为教学、课程与学习技术设计。 |
| 62 | [[主动回忆]] | 主动回忆是合上材料、从记忆中提取答案的学习方式（自测、默写、讲解），它比同等时间的重读产生更强、更持久的记忆——这就是测试效应。 |
| 63 | [[间隔重复]] | 间隔重复是把复习分散到逐渐拉长的间隔（1 天、3 天、1 周、1 月…）的学习策略；它在记忆将忘未忘时复习，用最少次数获得最长保持，对抗遗忘曲线的效率远超集中突击。 |
| 64 | [[自我调节学习]] | 自我调节学习是学习者主动地计划（设定目标与策略）、监控（评估理解与进度）并调整（更换策略）自己学习过程的循环；它是自主学习能力的核心。 |
| 65 | [[成长型思维]] | 成长型思维是相信能力可以通过努力与学习发展的信念（与"固定型思维"相对）；它影响人对挑战、失败与反馈的态度——但近年的可复现性质疑要求我们谨慎理解其效应。 |
| 66 | [[专家技能]] | 专家技能是领域内长期发展出的卓越表现能力；专家与新手的关键差异不是"知道更多事实"，而是知识按深层结构组织、模式识别自动化、问题表征更抽象。 |
| 67 | [[情境学习]] | 情境学习认为知识不是脱离情境的抽象物，而是在特定实践共同体中、通过参与真实活动被学会的；学习者是"合法的边缘参与者"——先在外围看，再逐步承担核心任务。 |
| 68 | [[认知科学]] | 认知科学是研究心智与智能的交叉学科——心理学、神经科学、计算机科学、语言学与哲学共同回答"认知是什么、如何实现"；它的核心框架是心智的计算-表征观。 |
| 69 | [[联结主义]] | 联结主义主张认知由大量简单单元（类神经元）的并行连接与权重调整实现，而非符号规则的串行计算；深度学习是联结主义在当代的工程胜利。 |
| 70 | [[认知神经科学]] | 认知神经科学通过脑成像（fMRI、EEG）、损伤研究与神经调控，把心理过程映射到神经回路，研究"认知的脑实现"；它是心理学与神经科学之间的桥梁。 |
| 71 | [[人为因素]] | 人为因素（人因工程）是研究人与系统交互的科学：把人的认知、感知与身体能力作为设计输入，使工具适配人，而非要求人适配工具；"人为错误"常是系统设计失败的标签。 |
| 72 | [[心智模型]] | 心智模型是人对系统如何运作的内在简化表征——"点击这个会发生什么""数据存到哪里"；当界面与用户心智模型一致时操作流畅，不一致时错误频发。 |
| 73 | [[自动化偏差]] | 自动化偏差是人在自动化系统出错时倾向于信任其输出、忽略相反证据、放弃自行核查的现象；它是自动化提高效率的同时引入的新型人为错误。 |
| 74 | [[人机信任]] | 人机信任是人对自己依赖的系统会按预期工作的信念；健康的信任是"校准的信任"——信任水平与系统真实可靠性匹配；过度信任（自动化偏差）与信任不足（弃用）都会导致事故。 |
| 75 | [[决策疲劳]] | 决策疲劳是持续做选择后自我控制与判断质量下降的状态——每做一个决策都消耗有限的自我调节资源，表现为回避决策、仓促决定或选择质量下降。 |
| 76 | [[游戏化]] | 游戏化是把游戏元素（积分、徽章、等级、进度条、挑战与反馈）应用于非游戏场景以影响动机与行为的设计实践；它有效与否取决于是否服务于内在动机，而非贴一层积分皮肤。 |
| 77 | [[神经多样性]] | 神经多样性主张自闭谱系、ADHD、阅读障碍等神经差异是人类认知的自然变异，而非需要"修复"的缺陷；它从"缺陷模式"转向"差异模式"，重视优势与环境的匹配。 |
| 78 | [[多任务处理]] | 真正的并行多任务在多数认知任务上并不存在——人做的是快速任务切换，而每次切换都有代价（时间损失、错误上升、上下文重建）；"擅长多任务"往往是擅长快速切换与掩盖代价。 |
| 79 | [[情境意识]] | 情境意识是操作者对"当前正在发生什么、意味着什么、接下来会怎样"的实时理解（感知-理解-预测三层）；它是飞行员、手术医生与运维值班员在动态系统中正确决策的前提。 |
| 80 | [[信息过载]] | 信息过载是可用信息量超出个人处理能力的状态——注意被稀释、判断被噪音干扰、决策质量下降；"信息越多越好"在认知有限的个体层面并不成立。 |
| 81 | [[群体极化]] | 群体极化是群体讨论后成员的立场比讨论前更极端的现象——倾向保守的群体更保守，倾向激进的群体更激进；讨论不会天然带来中庸，反而常常放大初始倾向。 |
| 82 | [[错误信息]] | 错误信息（假信息）研究关注虚假或误导内容为何被相信与传播——不是"人们太笨"，而是认知捷径、情绪驱动与社交奖励共同作用的可预测产物。 |
| 83 | [[数字成瘾]] | 数字成瘾指对社交媒体、游戏、短视频等数字产品形成强迫性使用——失控、戒断难受、挤占生活功能；它借用成瘾机制（可变强化、社交奖励、FOMO），但学界对其是否等同物质成瘾仍有争议。 |
| 84 | [[技术压力]] | 技术压力是新技术引发的适应压力——信息过载、随时在线的侵入感、技能更新的追赶焦虑、以及"技术故障时"的失控感；它解释了许多人"用着最先进工具却最累"的悖论。 |
| 85 | [[网络去抑制]] | 网络去抑制指人们在线上做出线下不会做的言行——或更友善（良性去抑制），或更攻击、更露骨（毒性去抑制）；匿名性、不见对方、异步与身份表演解除了社会抑制。 |
| 86 | [[可复现性危机]] | 可复现性危机指心理学（及其他科学）中大量已发表结果无法被重复验证的现象；其根源是研究实践的系统性偏差——p 值滥用、样本不足、发表偏倚与可疑研究操作。 |
| 87 | [[效应量]] | 效应量是量化效应"有多大"的指标（如 Cohen's d：两组均值差除以标准差）；它独立于样本量，回答"显著之后，到底差多少"，是解释研究结果的必要信息。 |
| 88 | [[心理健康素养]] | 心理健康素养是识别心理困扰、知道如何求助、了解常见心理疾病知识与减少污名的能力；它决定了从"我最近不对劲"到"我去寻求专业帮助"之间的路径是否通畅。 |
| 89 | [[跨文化心理]] | 跨文化心理研究心理过程在不同文化中的异同——从认知、情绪到自我观与道德判断；它提醒我们：许多"普遍心理规律"其实只在特定文化样本中被验证过。 |
| 90 | [[心智素养]] | 心智素养是把心理与认知科学内化为三种能力——理解自己的心智（学习、情绪、动机）、设计适配他人的系统（人因、产品、沟通）、并抵御对心智的滥用（操纵、成瘾、假信息）——它是这 90 张卡的收束站。 |
