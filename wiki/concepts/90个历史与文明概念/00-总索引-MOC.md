## 上期（01–30）：历史与史学基础——史料、方法与文明起点

| # | 概念 | 一句话定义 |
| ---: | --- | --- |
| 01 | [[历史]] | 历史一词兼指"过去本身"（发生的事情）与"对过去的书写与研究"（historia）——我们无法直接接触前者，只能经由史料与叙述接近它；因此历史既是事实之学又是解释之学：它要求敬畏证据、承认叙述的立场，并在"过去确实如此"与"我们只能如此讲述"之间保持张力。 |
| 02 | [[史料]] | 史料是过去遗留下来、可供历史研究的一切痕迹：文字（档案、史书、信件、碑刻）与实物（遗址、器物、图像、口述录音）——史料学的基本功是辨伪（它真是那个时代的产物吗？）、辨类（一手同时代记录 vs 二手转述？）、辨语境（谁在什么场合为什么留下它？）；没有史料就没有历史，但史料从不"自己说话"。 |
| 03 | [[考古学]] | 考古学是通过发掘与分析物质遗存（遗址、器物、骨骼、碳屑）重建过去之学：它让没有文字或文字失传的文明（史前、夏商、玛雅）开口说话，也用地层学、类型学与科学测年（碳-14、DNA、同位素）为文献史提供独立验证——考古学是历史学中最"理工科"的分支：一半是田野手艺，一半是实验室科学。 |
| 04 | [[档案]] | 档案是机构在职能活动中自然形成、被系统保存以备查考的原始记录（官府文书、企业账册、会议纪要、人事卷宗）——与史书不同，档案是"办事的副产品"而非"写给后人的作品"，因此成为历史研究最可信赖的史料类型；档案学的核心问题随之而来：什么被保存、什么被销毁、谁有权查阅（密级、开放期限与"档案政治"）。 |
| 05 | [[口述史]] | 口述史是通过访谈采集亲历者记忆来研究历史的方法：它让没有书写能力或未被文献记录的人（工人、农民、妇女、少数群体）进入历史，也记录重大事件的在场体验（大屠杀证词、三线建设者口述、航天工程亲历）——口述史料的特征：鲜活而主观、有记忆变形与时代滤镜，须与文献互证；访谈伦理（知情同意、录音版权、创伤保护）是它的职业底线。 |
| 06 | [[史学史]] | 史学史是"历史学自身的历史"：从希罗多德的叙事、中世纪的编年与神意史观、兰克的科学史学、马克思主义史学、年鉴学派到后现代主义与全球史——它追问的不是"过去发生了什么"，而是"人们如何书写过去、为何这样书写"；每个时代的历史书写都折射那个时代的关怀与权力结构。 |
| 07 | [[兰克学派]] | 兰克学派指德国史家兰克开创的现代专业史学传统：主张历史学家基于原始档案、经严格史料批判、"如实直书"（wie es eigentlich gewesen），追求客观地重建过去——它把历史从文学与神学中独立为大学学科（ seminar 研讨班制度），确立"以档案为据、注脚说话"的学术规范，成为 19 世纪全球史学的样板，也因聚焦政治外交史与"客观性"理想而受后世批评。 |
| 08 | [[年鉴学派]] | 年鉴学派是 20 世纪法国主导的史学革命（1929 年布洛赫与费弗尔创办《年鉴》杂志）：反对兰克式政治事件史，主张"总体史"——研究经济、社会、心态与日常，向社会科学（地理、经济、人口、人类学）开放方法；布罗代尔提出三层时间（长时段的地理时间、中时段的社会时间、短时段的事件时间），把历史从"王侯将相"改写为"结构、气候与普通人"。 |
| 09 | [[长时段]] | 长时段（longue durée）是布罗代尔的时间分层理论之首：历史时间分三层——长时段（近乎不动的结构：地理、气候、生物节律，变化以世纪计）、中时段（社会经济的周期与趋势：价格波动、人口涨落，以十年百年计）、短时段（事件：战争、政变、发布会，以日年计）；历史研究应把事件放回结构中解释，因为"事件是粉尘，结构才是山脉"。 |
| 10 | [[历史主义]] | 历史主义主张"一切事物都是历史的产物、须在其时代语境中被理解"：从维柯"各民族的世界确实是人类自己创造的"、赫尔德的文化个性论到兰克"每个时代都直接面对上帝"（每个时代自有其价值）——它反对用今人标准审判古人（"时代错置"），强调理解先于评判；它同时被批判为相对主义（若一切皆时代产物，还有普遍真理吗？）——这个张力至今是历史理解的底色。 |
| 11 | [[历史解释]] | 历史解释是回答"为什么会这样"的史学活动：解释的类型包括因果解释（追原因）、意图解释（看当事人的动机与理由）、结构解释（找制度与环境的约束）、功能解释（问它起了什么作用）；历史解释的独特难题——原因的多重性（一战有几十种"起因"）、反事实的不可检验（"若无此人会怎样"无法实验）、以及解释与叙述不可分（讲什么故事本身就是解释）。 |
| 12 | [[历史决定论]] | 历史决定论主张历史进程受客观规律支配、向着可预知的方向必然发展：黑格尔的"理性的狡计"、马克思的历史唯物主义（生产力决定生产关系）与各种"历史终将…"的叙事都属于这一家族——波普尔在《历史决定论的贫困》中批判它：历史没有可检验的规律（社会预测会改变被预测者），"必然规律"常沦为极权政治的辩护工具；反方则说温和版本只是承认"历史有结构约束"。 |
| 13 | [[大历史]] | 大历史是把宇宙史到人类史整合为一的叙事框架（戴维·克里斯蒂安）：138 亿年从大爆炸、恒星、地球、生命、人类到现代世界的八重门槛叙事，用"复杂性增长与能量流"贯穿各学科（宇宙学、地质学、生物学与历史学）——它给人类一个共同的宇宙故事，也把"人类世"放回地球史的尺度；批评者质疑其宏大叙事的简化与目的论味道。 |
| 14 | [[全球史]] | 全球史以超越民族国家为单位研究跨地区联系、交流与互动的历史：它关注物种传播（哥伦布交换）、贸易网络（丝绸之路、白银流通）、人员流动（移民、奴隶贸易）、思想传播（印刷术、革命观念）与疾病扩散（黑死病、大流感）——全球史反对"容器史观"（把历史装进国家盒子），主张联系先于单元：不是先有独立的文明再互相影响，而是互动本身塑造了各方。 |
| 15 | [[微观史学]] | 微观史学通过放大一个"小对象"（一个人、一个村庄、一次审判、一件器物）来回答大问题：意大利学派（卡洛·金兹伯格）的《奶酪与蛆虫》从磨坊主梅诺基奥的异端思想窥见平民文化与印刷术的碰撞——它的方法论是"例外即正常"（反常个案暴露常规结构）与"线索范式"（从细节追踪，像侦探一样推理），用显微镜看世界，答案却关乎整个时代。 |
| 16 | [[观念史]] | 观念史研究观念（自由、进步、自然、时间、自我）在历史中的诞生、演变与影响：洛夫乔伊开创的"观念单元"追踪法寻找贯穿思想史的恒定要素；剑桥学派（斯金纳）则反对把观念当永恒实体——主张每个思想都是对特定时代问题的"言语行动"，须还原到论战语境；观念史因此不只是哲学史，而是"人们用什么概念想问题、概念又如何反过来塑造人"的历史。 |
| 17 | [[环境史]] | 环境史研究人与自然关系的历史：自然如何塑造人类社会（气候、土壤、疾病决定文明的可能边界），社会又如何改造自然（农业扩张、森林砍伐、河流改道、碳排放）——它把"环境"从背景板变成历史主角（克罗斯比《哥伦布交换》、沃斯特对 Dust Bowl 的研究），并追问"自然史"与"人类史"如何合流成同一部历史。 |
| 18 | [[集体记忆]] | 集体记忆是社会群体对其同享过去的选择性建构与维持（哈布瓦赫）：家庭聚餐讲的故事、纪念碑、纪念日、教科书与电影共同塑造"我们记得什么、如何记得"——集体记忆不等于历史（历史求证据，记忆求认同），却是历史的燃料与对手：记忆被当下需要不断重写（"过去的形象随现在的信仰变化"），也常被权力动员（国族记忆工程）。 |
| 19 | [[农业革命]] | 农业革命是约一万年前人类从采集狩猎转向作物种植与动物驯化的转变——考古学称之为"新石器革命"（柴尔德）：它先在几个独立中心发生（西亚新月沃地、中国、中美洲等），带来定居、剩余、人口增长、阶级分工与城市国家，被长期赞颂为"进步"；但"农业是史上最大的错误"论（戴蒙德）提醒：早期农民身材更矮、疾病更多、劳作更苦——农业革命的账本远比"进步叙事"复杂。 |
| 20 | [[城市化]] | 城市化是人口向城市集中、城市生活方式扩张的历史进程：从公元前 3500 年两河流域的乌鲁克、古典时代的罗马百万人口，到工业革命后的爆炸性增长与今天的"城市世纪"（全球过半人口居城）——城市是权力、市场与创新的聚集器，也是疾病、污染与不平等的放大器；每次城市化浪潮都由技术与经济转型驱动（农业剩余→工业就业→服务业与知识经济）。 |
| 21 | [[文字]] | 文字是思想的体外存储系统：从苏美尔泥板记账符号（前 3200 年）、埃及圣书体、中国甲骨文到字母表的诞生——文字让知识跨越时空与个体大脑（"记忆的外挂"），使法律、经典、科学积累成为可能；文字系统的演化（表意→表音、书写成本下降）与社会权力深度纠缠：谁掌握文字谁掌握行政与神圣，识字率的扩张（印刷术、义务教育）本身就是一部权力再分配史。 |
| 22 | [[历法]] | 历法是人类组织时间的制度性技术：以天文周期（太阳回归年、朔望月）为基准，通过置闰调和，让社会活动（农时、节庆、税期、祭祀）可预期——历法从来不只是天文学：改历即政治（凯撒的儒略历、格里高利历改革、辛亥革命改用公历），历法之争是权力之争（谁规定"今天"属于谁的神与王）；它把自然时间变成社会时间，是"时间政治"的起点。 |
| 23 | [[国家起源]] | 国家起源回答"强制性公共权力从何而来"：考古学显示约五千年前（美索不达米亚、埃及、中国、中美洲）出现首批国家——理论竞争激烈：灌溉论（治水需要大规模协作——魏特夫"东方专制主义"）、冲突论（战争与征服催生等级——卡内罗"限制理论"）、内部分层论（剩余与分工产生阶级，国家保护有产者）、契约论（社会契约的哲学版本）与斯科特的"国家视角"反思（国家是"谷物化"定居者的发明，驯化人民如驯化作物）。 |
| 24 | [[青铜时代]] | 青铜时代（约前 3300–前 1200 年）是以铜锡合金为标志性材料的技术-社会阶段：青铜坚硬可铸，却需远程贸易（锡是稀有资源——塞浦路斯"铜岛"、阿富汗锡矿）与专门工匠，因此青铜天然与精英绑定（武器、礼器、奢侈品）——"青铜时代文明"（埃及、赫梯、迈锡尼、商周）是第一批"全球化"：远距离资源网络、宫廷手工业与国家战争；其终结（约前 1200 年"海上民族"大崩溃与商周之际）常被当作青铜时代体系的崩塌案例。 |
| 25 | [[轴心时代]] | 轴心时代是雅斯贝尔斯提出的概念：公元前 800–前 200 年间，几个互不相通的文明几乎同时发生精神突破——中国（孔子、老子）、印度（佛陀、奥义书）、波斯（琐罗亚斯德）、巴勒斯坦（犹太先知）与希腊（哲学家）各自出现超越性追问（是非、生死、终极实在），奠定此后两千多年人类思想的基本框架；"轴心"的谜题在于：为何同时？以及现代性是否构成"第二轴心"。 |
| 26 | [[帝国]] | 帝国是以一个中心（都城、王朝或民族）统治广袤多样疆域与民众的政治体：罗马、秦汉、蒙古、奥斯曼、大英帝国——帝国的机制在于"间接统治"（核心区直接治理、边缘区纳贡自治）、差异化管理（宗教与法律多元，只要效忠纳税）与基础设施整合（道路、文字、度量衡、驿站）；帝国史研究近年翻转视角：不再只讲"中心的光荣"，而讲"边缘的能动"与帝国作为全球化早期框架的作用。 |
| 27 | [[封建主义]] | 封建主义指中世纪欧洲以土地换效忠的政治-社会结构（封君封臣制）：国王把土地（采邑）封给领主，领主宣誓效忠并服兵役，领主再分封给下级骑士，农民（农奴）束缚于土地提供劳役——权力随土地层层下放（"我的附庸的附庸不是我的附庸"），中央权威稀薄；它由西罗马帝国崩溃后的暴力碎片化催生，以军事（重装骑兵）、庄园经济与基督教文化为支柱；比较史提醒：中国"封建"（封邦建国）与欧洲 feudalism 含义不同，用法须谨慎。 |
| 28 | [[行会]] | 行会是中世纪城市中间业者的自治组织：规定产品质量、价格、学徒年限与从业资格（师傅- journeyman -学徒三级），垄断本地市场并管理成员生老病死——行会同时是经济卡特尔（限制竞争、排斥外人）与社会保障网络（互助、葬礼、礼拜）与政治力量（城市议会席位）；它的兴衰解释了两件大事：欧洲城市自治与"工匠精神"传统如何形成，以及近代自由市场为何以打垮行会为前提。 |
| 29 | [[大学]] | 大学是中世纪欧洲的独特发明（博洛尼亚 1088、巴黎、牛津）：由教师与学生组成的自治社团（universitas），以"自由探究"为理念、以学位（学士-硕士-博士）认证知识——它把教育从修道院与宫廷解放为制度化的知识生产机构；大学的千年史是一部与社会关系的再谈判史：经院哲学（与宗教）、启蒙与民族国家（与政治）、工业革命（与产业）、20 世纪（与研究经费、大众化）——今天"大学为何存在"的争论（通识 vs 就业、论文 vs 教学）是这场谈判的最新回合。 |
| 30 | [[度量衡]] | 度量衡是长度、容量、重量的统一标准体系：从"布手知尺""掬手为升"的身体单位，到秦始皇"书同文、车同轨、统一度量衡"、英国《大宪章》要求全国统一尺度，再到法国大革命创立的米制（以地球子午线定义米、以水定义千克）与 2019 年国际单位制全面转向物理常数定义——度量衡史是"标准化=国家权力+市场信任+科学基础"的三合一叙事。 |

## 中期（31–60）：文明与近代转型——从古典文明到全球秩序

| 31 | [[希腊城邦]] | 城邦（polis）是古希腊以小规模公民共同体为核心的政治形态：一座城、一片乡野与一群"公民"（成年男性自由民）构成自足的"政治动物"世界——雅典的民主（公民大会、抽签官职）、斯巴达的军事共同体是它的两极；城邦的独特性：公民以言说与辩论参与公共事务（广场、剧场、法庭），孕育了哲学、史学、戏剧与科学（"希腊奇迹"的制度基础）；其局限同样刺眼：妇女、奴隶与外邦人被排除在"公民"之外。 |
| 32 | [[罗马帝国]] | 罗马帝国是从台伯河畔城邦扩张为环地中海霸权的古典超级大国（前 27–476 西罗马）：它的成就——法律（万民法与《民法大全》）、工程（大道、高架渠、混凝土穹顶）、行政（行省制与军团）与"罗马和平"（Pax Romana）；它的谜题——为何崩溃？吉本归咎于"蛮族与宗教"，当代研究指向经济（奴隶制与税负）、瘟疫（安东尼与西普里安大瘟疫）、气候（晚古小冰期）与边防成本——罗马的兴衰是"大系统韧性"的千年案例。 |
| 33 | [[拜占庭]] | 拜占庭帝国是东罗马帝国的延续（330–1453，都君士坦丁堡）：当西罗马崩溃进入"黑暗时代"，它以罗马法（查士丁尼《民法大全》）、希腊学术与基督教正统延续古典文明近千年——它的历史角色：欧洲的东方屏障（数次挡住波斯、阿拉伯与突厥的冲击）、斯拉夫世界的文明之母（西里尔字母与东正教）、丝绸之路的终点市场；1453 年陷落于奥斯曼，其学者西逃带去的希腊文献成为文艺复兴的燃料。 |
| 34 | [[伊斯兰文明]] | 伊斯兰文明是 7 世纪以来以伊斯兰教为纽带、跨欧亚非的文明体系：从阿拉伯半岛兴起（穆罕默德与四大哈里发）、倭马亚与阿拔斯王朝的"黄金时代"（巴格达"智慧宫"翻译希腊典籍）、到奥斯曼、萨法维与莫卧儿三大帝国——它的文明成就不止宗教：代数（花拉子米）、光学（伊本·海赛姆）、医学（伊本·西那《医典》）、天文与地理学皆领先数百年，并作为"知识中转站"把印度数字与希腊科学传给欧洲（"伊斯兰桥梁论"）。 |
| 35 | [[中华文明]] | 中华文明是东亚以黄河长江流域为核心、连续数千年未中断的农业文明：其独特性——文字连续（甲骨文到简体字一脉相承）、政治传统连续（秦以来"大一统"郡县制国家反复重建）、以儒家为核心的价值体系与科举-士大夫的治理模式；"何以延续"（与罗马、印度对照）与"何以在近代落后"（李约瑟问题）是两大经典之问；当代考古（良渚、二里头、三星堆）正不断改写其起源叙事——从"黄河中心"到"多元一体"。 |
| 36 | [[科举制度]] | 科举是隋唐至清末（605–1905）中国以考试选拔官员的制度：分科取士（明经、进士等），历经乡试、会试、殿试三级，以儒家经典与诗赋策论为内容——它把官员选拔从门阀世袭转向"机会开放"（原则上不论出身），创造"朝为田舍郎，暮登天子堂"的社会流动，维系了中央集权与儒家意识形态的统一；其代价：考试内容僵化（八股）、压制实用知识（算学、工学不入正途）、全社会投入的"科举内卷"。 |
| 37 | [[朝贡体系]] | 朝贡体系是古代东亚以中国为中心的国际秩序：周边政权（朝鲜、越南、琉球及更远的"藩属"）定期遣使"称臣纳贡"，中国"册封回赐"（赏赐常远超贡品价值）——它名义上是君臣等级，实际运作常是贸易网络（贡使即商队）与安全安排（中国保护藩属、不干涉内政）；"事大字小"的儒家外交让东亚维持了数百年相对稳定；19 世纪它与西方主权国家体系相撞（中法越南之争、甲午朝鲜之争），最终解体——"朝贡 vs 威斯特伐利亚"成为理解东亚近代转型的钥匙。 |
| 38 | [[王朝循环]] | 王朝循环是中国传统史观与历史现象：新朝开国（清明、均田、轻徭薄赋）→ 盛世（人口增长、版图扩张）→ 中期危机（土地兼并、财政恶化、官僚腐化）→ 衰世（民变、外患、天灾共振）→ 改朝换代——"其兴也勃焉，其亡也忽焉"；史家以"天命转移"解释（失德则失天命），现代研究则寻找结构性机制：人口-土地比例（马尔萨斯压力）、财政汲取能力（黄宗羲定律：税改越改越重）、以及气候波动（小冰期与王朝崩溃的相关性研究）。 |
| 39 | [[丝绸之路]] | 丝绸之路是贯通欧亚大陆的交通-贸易-文化网络（并非一条路）：从西汉张骞凿空西域（前 138 年）到蒙古帝国时代的"重新统一"，丝绸、瓷器、香料、马匹、纸张沿陆上与海上丝路流动，佛教、伊斯兰教、聂斯脱里派基督教与科学技术随之传播，驿站、商队与季风帆船构成其物流体系——丝路的本质不是"中国出口丝绸"而是欧亚非文明持续互动的骨架；它塑造了"世界史"最早的全球化（公元前后至 1500 年）。 |
| 40 | [[蒙古帝国]] | 蒙古帝国是 13 世纪由成吉思汗创建的史上最大连续陆地帝国（横跨太平洋到大西洋岸边）：以骑兵机动、十进制军政组织与"恐怖+宽容"双重策略横扫欧亚——它的历史双重性：屠城（花剌子模、巴格达陷落）与"蒙古和平"（Pax Mongolica：丝路重新贯通，马可·波罗、拉班·扫马等旅行者横穿亚洲，纸钞、黑火药、印刷术沿帝国网络西传）；帝国分裂为四大汗国后，其遗产（驿站、商贸、技术传播）仍塑造了近代世界的黎明。 |
| 41 | [[哥伦布交换]] | 哥伦布交换指 1492 年后新旧大陆之间生物与物种的大规模双向迁移：美洲作物（玉米、马铃薯、甘薯、辣椒、番茄）传入欧亚非，欧亚的动物与作物（马、牛、小麦、甘蔗）与病菌（天花、麻疹）传入美洲——它重构了全球人口与农业版图（爱尔兰马铃薯、意大利番茄、中国玉米番薯——"哥伦布交换"养活了旧大陆数亿新增人口，却让美洲原住民因传染病损失九成人口）；这是"全球化"的第一波生物基础。 |
| 42 | [[大航海时代]] | 大航海时代（约 15–17 世纪）是欧洲人系统突破大洋、建立全球航路的时代：葡萄牙沿非洲南下（迪亚士、达伽马抵印度 1498），西班牙西航（哥伦布 1492、麦哲伦环球 1519–1522），随后荷英法跟进——驱动因素：对香料与黄金的需求、奥斯曼阻断陆路的说辞（实则欧洲人想绕开中间商）、航海技术（罗盘、星盘、卡拉克帆船）与国家赞助；它把世界从"旧世界的欧亚网络"改写为"全球海洋网络"，欧洲从此占据中心位置直到 20 世纪。 |
| 43 | [[文艺复兴]] | 文艺复兴（14–17 世纪）是欧洲以"复兴古典"为旗号的文化-思想运动：从意大利（佛罗伦萨、威尼斯）发源，彼特拉克"重新发现"西塞罗与古典拉丁，到人文主义学者收集希腊罗马手稿、艺术家（达·芬奇、米开朗琪罗、拉斐尔）与科学家（哥白尼在波兰、伽利略在意大利）革新视野——"复兴"其实是发明：借古典之名确立人的价值（人文主义）、现实观察与个体尊严，为近代科学、艺术与个人主义奠基。 |
| 44 | [[宗教改革]] | 宗教改革是 16 世纪撕裂西方基督教世界的运动：马丁·路德 1517 年张贴《九十五条论纲》抗议赎罪券，主张"唯独信心、唯独恩典、唯独圣经"——人人可直接读经（不必经教士中介），随后加尔文（日内瓦）、茨温利及英国国教各自成派；它导致的后果远超神学：教随国定（欧洲政治版图重组）、三十年战争（1618–1648）、对权威的普遍怀疑传统（新教伦理与资本主义精神之争）、以及识字率与印刷书的爆炸（人人需读圣经）。 |
| 45 | [[人文主义]] | 人文主义（humanism）是文艺复兴兴起的价值与学问传统：以"人"为尺度——人的价值、尊严、理性与现世幸福值得关注（彼特拉克"我只要求灵魂知道自己"、皮科《论人的尊严》宣告人可自我塑造）；在学问上它表现为"人文学"（studia humanitatis：文法、修辞、历史、道德哲学）——研究人的表达与行动而非只研究神；其近代流变：启蒙的理性人文主义、19 世纪的历史人文主义（洪堡教育理想）、20 世纪对"人类中心主义"的批判（生态、后人类）——"何以为人"的答案始终在更新。 |
| 46 | [[启蒙运动]] | 启蒙运动是 17–18 世纪欧洲以"理性"为旗帜的思想运动：康德定义"启蒙是人类脱离自己造成的不成熟状态——敢于认知（Sapere aude!）"；它主张用理性与经验审查一切权威（教会、国王、传统），代表：洛克（政府契约论）、伏尔泰（宽容与讽刺）、孟德斯鸠（三权分立）、卢梭（社会契约与公意）、狄德罗《百科全书》（知识民主化）与休谟（经验主义怀疑）；它的成果：美国革命与法国革命的原则（人权、法治、分权）、现代科学世界观与公共领域（咖啡馆、报刊、沙龙）——它也是"现代性"的出生证明。 |
| 47 | [[印刷术]] | 印刷术是文字复制技术的革命：中国发明雕版印刷（唐代）与活字（毕昇，北宋 11 世纪），古腾堡 1450 年代在欧洲独立发明金属活字+油墨+压印机（融合葡萄压榨机与硬币冲压技术）——印刷机把书籍成本降低约两个数量级，催生了：宗教改革（路德论纲两周传遍德意志）、科学革命（哥白尼、维萨留斯的著作精确传播，同行评议的雏形）、民族语言与民族意识（方言出版物）、以及"公共领域"（报刊、小册子——信息不再由教会与宫廷垄断）；麦克卢汉说印刷术塑造了民族主义与个人主义——它是"信息爆炸"的第一次。 |
| 48 | [[三角贸易]] | 三角贸易指 16–19 世纪大西洋世界的循环贸易体系：欧洲（工业品：枪支、布匹、酒）→ 非洲（买奴——酋长与商人的合作）→ 美洲（贩卖黑奴为种植园劳动力，换取蔗糖、烟草、棉花、金银）→ 欧洲（精制与再出口）——"三角"是简化模型（实际航线复杂，也有直接两角贸易）；其规模：约 1250 万非洲人被贩运（途中死亡率 10–20%，"中间通道"是人类史上最大的强迫迁徙之一）；它喂饱了欧洲工业革命（糖与棉的原料与市场、资本积累）与美洲种植园经济，代价是非洲的长期创伤。 |
| 49 | [[奴隶制]] | 奴隶制是把人作为财产的制度——几乎一切古代文明都有（美索不达米亚、埃及、希腊罗马、中国、非洲、美洲原住民社会亦有战俘奴役）：其形式光谱极广（债务奴役、家内奴、种植园奴、国有奴）；近代大西洋奴隶制（16–19 世纪）因与种族主义、资本主义种植园结合而成为最极端形态之一——"人变成商品"的完整工业化；废除史（海地革命 1804、英国 1833、美国 1865、巴西 1888）是近代道德与政治史上最伟大的转型之一，但当代"现代奴隶制"（强迫劳动、债务奴役、人口贩卖）仍据估数千万人。 |
| 50 | [[殖民主义]] | 殖民主义是强国对异地的征服、定居、资源榨取与政治控制体系：两种基本形态——"移民殖民"（白人定居者社会：北美、澳洲——原住民被驱逐灭绝）与"剥削殖民"（少数官员统治多数土著：印度、非洲——劳力和资源外流）；15 世纪起欧洲扩张（西班牙葡萄牙→荷英法→19 世纪"瓜分非洲"）把世界大部分地区纳入殖民框架，20 世纪中叶去殖民化浪潮（1945–1975）终结了旧殖民帝国，但"新殖民主义"（经济控制、债务、文化霸权）与殖民遗产（边界、制度、心态、创伤）延续至今。 |
| 51 | [[帝国主义]] | 帝国主义指强国以正式或非正式手段扩张支配他国的政策与体系：经典阶段是 1870–1914 年欧洲列强瓜分非洲与亚洲（"瓜分非洲"会议 1884–85 把非洲画成直线国界）；理论之争：列宁（帝国主义是资本主义的最高阶段——金融资本输出需要海外市场）vs 霍布森（消费不足与寻租利益集团）vs 当代修正（"非正式帝国"：不占领也能支配——门户开放、美元体系）；与"帝国"（上期）的区别：帝国主义是动态的扩张过程与理论，帝国是静态的结构形态。 |
| 52 | [[民族国家]] | 民族国家是"民族"与"国家"重合的政治形态：一个拥有共同认同（语言、历史记忆、文化）的人民，在其主权领土内由统一政府治理——它诞生于近代欧洲（威斯特伐利亚体系承认主权国家，法国大革命把"臣民"变成"公民-民族"），随后扩散全球（去殖民化后亚非国家按民族国家模式建国）；查尔斯·蒂利的名言："战争制造国家，国家制造战争"——民族国家的形成与常备军、税收、官僚制同步；今天它面临挑战：全球化（资本与信息的跨界流动）、超国家组织（欧盟）、次国家认同（地区与族群）——但民族国家仍是世界秩序的基本单位。 |
| 53 | [[民族主义]] | 民族主义是以民族为最高忠诚对象与政治合法性来源的意识形态："民族"先于国家存在并应拥有自己的国家（盖尔纳定义：民族主义发明民族，而非相反）；两种谱系——公民民族主义（法国模式：以宪法与公民权界定成员——可加入）与族裔民族主义（德国模式：以血统语言文化界定——不可选择）；它的双重面孔：被压迫民族的解放旗帜（反殖民、反帝国——19 世纪意大利德意志统一、20 世纪亚非独立）与排外暴力的动员机器（两次世界大战、种族清洗）——"想象的共同体"既是温暖的家也是杀人的理由。 |
| 54 | [[革命]] | 革命是社会政治秩序的剧烈、根本且通常暴力的变革：经典案例——英国革命（1642–88）、法国大革命（1789）、俄国革命（1917）、中国革命（1911 与 1949）、以及 20 世纪的反殖民革命；与政变（换统治者不换制度）、叛乱（局部反抗）、改革（渐变）的区别在于"制度结构的整体更替+新合法性原则"（法国：从君权神授到人民主权）；革命研究的两大问题：为何爆发（斯考切波尔：国家危机+国际压力+阶级结构）与为何走向恐怖或稳定（法国大革命的"热月循环"之谜）。 |
| 55 | [[威斯特伐利亚体系]] | 威斯特伐利亚体系指 1648 年《威斯特伐利亚和约》奠定的国际秩序原则：主权国家平等、互不干涉内政、领土完整与"教随国定"（cuius regio, eius religio）——三十年战争（1618–1648，宗教+王朝大战）后的这套安排结束了欧洲的宗教统一幻想，把世界组织为"平权主权国家"的体系；它被视为现代国际关系的出生证（虽学者争论：和约文本并无"主权"一词——体系是后人的追认建构）；其扩张与危机：殖民时代它只适用于"文明国家"（欧洲之外无主权），联合国宪章（1945）才把主权平等普世化——今天它受全球化与人权干预的挑战，仍是国际法的基石。 |
| 56 | [[明治维新]] | 明治维新是日本 1868 年起以"富国强兵、殖产兴业、文明开化"为纲领的全面近代化改革：倒幕运动推翻德川幕府（王政复古），明治政府以天皇权威为轴心推行——废藩置县（中央集权）、地税改革与秩禄处分（财政基础）、学制与征兵令（1872 义务教育、1873 征兵）、殖产兴业（官营工厂→民营三菱三井）、宪法与议会（1889 大日本帝国宪法）；四十年内日本从锁国封建国变为亚洲第一个工业强国与殖民帝国（甲午、日俄战争）——"东方如何回应西方冲击"的最成功案例，也是军国主义道路的开端。 |
| 57 | [[世俗化]] | 世俗化指宗教从公共生活退场、社会制度与思维方式脱离宗教支配的过程：三个层面——制度世俗化（国家、法律、教育与宗教分离：政教分离、公立学校、世俗婚姻）、组织世俗化（教会影响力下降：礼拜率、信教率下滑）、文化世俗化（宗教世界观让位于科学与人本框架）；经典理论（现代性必然削弱宗教——孔德、韦伯"祛魅"）被 20 世纪后半叶打脸：美国信教率长期高位、全球南方宗教复兴、原教旨主义崛起——"世俗化理论"修正为：现代化削弱的是宗教的制度支配而非宗教需求本身。 |
| 58 | [[进步观念]] | 进步观念是"历史朝着更好方向前进"的信念：它并非古已有之——古典循环史观与基督教末世论都无"进步"（进步需等 17 世纪科学革命后：培根"知识就是力量"、启蒙哲人相信理性改良、孔德与斯宾塞把它系统化为社会进化律）；19 世纪是进步观念的黄金时代（工业革命+达尔文主义提供"科学背书"），20 世纪的两次大战与奥斯维辛重创线性进步信仰（本雅明"历史天使"面朝过去被风暴吹向未来）；今天它仍以科技叙事（奇点、加速主义）与"历史终结论"等形式延续——进步是事实描述还是信仰？ |
| 59 | [[全球化]] | 全球化是人员、商品、资本、信息与观念跨越国界的加速流动与相互依存：历史分期（全球史视角：不是 20 世纪新事——丝路与哥伦布交换是前现代全球化；但 19 世纪蒸汽船与电报、20 世纪后期集装箱与互联网带来"超全球化"）；衡量指标（贸易占 GDP 比、跨国投资、移民、思想引用）；双面评估：全球化使数亿人脱贫（中国融入世界的成就）也扩大不平等（国家间差距缩小、国内差距扩大——皮凯蒂）；它由谁推动（跨国公司与美国霸权——"华盛顿共识"）也可被逆转（1930 年代大萧条后的去全球化、今天的供应链脱钩）——全球化是过程不是终点。 |
| 60 | [[现代化]] | 现代化指传统社会向现代社会转型的过程与理论：经验特征——工业化、城市化、科层化、世俗化、教育普及、民主化；理论谱系——经典现代化理论（1950–60 年代：罗斯托"经济增长阶段论"、帕森斯结构功能主义——现代化是单线普世进程，西方是模板）、依附论与世界体系论（现代化=中心剥削边缘的意识形态）、多元现代性（艾森斯塔特：现代化不等于西方化——日本、中国各自走出独特现代性）、反思现代性（贝克"风险社会"、吉登斯：现代性的后果——制度与风险的失控）。中国的现代化：从洋务到改革开放的"中国式现代化"——后发国家的压缩式转型（几十年走完西方两百年）。 |

## 下期（61–90）：二十世纪与史学运用——冷战、行星纪元与概念的收束

| # | 概念 | 一句话定义 |
| ---: | --- | --- |
| 61 | [[福利国家]] | 福利国家是国家承担公民基本保障的制度形态：俾斯麦 1880 年代首建社会保险（疾病、工伤、养老——目的是收买工人对抗社会民主党），英国 1942 年《贝弗里奇报告》确立"从摇篮到坟墓"的全民保障理想（二战后的 NHS 全民医疗），北欧发展为"普惠型"（高税高福利），美国走"补缺型"（只保穷人——罗斯福新政与 1965 年医疗照顾）——福利国家的三种世界：社会民主主义型（北欧）、保守合作型（德法）、自由主义型（英美）；它把"市场失灵的风险"（失业、疾病、老年）社会化，是 20 世纪资本主义与社会主义之间的"第三条道路"。 |
| 62 | [[冷战]] | 冷战是 1947–1991 年美苏两大阵营间既未直接开战又全面对抗的全球对峙：铁幕（丘吉尔 1946）、柏林危机与封锁、朝鲜战争（1950–53）、古巴导弹危机（1962——人类最接近核毁灭的时刻）、越南战争、太空竞赛与军备竞赛（核威慑、相互确保摧毁）、代理人战争（安哥拉、阿富汗）与意识形态竞赛（自由世界 vs 共产主义）——冷战"冷"在超级大国之间，"热"在代理人战场；其终结（东欧剧变 1989、苏联解体 1991）出人意料地和平，至今是史学与政治学的核心谜题（军备拖垮说、改革失控说、信息开放说）。 |
| 63 | [[去殖民化]] | 去殖民化是 1945–1975 年殖民帝国瓦解、亚非拉国家独立的世界进程：印度（1947，非暴力运动与印巴分治的血腥代价）、印尼、越南（抗法抗美）、非洲（1960"非洲年"17 国独立——加纳的恩克鲁玛"殖民主义必须死亡"）、阿尔及利亚（1962 血腥战争）……约 80 国诞生，联合国会员从 51 增至 150+——它是 20 世纪最宏大的政治重组：世界从此从"帝国时代"进入"主权国家时代"；但"去殖民化"未完成：经济依附（新殖民主义）、边界遗留（非洲直线国界）、文化殖民（语言与教育）与知识去殖民（谁的大学、谁的历史）——"去殖民化"今天更常指后殖民批判的思想工程。 |
| 64 | [[人口转型]] | 人口转型是死亡率先行下降、生育率随后下降、人口从高出生高死亡转向低出生低死亡的过程：欧洲 18 世纪起经历此转型（死亡率先降：卫生、营养、医学——天花疫苗、下水道；生育率滞后 50–100 年下降：城市化、教育、避孕、儿童成活率高使"多生"不再理性）——转型期人口爆炸（世界人口 1800 年 10 亿→今天 80 亿）；全球分层：欧美已完成转型（低增长+老龄化），非洲仍在转型早期（高生育率——人口结构最年轻），东亚最快（日本、韩国、中国——总和生育率跌破 1.3 的超低生育率）；人口转型解释了过去两百年几乎所有大事（城市化、移民、战争、经济增长）与未来难题（老龄化、养老金、劳动力）。 |
| 65 | [[黑死病]] | 黑死病是 1346–1353 年横扫欧亚的鼠疫大流行：由鼠疫耶尔森菌（1894 年发现）经跳蚤与老鼠传播，沿丝绸之路商路西传（蒙古围城抛尸入城的传说与史实存争议），欧洲人口损失约 30–60%（总人口从约 8000 万降到 3000–5000 万）——它是人类历史上最致命的单次流行病：城镇化为废墟（薄伽丘《十日谈》的背景）、劳动力骤减反而提高工资（农奴地位改善——封建制松动的推力之一）、对教会权威的冲击（祈祷无效的信仰危机）、以及艺术与心态的转变（死亡艺术、天启恐惧）。 |
| 66 | [[全面战争]] | 全面战争是动员全部社会资源、以消灭敌方整体（含平民与工业）为目标的战争形态：美国南北战争与普法战争是前奏（谢尔曼"向大海进军"、围城），第一次世界大战全面化（总体战：全民入伍、配给制、潜艇无限制战、宣传战——"国家处于战争状态"成为社会常态），第二次世界大战达峰（闪电战、战略轰炸（伦敦、德累斯顿、东京）、原子弹——平民死亡超过军人、工业是打击目标）；全面战争依赖工业化（铁路、电报、流水线武器生产）与民族主义动员（人人都是战士——宣传与义务教育的战争功能）；核武器出现后，全面战争从可想到的自杀——冷战以"确保相互摧毁"冻结了全面战争，战争形态转向代理人战争与混合战争。 |
| 67 | [[女权运动]] | 女权运动是争取性别平等的社会运动与思想传统：第一波（19–20 世纪初：选举权——英国妇女参政运动、美国 1920 第十九修正案、中国五四运动中的女性解放话语）、第二波（1960–70 年代：平等就业与生育权——波伏瓦《第二性》"女人不是天生的而是变成的"、弗里丹《女性的奥秘》）、第三波与当代（1990 年代起：多样性、交叉性——性别与种族阶级的叠加）；女权主义不只关于女性：它重新审视权力、劳动分工、家庭与语言本身（性别与技术的争论：为什么工程师多为男性——技术与性别气质的社会建构）。 |
| 68 | [[历史终结论]] | 历史终结论是福山 1989 年（冷战将终之际）提出的命题："历史"作为意识形态演化史已经终结——自由民主制是人类政治形式的终点（没有更高形态可追求，剩下的只是技术与管理问题）；其源头是黑格尔-科耶夫的历史哲学（历史的终结=普遍承认的实现）；福山区分"历史终结"与"事件继续"（自由民主内部仍有无穷琐事与冲突）；1990 年代它成为胜利话语（"华盛顿共识"的哲学包装），2008 金融危机、民粹回潮与中国崛起等"历史回归"事件使其广受嘲笑——但福山后来辩护：没有更好的替代方案出现，反例只是执行问题？争论仍在继续。 |
| 69 | [[全球南方]] | 全球南方指亚洲、非洲、拉丁美洲及大洋洲的前殖民与"发展中"世界（相对"全球北方"=欧美日等发达工业国）：概念源流——"第三世界"（1952 年索维造词：既非美国阵营也非苏联阵营——政治性概念）、"发展中国家"（经济学分类）、"全球南方"（1990 年代后流行：更强调南北权力结构而非意识形态）；它不是纯地理概念（澳大利亚在新西兰算"南方"？澳大利亚通常属北方；中国是世界最大"南方"国家却经济总量第二——概念的张力所在）；组织形态：不结盟运动（1961）、七十七国集团（1964）、金砖国家（2009——"全球南方的崛起"的新象征）；核心议题：发展鸿沟、债务、气候责任（历史上北方排放 vs 南方受害）、全球治理的代表权（国际货币基金组织份额、联合国安理会改革）。 |
| 70 | [[数字史学]] | 数字史学是运用计算与数字技术研究历史的领域：三个层面——数字化（史料扫描建库：档案馆数字化、全文检索——研究条件的革命）、量化分析（计量史学：用数据库与统计检验历史命题——奴隶贸易规模、社会流动率、文本的词频与网络分析）、数字叙事（可视化、地图、交互作品：时间轴、GIS 历史地图、网络图）；源流：1960 年代计量史学（新经济史、克莱奥学派）的成败（早期承诺过度——"没有数字就没有历史"的傲慢被叙事史反击）、1980–90 年代个人电脑与超文本（超文本历史实验）、21 世纪的"大历史数据"（谷歌图书词频、历史报纸数字化、家谱大数据）；挑战：OCR 错误、数字化偏见（谁的材料被数字化？）、可重复性与档案权力的数字维度。 |
| 71 | [[公众史学]] | 公众史学是历史学面向公众的实践与研究：博物馆展览、历史纪录片与影视（"影视史学"——《兄弟连》《长安十二时辰》的史实之争）、纪念地与遗产保护、口述历史项目、家谱与社区记忆（美国 1970 年代环保与民权运动的公共史转向——加州大学圣巴巴拉分校首开学位）、以及数字公众史学（维基百科、历史类短视频、游戏历史（《刺客信条》的历史教育争议））——它的问题意识：历史为谁书写？公众如何参与历史建构？"人人都是自己的历史学家"（卡尔·贝克尔）——公众史学把历史学的认识论问题变成公共文化问题。 |
| 72 | [[物质文化]] | 物质文化研究物（工具、器物、建筑、消费品）与人之间的互构关系：物的"社会生命"（阿帕杜莱：物像人一样经历出生、交换、崇拜与废弃）、物的语言（物品传达身份、阶级与信仰——"我们塑造了建筑，然后建筑塑造我们"（丘吉尔））、物证的历史（考古学的基本方法：无文字社会与平民生活靠物说话——垃圾堆里的历史）；代表研究：布罗代尔《物质文明》（日常生活的结构——面包、住房、服装的长期史）、消费史（18 世纪"消费革命"：糖、茶、棉布如何重构全球与身份）、技术物（自行车改变女性服饰与行动自由、冰箱改变饮食与家庭节奏、智能手机重构社交）——物是凝固的社会关系。 |
| 73 | [[医学史]] | 医学史研究疾病、医疗知识与医疗体制的变迁：从体液说（希波克拉底-盖伦：四体液失衡——放血疗法统治两千年）到细菌学革命（19 世纪：巴斯德、科赫——疾病从"体质失衡"变成"特定病原"）、从"医院是临终收容所"到现代医院（19 世纪护理革命：南丁格尔；消毒与麻醉手术革命）、20 世纪的医药黄金时代（青霉素 1928、疫苗消灭天花 1980、基因医学）——医学史的核心命题：医学进步是纯粹的（科学发现）还是社会的（权力、经济、文化塑造"什么是病"）？——"疾病是被社会建构的"（福柯《临床医学的诞生》：医学凝视与医院作为规训空间）。 |
