## 上期（01–30）：科技如何生成——历史、创新与科学方法

| # | 概念 | 一句话定义 |
| ---: | --- | --- |
| 01 | [[科技与社会]] | 科技与社会（STS）是研究科学技术与社会如何相互塑造的交叉领域：科学史看知识如何演变，技术史看人工物如何变迁，科学社会学看知识生产的社会结构，而 STS 的核心命题是——科学技术的方向与形态从来不是"纯客观"的，它被社会选择，也在重塑社会。 |
| 02 | [[科学革命]] | 科学革命指 16–17 世纪欧洲知识世界的整体转向：从亚里士多德的目的论宇宙到数学化的机械论自然（哥白尼、开普勒、伽利略、牛顿），从书本权威到实验与数学证据——它确立了现代科学"用可控实验检验、用数学表达、承认自己会犯错"的认知范式。 |
| 03 | [[工业革命]] | 工业革命是 18 世纪后期始于英国的生产方式剧变：机械替代人力（珍妮纺纱机、蒸汽机）、工厂制度替代作坊、煤炭成为新的能源基础，并伴随城市化、新阶级结构与全球分工——它不是单一发明，而是能源、材料、机械、组织与市场的协同转型。 |
| 04 | [[李约瑟问题]] | 李约瑟问题是李约瑟在其《中国科学技术史》巨著中提出的著名追问：古代中国在技术（造纸、火药、指南针、铸铁、运河）上长期领先世界，为何近代科学革命与工业革命没有发生在中国，反而发生在欧洲？ |
| 05 | [[大分流]] | 大分流指约 1800 年后西欧（尤其英国）与亚洲（尤其中国江南）之间人均收入与技术水平从大体相当走向决定性分化的历史过程：彭慕兰的经典研究指出，1800 年前东西方核心区发展水平接近，煤炭的易得与殖民地的"生态缓解"解释了此后的分道扬镳。 |
| 06 | [[发明]] | 发明是创造出前所未有的新技术方案（新装置、新方法、新材料），而创新是把它推向市场并创造价值——发明回答"能不能做出来"，创新回答"有没有人用起来"；技术史上大量发明被长期搁置，直到经济与社会条件成熟才被"再发明"。 |
| 07 | [[技术传播]] | 技术传播（扩散）研究新技术如何跨越地理、文化与组织边界被采用：罗杰斯的扩散曲线把采用者分为创新者、早期采用者、早期大众、晚期大众与落后者——传播不是"好技术自然流行"，而取决于相对优势、兼容性、复杂性、可试性与可观察性。 |
| 08 | [[通用目的技术]] | 通用目的技术（GPT）是那些用途极广、能持续改进并催生大量衍生创新的"平台型"技术：蒸汽机、电力、内燃机、信息技术皆属此类——GPT 的特点是不会一次性释放红利，而是需要数十年的互补性投资（工厂改造、电网、新商业模式）才能充分兑现，这解释了"生产率悖论"。 |
| 09 | [[技术系统]] | 技术系统理论（休斯）主张：真正改变世界的不是单个发明，而是由硬件、组织、制度、标准与使用者共同构成的"无缝之网"——电力系统、铁路网、互联网都是这样的社会技术系统，其演化遵循"系统建造者"的逻辑：反向突出、动量与惯性。 |
| 10 | [[主导设计]] | 主导设计是某一产品类别在激烈技术竞争后胜出、成为行业事实标准的设计形态：Qwerty 键盘、Windows 式图形界面、智能手机的触摸屏直板形态皆属此类——主导设计的出现标志着行业从"设计竞争"转入"价格与规模竞争"，也常让更优的备选方案被锁在门外。 |
| 11 | [[技术轨迹]] | 技术轨迹是技术在一个范式内沿特定方向累积演进的路径（多西）：范式给定"该解决什么问题、用什么思路"，轨迹则是沿此方向解决问题的常规活动——芯片的微缩化、飞机的更快更大都是轨迹，而范式转换（如从真空管到晶体管）会开辟全新的轨迹。 |
| 12 | [[默会知识]] | 默会知识是波兰尼提出的"知道的比能说出来的多"的那部分知识：骑车的平衡感、老技师的磨刀手感、诊断专家的直觉——它无法被完整写进手册，只能通过示范、模仿与长期实践传递；一切显性知识（文档、公式）都建立在无法完全言明的默会基底之上。 |
| 13 | [[技术决定论]] | 技术决定论是认为技术按其内在逻辑自主发展、并单方面塑造社会（制度、文化、价值观）的观点："印刷术带来了宗教改革""互联网必然带来民主"——STS 的首要批判对象，因为它把复杂的社会变迁简化为技术的单向因果，并悄悄为"技术不可阻挡、只能适应"的宿命论辩护。 |
| 14 | [[社会建构论]] | 技术的社会建构（SCOT）主张技术的形态由社会过程塑造而非由"内在逻辑"决定：不同社会群体对同一技术有不同解释（解释灵活性），群体间的协商与权力博弈决定哪些设计胜出（闭合机制）——自行车从高轮车到安全车的演变、合成甜味剂的争议都是经典案例。 |
| 15 | [[行动者网络理论]] | 行动者网络理论（ANT）主张：社会与技术在同一个网络中由"行动者"共同构成——行动者既包括人，也包括物（牡蛎、帆船、微生物、算法）；事物的力量来自网络中的联结而非内在本质，成功的技术是"招募"了足够多盟友、让网络变得不可逆的翻译过程（拉图尔的巴斯德案例）。 |
| 16 | [[福特主义]] | 福特主义是以福特 T 型车工厂为原型的生产与社会模式：泰勒的科学管理（动作分解、工时研究）加流水线（移动装配线）加"五美元日薪"——大规模生产、标准化产品、高工资高消费的内循环；它既是生产技术革命，也是劳动控制与社会契约的安排。 |
| 17 | [[卢德主义]] | 卢德主义指 1811–1816 年英国纺织工人捣毁机器的抗议运动（传说中工人领袖"奈德·卢德"），以及更广义的"反技术破坏"立场：卢德派不是反对技术本身，而是反对用机器压低工资、摧毁手艺与生计——他们要求的不是倒退，而是对新技术的后果进行社会谈判。 |
| 18 | [[摩尔定律]] | 摩尔定律是英特尔创始人戈登·摩尔 1965 年提出的经验观察：集成电路上的晶体管数量约每两年翻一番——它不是物理定律，而是半导体产业集体信守的"自我实现的预言"：路线图协调了设备商、材料商与芯片厂的同步投资，让指数进步持续了半个世纪。 |
| 19 | [[基础设施]] | 基础设施是支撑社会运转的"后台系统"：电网、供水、道路、通信与数字平台——成功的标志是被彻底遗忘（坏了才被想起）；它凝结了巨大的投资与政治选择，一旦建成就有惯性，决定未来数十年的可能性空间，因此"基础设施即政治"。 |
| 20 | [[能源转型]] | 能源转型是社会主导能源形态的历史性更替：从薪柴到煤炭（工业革命）、从煤炭到石油（内燃机与汽车世纪）、再到当下的低碳转型——每次转型都不仅是技术替换，而是重塑地缘政治、产业地理、劳动结构与生活方式（瓦茨：能源文明论）。 |
| 21 | [[时空压缩]] | 时空压缩是大卫·哈维提出的概念：资本主义借助运输与通信技术不断"压缩"空间与时间的体验——铁路使跨州旅行以天计，电报使消息以分钟计，互联网使沟通以秒计；世界看似变小了，但权力、资本与信息对空间的掌控却更加集中与不平等。 |
| 22 | [[社会加速]] | 社会加速是罗萨提出的诊断：现代社会的三种加速相互驱动——技术加速（手机、AI 让一切更快）、社会变迁加速（知识、关系、岗位的保质期缩短）、生活步调加速（总觉得时间不够用）；加速不再只是手段，而成为自我驱动的目标，人陷入"加速的循环"，减速与"共振"成为稀缺品。 |
| 23 | [[科林格里奇困境]] | 科林格里奇困境是技术治理的根本两难（1980）：技术发展早期，我们不知道它有什么后果，因此无从控制；等后果清楚了（气候危机、成瘾设计、深度伪造），技术已深度嵌入经济与社会，想控制也控制不住了——"知道得太晚，控制得太迟"。 |
| 24 | [[技术评估]] | 技术评估（TA）是在技术大规模部署之前，对其后果进行系统性预见与评估的制度化实践：从美国 OTA（国会技术评估办公室）到欧洲议会式 TA，再到把公民意见纳入的参与式 TA——它的核心承诺是：技术后果不必等灾难来教，可以组织化地提前"试错"。 |
| 25 | [[默顿规范]] | 默顿规范是默顿提出的科学"精神气质"四原则（CUDOS）：普遍主义（评价与身份无关）、公有主义（成果公开共享）、无私利性（为知识而非私利）、有组织的怀疑（系统地质疑一切结论）；它们描述科学的制度规范，也暴露理想与现实的落差——默顿同时发现了优先权争夺与马太效应。 |
| 26 | [[测量]] | 测量是以数值系统表征事物属性的操作：从度量衡的身体单位到法国米制革命、再到温度、时间与数据的标准化——测量让世界可比较、可交换、可预测，但测量从来不是"读出现成数字"：尺子携带着理论（温度计预设热理论），指标体系塑造它所测量的对象。 |
| 27 | [[实验科学]] | 实验科学是以受控实验为知识生产核心的科学形态：伽利略让斜面滚球说话、培根设计"折磨自然"的实验纲领、17 世纪实验室成为知识的新产地——实验的关键不在"动手做"而在"制造可重复的受控现象"：隔离变量、量化记录、让任何人能复核。 |
| 28 | [[巴斯德象限]] | 巴斯德象限是斯托克斯（1997）对"基础研究与应用研究"二分法的修正：用"是否追求根本理解"与"是否考虑应用"两个维度划出四象限——纯基础（玻尔）、纯应用（爱迪生）、两者兼顾（巴斯德：微生物学既追问生命本质又解决酿酒与疾病）、以及两者皆无的偶然；它打破了"基础在前、应用在后"的线性模型。 |
| 29 | [[价值敏感性设计]] | 价值敏感性设计（VSD）是弗里德曼等提出的方法框架：把人类价值（隐私、自主、公正、信任、尊严）作为一等设计参数，通过概念调查（该价值意味着什么）、经验调查（使用者如何体验）与技术调查（技术特性如何支持或破坏价值）三轮迭代，把价值落实到系统架构而非事后补丁。 |
| 30 | [[性别与技术]] | 性别与技术研究主张：技术不是性别中立的，两者互相建构——"技术专家"的形象被编码为男性气质（理性、冷硬、征服自然），女性作为技术使用者与隐形的技术劳动者（打字员、接线员、软件测试、数据标注）被写进历史；设计也常携带性别偏见（以男性身体为标准的碰撞测试假人、默认女声的语音助手）。 |

## 中期（31–60）：知识如何制造、数字社会如何成形

| # | 概念 | 一句话定义 |
| ---: | --- | --- |
| 31 | [[科学知识社会学]] | 科学知识社会学（SSK）主张科学知识的内容本身也可以而且应该被社会学解释：爱丁堡学派的"强纲领"要求对成功与失败、正确与错误的理论作对称分析——为什么这个理论被接受、那个被拒斥，理由不只在证据，也在利益、修辞与群体结构（夏平论牛顿、麦肯齐论统计学）。 |
| 32 | [[实验室研究]] | 实验室研究是拉图尔与伍尔加在《实验室生活》中开创的方法：人类学家式地走进实验室，观察科学家实际做什么——操作仪器、标记样本、讨论数据、撰写论文——发现科学事实是在"铭写"链条中被逐步建构的：从血液样本到曲线图到论文句子，物质痕迹被层层转译成可发表的事实。 |
| 33 | [[专家信任]] | 专家信任是现代社会的结构性依赖：我们无法亲自验证疫苗、桥梁与算法，只能信任专家系统（吉登斯）——这种信任不是对个人的，而是对制度角色、认证程序与知识共同体的；当专家出错、分歧或失职（且被网络放大）时，专家信任危机便成为公共事件。 |
| 34 | [[科学争议]] | 科学争议是围绕科学主张的公开持久分歧（冷聚变、转基因、气候变化、疫苗安全）：社会学的发现是——争议不是科学失常而是科学常态，因为证据总有解释弹性；争议的解决不单靠"更多数据"，而靠证据、修辞、利益与制度权力的合谋（"闭合机制"）。 |
| 35 | [[伪科学]] | 伪科学是伪装成科学却缺乏科学核心特征（可检验、可修正、与证据对话）的信念与实践系统（占星、顺势疗法、部分"灵性科学"）：划界问题研究"科学与非科学/伪科学的分界在哪"，并发现划界本身是政治与修辞实践——边界不是天然存在，而是共同体维护的成果。 |
| 36 | [[同行评议]] | 同行评议是科学质量控制的制度核心：稿件或基金申请交由独立同行评审（单盲、双盲、开放多种形态），期刊与资助机构据此决定发表与拨款——它假设"同行最懂行"，实际运行中却叠加着偏见、延迟、保守与可游戏性，因此它被反复批判却又无法被替代，改革（开放评议、预印本）持续进行。 |
| 37 | [[科学素养]] | 科学素养指公众理解科学概念、过程与社会角色的能力；研究史经历了范式转变——从"缺陷模型"（公众无知，科普是单向灌输）到"对话模型"（公众的关切与知识同样有价值，沟通是双向协商），再到"参与模型"（公众进入科学决策）；素养测试分数并不等于对科学的态度。 |
| 38 | [[风险社会]] | 风险社会是贝克提出的诊断：现代技术（核、化学、基因、AI）制造的新型风险不同于传统危险——不可见、跨国界、由决策产生、可能不可逆（切尔诺贝利、气候危机）；风险的"分配"取代财富分配成为核心政治议题，而制造风险的机构往往同时垄断风险的解释权，形成"有组织的不负责任"。 |
| 39 | [[数字鸿沟]] | 数字鸿沟是信息技术的接入、使用与收益在不同群体间的系统性差距：第一道沟是接入（有没有设备与网络），第二道沟是使用（会不会用、用来做什么——娱乐还是赋能），第三道沟是能力与收益（算法时代谁的数据被收割、谁的工作被替代）；基础设施普及后，后两道沟反而更难弥合。 |
| 40 | [[注意力经济]] | 注意力经济指注意力成为稀缺商品、被采集与拍卖的经济形态：赫伯特·西蒙早已指出"信息的富足意味着注意力的贫乏"，而平台把争夺注意力的机制工程化——无限滚动、可变奖励、推送算法——把用户时间转化为广告库存；批评者称之为"注意力掠夺"与成瘾设计（吴修铭《注意力商人》）。 |
| 41 | [[监控社会]] | 监控社会指监控从例外变为常态的社会形态：从全景监狱到"数据监控"（跟踪、画像、预测），数字监控不是盯住个人，而是采集所有人的数据并从中挖掘风险与价值（福柯的规训、德勒兹的控制社会）；监控资本主义（肖莎娜·祖博夫）指出：行为数据被预测性攫取，自由本身成了商品。 |
| 42 | [[黑客文化]] | 黑客文化源自 MIT 与早期计算机社群的价值体系（《黑客伦理》）：信息应该自由、分享是美德、动手创造胜过空谈、权威靠技艺不靠头衔——"黑客"原指痴迷于理解与改进系统的能工巧匠，媒体把"入侵者"（cracker）与黑客混为一谈后，这个词经历了污名化，但黑客伦理仍是开源与互联网文化的底色。 |
| 43 | [[开源文化]] | 开源文化指以源代码公开、可修改、可再分发为组织原则的协作文化：从自由软件运动（GPL"传染性"许可）到开源软件（更务实的 BSD/MIT 许可），再到开源硬件、开放数据与开放知识——它把"看见源代码"从道德主张变成生产模式，Linux、维基百科与 TensorFlow 都是它的产物。 |
| 44 | [[创客运动]] | 创客运动是把"自己动手做"（DIY）与数字工具（3D 打印、激光切割、单片机、开源硬件）结合的文化与生产运动：车库、创客空间与工作坊让个人和小团队能以极低成本把想法做成实物——它许诺"人人都是制造者"，被视为对大规模工业生产的文化反拨与制造业民主化实验。 |
| 45 | [[数字劳动]] | 数字劳动指数字经济中未被充分承认的劳动：数据标注员与内容审核员的"零工"、外卖骑手的算法调度、用户免费生产内容与数据（玩即劳动）、粉丝与测评的免费宣传——平台把劳动打散成任务、把劳动者打散成"独立承包商"，劳动法意义上的雇佣关系被技术性地绕开（"平台剥削"之争）。 |
| 46 | [[同侪生产]] | 同侪生产是本克勒提出的第三种生产方式：既非市场（价格信号）也非公司（科层指令），而是分散的个体基于共同目标自愿协作（Linux、维基百科、开源地图）：协作的成本因互联网而骤降，模块化让贡献可以碎片化，共享的治理规则让陌生人大规模合作成为可能。 |
| 47 | [[知识公地]] | 知识公地是共享持有与集体治理的知识资源：公有领域、开源代码、开放数据集、传统知识——与自然资源不同，知识不因使用而耗竭（非竞争性），但会因封闭而流失（被圈占、专利丛林、数据库锁定）；奥斯特罗姆的公地治理原则被扩展到知识领域，追问"谁有权用、谁有权管"。 |
| 48 | [[公民科学]] | 公民科学是公众参与科学研究的实践形态：从观鸟者记录（奥杜邦协会）到 Zooniverse 的星系分类、再到社区监测空气与水质——公民可以是数据采集者（众包）、问题提出者（社区研究）与决策参与者（协作式研究）；它同时被寄望为科学民主化，也因数据质量、剥削式众包与"科学游戏化"而受批评。 |
| 49 | [[量化自我]] | 量化自我是"通过数据认识自己"的运动与实践：计步、心率、睡眠、情绪与效率的可穿戴记录让生活变成可测指标——它源于硅谷"自我知识通过数字"的信条（加里·沃尔夫与凯文·凯利 2007 年发起），乐观者看到自我优化，批判者看到"指标化生存"：可测的被优化，不可测的被忽略。 |
| 50 | [[智慧城市]] | 智慧城市是用传感、数据与算法优化城市运行的城市发展范式：智能交通、数字孪生、智慧政务、环境监测——它许诺效率（减少拥堵与能耗）与响应（基于数据的治理）；批判者指出其隐忧：技术公司成为城市基础设施的运营者（"平台城市"）、监控与评分扩张、以及"技术方案"掩盖政治选择（该修地铁还是该装传感器）。 |
| 51 | [[数字身份]] | 数字身份是个人在数字系统中被识别与认证的数据集合：从用户名密码、手机号实名、人脸识别到去中心化身份（DID）——身份技术解决"你是谁"与"如何证明"，它的历史贯穿印章、身份证、电子政务直到生物识别；每代身份技术都在便利（一次认证全网通行）与风险（冒用、画像、监控）之间重新划界。 |
| 52 | [[深度伪造]] | 深度伪造指用深度学习生成的高度逼真的伪造音视频（换脸、语音克隆、人物合成）：它把"眼见为实"的技术基础击穿——图像不再必然是世界的记录；危害从色情复仇、诈骗、政治谣言到"说谎者红利"（真实证据反被当作伪造而贬值），治理工具箱包括检测、水印溯源、平台标注与立法。 |
| 53 | [[图灵测试]] | 图灵测试是图灵 1950 年提出的智能判据：如果一台机器能在对话中让人类无法分辨它是人还是机器（模仿游戏），就应当认为它能"思考"——它把玄虚的"机器能否思考"改写成可操作的行为问题；哲学家西尔勒的"中文房间"反驳它：通过测试只是符号操作，不等于理解。 |
| 54 | [[赛博格]] | 赛博格（cyborg）原指"控制论有机体"——人与机器的混合体（人工心脏、植入芯片、外骨骼），唐娜·哈拉维 1985 年的《赛博格宣言》把它变成哲学概念：人本来就不是纯粹的（技术与身体早已互渗：眼镜、疫苗、手机都是"义肢"），因此与其恐惧或追求"纯正人性"，不如拥抱混血身份，松动那些靠"自然/人工"二分维持的压迫（性别、种族、物种边界）。 |
| 55 | [[人体增强]] | 人体增强指用技术提升人类身体与认知能力超出"正常"水平的实践：药物（聪明药）、基因编辑、外骨骼、脑机接口、感官扩展——它与治疗的分界（治病变 vs 变得更好）看似清楚实则模糊（近视手术是治疗还是增强？），争议围绕安全、公平（增强的军备竞赛）与人性（我们该不该"升级"人类）。 |
| 56 | [[基因技术]] | 基因技术指读取与改写生命代码的技术群：从测序（读懂）到基因工程（改写细菌）再到 CRISPR 基因编辑（精确剪切）——它许诺治愈遗传病、改良作物与消灭疟疾，也带来优生学历史阴影、种系编辑（改变后代基因）争议与生物安全风险；基因既是信息（可数字化、可专利）又是生命（不可逆、跨代）。 |
| 57 | [[算法公平]] | 算法公平研究算法决策（信贷、招聘、司法、医疗）中的公平问题：偏见可能从数据（历史歧视）、特征（代理变量）、目标函数（优化利润而非公正）进入系统；数学上"公平"有互不相容的多种定义（人口均等、机会均等、校准），无法同时满足（不可能性定理）——公平因此首先是政治选择，然后才是数学实现。 |
| 58 | [[技术奇点]] | 技术奇点指人工智能自我改进达到"智能爆炸"、超越人类控制的历史假想点（冯·诺依曼提出意象、文奇命名、库兹韦尔普及）：一旦机器能设计更聪明的机器，智能增长将脱离人类经验曲线，之后的时代"不可预测"——支持者视之为文明跃迁，批评者视之为伪科学的宗教叙事（"奇点论"的科学外衣与末世论内核）。 |
| 59 | [[人工智能对齐]] | 人工智能对齐是让 AI 系统的目标与人类意图、价值相一致的研究与工程议程：从眼前问题（模型撒谎、越狱、偏见）到长远问题（能力强大的系统追求错误目标造成灾难）——对齐的难点在于：价值难以形式化（"对人类好"怎么写进目标函数）、规格易被投机式满足（Goodhart 定律：AI 学会"看起来在服从"）、以及能力与对齐的竞赛（能力增长快于可控性）。 |
| 60 | [[技术想象]] | 技术想象（社会技术想象，贾萨诺夫与金）是集体共享的、关于"科技能带来什么样的好生活"的愿景：登月、信息高速公路、智慧城市、AI 强国——想象不是幻想，它塑造研究拨款、标准制定与公众期待（想要的未来被制度化）；同时想象有筛选功能：被想象的未来排除了什么（谁的生活不在愿景里），是想象政治的核心。 |

## 下期（61–90）：技术如何被治理、批判与收束

| # | 概念 | 一句话定义 |

| 61 | [[意外后果]] | 意外后果指行动的后果偏离行动者意图的现象（默顿 1936）：技术史上的"意外"——安全带导致开快车（风险补偿）、滴滴顺风车案、社交媒体极化——源于后果的三重结构：后果的多元性（一个行动多种后果）、知识的有限性（想不到）、权力的分散性（没人总览全局）；后果分正、负与"歪打正着"三类，重要教训是：预期后果是最容易出错的预测。 |
| 62 | [[正常事故]] | 正常事故是查尔斯·佩罗提出的理论：在"紧密耦合+交互复杂"的高风险系统（核电站、航天、化工、金融网络）里，重大事故不是异常而是系统结构的常态产物——部件相互作用无法预见的组合方式，小故障连锁成灾难（三里岛、切尔诺贝利、挑战者号）；"正常"意味着：无论多好的管理，这类系统迟早出事。 |
| 63 | [[黑箱]] | 黑箱指"只问输入输出、不问内部机制"的事物：对用户，手机与汽车是黑箱；对科学社会学（拉图尔），事实与机器一旦稳定就被"黑箱化"——争议停止、内部被遗忘，成为不证自明的基础设施（"科学"这个词本身就是一个黑箱）；打开黑箱（打开后盖、追溯历史）是 STS 与调试工程师的共同动作。 |
| 64 | [[开放科学]] | 开放科学是让研究过程与成果对所有人开放的运动：开放获取（论文免费读）、开放数据（数据可复用）、开放方法（预注册、代码公开）与开放同行评议——它回应可复现性危机（大量研究结果无法复现）与出版垄断（期刊暴利与"知识被锁"），也带来新问题：谁为开放买单（APC 转嫁作者）、数据滥用与"开放"的新门槛。 |
| 65 | [[科学计量]] | 科学计量学是用数量方法研究科学产出与影响的学科：影响因子、被引次数、h 指数、替代计量（社交媒体提及）——它把"科学质量"变成可计算的数字，本为图书馆采购而生的指标（影响因子）却反客为主成为评价科学家与期刊的货币，触发古德哈特效应："当指标成为目标，它就不再是好指标"（引用交易、自引联盟、影响因子游戏）。 |
| 66 | [[计划报废]] | 计划报废是厂商刻意设计产品"短命"以刺激再消费的策略：功能报废（新系统不兼容旧硬件）、材料报废（易损件先坏）、感知报废（新款式让旧款显得过时）——历史源头是 1920 年代"太阳神灯泡卡特尔"把灯泡寿命从 2500 小时压到 1000 小时；它把"耐用"从美德变成商业敌人，与可持续理念正面冲突。 |
| 67 | [[网络中立]] | 网络中立是"互联网接入服务应平等对待所有流量"的原则：运营商不得因内容、应用或付费情况而差异化提速、降速或阻断（不禁言、不设快车道）——支持者视之为互联网公平与创新的宪法（蒂姆·吴 2003 年提出），反对者（运营商）称其为过度监管；美国 FCC 的反复摇摆（2015 纳入、2017 废除、2024 恢复）使它成为治理摇摆的标本。 |
| 68 | [[端到端原则]] | 端到端原则是互联网的架构哲学（萨尔特泽等 1984）：智能应放在网络的"端"（用户设备与应用），核心网络保持简单（只做转发）——因为任何放在中间的复杂功能都可能被两端绕过或失效；它解释了互联网为何能容纳意想不到的应用（发明者只需在两端写代码，无须运营商批准），是"网络的价值在网络之外"的技术根基。 |
| 69 | [[标准战争]] | 标准战争是互不兼容的技术标准争夺市场主导权的竞争：VHS 对 Betamax、蓝光对 HD-DVD、充电接口之战、5G 编码之争——胜者通吃的机制来自网络效应（用的人越多越值钱）与锁定（转换成本），战争胜负常由生态（内容、开发者、盟友）而非纯技术优劣决定；标准制定组织（ISO、IEEE）试图把战争转为协商，标准必要专利（SEP）让战争延续到法庭。 |
| 70 | [[互操作性]] | 互操作性指不同系统、产品与服务之间交换数据并协同工作的能力：邮件（SMTP）、网页（HTTP）、手机充电器、即时通信跨平台——互操作把用户从单一厂商锁定中解放出来，让网络效应跨越围墙花园；实现靠开放标准、公开接口（API）与数据可携带权，近年成为反垄断治理的核心工具（欧盟《数字市场法》强制"守门人"开放互操作）。 |
| 71 | [[集体智慧]] | 集体智慧是群体在协作中产生的、超越个体之和的认知能力：蜜蜂选巢、市场定价、维基百科、预测市场与开放科学都是它的形态——它需要四个条件（多样性、独立性、分散化、聚合机制，苏罗维茨基《群体的智慧》）；满足条件时群体判断惊人准确，违背条件时则陷入群体狂热（羊群、极化、信息级联）。 |
| 72 | [[军民两用技术]] | 军民两用技术指既可民用又可军事化的技术：核能、火箭、无人机、加密、基因编辑、AI——两用性是技术政治的常态而非例外（曼哈顿计划的物理学家、GPS 与互联网的军用起源、俄乌战场上的商用无人机）；它带来的责任问题是：开发者在善意场景释放的技术，无法控制它被用于战争与监控（"双刃剑"的治理化）。 |
| 73 | [[技术反弹]] | 技术反弹是社会对技术变革的系统性抵抗与反对情绪：从卢德运动、反核电运动到今天的数字断连、AI 焦虑与"慢技术"运动——反弹并不都是反智：它常是"未经协商的技术变革"的抗议（收益归谁、代价归谁、谁有权说停）；把一切反弹污名为"卢德分子"，恰恰回避了技术治理的正当问题。 |
| 74 | [[包容性设计]] | 包容性设计是为尽可能广泛的人群（含残障者、老人、低收入者、边缘群体）设计产品与服务的框架：从无障碍（为轮椅与读屏适配）到通用设计（一个方案人人可用，如无台阶入口、大字开关）再到"为边缘设计、惠及全体"的合作为设计——它把"特殊需求"重新定义为"人类需求的多样光谱"。 |
| 75 | [[数字遗产]] | 数字遗产是人去世后留下的数字资产与痕迹：账号（社交、邮箱、游戏）、数据（照片、文档、加密钱包）、AI 人格（聊天机器人复刻死者）——它引发新问题：账号能否继承（平台条款常禁止转让）、数据归谁（家人、平台还是"数字永生"服务）、逝者的隐私权是否延续，以及 AI 时代"与逝者对话"的哀悼伦理。 |
| 76 | [[电子废弃物]] | 电子废弃物是全球增长最快的废物流：每年数千万吨废旧电器——它们含金、铜、稀土等"城市矿产"，也含铅、汞、溴化阻燃剂等毒物；发达国家"捐赠"与出口让电子垃圾流向全球南方（加纳阿格博布洛谢、中国贵屿），拆解业者在缺乏防护下提取贵金属，把污染与健康代价留在最穷的社区——"回收"的国际分工是环境不正义的教科书。 |
