# 基础设施

> 一句话定义：基础设施是支撑社会运转的"后台系统"：电网、供水、道路、通信与数字平台——成功的标志是被彻底遗忘（坏了才被想起）；它凝结了巨大的投资与政治选择，一旦建成就有惯性，决定未来数十年的可能性空间，因此"基础设施即政治"。

## 它解决的问题

基础设施研究把视线从"显眼的技术"转向"隐形的底座"：为什么水管、电网、标准与协议比任何单一发明都更深刻地塑造生活？三个特性：不可见性（成功即隐身）、持久性（寿命数十年，锁定后代选择）、政治性（路线经过谁家、电价归谁管、网络中立与否都是权力安排）。数字时代的基础设施化：云服务、支付网络、身份系统成为新的"管道"——它们的故障（宕机）与治理因此成为公共议题。

对工程师：你维护的"内部系统"若被他人依赖，你就是他们的基础设施——这带来责任伦理。

## 技术或生活案例

**场景：**云服务商宕机四小时，半个互联网的支付、登录都挂了。

**分析：**数字基础设施的现实：你的"高可用架构"依赖别人家的"底座"；反之，你的开放 API 若被上千家公司依赖，你就成了他们的基础设施——需要公布状态页、变更公告、弃用周期，并承担"被依赖的责任"。成为基础设施是影响力，也是负担：破坏性变更前，想想你的下游。
