# Seven-Questions-Self-Awareness-Framework

**Type**: Concept  
**Category**: Self-Development / Cognitive Tools

## Definition

一套通过七个核心问题系统化探索自我认知的框架。该框架将抽象的“自我了解”转化为可操作的问题序列，帮助个体从多个维度审视自己的认知、动机和知识结构。

## Core Questions

1. 你频繁遇到但希望了解更多的领域？
2. 哪种知识对你生活影响最大？
3. 想掌握哪些实践技能？
4. 想在什么领域被视为权威？
5. 你持续思考的是什么？
6. 明显的知识盲区？让你觉得尴尬的不足？
7. 你的宏大目标？哪些主题是垫脚石？

## Strategic Value

这套问题本质上是一个**课程表生成器**。它将模糊的自我探索转化为结构化的认知地图。
