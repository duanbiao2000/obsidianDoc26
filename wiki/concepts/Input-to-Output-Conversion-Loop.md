# Input-to-Output-Conversion-Loop

**Type**: Concept  
**Category**: English Speaking

## Definition

可理解输入只是原料，**主动输出 + 反馈 + 重复**才是把输入转化为可输出能力的转化机制。

## Five-Step Conversion Process

1. **输入**：吸收地道表达
2. **加工**：提炼成自己能用的表达
3. **输出**：用自己的话说出来
4. **反馈**：发现问题并修正
5. **重复**：让表达自动化

## Key Principle

看 100 小时美剧 ≠ 会说英语。  
“看懂”是识别能力，“说出来”是生成能力。
