# Note-Classification-Matrix

**Type**: Framework  
**Category**: Knowledge Management

## Overview

A classification system that routes different types of notes to appropriate restructuring strategies.

---

## Classification Categories

| Category   | Characteristics                    | Restructuring Focus                     |
|------------|------------------------------------|-----------------------------------------|
| **Fleet**  | Fragmented ideas, to-be-organized  | Raw record + deepening prompts         |
| **Lit**    | External summaries, digested views | Distinguish “original” vs “self-insight” |
| **Perm**   | Original insights, mature knowledge | Core conclusion + evidence + scenarios |
| **Proj**   | Task decisions, progress records   | Goal + obstacles + next steps          |
| **Meet**   | Records, key points, action items  | Participants + topics + resolutions    |

---

## Usage

Use this matrix as the first step when processing any note to determine the optimal output structure and depth.
