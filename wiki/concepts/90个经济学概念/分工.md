# 分工

> 一句话定义：分工是把生产拆分为专业化任务、由不同人或组织分别完成并交换的制度安排；它通过熟能生巧、减少切换与规模经济大幅提高产出。

## 它解决的问题

一个人自给自足只能拥有很少的东西。分工让每个人专注少数任务，再通过交换享受全部成果——这是财富增长的真正引擎。

从斯密的制针工厂到现代的模块化软件与全球供应链，分工的逻辑一致：专业化提高效率，交换使专业化可行。

## 它反对或区别于

- **[[比较优势]]：分工的方向由比较优势指引
- **[[交易成本]]：分工越细，协调与交易成本越高，二者相互制衡
- **[[企业]]：企业内部的分工与市场分工互为替代
- **[[规模经济]]：分工是规模经济的重要来源
- **常见误解：**分工就是让人做枯燥重复的工作；它也意味着深度专业与生态协作

- **亚当·斯密：**《国富论》开篇即论分工

- **阿林·杨格：**分工与市场规模相互促进
- **现代经济学家：**杨小凯等人发展新兴古典分工理论

## 技术或生活案例

**场景：**现代软件由框架作者、库维护者、平台工程师与业务开发者协作而成。

**分析：**没有人能独自完成操作系统、浏览器与应用的每一层——分工让个人专注一层的深度，通过 API 与包管理器交换成果。你的生产率，很大程度取决于你选择在哪个层级专业化。

## 我自己的反问

- 我是在做自己最有比较优势的事，还是什么都自己做？
- 我的工作哪些部分应外包、自动化或交给更专业的人？
- 我的协作成本是否已经超过分工收益？
- 我依赖的别人的专业化，我如何回报与维护？
- 我的团队分工是被设计过的，还是自然长成的？
