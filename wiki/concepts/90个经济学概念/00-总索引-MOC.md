## 上期（01–30）：选择、价格与市场（微观基础）

| # | 概念 | 一句话定义 |
| ---: | --- | --- |
| 01 | [[经济学]] | 经济学研究稀缺资源如何被选择、配置与评价：个人、企业与政府在约束下如何决策，以及这些决策如何通过市场、制度与政策汇合成总体结果。 |
| 02 | [[稀缺性]] | 稀缺性是指资源有限而人的需求无限这一基本事实；它意味着任何资源被用于一处，就不能同时用于另一处，因此选择与竞争不可避免。 |
| 03 | [[机会成本]] | 机会成本是为做一件事而放弃的次优选择的价值；它是经济学衡量任何决策真实代价的核心标尺。 |
| 04 | [[权衡取舍]] | 权衡取舍是指由于资源稀缺，增进一个目标往往以牺牲另一个目标为代价；决策的本质是在多个目标之间比较并接受交换。 |
| 05 | [[激励]] | 激励是影响人们行为的奖励与惩罚结构；经济学的基本假设之一是：人们会对激励作出系统而可预测的反应，无论他们是用户、员工、企业还是政府。 |
| 06 | [[经济人假设]] | 经济人假设是把决策者模型化为拥有稳定偏好、掌握相关信息并追求自身目标最大化的人；它是建模工具，而非对人的道德或心理学描述。 |
| 07 | [[边际分析]] | 边际分析关注“再多一个单位”带来的收益与成本之差，主张最优决策发生在边际收益等于边际成本之处，而不是“全有或全无”的粗略判断。 |
| 08 | [[偏好]] | 偏好是个体对不同选项的价值排序；标准理论假设它稳定、可比较且自洽，现实中它却常被情境、框架与习惯塑造。 |
| 09 | [[效用]] | 效用是经济学用来表达一个选项带给决策者的满足或价值高低的数值工具；它用于比较与排序，不必对应某种可测量的心理快乐。 |
| 10 | [[边际效用递减]] | 边际效用递减是指随着消费量增加，每多一个单位带来的额外满足通常逐渐下降；它解释了价值为何取决于数量与情境，而非物体本身。 |
| 11 | [[需求]] | 需求是在其他条件不变时，消费者在不同价格下愿意且能够购买的数量关系；价格上升通常使需求量下降，这一关系被称为需求定律。 |
| 12 | [[供给]] | 供给是生产者在不同价格下愿意且能够提供的数量关系；价格上升通常使供给量上升，因为更高的价格让更多生产变得有利可图。 |
| 13 | [[市场均衡]] | 市场均衡是价格调整到使需求量等于供给量的状态；在均衡价格上，没有系统性短缺或过剩，买卖双方的计划相互一致。 |
| 14 | [[弹性]] | 弹性度量一个变量对另一个变量变化的反应程度——典型的是需求量对价格变化的敏感度；它回答“涨价 10% 会流失多少用户”。 |
| 15 | [[价格机制]] | 价格机制是分散经济中协调千百万人的信息系统：价格同时传递稀缺信息、提供行动激励并分配产出，无需任何中央机构逐一下令。 |
| 16 | [[看不见的手]] | 看不见的手是指：在竞争、产权与信息得到适当制度保障时，个人追求自身利益的分散行动，会自发产生某种社会协调，而无须依靠善意或中央命令。 |
| 17 | [[消费者剩余]] | 消费者剩余是消费者愿意支付的最高价格与实际支付价格之间的差额，衡量交易给买家带来的净好处。 |
| 18 | [[生产者剩余]] | 生产者剩余是生产者实际收到的价格与其愿意接受的最低价格（通常由边际成本刻画）之间的差额，衡量交易给卖家带来的净好处。 |
| 19 | [[分工]] | 分工是把生产拆分为专业化任务、由不同人或组织分别完成并交换的制度安排；它通过熟能生巧、减少切换与规模经济大幅提高产出。 |
| 20 | [[企业]] | 企业是替代市场价格协调、以科层命令组织生产与交易的制度安排；它为何存在、边界在哪里，是企业理论的核心问题。 |
| 21 | [[生产函数]] | 生产函数描述投入（劳动、资本、技术等）与最大产出之间的技术关系；它回答“给定这些资源，最多能做出多少”。 |
| 22 | [[成本]] | 经济学的成本是生产某物所放弃的全部价值，包括显性的金钱支出与隐性的机会成本；它不是会计意义上的历史支出。 |
| 23 | [[边际成本]] | 边际成本是再多生产一个单位产品所增加的成本；它是产量决策的关键变量，因为最优产量取决于边际成本与边际收益的比较。 |
| 24 | [[沉没成本]] | 沉没成本是已经发生且无法收回的支出；理性决策应完全忽略它，只看未来的边际收益与成本，但人常常受它牵制。 |
| 25 | [[利润]] | 经济利润是收益减去全部经济成本（含资本的机会成本）后的余额；会计利润为正，经济利润可能为零甚至为负。 |
| 26 | [[完全竞争]] | 完全竞争是大量同质卖买者、自由进出、信息充分、无人能影响价格的市场结构；它是衡量现实市场的效率基准，而非对现实市场的描述。 |
| 27 | [[垄断]] | 垄断是市场上只有一个卖者、几乎没有替代品的市场结构；垄断者通过把产量压到竞争水平之下、价格抬到边际成本之上来获取超额利润。 |
| 28 | [[寡头]] | 寡头是少数大企业主导、彼此行为相互依赖的市场结构；每家企业的定价与产量决策都会引发对手反应，因此必须用博弈思维分析。 |
| 29 | [[自然垄断]] | 自然垄断指固定成本巨大而边际成本很低、单一供给者比多家竞争更高效的市场；竞争在这里反而造成重复建设与浪费。 |
| 30 | [[价格歧视]] | 价格歧视是对同一产品向不同支付意愿的买家收取不同价格；它不是“乱收费”，而是厂商在拥有定价权时提取消费者剩余的理性策略。 |

## 中期（31–60）：失灵、制度、博弈与行为（含分配）

| # | 概念 | 一句话定义 |
| ---: | --- | --- |
| 31 | [[市场失灵]] | 市场失灵是指价格机制无法实现有效率（或社会合意）配置的情形，典型来源包括外部效应、公共物品、信息不对称、垄断与分配问题。 |
| 32 | [[外部效应]] | 外部效应是某人的行为给无关第三方带来、却未通过价格补偿或付费的成本或收益；负外部性如污染，正外部性如开源代码。 |
| 33 | [[公共物品]] | 公共物品是同时具有非排他性（无法阻止不付费者使用）与非竞争性（一人使用不减损他人使用）的物品，典型如国防、基础研究、清洁空气。 |
| 34 | [[搭便车问题]] | 搭便车是指个体不承担成本却享受集体成果的现象；当搭便车普遍时，公共物品或集体行动就会供给不足。 |
| 35 | [[公地悲剧]] | 公地悲剧指共享且竞争性使用的资源（牧场、渔场、地下水）因每个人只计算私人收益而被过度使用，最终损害所有人。 |
| 36 | [[产权]] | 产权是界定谁拥有、使用、收益、转让与处分资源的权利束；清晰的产权让激励、交易与责任成为可能。 |
| 37 | [[科斯定理]] | 科斯定理指出：若交易成本为零，无论产权初始归属谁，当事人都能通过自愿谈判达成有效结果；现实中交易成本为正，因此产权界定与制度至关重要。 |
| 38 | [[交易成本]] | 交易成本是完成一笔交易所付出的搜寻、谈判、签约、执行与监督成本；它决定了市场、企业与制度的形态。 |
| 39 | [[信息不对称]] | 信息不对称是交易一方掌握另一方不知道的关键信息；它颠覆“自愿交易必互利”的直觉，是许多市场失灵的总根源。 |
| 40 | [[逆向选择]] | 逆向选择是交易前信息不对称导致高质量一方退出、低质量一方留下，市场质量螺旋下降的现象，如二手车市场的“柠檬”问题。 |
| 41 | [[道德风险]] | 道德风险是交易发生后，一方因对方无法完全监督而改变行为、增加风险的现象，如投保后开车更随意、有保底后更敢冒险。 |
| 42 | [[委托代理]] | 委托代理问题是委托人把任务交给目标不同、信息占优的代理人执行时产生的激励冲突：代理人可能偷懒、冒进或追求自己的目标。 |
| 43 | [[信号发送]] | 信号发送是信息占优方通过有成本、可验证的行动向对方展示自己隐藏质量的行为；信号之所以可信，正因为它对低质量者更昂贵。 |
| 44 | [[拍卖]] | 拍卖是在信息分散、价值难定时，通过竞价规则分配稀缺物品并发现价格的制度；规则设计会显著改变结果。 |
| 45 | [[机制设计]] | 机制设计是“逆向博弈论”：给定想要的社会结果（效率、收入或匹配），设计游戏规则使自利参与人在追求自身利益时恰好产生该结果。 |
| 46 | [[博弈论]] | 博弈论研究策略互动：当我的最优选择取决于你的选择、而你的最优选择又取决于我的选择时，理性人将如何行动、结果如何稳定。 |
| 47 | [[纳什均衡]] | 纳什均衡是一种策略组合：给定其他人的策略，每个参与人单方面改变自己的策略都无法变得更好；它是策略互动中“没人想先动”的稳定状态。 |
| 48 | [[囚徒困境]] | 囚徒困境是个体理性导致集体次优的博弈：对每个人最优的选择（背叛）组合起来，却让所有人比合作时更差。 |
| 49 | [[重复博弈]] | 重复博弈是同一博弈被反复进行、且参与者在意未来收益的情形；它使“以牙还牙”式惩罚可信，从而让一次性博弈中无法维持的合作成为可能。 |
| 50 | [[行为经济学]] | 行为经济学用心理学实验证据修正新古典假设，研究人在有限认知、启发式与情绪影响下实际如何决策，以及这些偏差如何系统化。 |
| 51 | [[有限理性]] | 有限理性指人的认知能力、信息与时间都有限，无法真正“最大化”，只能构建简化模型、寻找“足够好”的方案，即西蒙所说的满意化。 |
| 52 | [[前景理论]] | 前景理论是描述人在不确定下如何决策的行为模型：价值取决于相对参考点的得失而非最终财富，损失比等量收益更痛，小概率被高估、大概率被低估。 |
| 53 | [[损失厌恶]] | 损失厌恶指同样金额的损失带来的痛苦显著大于等量收益带来的快乐（约两倍），人们因此会不惜代价避免损失、紧握已拥有的东西。 |
| 54 | [[助推]] | 助推是通过改变选择架构（默认选项、信息呈现、提醒时机）引导行为向更好方向，而不禁止任何选项、也不显著改变经济激励的做法。 |
| 55 | [[路径依赖]] | 路径依赖指历史事件与早期选择通过锁定效应塑造后续发展，使最终结果未必是最优者胜出，而可能是“先到者”胜出。 |
| 56 | [[帕累托最优]] | 帕累托最优是一种无法再通过任何改变让某人变好而不使他人变坏的资源配置状态；帕累托改进则是至少让一人变好且无人变坏的改变。 |
| 57 | [[收入分配]] | 收入分配研究一个社会的产出如何在劳动与资本、不同人群与家庭之间分配，以及工资、利润、租金与转移支付如何决定这种分配。 |
| 58 | [[基尼系数]] | 基尼系数是基于洛伦兹曲线度量收入或财富分配不平等程度的指标：0 表示完全平均，1 表示一人独占全部。 |
| 59 | [[贫困陷阱]] | 贫困陷阱指贫困状态自我维持的机制：穷到无法储蓄、投资健康与教育，因而难以跳出贫困，形成“越穷越难翻身”的循环。 |
| 60 | [[寻租]] | 寻租是通过游说、牌照争夺、管制俘获等非生产性活动，获取或保护既有“租金”（超额收益）的行为；它消耗资源却不创造价值。 |

## 下期（61–90）：宏观、金融、增长与数字经济

| # | 概念 | 一句话定义 |
| ---: | --- | --- |
| 61 | [[国内生产总值]] | 国内生产总值（GDP）是一国境内一定时期内生产的全部最终产品与服务的市场价值总和；它衡量经济活动的规模与增速，是宏观经济的核心标尺。 |
| 62 | [[经济增长]] | 经济增长是人均产出（收入）的长期持续提升；它由资本积累、人力资本与技术进步的复合作用驱动，复利效应使其差异在代际间被急剧放大。 |
| 63 | [[全要素生产率]] | 全要素生产率（TFP）是产出中无法由资本与劳动投入数量解释的“剩余部分”，反映技术、组织、配置与制度带来的综合效率；索洛称其为“余值”。 |
| 64 | [[人力资本]] | 人力资本是凝结在人身上的知识、技能、健康与经验，它们像机器一样能提高生产率、需要投资（教育、培训、医疗）且会折旧（遗忘、技能过时）。 |
| 65 | [[经济周期]] | 经济周期是总产出围绕长期趋势的扩张与收缩波动，包含繁荣、衰退、萧条与复苏阶段；其根源在需求冲击、信贷周期、技术冲击与预期的相互作用。 |
| 66 | [[失业]] | 失业是有劳动能力、正在找工作的人找不到工作；按成因分为摩擦性（匹配需时间）、结构性（技能与岗位错配）与周期性（总需求不足）。 |
| 67 | [[通货膨胀]] | 通货膨胀是总体价格水平的持续上升，使货币购买力下降；它源于总需求过旺、成本推动或货币增长过快，并受预期影响而自我强化。 |
| 68 | [[货币]] | 货币是承担交换媒介、记账单位与价值储藏功能的制度；现代货币主要是信用货币，其价值来自信任与法定地位，而非内在材质。 |
| 69 | [[中央银行]] | 中央银行是负责发行货币、制定货币政策、维护金融稳定并充当最后贷款人的机构；其效力高度依赖可信的独立性。 |
| 70 | [[利率]] | 利率是资金的价格：它补偿时间的等待、通胀的侵蚀与违约的风险；名义利率扣除通胀才是实际利率。 |
| 71 | [[货币政策]] | 货币政策是中央银行通过调节政策利率、存款准备金与公开市场操作（必要时量化宽松）影响信贷条件、总需求与通胀的整套工具。 |
| 72 | [[财政政策]] | 财政政策是政府通过调整支出与税收影响总需求、收入分配与资源配置的政策；赤字与债务是其跨期工具，自动稳定器是其内置缓冲。 |
| 73 | [[比较优势]] | 比较优势指即使一方在所有活动上都更高效（拥有绝对优势），只要双方各自专注于机会成本相对更低的活动并交换，双方仍能获益。 |
| 74 | [[自由贸易与保护主义]] | 自由贸易主张减少跨境货物、服务与资本流动的壁垒；保护主义则用关税、配额、补贴与出口管制保护本国产业，二者之争本质是效率与分配、安全与开放之间的权衡。 |
| 75 | [[汇率]] | 汇率是一国货币兑换另一国货币的价格；长期由购买力与生产率决定，短期则被利差、资本流动与预期主导，其制度安排有浮动、固定与管理浮动之分。 |
| 76 | [[全球价值链]] | 全球价值链是指产品生产被拆解为设计、零部件、组装、营销等环节、分散到多国完成的组织形态；贸易的真正内容因此是“任务”而非“成品”。 |
| 77 | [[风险分散]] | 风险分散是通过持有多种相关性低的资产（或开展多种不相关业务）降低组合整体波动而不必然降低期望收益的技术；它消除的是非系统性风险。 |
| 78 | [[有效市场假说]] | 有效市场假说（EMH）认为资产价格已充分反映可用信息，因此难以持续跑赢市场；其强弱形式分别对应历史价格、公开信息与内幕信息。 |
| 79 | [[资产泡沫]] | 资产泡沫是资产价格脱离基本面支撑、由“价格上涨预期本身”推动的自我强化上涨；它最终因新增买家枯竭而破裂，典型路径是狂热、迟疑与恐慌。 |
| 80 | [[系统性风险]] | 系统性风险是单个机构或市场的冲击通过传染、共同敞口与流动性螺旋扩散为整个体系崩溃的风险；2008 年金融危机是其教科书式案例。 |
| 81 | [[创新]] | 创新是把新想法落实为新产品、新方法、新市场或新组织形态并创造价值的过程；它与发明不同——发明是想法，创新是商业化与扩散。 |
| 82 | [[创造性破坏]] | 创造性破坏是创新不断淘汰旧技术、旧企业与旧技能、同时创造新结构的过程；熊彼特视之为资本主义经济的本质发动机。 |
| 83 | [[知识产权]] | 知识产权（专利、版权、商标、商业秘密）是政府为激励创造而授予的暂时性排他权：用一段时间的垄断，换取创新的公开披露与商业化激励。 |
| 84 | [[技术性失业]] | 技术性失业是技术进步直接取代部分工作岗位的现象；历史上由新任务创造与工资调整补偿，但补偿需要时间，且技能偏向型技术会重塑收入分配。 |
| 85 | [[网络效应]] | 网络效应是产品的价值随使用者数量增加而上升的现象——直接效应来自同侧用户互连（电话、社交），间接效应来自跨侧生态繁荣（平台、应用商店）。 |
| 86 | [[平台经济]] | 平台经济是以数字平台为中介、协调多边用户（消费者、商家、开发者、广告主）互动并从中撮合与治理的经济形态；双边市场与交叉网络效应是其核心结构。 |
| 87 | [[数据要素]] | 数据要素指数据作为可投入生产、训练与预测的要素，与劳动、资本并列；其经济特性是可用性非竞争、边际复制近零、价值依赖场景与组合。 |
| 88 | [[零边际成本]] | 零边际成本指数字产品多复制一份、多服务一个用户的增量成本趋近于零；这让传统“按成本定价”失效，也重塑了价格、竞争与商业模式。 |
| 89 | [[反垄断]] | 反垄断（竞争政策）是通过禁止垄断协议、滥用支配地位与有害并购来维护竞争过程的法律与政策体系；它处罚的是反竞争行为，而非规模本身。 |
| 90 | [[经济学的边界]] | 经济学提供关于稀缺、激励、权衡与制度的分析工具，但不自动裁决价值：什么是值得追求的生活、权利如何排序、代际责任多重，都需要伦理、政治与公共讨论补完。 |
