# 需求

> 一句话定义：需求是在其他条件不变时，消费者在不同价格下愿意且能够购买的数量关系；价格上升通常使需求量下降，这一关系被称为需求定律。

## 它解决的问题

“想要”不等于“需求”：需求必须有支付能力与购买意愿支撑。需求分析帮助判断：降价能带来多少增量、提价会流失多少用户、市场容量到底多大。

它把“用户很多”这种模糊感觉变成“在什么价格下有多少人愿意买”的可检验问题。

## 它反对或区别于

- **[[供给]]：需求来自消费者一侧，供给来自生产者一侧
- **[[市场均衡]]：需求与供给共同决定价格与数量
- **[[弹性]]：需求对价格的反应强度
- **[[偏好]]：偏好加收入与约束才构成需求
- **常见误解：**“需求量上升”等于“需求上升”；前者沿曲线移动，后者是整条曲线平移

## 一个代表人物／传统

- **阿尔弗雷德·马歇尔：**以需求曲线系统化需求分析
- **边际主义传统：**从边际效用推导需求曲线
- **实证研究：**用价格实验与 A/B 测试估计真实需求
- **行为经济学：**修正需求对价格的机械反应

## 技术或生活案例

**场景：**你把 API 价格从每千次 0.5 元涨到 0.8 元。

**分析：**需求定律预测调用量会下降，但下降多少取决于弹性：替代品多则流失大，绑定深则流失小。先用小范围价格实验测弹性，再决定全面调价，比拍脑袋可靠。

## 我自己的反问

- 我说“用户需要”时，有没有检验他们的支付意愿？
- 价格变化时，用户会转向什么替代品？
- 我观察到的是需求量变化还是需求本身变化？
- 哪些非价格因素（收入、偏好、预期）正在移动需求曲线？
- 免费策略是扩大了需求，还是只是掩盖了价格信号？
