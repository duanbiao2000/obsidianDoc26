# 零边际成本

> 一句话定义：零边际成本指数字产品多复制一份、多服务一个用户的增量成本趋近于零；这让传统“按成本定价”失效，也重塑了价格、竞争与商业模式。

## 它解决的问题

软件、内容与数据拷贝的边际成本几乎为零，若按边际成本定价，价格趋零——于是数字企业转向订阅、广告、增值服务与价值定价来回收巨大的固定开发成本。

这也意味着：在位者可用“免费+增值”压制进入者；盗版与共享难以禁止；知识产品天然滑向公共物品，需要制度维持生产激励。

## 它反对或区别于

- **[[边际成本]]：趋零是边际成本的极端情形
- **[[自然垄断]]：高固定成本与低边际成本的相似结构
- **[[公共物品]]：数字产品趋近非竞争性
- **[[知识产权]]：保护零成本复制品的制度
- **常见误解：**边际成本为零=总成本为零或“就该免费”；开发、维护、合规与客服成本真实存在

## 技术或生活案例

**场景：**你的 AI API 每多一次调用，边际成本主要是算力，接近零但非零。

**分析：**定价逻辑于是变成：按用量收费覆盖算力边际成本，订阅费覆盖研发与维护的固定成本，增值层捕捉差异化价值。三个价格锚对应三类成本，混为一谈就会亏损或吓跑用户。
