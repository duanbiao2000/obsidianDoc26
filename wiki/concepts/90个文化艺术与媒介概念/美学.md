# 美学

> 一句话定义：美学（aesthetics，鲍姆加登 1750 年命名：aisthesis＝感性之学）研究感性认识与审美经验：传统核心问题是"美是什么"（客观论：比例、和谐、完善；主观论：美在观赏者眼中）；康德《判断力批判》给出转折性框架——审美判断是"无功利而愉悦、无概念而普遍、无目的而合目的"的（我欣赏晚霞不为占有它，也不需先懂气象学）；20 世纪美学转向：分析美学（审美判断的语言分析）、实用主义美学（杜威：艺术即经验——审美回到日常生活）、以及当代扩展（环境美学、身体美学、日常美学、数字美学）——美学的现代命运：从"美的哲学"变成"审美经验与判断的哲学"，并成为批判理论的一部分（审美意识形态：见[[文化资本]]（上期））。

## 它解决的问题

审美判断可能客观吗？美学的经典难题：趣味的主观性与普遍性之争（休谟求"趣味的标准"，康德用"共通感"担保普遍性，布尔迪厄揭露趣味的社会性——见[[趣味]]）；审美的无利害性与艺术的介入性之争（无功利审美 vs 艺术的政治——见[[先锋派]]）；审美与伦理的关系（美能是善的象征吗？纳粹也懂美学——"政治美学化"的危险：见[[仪式]]（上期））；"美"的衰落与"审美"的扩张（当代艺术不再追求美，但审美经验扩展到一切感官领域）；对理工科：美学是"体验设计"的底层理论（人机交互的"愉悦感"、界面的"和谐"、产品的"合目的性"都是康德问题的工程化）；"美"在工程中不是装饰而是可用性的组成部分（吸引、信任、留驻——见[[设计]]）。

## 它反对或区别于

- **[[艺术]]：美学的对象不止艺术（自然、日常、身体）
- **[[趣味]]：审美判断的社会层
- **[[形式主义]]：审美的一个理论分支
- **[[再现]]：审美与摹仿的纠葛
- **常见误解：**"美学=艺术理论"；美学研究一切感性经验（美食、风景、代码之美、数学之美）；"美学=研究美"也已过时（分析美学更多研究审美判断语句的逻辑）；代码之美（简洁、优雅）是真实的审美范畴——工程师早已是美学的实践者，只是没意识到自己在做美学

## 一个代表人物／传统

- **康德：**《判断力批判》——现代美学奠基
- **鲍姆加登：**学科命名者
- **杜威：**《艺术即经验》
- **维特根斯坦：**美学是"描述性的"而非理论性的

## 技术或生活案例

**场景：**"这个代码很优雅""这个 API 设计很美"——程序员的美学判断可靠吗？

**分析：**用康德框架检验：代码"优雅"判断符合审美判断的结构——无功利（优雅的代码不一定更高效——但判断时不盘算功利）、无概念（说不出哪条规则让它优雅，却能直接感到）、无目的而合目的（它仿佛为可读性而生却非刻意设计）；可见工程师群体有自己的审美共同体（共识靠"共通感"式默契维持：code review 中的"这很丑"）。工程含义：审美判断是真实的质量信号（优雅的代码往往 bug 更少——简洁性与正确性相关）；审美训练（读好代码、重构练习）因此是工程能力而非法外之物；但也要警惕"审美霸权"（"优雅"标准由少数社区权威定义——见[[文化资本]]（上期）的机制：代码审美也有阶层）。
