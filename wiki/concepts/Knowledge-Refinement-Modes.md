# Knowledge-Refinement-Modes

**Type**: Core Framework  
**Category**: Knowledge Management

## Overview

A multi-mode system for transforming raw notes into high-value knowledge assets. Combines five complementary refinement approaches.

---

## The Five Modes

### 1. Knowledge Refinement (Deep Understanding)
- Focus: First-principles explanation + vivid analogies
- Output: Core view → Why → When to use → When NOT to use → How → Glossary
- Best for: Teaching, onboarding, complex concept explanation

### 2. Semantic Compression
- Focus: Rapid extraction using Three-Question Filtering
- Techniques: Minimalist structure, symbolic marking (★ △ ❗), context-independent abstraction
- Best for: Review, indexing, Zettelkasten linking

### 3. Knowledge Distillation (Entropy Filtering)
- Entropy dimensions: Connectivity, Abstraction, Novelty, Irreplaceability
- Process: Identify Top 20% core components using Pareto principle
- Best for: Efficient learning paths and high-density concept identification

### 4. Deep Refinement (Full Sanitization)
- Strict rules: Remove dead links, keep full lists, maintain data integrity
- Goal: Upgrade drafts to permanent archive status
- Best for: Long-term knowledge preservation

### 5. Concept Compression Pack (Mental Model Building)
- Process: Core definition → Metaphor → Boundary cases → Diverse real cases → Core paradox
- Goal: Build high-resolution mental models through case libraries
- Best for: Pattern recognition and decision-making under complexity
