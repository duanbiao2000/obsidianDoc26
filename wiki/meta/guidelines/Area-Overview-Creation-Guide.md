# Area & Overview Page Creation Guide

**Version**: 1.0  
**Date**: 2026-06-29

## When to Create an `area` Page

- When a knowledge domain reaches **15+ pages**
- When you need a central navigation point (MOC)

**Examples**:
- `areas/English.md`
- `areas/IELTS.md`
- `areas/PKM.md`

## When to Create an `overview` Page

- When you have multiple `synthesis` pages on the same topic
- When you want a strategic summary of a domain

## Recommended Structure

### `area` Page (MOC)

```markdown
# English

## Core Concepts
- [[Lexical-Chunk-System]]
- [[Eliminate-Weak-Language]]

## Key Entities
- [[IELTS]]

## Projects
- [[IELTS-Preparation-Project]]

## Quick References
- [[English-Expression-速查]]
```

### `overview` Page

```markdown
# English Expression Overview

## Current Thesis
[High-level summary]

## Major Frameworks
- Framework 1
- Framework 2

## Open Questions
- Question 1
```
