# Tana

Tana is a next-generation knowledge management tool that combines Notion's database views with Roam Research's bidirectional linking capabilities. It is rated **A Tier** in the source "27 Learning Techniques and Productivity Tools Tier List."

## Key Features

- **Database views** — Similar to Notion, with tables, lists, and galleries.
- **Bidirectional linking** — Automatic backlinks between nodes.
- **Supertags** — Customizable metadata and templates for different node types.
- **Live search** — Real-time search across all content.
- **API and integrations** — Extensible through API.

## Strengths

- **Powerful combination** — Merges the best features of Notion and Roam.
- **Flexibility** — Supertags allow for structured data without rigid schemas.
- **Modern interface** — Clean, fast, and responsive.

## Weaknesses

- **Beta status** — Still in development, with potential instability.
- **Learning curve** — The combination of features can be complex.
- **Cloud-only** — No local storage option.

## Comparison with Other Tools

- [[notion]] — Notion is more mature and has broader project management features; Tana has better linking and a more modern interface.
- [[obsidian]] — Obsidian is local-first and more customizable; Tana is cloud-based with built-in database features.
- [[roam-research]] — Roam pioneered bidirectional linking but has stagnated; Tana is seen as a more modern evolution.
