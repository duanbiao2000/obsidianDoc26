# Perplexity

Perplexity is an AI-powered research and conversational search engine that provides answers to questions with cited sources. It combines large language model capabilities with real-time web search.

## Key Features
- AI-powered search with cited sources
- Conversational interface for follow-up questions
- Real-time web search integration
- Free tier with premium subscription for advanced features

## Relevance to Wiki
Perplexity is a key tool for [[self-directed learning]] and research, complementing [[ChatGPT]] for AI tutoring and [[Google Scholar]] for academic search. It connects to AI agent workflows discussed in [[Learn Claude Code]] and [[AI 編碼代理核心循環]].
