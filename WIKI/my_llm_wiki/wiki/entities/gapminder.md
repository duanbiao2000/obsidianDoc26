# Gapminder

Gapminder is a non-profit organization that promotes sustainable global development by using data to debunk misconceptions about the world. It provides interactive data visualizations and teaching resources.

## Key Features
- Interactive data visualizations on global trends
- Tools like Gapminder World and Dollar Street
- Teaching resources and presentations
- Free access to all content

## Relevance to Wiki
Gapminder is a key resource for [[self-directed learning]] in global development and data literacy, complementing [[Our World in Data]] for research-based visualizations and [[Statista]] for broader statistics.
