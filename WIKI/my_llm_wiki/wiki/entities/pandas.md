# pandas

**pandas** 是一個基於 Python 的開源資料分析和操作函式庫。它提供了高效能、易於使用的資料結構，如 DataFrame 和 Series，使得資料的載入、清洗、轉換、分析和視覺化變得非常便捷。pandas 是資料科學和資料工程領域中最受歡迎的工具之一。

## 在資料管道中的作用

在[[etl-管道]]中，pandas 主要用於 **Transform (轉換)** 階段，特別是在 Python 程式碼中進行資料清洗和預處理：
*   **資料清洗**：pandas 提供了豐富的功能來處理資料中的常見問題，例如：
    *   **缺失值處理**：填充、刪除或插補缺失值。
    *   **重複值處理**：識別並刪除重複的行。
    *   **資料格式化**：轉換資料類型、日期時間格式、字串操作等。
    *   **資料篩選與排序**：根據條件篩選資料，或按特定列排序。
*   **資料轉換**：
    *   **特徵工程**：創建新特徵、聚合資料。
    *   **資料合併與聯結**：將多個資料集根據共同鍵進行合併。
    *   **資料重塑**：樞紐分析、堆疊/解堆疊等。

由於其直觀的 API 和強大的功能，pandas 成為資料工程師和資料分析師在處理中小型資料集時進行資料清洗和轉換的首選工具。對於大規模資料集，通常會結合 [[Spark]] 等分散式處理框架使用。
