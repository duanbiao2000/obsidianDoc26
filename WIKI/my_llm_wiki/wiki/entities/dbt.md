# dbt

**dbt** (data build tool) 是一個開源的資料轉換框架，專為資料分析師和資料工程師設計，用於在資料倉儲中以 SQL 為中心進行資料轉換。它允許使用者將 SQL 查詢編寫為模型，並透過版本控制、測試和文件來管理這些模型。

## 在資料管道中的作用

在[[etl-管道]]中，dbt 主要負責 **Transform (轉換)** 階段。它使得資料團隊能夠：
*   **模組化 SQL 轉換**：將複雜的資料轉換邏輯分解為可重用、可測試的 SQL 模型。
*   **建立資料血緣**：自動追蹤資料從原始來源到最終報表的轉換路徑。
*   **實施資料品質測試**：在資料載入到下游系統之前，對資料進行自動化測試，確保資料的準確性和完整性。
*   **生成資料文件**：自動為資料模型和轉換邏輯生成文件，提高團隊協作效率。

dbt 的核心理念是將軟體工程的最佳實踐（如版本控制、測試、文件）引入到資料轉換流程中，從而提高資料轉換的可靠性、可維護性和效率。它通常與雲端資料倉儲（如 [[Snowflake]]、BigQuery、Redshift）結合使用。
