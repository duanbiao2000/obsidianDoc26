# OpenLibrary

OpenLibrary is an open, editable library catalog that aims to create a web page for every book ever published. It allows users to borrow millions of books online for free, including both public domain and in-copyright works.

## Key Features
- Borrow millions of books online for free
- Includes both public domain and in-copyright works
- Editable catalog with community contributions
- Integrated with [[Archive.org]]

## Relevance to Wiki
OpenLibrary is a key resource for [[self-directed learning]], providing free access to a vast collection of books. It complements [[Project Gutenberg]] for public domain works and [[Librivox]] for audiobooks.
