# Claude Code

[[Claude Code]] 是一個特定的 AI 編碼代理，被 [[Learn Claude Code]] 教程作為一個參考目標，用於展示如何從零開始建構一個具備類似功能的 AI 系統。它代表了一種能夠自主理解、規劃、執行和測試程式碼的先進 AI 代理。

## 核心能力

雖然具體細節未完全揭露，但從教程內容推斷，Claude Code 類型的代理應具備以下核心能力：

*   **[[AI 編碼代理核心循環]]**：能夠執行「呼叫模型、執行工具、回饋結果」的迭代循環，以逐步完成編碼任務。
*   **工具使用**：能夠有效地利用各種開發工具（如程式碼編輯器、編譯器、測試框架、版本控制系統）來執行任務。
*   **問題解決**：能夠理解複雜的編碼需求，將其分解為可管理的子任務，並逐步解決。
*   **協作潛力**：能夠與其他代理協作，形成[[代理團隊]]，共同完成大型專案。
*   **環境隔離**：能夠在獨立的執行環境中工作，例如透過[[工作樹-task-isolation]]機制，確保任務之間互不干擾。

## 在教程中的角色

在 [[Learn Claude Code]] 教程中，Claude Code 作為一個「納米級」的實現目標，幫助學習者理解和掌握建構複雜 AI 編碼代理所需的各種機制和架構層次。它不僅是一個產品，更是一個概念模型，展示了現代 AI 代理在軟體開發領域的潛力。
