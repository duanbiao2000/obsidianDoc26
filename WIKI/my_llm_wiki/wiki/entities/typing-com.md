# Typing.com

Typing.com is a free online typing tutor that helps users learn to type properly and improve their typing speed and accuracy through structured lessons and games.

## Key Features
- Free typing lessons for all skill levels
- Structured curriculum with progress tracking
- Typing games and tests
- Available for schools and individuals

## Relevance to Wiki
Typing.com is a foundational skill-building resource for [[self-directed learning]], particularly relevant for coding ([[Codecademy]], [[Replit]]) and any computer-based work.
