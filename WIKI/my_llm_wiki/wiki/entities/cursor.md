# Cursor

**Cursor** is an AI-powered code editor that serves as a central tool in the modern "build first, understand later" paradigm. It enables designers and non-engineers to bridge the gap between conceptual design and executable code by leveraging AI agents for iterative collaboration.

## Role in Modern Development

Cursor facilitates **[[AI-Mediated Prototyping]]** by allowing users to generate runnable code prototypes directly, bypassing the need for static mockups in tools like **Figma**. Its philosophy emphasizes:

*   **Plan Mode:** Decomposing complex tasks into manageable steps.
*   **Iterative Collaboration:** Treating AI interaction as a dialogue rather than a one-off prompt.
*   **Sandboxing:** Providing safe environments to test and verify code without local environment pollution.

## Impact on Design Workflow

By lowering technical barriers such as Git, npm, and terminal usage, Cursor empowers designers to adopt **[[The Builder Role]]**. It shifts the focus from visual decoration to **[[Conceptual System Design]]**, enabling rapid iteration on real behavior and data rather than static states.
