# New York Elite Social Code

An archetypal social code governing behavior in elite New York circles. The core principle is **social awareness** — respecting others' time, space, and attention.

## Core Values

- **Accountability:** Own your failures; don't blame external factors.
- **Efficiency:** Get to the point; don't waste cognitive bandwidth.
- **Boundaries:** Don't ask personal questions (salary, age, relationships) on first meeting.
- **Authenticity:** Don't perform indifference to money; don't name-drop.

## Language Rules

| Rough Expression | Elite Alternative |
|---|---|
| "Like, like, like..." | "I mean..." or pause |
| "You know what I'm saying?" | "Does that make sense?" |
| "Basically, basically, basically..." | Say it once, then develop |
| "Whatever" | "Fair enough" |
| "I was like..." | "I said..." / "My reaction was..." |

## Social Taboos

- Being late without warning
- Checking phone during meetings
- Excessive preamble before making a point
- Asking a question and not listening to the answer
- Getting someone's name wrong without apologizing
- Scanning the room while talking to someone
- Name-dropping
- "Do you know who I am?"

## Conversation Taboos

- "I'm so busy" as a status signal
- Oversharing therapy details on first meeting
- Blaming external factors for failures
- Performing indifference to money in startup circles

## Hardest-to-Fake Tells

- Knowing exactly when to stop talking
- Being genuinely curious about the other person without performing it
- Disagreeing without needing to win
