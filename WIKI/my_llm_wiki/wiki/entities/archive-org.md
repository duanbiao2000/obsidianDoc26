# Archive.org

Archive.org (Internet Archive) is a non-profit digital library offering free access to millions of books, movies, software, music, websites, and more. It includes the Wayback Machine for browsing archived versions of web pages.

## Key Features
- Millions of free books, movies, software, and music
- Wayback Machine for historical web page access
- Open Library integration for borrowing digital books
- Free and open to all users

## Relevance to Wiki
Archive.org is a cornerstone resource for [[self-directed learning]], providing access to a vast repository of human knowledge. It complements [[Project Gutenberg]] for classic literature and [[OpenLibrary]] for borrowing books.
