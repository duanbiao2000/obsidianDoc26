# Figma

Figma is a web-based vector graphics editor and prototyping tool primarily used for user interface (UI) and user experience (UX) design. It offers a free tier with collaborative features.

## Key Features
- Web-based vector graphics editor
- Real-time collaboration and commenting
- Prototyping and design system management
- Free tier with extensive features
- Large community with templates and plugins

## Relevance to Wiki
Figma is a key resource for [[self-directed learning]] in professional design, complementing [[Canva]] for simpler design tasks and [[Drawabox]] for drawing fundamentals.
