# Canva

Canva is a graphic design platform that allows users to create social media graphics, presentations, posters, documents, and other visual content using drag-and-drop templates. It offers a free tier with premium features available.

## Key Features
- Drag-and-drop design interface
- Thousands of templates for various use cases
- Free tier with extensive features
- Collaboration and team features
- Integrates with [[Grammarly]] and other tools

## Relevance to Wiki
Canva is a key tool for [[self-directed learning]] in design and visual communication, complementing [[Figma]] for professional design and [[Grammarly]] for writing. It also relates to [[生產力優化]] and [[家庭辦公室設置]] as a productivity tool.
