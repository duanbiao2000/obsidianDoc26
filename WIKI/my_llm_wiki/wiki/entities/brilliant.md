# Brilliant

Brilliant is an interactive learning platform focused on mathematics, science, and computer science. It uses hands-on puzzles, guided problems, and visual explanations to build intuition and problem-solving skills.

## Key Features
- Interactive, puzzle-based approach to learning
- Covers math, logic, physics, computer science, and data science
- Guided problem-solving with immediate feedback
- Free tier available with premium subscription for full access

## Relevance to Wiki
Brilliant complements other interactive learning tools like [[PhET Simulations]] and [[Desmos]], providing a structured yet exploratory approach to STEM education. It is a key resource for [[self-directed learning]] in quantitative fields.
