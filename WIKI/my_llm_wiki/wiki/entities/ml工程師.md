# ML 工程師

[[ML工程師]] (Machine Learning Engineer) 是資料團隊中負責將機器學習模型從開發環境整合到生產系統，並確保其穩定、高效運行的專業人員。他們是 [[MLOps]] 實踐的核心推動者。

## 職責與產出
在「[[數據團隊端到端的業務場景：電商平台使用者流失預警系統]]」中，ML 工程師的主要職責和產出包括：
*   **模型生產化部署**：將 [[資料科學家]] 訓練好的模型部署為可提供即時預測服務的 API。
*   **架構設計**：設計模型服務架構，包括特徵服務 (如使用 [[Redis]] 快取特徵)、模型 API (如使用 [[FastAPI]]) 和與下游系統 (如 [[CRM 系統]]) 的整合。
*   **效能優化**：採用技術手段 (如將模型轉換為 [[ONNX]] 格式) 提升模型推理速度和降低延遲。
*   **建立 A/B 測試框架**：用於驗證新模型的效果並逐步推廣。
*   **構建監控體系**：實施 [[資料漂移監控]]、模型性能監控和業務指標監控，確保模型在生產環境中的穩定性和有效性。

## 協作關係
ML 工程師與資料科學家緊密合作，將模型從實驗室帶到生產環境；他們也與 [[資料工程師]] 協作，確保特徵資料的即時性和可用性。
