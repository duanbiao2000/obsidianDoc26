# Obsidian

Obsidian is a local Markdown-based note-taking and knowledge management tool with powerful plugins and bidirectional linking. It stores all notes as plain text files on the user’s computer, with no proprietary format or cloud lock-in. It is rated **A Tier** in the source "27 Learning Techniques and Productivity Tools Tier List."  In a [[Second Brain]] system, Obsidian serves as the “remembering” component, complementing [[NotebookLM]]’s “thinking” role.

## Key Features

- **Local-first / Plain text storage** — Notes are future-proof, truly owned by the user, and stored as plain Markdown files on the user's device.
- **Bidirectional linking / [[wikilink]] system** — Every note can connect to every other note, creating a bi-directional knowledge graph with automatic backlinks.
- **Graph view** — Visualize connections between notes and see all notes that reference each idea.
- **Plugin ecosystem** — Extensive community plugins for customization.
- **Obsidian Publish** — Optional paid service for publishing notes as a website.

## Role in the Second Brain System

In the [[NotebookLM-Obsidian Pipeline]], Obsidian acts as the permanent storage and linking layer. Insights processed by NotebookLM are rewritten in the user’s own words, given insight-titled names, organized using the [[PARA Method]], and linked to related notes. Obsidian notes can then be fed back into NotebookLM for meta-analysis.

## PARA Organization

The source recommends organizing Obsidian into four [[PARA Method]] folders:

- **Projects** — Short-term efforts with deadlines
- **Areas** — Ongoing responsibilities without deadlines
- **Resources** — Topics of interest not currently active
- **Archives** — Everything finished or inactive

## Strengths

- **Freedom and flexibility** — Users have complete control over their note structure.
- **Privacy** — Local storage means no data leaves the user's device.
- **Longevity** — Plain Markdown files are future-proof and portable.
- **Customization** — Plugins and themes allow deep personalization.

## Weaknesses

- **Setup overhead** — Requires time to configure and maintain.
- **Learning curve** — The flexibility can be overwhelming for new users.
- **No built-in sync** — Syncing across devices requires additional setup (e.g., iCloud, Git).

## Comparison with Other Tools

- [[notion]] — Notion is more all-in-one (databases, project management) but cloud-dependent; Obsidian is more focused on note-taking and local storage.
- [[roam-research]] — Roam pioneered bidirectional linking but is cloud-only and subscription-based; Obsidian offers similar functionality with local storage.
- [[tana]] — Tana combines Notion's database views with Roam's linking, but is still in beta.
- [[logseq]] — Open-source and similar to Obsidian, but with a different interface and workflow.
