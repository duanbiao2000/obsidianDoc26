# Anki

Anki is a free, open-source flashcard program that uses spaced repetition to optimize memory retention. It is widely used for language learning, medical studies, and any domain requiring memorization of large amounts of information.

## Key Features
- Spaced repetition algorithm for efficient memorization
- Supports text, images, audio, and video in flashcards
- Customizable decks and card templates
- Cross-platform (desktop, mobile, web)
- Large community with shared decks

## Relevance to Wiki
Anki is described in the source as "the most powerful memory tool ever built." It is central to language learning workflows in the wiki, complementing [[Duolingo]] for structured lessons and [[Quizlet]] for flashcard study. It connects to existing content on [[English is EZ with Connor]] and the shadowing methodology.
