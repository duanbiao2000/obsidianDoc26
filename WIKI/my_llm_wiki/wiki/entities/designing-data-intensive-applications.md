# Designing Data-Intensive Applications

**Designing Data-Intensive Applications (DDIA)** is a seminal book in the field of data engineering and software architecture. It provides a comprehensive overview of the principles and practices behind building reliable, scalable, and maintainable data systems.

## Core Themes

*   **Data System Architecture Trade-offs**: Understanding the choices between analytical vs. transactional systems, cloud vs. self-hosted, and distributed vs. single-node systems.
*   **Non-Functional Requirements (NFRs)**: Defining and prioritizing performance, reliability, scalability, and maintainability.
*   **Data Models and Query Languages**: Exploring relational, document, graph, and event-sourcing models.
*   **Storage and Retrieval**: Deep dive into OLTP storage, indexing, and analytical data storage.
*   **Replication and Sharding**: Strategies for scaling data systems horizontally.
*   **Transactions and Consistency**: Understanding ACID properties, isolation levels, and distributed consensus.
*   **Batch and Stream Processing**: Paradigms for processing large volumes of data, both in batches and in real-time streams.

## Relevance to Data Engineering

DDIA is considered essential reading for [[資料架構師|Data Architects]] and [[資料工程師|Data Engineers]]. It bridges the gap between theoretical concepts and practical implementation, providing a foundation for understanding tools like [[Airflow]], [[Kafka]], [[MongoDB]], and [[MySQL]].
