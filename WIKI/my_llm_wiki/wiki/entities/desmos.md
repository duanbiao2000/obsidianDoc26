# Desmos

Desmos is a free, web-based graphing calculator that allows users to graph functions, plot data, evaluate equations, and explore transformations interactively.

## Key Features
- Free, powerful graphing calculator
- Interactive function plotting and data visualization
- Sliders for exploring parameter changes
- Classroom activities and teaching resources
- Works in browser and as mobile app

## Relevance to Wiki
Desmos is a key tool for [[self-directed learning]] in mathematics, complementing [[Wolfram Alpha]] for computational answers and [[Brilliant]] for interactive problem-solving. It also connects to [[Khan Academy]] for structured math learning.
