# Mindmeister

Mindmeister is a web-based mind mapping tool that allows users to create, share, and collaborate on mind maps for brainstorming, project planning, and organizing ideas.

## Key Features
- Web-based mind mapping with real-time collaboration
- Templates for various use cases
- Integration with [[Notion]] and other tools
- Free tier with basic features

## Relevance to Wiki
Mindmeister is a tool for [[生產力優化]] and visual thinking, complementing [[Notion]] for organization and [[Readwise]] for knowledge management. It supports [[self-directed learning]] by helping structure and connect ideas.
