# Codecademy

Codecademy is an interactive online platform that offers free coding classes in programming languages including Python, JavaScript, HTML/CSS, SQL, and more. It provides hands-on coding exercises with immediate feedback.

## Key Features
- Interactive coding exercises in the browser
- Free tier with structured learning paths
- Covers Python, JavaScript, HTML/CSS, SQL, and more
- Immediate feedback on code
- Paid Pro tier for additional features

## Relevance to Wiki
Codecademy is a primary resource for [[self-directed learning]] in programming, complementing [[GitHub]] for real-world projects and [[Replit]] for browser-based coding.
