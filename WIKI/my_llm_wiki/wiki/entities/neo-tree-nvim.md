# neo-tree.nvim

[[neo-tree.nvim]] is a Neovim plugin that provides a file explorer in the form of a sidebar tree view. It was the default file browser in [[LazyVim]] versions prior to 3.x. [[neo-tree.nvim]] offers a visual, hierarchical representation of the file system, allowing users to navigate, open, and manage files and directories through a dedicated interface.

## Key Features

*   **Tree View:** Displays files and directories in a collapsible tree structure.
*   **Git Integration:** Shows git status indicators next to files.
*   **Customization:** Supports custom icons, keybindings, and filters.
*   **Multiple Windows:** Can be opened in multiple windows or tabs.

## Legacy Status in LazyVim

With the release of [[LazyVim]] 3.x, [[neo-tree.nvim]] was replaced by [[oil.nvim]] as the default file explorer. However, users can still install and configure [[neo-tree.nvim]] manually if they prefer its tree-based navigation paradigm over the buffer-based approach of [[oil.nvim]].
