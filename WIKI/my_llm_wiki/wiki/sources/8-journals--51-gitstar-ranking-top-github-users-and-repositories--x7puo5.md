# Gitstar Ranking - Top GitHub users and repositories

This source provides a link to **Gitstar Ranking**, a third-party service that ranks GitHub users, organizations, and repositories based on their star counts. It serves as a tool for discovering popular or influential open-source projects and benchmarking one's own rank within the community.

The source also references the table of contents for **"Designing Data-Intensive Applications" (DDIA)**, specifically the Chinese translation hosted by Vonng. This book is a seminal text in data engineering, covering fundamental trade-offs in data system architecture, non-functional requirements, data models, storage and retrieval, replication, sharding, transactions, distributed systems challenges, consistency, batch processing, and stream processing.

## Key Concepts

*   **GitHub Star Ranking**: A metric-based ranking system for open-source projects and contributors based on community engagement (stars).
*   **Data System Architecture Trade-offs**: The core theme of DDIA Chapter 1, discussing choices between analytical vs. transactional systems, cloud vs. self-hosted, etc.
*   **Non-Functional Requirements (NFRs)**: DDIA Chapter 2 focus: performance, reliability, scalability, and maintainability.
*   **Distributed Systems Challenges**: Covered in DDIA Chapters 9-10: faults, network unreliability, consistency, and consensus.
*   **Batch vs. Stream Processing**: DDIA Chapters 11-13. Distinction between processing data in chunks vs. continuous events.
