# 让句法替你完成一半的论证 (Let Syntax Do Half Your Arguing)

This source presents a pedagogical framework for advanced English argumentation, arguing that high-scoring speakers (IELTS 8.5) rely on syntactic structure rather than explicit content to persuade. It introduces five core syntactic techniques — concessive reversal, parallel contrast, dangling participles, subjunctive mood, and nominalization chain reactions — each demonstrated with multiple example sentences across various debate topics. The source claims that grammatical "shape" pre-commits the listener to a conclusion before evidence is presented, positioning this as the key differentiator between band 7 and band 8.5 performance.

## Key Techniques

1. **Concessive Reversal** — `However/For all/Much as + clause, main clause negates`
2. **Parallel Contrast** — Symmetrical sentence shells with contrasting lexical content
3. **Dangling Participle** — Fronted participial phrase setting emotional tone
4. **Subjunctive as Argumentation** — Counterfactual `Had/Were to/Without` constructions
5. **Nominalization Chain Reaction** — Compressing causal arguments into noun phrase subjects
6. **Short Sentence Hammer** — Brief declarative sentence following complex structure
