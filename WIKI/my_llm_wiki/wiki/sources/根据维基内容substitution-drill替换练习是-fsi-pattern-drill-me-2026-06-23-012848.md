# 根据维基内容：Substitution Drill替换练习是FSI Pattern Drill

## 来源概述

本来源基于已有维基知识库内容（特别是 [[8-journals--41-2026-03-13-fsis-pattern-drill-methodology--hly2u4]]），提出了一个概念分类主张：**Substitution Drill（替换练习）属于 FSI Pattern Drill Methodology 的范畴**。

## 核心主张

来源标题将 Substitution Drill 直接表述为"是 FSI Pattern Drill"，即替换练习等同于或归类于 FSI 的句型操练方法论。这一主张的逻辑基础是：替换练习作为 FSI 方法论中最核心的操练子类型之一，在操作机制上完全符合 FSI Pattern Drill 的定义框架。

## 概念精确性备注

需注意范畴上的区分：FSI Pattern Drill Methodology 是一个包含多种操练变体的宏观教学法体系（包括 [[substitution-drill]]、Transformation Drill、Response Drill 等），而 Substitution Drill 是其中的一个具体子类型。将两者直接等同可能混淆子集与全集的关系。更精确的表述应为：**Substitution Drill 是 FSI Pattern Drill Methodology 的核心子类型之一**。
