# 27 Learning Techniques and Productivity Tools Tier List

This source is a tier list ranking 27 learning techniques and a large set of productivity tools, based on the subjective opinion of a YouTube creator (video linked: [https://www.youtube.com/watch?v=xEAGAKE0z_8](https://www.youtube.com/watch?v=xEAGAKE0z_8)). The rankings are anecdotal and opinion-based, not evidence-based research. The value lies in the comparative framework and the creator's reasoning.

## Learning Techniques Rankings

The source contains two separate tables with some conflicting ratings.

### Table 1: 27 Learning Techniques

| Tier | Techniques |
|------|------------|
| S | Feynman Technique (Teaching), Study Planning, Interleaving, Sleep, Creating Content |
| A | Pomodoro, Practice Problems, Priming, Chunking, Spaced Repetition, Mind Mapping, Visual Associations, Active Recall |
| B | Syntopical Reading, Frameworking, Exercise, Group Discussions, Prompting/ChatGPT |
| C | Flashcards, Blurting, Going to Class, Mnemonics, Doing Homework, Studying with Music, Cramming |
| D | Rereading, Highlighting, Rewatching |

### Table 2: 16 Learning Techniques (Alternate)

| Tier | Techniques |
|------|------------|
| S | Spaced Repetition, Sleep |
| A | Practice Papers, Pomodoro, Feynman Technique / Self-Explanation, Active Recall |
| B | Pre-study, Mnemonics, Cornell Note-Taking |
| C | Brain Dumps / Blurting, Summary Pages, Mindmaps |
| D | Flashcards, Watching Videos and Lectures, Listening to Music While Studying, Re-reading and Highlighting |

### Notable Conflicts Between Tables

- **Flashcards:** C (Table 1) vs. D (Table 2)
- **Mind Mapping:** A (Table 1) vs. C (Table 2)
- **Mnemonics:** C (Table 1) vs. B (Table 2)
- **Studying with Music:** C (Table 1) vs. D (Table 2)
- **Priming:** A (Table 1) vs. B (Table 2)
- **Spaced Repetition:** A (Table 1) vs. S (Table 2)

## Key Insights

- The highest-rated learning techniques (S Tier) emphasize active engagement, metacognition, and creation: teaching, planning, interleaving, sleep, and content creation.
- Passive techniques (rereading, highlighting, rewatching) are consistently rated lowest (D Tier).
- The tool rankings reflect a strong preference for flexible, customizable, and indie/innovative tools over enterprise or legacy solutions.
- The source is opinion-based and should be cross-referenced with evidence-based research (e.g., Dunlosky et al., 2013).
