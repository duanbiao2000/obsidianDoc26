# Agentic Learning System & TV-Show Language Learning: Two Methods

This source documents two distinct learning methodologies presented in a conversational, timestamped format. The first method, "How I Use Claude Code + Anki to Memorize Anything (My Agentic Learning System)," describes a workflow that combines the [[Claude Code]] AI agent with the [[Anki]] spaced repetition system to automate and enhance memorization. The second method, a TV-show-based language learning approach, details a systematic process for acquiring a language through subtitled television content.

## Video 1: Agentic Learning System (Claude Code + Anki)

The core thesis is that [[Claude Code]] can "amplify whatever you're already doing" with [[Anki]] without replacing human thinking. The AI automates file handling, quiz generation, and card creation, while the human still decides what matters and how to study deeply.

Key workflow components include:
- **Quiz-first approach:** Feeding a PDF to Claude Code to generate an HTML quiz, taking the quiz to identify knowledge gaps, and then creating targeted Anki flashcards for what was not retained.
- **Timestamped YouTube cards:** Using YouTube's "copy link to current timestamp" feature on the back of Anki cards to enable direct context recovery during review.
- **Transcript extraction:** A Python script pulls full transcripts and video links, which are then processed by Claude Code with custom prompts to extract key sections with timestamps.
- **Database-level automation:** A skill that writes cards directly into the Anki database, automating repetitive card creation.

The source emphasizes that this system is flexible — users can start with simple prompts in a chat interface and add complexity (Claude Code, Obsidian) later. A key caveat is that letting the AI prompt decide everything is a "weak way" to use AI; human intentionality remains essential.

## Video 2: TV-Show Language Learning Method

This method presents television shows as a primary, effective language learning tool when used systematically. The creator learned English 10 years ago using this method and is now applying it to Chinese.

Key principles include:
- **Content selection:** Avoid too-easy (kids' cartoons) and too-hard (legal/medical/political shows). Ideal content is about people and their daily lives, with subtitles in the target language. Examples include sitcoms like *Friends* and *iCarly*, and YouTube vlogs.
- **Learning process:** Watch and write down subtitles, add pronunciation marks, rough grammar breakdowns, and vocabulary explanations using multiple dictionaries (bilingual and monolingual).
- **"Leave it" strategy:** For unknown phrases, skip them — common phrases will reappear naturally, and rare ones are not worth the stress.
- **Shadowing with role-play:** Act like an actor playing a role, starting from an abstract idea in the head and converting it into sounds in the target language, rather than just reading aloud.
- **Review:** Listen to the episode again while reading the personal script, ideally during commutes or other routine activities.

The method acknowledges significant time investment (e.g., watching ten seasons of *Friends* three times) but frames enjoyment as the key sustainer of long-term effort.
