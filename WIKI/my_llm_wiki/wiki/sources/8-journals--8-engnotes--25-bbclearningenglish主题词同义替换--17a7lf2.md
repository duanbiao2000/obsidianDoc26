# BBC Learning English 主题词同义替换

这份资料整理自 [[BBC Learning English]] 频道的教学内容，系统性地提供了雅思口语和写作中的同义替换与高分词汇搭配策略。文档以场景立意为核心，将词汇学习置于具体话题（如社会安全、旅游、学术研究）中，强调通过精准替换和自然搭配来提升语言评分。

## 核心内容

### 1. 核心专题：社会安全与犯罪 (Social Safety & Crime)

文档以“旅游+安全”和“媒体暴力/模仿犯罪”为场景，提供了从基础表达（如 `lone gunman`, `mass shooting`）到精英级替换（如 `single attacker`, `large-scale shooting incident`）的升级路径，并给出了句型改写模板（如 `wounded` → `sustained injuries`）。

### 2. 核心矩阵：10组高频名词及万能动词搭配 (The Core 10)

这是文档最具价值的部分，强调雅思考官看重的是 **Collocations (词汇搭配)**。矩阵按基础生活、学术研究、科技社会三类组织，为每个核心名词（如 `trip`, `goal`, `theory`, `method`, `technology`, `challenge`）提供了动作搭配和高分替换思路。例如：
- `challenge` → `pose a significant challenge` / `rise to the challenge`
- `theory` → `formulate a theory` / `cast doubt on a theory`
- `image` → `polish one's image` / `tarnish one's reputation`

### 3. 分类速查：口语与写作高分替换库

按学习与能力、工作与求职、金钱与理财三个主题，以闪卡形式列出了高频替换对，如：
- `improve` → `enhance` / `elevate`
- `job` → `gig` / `position` / `occupation`
- `save money` → `set aside funds` / `accumulate savings`

### 4. 精细辨析与脚注

提供了对易混淆词汇的深度辨析（如 `devise` 与 `campaign` 的用法区别），以及 `locate` 与 `identify` 在描述 `source` 时的细微差异。
