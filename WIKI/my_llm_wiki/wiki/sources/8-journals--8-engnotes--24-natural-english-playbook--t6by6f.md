# Natural English Playbook

A self-contained pedagogical document arguing that ESL learners' fundamental problem is not insufficient vocabulary but the absence of an operational standard for what "sounds like a real person." The document presents 10 observable, learnable discourse and pragmatic behaviors that constitute natural spoken American English.

## Core Claim

Natural English is a **system of 10 discourse/pragmatic behaviors**, not a vocabulary problem. The document provides contrastive ❌/✅ examples for each rule and an AI prompt for practice.

## The 10 Rules

### Rule 1 — Cushion Requests
Never start with "I want." Always add a modal or softener before the verb.

|❌|✅|
|---|---|
|I want water.|I'll have some water, thanks.|
|I want to know...|I was wondering...|
|I want you to help me.|Would you mind helping me out?|

### Rule 2 — Use Contractions Always
Uncontracted speech sounds robotic. If you catch yourself not using a contraction in casual speech, stop and redo it.

|❌|✅|
|---|---|
|I do not know.|I don't know.|
|I am not sure.|I'm not sure.|
|It is not a problem.|It's not a problem.|

### Rule 3 — Add Fillers for Thinking Time
Native speakers don't pause in silence. One filler word buys 2 seconds naturally.

|Situation|Use|
|---|---|
|Need a second to think|"Hmm, let me think..."|
|Slightly surprised|"Oh wow, actually..."|
|Reconsidering|"I mean, I guess..."|
|Softening opinion|"Honestly, I feel like..."|

### Rule 4 — Replace Textbook Vocab with Spoken Vocab

|❌ Textbook|✅ Spoken|
|---|---|
|However|Though / But honestly|
|Therefore|So|
|In addition|Also / Plus|
|Nevertheless|Still / Even so|
|Commence|Start|
|Inform|Tell|
|Assist|Help|

### Rule 5 — End Statements with a Soft Check-In
Native speakers constantly loop the listener in.

|Tag|Function|
|---|---|
|you know?|sharing common ground|
|right?|seeking light agreement|
|I guess|softening certainty|
|or something|leaving room for correction|
|kind of|hedging|

**Standard:** At least one hedge or check-in per 3 sentences in casual conversation.

### Rule 6 — React Visibly and Verbally
ESL learners often listen in silence. Native speakers react constantly.

|Moment|Say|
|---|---|
|Surprised|"Wait, really?"|
|Agreeing|"Yeah, totally." / "Exactly."|
|Sympathizing|"Oh man." / "That's rough."|
|Interested|"No way." / "Huh, interesting."|
|Buying time|"Oh for sure, yeah."|

**Standard:** React within 1 second of someone finishing. Silence reads as cold or confused.

### Rule 7 — Downgrade Your Certainty
Sounding natural = sounding less certain.

|❌ Too definite|✅ Natural|
|---|---|
|"This is correct."|"I think this is right."|
|"You should do this."|"It might be worth trying."|
|"That is wrong."|"I'm not sure that's quite right."|
|"I know the answer."|"I'm pretty sure it's..."|

### Rule 8 — Use Spoken Grammar, Not Written Grammar

|Written|Spoken|
|---|---|
|"With whom did you go?"|"Who'd you go with?"|
|"That is something I cannot do."|"That's not really something I can do."|
|"I have been waiting."|"I've been waiting forever."|
|"It is I."|"It's me."|

**Standard:** Prepositions go at the end. Sentences start with So / And / But.

### Rule 9 — Tell, Don't List
ESL speakers enumerate. Native speakers narrate.

❌ "There are three reasons. First... Second... Third..."

✅ "So basically what happened was... and then it kind of spiraled from there, you know?"

**Standard:** In casual conversation, no numbered lists. Use "so," "and then," "basically," "the thing is."

### Rule 10 — Match Energy, Not Just Words
Natural English is 30% vocabulary, 70% delivery.

|What to match|How|
|---|---|
|Casual setting|Drop volume, slow slightly, use fillers|
|Excited friend|Speed up, use "Oh my god / no way / that's insane"|
|Serious topic|Pause more, use "I mean... honestly..."|
|Small talk|Short answers + return question immediately|

**Standard:** Before speaking, read the room's energy level. Calibrate yours to match ±10%.

## One-Page Summary

```
1. Cushion requests      → "I was wondering / would you mind"
2. Always contract       → don't / I'm / it's
3. Fill the silence      → "Hmm / I mean / honestly"
4. Use spoken vocab      → help not assist / start not commence
5. Loop listener in      → "you know? / right? / I guess"
6. React constantly      → "wait really / totally / oh man"
7. Downgrade certainty   → "I think / probably / kind of"
8. Spoken grammar        → end with prepositions, start with So/But
9. Narrate don't list    → "so basically / and then / the thing is"
10. Match the energy     → read the room first, then speak
```

> **The real standard:** If a native speaker could say your sentence while walking and eating a sandwich — it's natural. If it sounds like you're presenting a report — rewrite it.

## AI Prompt for Practice

The document includes a system prompt for any AI assistant to act as a "Natural English Coach" that transforms formal or ESL text into natural spoken American English across three registers: Casual, Conversational, and Polished Spoken.

**Example transformation:**
> Input: "I would like to inform you that the meeting has been postponed due to unforeseen circumstances."
>
> Casual: "Hey, so the meeting's been pushed back — something came up."
> Conversational: "Just wanted to let you know, the meeting got moved. Stuff happened."
> Polished Spoken: "So quick heads up — we're actually gonna need to reschedule the meeting. Things kind of came up last minute."
