# Invisible Infrastructure

**Invisible Infrastructure** is a design principle where critical tools and systems fade from conscious awareness because they work seamlessly. The analogy often used is **Wi-Fi**: it is essential, but only noticed when it fails.

## Application in IDEs

For **IntelliJ IDEA**, the goal is to become invisible infrastructure for developers. When the IDE works well, developers do not think about the tool; they think about the code. This invisibility is achieved through:

*   **Reliability:** Consistent performance and accurate features.
*   **Responsiveness:** Minimal latency in user interactions.
*   **Predictability:** Behavior that aligns with user expectations.

## Don Norman’s Design Principles

This concept aligns with **Don Norman**’s ideas in *The Design of Everyday Things*, where good design makes the function of an object obvious and its use effortless. When a tool requires conscious effort to operate, it adds **cognitive load** and breaks **Flow State**.
