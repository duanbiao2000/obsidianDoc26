# Working Memory Limit (4 Items)

Modern cognitive science estimates that working memory can hold approximately four items at a time (revised from the earlier 7±2 model). This limit is used in the visual learning video to explain why [[chunking-with-visuals]] is effective: visual summaries compact complex information into fewer chunks, allowing more content to fit into working memory.
