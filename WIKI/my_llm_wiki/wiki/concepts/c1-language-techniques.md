# C1 Language Techniques

A collection of language enhancement strategies for C1 Advanced writing, designed to lift the Language score by adding precision, formality, and topic-specific vocabulary. The key principle is performing a **deliberate language upgrade pass** after drafting, rather than trying to produce sophisticated language during the initial write.

## Language Upgrading

A post-writing revision step where the writer scans each sentence and replaces plain word choices with more precise or formal alternatives.

**Example from the source:**
- Plain: "People took part in the seminar."
- Upgraded: "Participants enthusiastically engaged in the online seminar."

**Typical upgrades:**
- Add precise adverbs: enthusiastically, significantly, notably
- Replace generic verbs with specific ones: "carry out" → "undertake," "show" → "demonstrate"
- Use topic-specific vocabulary: pedestrian-friendly, heritage, energy-efficient, breakout rooms

## Nominalization

Transforming verbs and adjectives into nouns for a more formal register:
- "The cost is justified by..." (not "It costs a lot but is worth it")
- "The implementation of these measures would result in..."
- "An evaluation of the current system reveals..."

## Lazy Alignment Method

A coherence technique where each suggestion directly "patches" a previously identified problem. This ensures structural alignment between evaluation and recommendation sections, making the argument logically sound without extra planning effort.

**Pattern:**
- Paragraph 3: Problem A, Problem B
- Paragraph 5: Suggestion A (addresses Problem A), Suggestion B (addresses Problem B)

## Sentence Structure Variety

The source recommends using at least 2–3 higher-level sentence structures per piece:
- Relative clauses: "...which aim to..."
- Participial phrases: "Having done this, I would..."
- Formal connectors: "Furthermore," "More importantly," "What is more"
- Conditional structures: "Should these suggestions be implemented..."

## Application Workflow

1. Write the first draft with plain, clear language
2. Set aside 2–3 minutes for a language upgrade pass
3. Scan each paragraph for upgrade opportunities: one adverb, one topic-specific word, one nominalization
4. Check for 2–3 higher-level sentence structures across the whole piece
5. Proofread for errors introduced during upgrading
