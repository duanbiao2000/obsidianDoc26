# C1 Report vs. Proposal Distinction

A decision framework for determining whether a C1 Advanced Part 2 writing task requires a Report or a Proposal. The core differentiator is **temporal orientation**: reports focus on the present, proposals on the future.

## Decision Rule

| Criterion | Report | Proposal |
|-----------|--------|----------|
| **Primary focus** | Current situation | Future action |
| **Key question** | "What is happening now?" | "What should happen next?" |
| **Prompt signals** | "report on," "outline the current situation," "describe existing" | "plan to," "what could be done," "how it could be improved" |
| **Tone** | Descriptive + evaluative | Persuasive + forward-looking |
| **Main sections** | Current situation → Evaluation → Suggestions | Justification → Modernization → Benefits |

## Shared Features

Both genres share:
- Formal register with distancing (avoid direct "I/you," use passive and third person)
- Clear structure with headings and subheadings
- A final section with recommendations or a position statement
- The need to address all [[c1-command-words]] in the prompt

## Common Pitfalls

- Writing a proposal like a report (describing current problems without arguing for specific future actions)
- Writing a report like a proposal (making forward-looking arguments without adequately describing the present situation)
- Using overly direct suggestions ("you should do X") instead of polite indirect structures appropriate for a higher-status reader

## Practical Heuristic

Read the prompt and identify whether the primary action is:
- Describing an existing system → **Report**
- Proposing a change or new initiative → **Proposal**

If the task blends both, prioritize the dominant orientation but incorporate elements of the other as sub-sections.
