# Cognitive Positioning Framework

## Overview

The Cognitive Positioning Framework is a taxonomy of 10 thematic directions for positioning content channels focused on AI, technology, and cognition. It provides a structured way to evaluate and select a channel's core value proposition across multiple dimensions.

## The 10 Dimensions

| Dimension | Core Value Proposition | Example Names |
|-----------|----------------------|---------------|
| Signal/Noise | Filtering noise, capturing signal | SignalLab, SNR Station |
| Depth | Going beyond surface understanding | DeepDive, DeepThink |
| Insight/Cognition | Cognitive upgrade, thinking methods | InsightLab, MindEvolve |
| AI Frontier | Technology focus, cutting-edge | AI Unpacked, AI Era |
| Distillation | Removing fluff, keeping core | Distilled, NoFluff |
| Companionship | Community, shared growth | AI Pacer, GrowthSignal |
| Clarity/Light | Cognitive clarification | OneRay, TheLens |
| Future Outpost | Ahead of trends | Outpost, TomorrowNotes |
| Curiosity/Questioning | Questioning as method | WhyThough, CuriosityLab |
| Bilingual/Persona | Brand personality | SignalSquad, CogLab |

## Usage

This framework can be used to:
- Map existing content against positioning dimensions
- Identify gaps or overlaps in channel positioning
- Generate new naming and branding options
- Align content strategy with audience expectations
