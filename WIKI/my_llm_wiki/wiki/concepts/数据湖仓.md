# 数据湖仓

数据湖仓（Data Lakehouse）是一种结合数据湖和数据仓库的架构，旨在同时支持数据湖的灵活性和数据仓库的可靠性。它通常基于对象存储（如 S3）和开放表格式（如 Apache Iceberg）构建。

## 核心特性

- **开放格式**：使用 Parquet、ORC 等开放列式存储格式。
- **表格式管理**：通过 Apache Iceberg、Delta Lake 等表格式管理表到文件的映射、名称、类型等元数据。
- **ACID 事务**：支持原子性、一致性、隔离性和持久性。
- **时间旅行**：允许访问数据的历史版本。
- **批流一体**：同时支持批处理和流处理。

## 与批处理的关系

数据湖仓是批处理系统的重要演进方向。批处理系统与云数据仓库正在收敛，两者越来越像。但并非所有批任务都容易用 SQL 表达，如 PageRank 等迭代图算法、复杂机器学习任务。

## 代表系统

- **Apache Iceberg**：开放表格式，管理表元数据。
- **BigQuery**：Google 的云数据仓库。
- **Snowflake**：云数据仓库。
- **DuckDB**：嵌入式数据库。
- **Trino**：分布式 SQL 查询引擎。
