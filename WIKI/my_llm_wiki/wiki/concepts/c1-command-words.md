# C1 Command Words

A technique for parsing task verbs in C1 Advanced writing prompts to determine required content. Each command word (evaluate, outline, comment on, suggest, etc.) dictates a specific paragraph or section that must be included; missing any one directly loses content marks.

## Core Command Words

| Command Word | Required Action |
|---|---|
| **evaluate** | Assign value — state what is good/bad, effective/ineffective |
| **outline** | Describe the current situation or key features |
| **comment on** | Give your assessment or opinion with supporting reasons |
| **suggest** | Propose specific improvements or changes |
| **explain** | Clarify reasons, causes, or rationale |
| **describe** | Give a detailed account of features or characteristics |

## Application Method

1. **Circle every command word** in the prompt before planning
2. **Map each command word to a paragraph** — the report/proposal structure must cover all of them
3. **Number them** to check you have addressed every requirement
4. **Include specifics** — each command word response needs at least one concrete example or detail

## Why It Matters

Content is one of the four C1 grading dimensions. Skilled test-takers can produce well-written responses that still lose marks if they fail to address a command word. The technique is the highest-leverage action for securing content marks.
