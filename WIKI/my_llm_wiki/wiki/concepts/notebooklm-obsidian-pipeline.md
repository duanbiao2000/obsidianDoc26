# NotebookLM-Obsidian Pipeline

The NotebookLM-Obsidian Pipeline is a knowledge management workflow that combines [[NotebookLM]] (Google's AI research tool) with [[Obsidian]] (a knowledge management app) to create a [[Second Brain]] system. The pipeline has three layers: thinking, remembering, and meta-thinking.

## Layer 1: Research in NotebookLM (Thinking)

1. Create focused notebooks in NotebookLM, one per research topic.
2. Upload relevant sources (PDFs, Google Docs, slides, YouTube videos, websites, audio files).
3. Ask strategic questions across multiple sources — what they disagree about, what A claims that B contradicts, which source has the strongest evidence.
4. Use source toggling to scope AI responses to specific documents.
5. Optionally use Audio Overviews for time-efficient consumption (listen during a run or commute).

## Layer 2: Store in Obsidian (Remembering)

1. Take only the valuable insights from NotebookLM and rewrite them in your own words as concise notes.
2. Use insight-titled notes (e.g., "Retention drops when onboarding exceeds three steps") rather than source-based titles (e.g., "Notes from McKinsey article").
3. Place each note in the appropriate [[PARA Method]] folder (Projects, Areas, Resources, Archives).
4. Link new notes to related notes using [[wikilinks]] to create a bi-directional knowledge graph.

## Layer 3: Meta-Analysis (Obsidian → NotebookLM Feedback Loop)

1. Export Obsidian notes as markdown files.
2. Upload them as sources into a new NotebookLM notebook ("My Second Brain").
3. Ask meta-questions: "Based on everything I've collected, what's the biggest pattern I haven't explicitly connected yet?"
4. Use the discovered patterns as theses for presentations, articles, or strategic decisions.

## Delayed Value Curve

- **1 week (10-20 notes):** Feels like extra work; connections are sparse.
- **1 month (50-100 notes):** System starts working for you; unexpected connections emerge.
- **3 months:** Vault becomes a searchable knowledge base reflecting how you think.

## Practical Starting Point

Pick one active project, create a focused NotebookLM notebook for it, upload a few key sources, pull one or two insights, rewrite them as linked notes in Obsidian. Do one short research session per week, focus on clear titles and meaningful links rather than volume.
