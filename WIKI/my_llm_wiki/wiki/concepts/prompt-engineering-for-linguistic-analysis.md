# Prompt Engineering for Linguistic Analysis

**Prompt Engineering for Linguistic Analysis** refers to the practice of designing targeted AI prompts to extract, categorize, and analyze specific linguistic features from source texts or transcripts. This methodology enables systematic study of language patterns without manual annotation.

## Core Principles

1. **Task Specification** — clearly define what linguistic feature to extract (e.g., transition sentences, lead-in openings, contrast markers)
2. **Medium Awareness** — tailor prompts for the source medium (speech vs. written text)
3. **Output Format Control** — specify how results should be structured (verbatim lists, categorized groups, pattern libraries)
4. **Function-Based Grouping** — request organization by linguistic function (addition, contrast, cause-effect, etc.)

## Example Prompt Templates

### Direct Extraction
> "Extract all transition sentences and phrases that connect ideas, both at the beginning of paragraphs and inside them."

### Speech-Specific
> "From the transcript, extract the sentences the speaker uses to move from one point to the next, including in the middle of a paragraph."

### Pattern Building
> "For each transition sentence, also output the core transition phrase (e.g. 'however', 'as a result', 'in addition') so I can build a pattern list."

## Applications in Language Learning

- Building personal phrase banks from authentic materials
- Analyzing rhetorical structure of model texts
- Creating targeted practice exercises for specific transition functions
- Comparing transition usage across different genres and registers
