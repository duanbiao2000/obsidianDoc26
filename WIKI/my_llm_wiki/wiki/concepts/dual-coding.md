# Dual Coding

Dual coding theory posits that the brain has separate verbal and visual memory channels. Using both channels to encode information creates two memory traces, improving recall. The visual learning video (“Stop Information Overwhelm”) cites dual coding as the mechanism behind the [[picture-superiority-effect]] and explains that adding visuals to text immediately improves retention.
