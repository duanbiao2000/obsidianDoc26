# C1 Advanced Report Writing

A structured approach to writing Reports for the C1 Advanced Writing paper Part 2. The report genre focuses on describing and evaluating an existing situation, with the primary temporal orientation being the present.

## Template Structure

### 1. Title
- Format: **Report on + [topic]**
- Example: *Report on Public Transport in Seville*
- Should be clear and factual, not creative

### 2. Introduction
- State the purpose in one sentence
- Template: *This report aims to [evaluate/outline/comment on/suggest] ...*

### 3. Current Situation Paragraphs
- One sub-section per aspect or system (e.g., Subway, Tram, Cycling)
- Each paragraph includes:
  - Description: what exists currently (routes, speed, comfort)
  - Brief value judgment: who benefits, who faces difficulties

### 4. Evaluation Paragraph
- Combine description with assessment
- Example: "The metro is modern and fast, but has only one line, making it inaccessible to most residents; the tram is environmentally friendly but too slow and overlaps with metro routes."

### 5. Suggestions Paragraph
- Apply the **lazy alignment method**: each suggestion directly patches a problem identified in the evaluation
  - Problem: only one metro line → Suggestion: add a north-south route
  - Problem: tram overlaps metro → Suggestion: extend tram to airport/train station
- Ensure every problem has a corresponding suggestion

### 6. Conclusion
- Summarize and offer a polite, indirect recommendation
- Template: *Should these suggestions be implemented, ...*
