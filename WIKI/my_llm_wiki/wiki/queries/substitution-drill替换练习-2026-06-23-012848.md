根据维基内容，**Substitution Drill**（替换练习）是 \[\[FSI Pattern Drill Methodology]] 中的一种核心练习方法。它的核心目标是通过在固定的复杂句子框架中替换不同的变量成分，帮助学习者掌握句法的灵活性，实现“自动的语言反射”（automatic language reflection），而非死记硬背词汇 \[11]。

以下是维基中提供的具体示例：

### 1. 句法框架层面的替换练习

页面 \[2] 中提供了一个典型的 \[\[Substitution Drill]] 句子骨架，学习者通过替换括号内的变量来内化高阶句法结构：

> *"The extent to which \[subject] can \[action] hinges on \[factor A] rather than \[factor B], as \[reason/clause].*"

通过将不同的词汇填入 `[subject]`（主语）、`[action]`（动作）、`[factor A/B]`（因素）和 `[reason/clause]`（原因/从句），学习者可以在不同语境下反复练习这一高阶复杂句型，从而将其逻辑和结构内化为自然反应。

### 2. 词汇与语域层面的替换练习

页面 \[1] 中的雅思备考资源虽然侧重于语域转换，但其核心机制同样是替换练习，旨在提升 Lexical Resource 的得分。该资源提供了多种分类的具体替换对：

* **基础口语 → 书面语替换**：

  * "get" → "obtain"

  * "thing" → "factor / aspect / element"

* **Phrasal Verb → Formal Verb（短语动词 → 正式动词）**：

  * "go up" → "surge / escalate"

* **Weak → Precise Words（弱词 → 精确词）**：

  * "say" → "assert / contend / argue"

* **Generic → Specific Adjectives（泛指形容词 → 具体形容词）**：

  * "very big" → "enormous / immense / substantial"

* **Vague → Precise Nouns（模糊名词 → 精确名词）**：

  * "problem" → "dilemma / predicament / constraint"

* **Discourse Marker Upgrades（话语标记升级）**：

  * "but" → "however / nonetheless / conversely"

这些替换练习强调**register appropriateness**（语域适用性）和 **collocation accuracy**（搭配准确性），提醒考生在写作中应使用书面词汇替代口语词汇，但在口语考试中则应优先追求自然流利，而非强行塞入书面词汇 \[1]。
