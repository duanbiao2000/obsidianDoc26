- **四瑕（瑕疵核查）：**
    - **逻辑断裂：** 100个概念与20个模型在笔记中仅列出了碎片化的示例，缺乏**分类学大纲（Taxonomy）**。用户在“举一反三”时会面临分类迷茫，无法自主补全剩余的 80% 库容。
    - **表达含混：** 口语模型中的“STAR+R”概念未作本土化与雅思适配性解释（STAR 原为行为面试模型，直接套用至雅思口语易导致答案过长、偏离主题）。
- **八冥（暗区识别）：**
    - **缺少边界：** 未明确该模板的适用分段（如：5.5分冲7.5分，还是4.5分打基础？）。像“Nominalization（名词化）”与“Hedging（学术软化）”这类高阶写作技术，若强行塞给低分段备考者，会导致严重的语言石化与中式英语。
    - **结构失衡：** 极度偏重写作（Task 2），听力与阅读的模型极度单薄，沦为点缀。
- **九蠹（信息损耗）：**
    - **自我感动与行动缺失：** IPO 循环（输入-处理-输出）设计得非常理想化，但**严重缺失了“反馈闭环（Feedback Loop）”**。没有纠错的 Output（输出）只是在强化错误的肌肉记忆，属于低效的“自我感动式”努力。
    - **术语堆砌：** 罗列了 “Cohesion vs Coherence”，但没有给出判定其及格与优秀的量化标准。

### 🚀 升级版笔记：[[雅思「100-20-5」认知重构与闭环执行操作系统]]

#### 导言：系统边界与适用人群
本系统专门针对 **当前成绩 5.5 - 6.0，目标突破 7.5+** 的中高段备考者。其底层逻辑是：**以认知带宽的压倒性优势，降维打击应试本身。**

### 一、 核心底座：100个概念的“四维分类法”
（拒绝无序堆砌，将100个概念划分为四个结构化维度，引导备考者按图索骥）

- **维度 A：论证逻辑（Logic & Argumentation）[占 30%]**
    - **Hedging Language（学术限定语）：** 运用 *tend to, arguably, to some extent* 消除绝对化陈述，建立学术客观性。
    - **Intellectual Tension（思想张力）：** 在段落中主动引入对立观点并进行反驳，展示思维的深度与辩证性。
    - **Conceptual Overlap（概念滑移）：** 警惕论证过程中的概念偷换（如：将“教育”等同于“学校上课”）。
- **维度 B：语言表征（Lexical & Grammatical Mechanics）[占 30%]**
    - **Nominalization（动名词化）：** 将动作转化为概念（如 *destroy $\rightarrow$ destruction*），提高学术书面语的信息密度。
    - **Collocation Congruency（搭配一致性）：** 规避中式直译，确保动宾、形容词+名词的高度内聚。
- **维度 C：官方评估标准（Band Descriptors Decoded）[占 20%]**
    - **Task Response Boundary（任务回应边界）：** 严格区分 "Discuss both views" 与 "To what extent do you agree" 的段落结构差异。
- **维度 D：考官心理学（Examiner Bias & Expectations）[占 20%]**
    - **Readability Index（可读性指数）：** 确保考官在 15 秒内能通过段首句（Topic Sentence）清晰抓取段落核心。

### 二、 核心模型：精益思考模型库（重构版）

#### 1. 写作（Writing Task 2）模型
- **模型：「1-3-1」论证演进流**
    - **Point（论点）：** 提出核心主张。
    - **Elaboration（机制展开）：** 拆解因果链条（A $\rightarrow$ B $\rightarrow$ C），不跳跃步骤。
    - **Nuance/Counter（边界限定）：** 补充适用范围或进行轻度让步。
- **模型：「代偿性」词汇替换三阶梯**
    - *不要盲目查字典找同义词，采用维度升维：*
    - **L1 局部替换：** *people $\rightarrow$ citizens / individuals* (基础)
    - **L2 句法重构：** *The government should pay... $\rightarrow$ It is highly recommended that fiscal allocation be directed towards...* (中阶)
    - **L3 范畴转换：** 将具体动作抽象化（如：*studying abroad $\rightarrow$ cross-cultural academic pursuit*）（高阶）

#### 2. 口语（Speaking）模型
- **模型：「E-STAR」答题架构（针对 Part 3 深度论证）**
    - **Evaluation（宏观评估）：** *“It’s a multi-faceted issue...”* (先定调，争取思考时间)
    - **Situation（现状背景）：** 简述核心现象。
    - **Trigger（触发机制）：** 解释导致该现象的深层原因。
    - **Action/Result（行动与后果）：** 产生的影响。
    - **Reflection（前瞻反思）：** 归纳总结或指出未来趋势。

#### 3. 听力/阅读（Passive Skills）模型
- **模型：「反向命题人」预测模型**
    - **核心逻辑：** 拿到题目后，不直接寻找答案，而是标注出题目中的 **“极值词（only, must）”、“因果词（because, lead to）” 与 “修饰词”**。在听/读时，高度警惕这些词在原文中的“否定性同义替换”。

### 三、 专家池（5位大神的元认知提取）
（拒绝空泛的“找大神”，将其转化为可调用的**评审算子**）

- **考官 Simon 的核心逻辑：** “Simple but academic”。
    - **调用规则：** 写作时，每写完一句话，问自己：如果把这句话大声读出来，考官能在 2 秒内听懂它的核心意思吗？如果不能，立即做句法降维。
- **高分考生（7.5+）的避坑指南：** “Feedback is king”。
    - **调用规则：** 坚决不写没有反馈的作文。每写完一篇，必须对照范文，使用彩笔标注出自己与范文在“连贯性（Coherence）”上的差距。

### 四、 IPO-F（反馈版）日用执行节奏

为了消灭“低效勤奋”，将原 IPO 循环重构为 **IPOF（Feedback）闭环系统**：

```
                    ┌────────────────────────┐
                    │  INPUT (30 Min)        │
                    │  获取高质量范文/原声输入  │
                    └───────────┬────────────┘
                                │
                                ▼
                    ┌────────────────────────┐
                    │  PROCESS (20 Min)      │
                    │  套用模型拆解、分析逻辑链   │
                    └───────────┬────────────┘
                                │
                                ▼
                    ┌────────────────────────┐
                    │  OUTPUT (30 Min)       │
                    │  局部刻意练习(写1段/说2题) │
                    └───────────┬────────────┘
                                │
                                ▼
                    ┌────────────────────────┐
                    │  FEEDBACK (10 Min)★    │
                    │  对照原文纠错, 修正认知边界 │
                    └────────────────────────┘
```
