### 🏛️ 斯多葛内核：Stoic OS 极简运行手册

#### 一、 核心架构：控制二分法 (Dichotomy of Control)

$$\text{外部事件} \longrightarrow \begin{cases} \text{由我决定 (可控)} \longrightarrow \text{全神贯注：意图、准备、行为} \\ \text{不由我决定 (不可控)} \longrightarrow \text{平静接纳：结果、环境、他人} \end{cases}$$

- **禅意逻辑**：只对可控的“输入（意图）”分配认知资源，对不可控的“输出（结果）”直接抛出平静异常（Exception Acceptance）。

---

#### 二、 运行管线：三大核心线程

##### 1. 情绪重构过滤器 (Emotion Reframer)
- **Bug 现象**：外界刺激导致情绪过载（如愤怒、受辱感）。
- **重构算法**：$\text{情绪反应} = \text{认知判断}$。将“他人的侮辱”显式重构为“无害的空气震动”，从源头阻断情绪升级。

##### 2. 意图自检器 (Intention Validator)
- **美德判定**：行为的价值取决于“动机”，而非“结果”。
- **自检逻辑**：
```python
if motive == "sincere_virtue":  # 真诚利他
    return "Virtuous"
elif motive == "resume_padding":  # 功利/刷简历
    return "Character_Damaged"
```

##### 3. 顺应天性系统 (Human Nature API)
- **硬件脱壳**：利用理性抵御有害的自然本能（如暴食、非理性易怒）。
- **同心圆广播**：将关怀范围由【自我 $\rightarrow$ 家人 $\rightarrow$ 朋友 $\rightarrow$ 全人类】层层向外广播，实现社会协作最大化。

---

- **知行对齐**：概念如举重般简单，内化需每日肉体训练。
- **运行目标**：通过日复一日的练习，将认知原则沉淀为底层硬件反应，最终改变情绪模式。
