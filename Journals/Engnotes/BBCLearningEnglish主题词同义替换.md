## 一、 核心专题：社会安全与犯罪 (Social Safety & Crime)

> [!abstract] 场景立意 (Writing Task 2)
> 1. **旅游+安全**：景点涌入游客 $\rightarrow$ 安保压力上升 $\rightarrow$ 政府职责（监控/应急）。
> 2. **媒体暴力/模仿犯罪 (Copycat Crimes)**：媒体过度报道可能 **glorify** 攻击者，引发模仿。

### 1. 核心词汇与替换
| 原始表达 | 精英级替换 (IELTS) | 适用场景 |
| :--- | :--- | :--- |
| **lone gunman** | single attacker / armed individual | 犯罪、社会安全 |
| **historic site** | internationally recognised heritage site / protected cultural site | 旅游、文化遗产 |
| **mass shooting** | large-scale shooting / fatal shooting incident | 犯罪、暴力 |

### 2. 句型改写模板
- **wounded / injured 类**
    - $Standard$: The crash left 50 people **wounded**.
    - $Elite$: 50 people **sustained injuries** in the accident.
- **open fire 类**
    - $Standard$: The guards **opened fire on** the intruder.
    - $Elite$: The guards **fired shots at / responded with gunfire** to the intruder.

## 二、 核心矩阵：10组高频名词及万能动词搭配 (The Core 10)

> [!tip] 学习逻辑
> 雅思考官不仅看你的词汇量，更看重 **Collocations (词汇搭配)**。

### 1. 基础生活类 (Trip, Goal, Environment)
| 核心名词 | 动作搭配 (Verbs) | 高分替换/同义思路 |
| :--- | :--- | :--- |
| **trip** | plan / arrange / extend / cut short | extend $\rightarrow$ **stay longer than planned** |
| **goal** | set / pursue / achieve / reach | pursue $\rightarrow$ **strive for**; achieve $\rightarrow$ **accomplish / fulfil** |
| **environment** | create / adapt to / preserve / safeguard | adapt to $\rightarrow$ **adjust to a new setting**; safeguard $\rightarrow$ **conserve** |

### 2. 学术研究类 (Theory, Method, Source)
| 核心名词 | 动作搭配 (Verbs) | 高分替换/同义思路 |
| :--- | :--- | :--- |
| **theory** | formulate / develop / test / challenge | formulate $\rightarrow$ **propose**; challenge $\rightarrow$ **cast doubt on** |
| **method** | devise / adopt / employ / involve | devise $\rightarrow$ **come up with**; adopt $\rightarrow$ **take up** |
| **source** | provide / tap into / locate | tap into $\rightarrow$ **exploit / make use of**; locate $\rightarrow$ **identify** [^1] |

### 3. 科技与社会类 (Technology, Image, Opinion, Challenge)
| 核心名词 | 动作搭配 (Verbs) | 高分替换/同义思路 |
| :--- | :--- | :--- |
| **technology** | invest in / introduce / enable | enable $\rightarrow$ **make it possible to** |
| **challenge** | pose / rise to / face / meet | pose $\rightarrow$ **present a significant challenge** |
| **image** | project / polish / tarnish | polish $\rightarrow$ **rebuild / enhance**; tarnish $\rightarrow$ **undermine** |
| **opinion** | give / air / voice / vary | vary $\rightarrow$ **hold conflicting / diverging opinions** |

## 三、 分类速查：口语与写作高分替换库 (Flashcard Style)

### 🧩 1. 学习与能力 (Education)
- [ ] **improve** $\rightarrow$ `level up` / `enhance` / `elevate`
- [ ] **speaking skills** $\rightarrow$ `oral proficiency` / `verbal ability`
- [ ] **repeat** $\rightarrow$ `recite` / `imitate`
- [ ] **difficult** $\rightarrow$ `challenging` / `demanding` / `formidable`
- [ ] **long sentence** $\rightarrow$ `lengthy utterance` / `complex sentence`

### 💼 2. 工作与求职 (Career)
- [ ] **job** $\rightarrow$ `gig` / `position` / `occupation`
- [ ] **get a job** $\rightarrow$ `land a job` / `secure a position`
- [ ] **nervous** $\rightarrow$ `anxious` / `stressed` / `tense`
- [ ] **mess up** $\rightarrow$ `botch` / `ruin` / `spoil`
- [ ] **promotion** $\rightarrow$ `career advancement`
- [ ] **opportunity** $\rightarrow$ `prospect` / `opening`

### 💰 3. 金钱与理财 (Finance)
- [ ] **money** $\rightarrow$ `funds` / `wealth` / `capital`
- [ ] **save money** $\rightarrow$ `set aside funds` / `accumulate savings`
- [ ] **rich** $\rightarrow$ `wealthy` / `affluent`
- [ ] **financial stability** $\rightarrow$ `economic security`
- [ ] **emergency** $\rightarrow$ `unexpected crisis`
- [ ] **win the lottery** $\rightarrow$ `hit the jackpot` / `strike it rich`

## 四、 精细辨析与脚注 (Detailed Analysis)

> [!info] 深度辨析（从原文末尾提取）
> - **Devise** (v.): 侧重于“设计”出一个复杂的系统或计划（design/invent）。
> - **Campaign** (n.): 专门指为了达成政治、商业、社会目标的“系列活动/运动”。
> - **Opinion Vary**: 用于引出双边论点，如 "*Opinions vary regarding whether...*"。

[^1]: **Locate vs Identify**: 在描述 source 时，`locate the source` 强调物理上或源头上找到，而 `track down` 往往带有一种经过努力后寻获的语感。
