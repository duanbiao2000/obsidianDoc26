 浙江图书馆知网入口
 
 这里提到的 **Consensus** 是一个基于 AI 的**学术论文搜索引擎**，核心特点是能直接回答你的研究问题，并给出支持该结论的论文证据。

---

## Consensus 是什么

| 属性 | 说明 |
|------|------|
| 官网 | [consensus.app](https://consensus.app) |
| 核心功能 | 用自然语言提问 → AI 从学术论文中找答案 |
| 特色 | 不只给论文列表，而是**综合多篇论文的结论**给出答案，并标注支持度 |
| 收费 | 基础搜索免费，深度功能需订阅 |
| 适合场景 | 快速验证某个观点是否有学术支持、找研究趋势 |

**示例用法**：输入 "Does caffeine improve cognitive performance?"，它会总结多篇论文的共识，而不是扔给你一堆 PDF。

## 其他快速触达论文的工具

### 🔬 学术搜索引擎

| 工具                   | 特点                | 网址                      |
| -------------------- | ----------------- | ----------------------- |
| **Google Scholar**   | 最全面、免费、支持引用追踪     | scholar.google.com      |
| **Semantic Scholar** | AI 驱动，自动提取关键图表和结论 | semanticscholar.org     |
| **PubMed**           | 医学/生命科学领域权威       | pubmed.ncbi.nlm.nih.gov |
| **Web of Science**   | 高质量期刊，适合深度研究      | 需机构订阅                   |
| **Scopus**           | Elsevier 旗下，引文分析强 | 需机构订阅                   |
| **CNKI / 知网**        | 中文论文首选            | cnki.net                |

---

### 🤖 AI 辅助读论文工具

| 工具 | 核心能力 |
|------|---------|
| **Consensus** | 问答式搜索，找研究共识 |
| **Elicit** | 自动总结论文、提取数据、对比研究 |
| **SciSpace** | 读论文时实时解释术语、总结段落、找相关文献 |
| **ChatPDF** | 上传 PDF，直接问答 |
| **ResearchRabbit** | 可视化文献网络，追踪引用关系 |
| **Connected Papers** | 输入一篇论文，生成相关论文图谱 |

---

### ⚡ 快速获取论文全文

| 场景 | 方法 |
|------|------|
| 学校/机构用户 | 通过图书馆 VPN 访问数据库 |
| 开源论文 | arXiv.org、bioRxiv、SSRN（预印本平台） |
| 找不到全文 | **Sci-Hub**（灰色地带，谨慎使用）|
| 请求作者 | 直接邮件联系作者要 PDF，大部分学者乐意分享 |

## 高效读论文的实战流程

```
1. 用 Google Scholar / Consensus 搜关键词
        ↓
2. 扫标题 → 筛选 5-10 篇相关
        ↓
3. 读 Abstract（摘要）判断价值
        ↓
4. 值得深入？→ 看 Figures（图表）+ Conclusion
        ↓
5. 核心论文？→ 用 SciSpace / ChatPDF 精读全文
        ↓
6. 扩展阅读 → ResearchRabbit / Connected Papers 找关联文献
```
