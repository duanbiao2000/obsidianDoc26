# 06｜中文字幕与术语规范

## 目标

中文字幕不是英文逐词替身，而是观众理解复杂观点的第二条叙事线。它应当准确、自然、可快速阅读，并保留人物说话的节奏。

## 1. 字幕原则

1. **意译优先，事实不改。** 英文能省略主语，中文可补；英文有修辞，中文应先保意义。
2. **一句一个意思。** 不为了对齐英文语法，把中文做成冗长从句。
3. **中文要像自然汉语。** 不使用“进行一个……的”“对于……而言”等翻译腔。
4. **不要替口播增加观点。** 口播没有说的判断，不加进字幕。
5. **专有名词第一次出现中英对照。** 后续固定一种写法。
6. **所有术语进入术语表。** 同一季不得把同一概念反复翻成不同中文。

## 2. 排版与阅读速度

- 每屏优先 1 行，必要时 2 行；避免 3 行。
- 中文每行建议 13–18 个汉字（含标点）；长概念可在逻辑停顿处分行。
- 一条字幕通常停留 1.2–4 秒；概念句和引文可以更久。
- 画面有信息卡时，字幕应避开信息卡，不双重堆叠。
- 术语卡不重复全文字幕，只呈现核心词与 6–12 字释义。

## 3. 人名、书名与术语写法

| 项目 | 首次出现 | 后续出现 |
|---|---|---|
| 人名 | Ryan Holiday（瑞安·霍利迪） | Ryan Holiday / 霍利迪，按当期统一 |
| 英文书名 | *The Obstacle Is the Way*《障碍即道路》 | 优先用英文或既定中文名，勿混用 |
| 概念 | agency｜行动自主性 | 行动自主性 / agency，按语境 |
| 原典词 | *memento mori*｜记住你终将死去 | 记住死亡 / memento mori |

如无公认中译，采用“节目暂译”，并把原词保留在术语卡或简介中。

## 4. 翻译优先级

```text
事实准确
  > 思想关系清晰
  > 中文自然
  > 节奏与语气
  > 与原句逐词对应
```

示例：

| 英文口播 | 不推荐 | 推荐 |
|---|---|---|
| “The result is information, not a verdict.” | 结果是信息，而不是判决。 | 结果提供信息，却不该替你判定价值。 |
| “We can borrow the principle without borrowing the life.” | 我们可以借原则而不借人生。 | 原则可以借，人生不必照抄。 |
| “Stillness is not inactivity.” | 静止不是不活动。 | 平静不等于什么也不做。 |

## 5. 双语术语表模板

每期建立一个术语表，至少含：

| 英文/原文 | 节目标准译法 | 第一次出现时间 | 简短解释 | 备注 |
|---|---|---:|---|---|
|  |  |  |  |  |

术语译法经发布后，若无重大错误，应视为该栏目资产；修改要同步更新此前/后续文件的用法说明。

## 6. 引文字幕

- 短引文可显示英文原文 + 一行中文节目译；不要把整段原文塞入画面。
- 标注作者、作品或演讲名称；需要时标页码/年份。
- 人物原话与主持人解释要使用不同视觉层级。
- 对经典或有多个译本的文本，使用“节目译”或注明版本；避免把自己的译文伪装成通行译本。

## 7. 字幕最终检查

- [ ] 静音观看时，能否理解本期 80% 以上逻辑？
- [ ] 同一概念是否前后一致？
- [ ] 人名、书名、日期、数字是否与画面和简介一致？
- [ ] 是否有超过 2 行且来不及读完的字幕？
- [ ] 是否出现英文术语未经解释就重复出现？
- [ ] 所有引文译文是否经过来源回查？
