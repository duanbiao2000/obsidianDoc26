# Skill｜实时交接与收尾

## 触发

每次发生实质变更后、向用户汇报前调用。实质变更包括正式名单、EP 状态、研究结论、资料路径、版权风险、可复用资产、自动化配置或下一步优先级变化。

## 读取

- `../../../AGENT.md`
- `../../../00-项目交接与实时状态.md`
- 本次实际修改过的正式文件；
- `../../自动化/hook-manifest.v0.1.json`。

## 本 Skill 负责的结果

只更新实时交接文档中确实发生变化的字段：当前基线、活跃项目、未决事项、下一步 P0、会话成果和更新日志。它不复制正式名单内容、研究正文或长期规则。

## 执行步骤

1. 先确认实际文件已更新且事实正确；
2. 运行与本次变更相匹配的阻断校验；
3. 更新交接文件 frontmatter 的 `last_updated`；
4. 用一句当前状态概括本次完成后的真实位置；
5. 将下一步写成可直接打开的文件与可执行动作；
6. 追加一条更新日志；
7. 运行：

```bash
python3 可复用资产/自动化/check_session_close.py --expect-date YYYY-MM-DD --strict
```

## 不负责

不重复 `AGENT.md` 的长期规则，不替代版本记录，也不靠自动脚本猜测下一步或替人做编辑判断。
