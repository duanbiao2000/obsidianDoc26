# Skill｜英文完整口播开发

## 触发

仅在对应 EP 已经是 `ERP GREEN`，且已具备叙事设计与英文逻辑脊柱时调用。

## 强制前置校验

从项目根目录运行：

```bash
python3 可复用资产/自动化/check_episode_gate.py --episode <EP目录名> --action full-script
```

校验失败时，不创建或实质改写 `05-英文口播稿`；回到 `episode-readiness` 补缺口。

## 读取

- 对应 EP 的项目看板、研究档案、ERP、叙事设计、逻辑脊柱、术语表；
- `../../04-单集叙事与节拍模板.md`
- `../../05-英文口播风格规范.md`
- `../../06-中文字幕与术语规范.md`
- `../../模板/02-英文口播稿模板.md`

## 本 Skill 负责的结果

- 可录制的 `05-英文口播稿_v0.x.md`；
- 每一段强事实和引用可回到研究档案；
- 同步更新的字幕/术语需求和项目看板阶段；
- 需要时注明尚待录制前复核的事实或版权风险。

## 不负责

不从空白直接写满人物传记，不用无出处的金句填补论证，不把中文解释伪装为人物英文原话，也不替代录制、剪辑或发布 QC。
