# 02｜人物选题评分卡

> **影响力只是入口。人物只有在“作品、张力、可转译性、资料可信度”同时成立时，才值得占用一期。**

## 使用方式

1. 每位候选人由策划先填写评分卡，再决定是否投入深度研究。
2. 六项各 0–5 分，总分 30 分。
3. **硬门槛：** `一手作品 / 完整表达` 与 `资料可信度` 任一低于 3 分，直接不立项。
4. 建议 22 分及以上进入开发；19–21 分进入观察池；18 分及以下淘汰或等待更好角度。
5. 除总分外，必须写出一个“不能做他的理由”，以检验是否只是个人偏爱。

## 六维评分表

| 维度 | 0–1 分 | 2–3 分 | 4–5 分 | 分数 |
|---|---|---|---|---:|
| **A. 一手作品 / 完整表达** | 只有转述、短视频切片或营销文案 | 有零散文章/访谈或单一作品 | 有书、完整演讲、可分析的代表性作品或持续创作，且可获取 | /5 |
| **B. 可证实影响力** | 只有短期流量 | 有圈层影响 | 有跨圈层、跨语言、跨代际或长期实践影响 | /5 |
| **C. 人生张力** | 履历平直，只有头衔 | 有一个转折 | 有清晰矛盾、选择、代价或转向，且可证实 | /5 |
| **D. 思想可转译性** | 只能崇拜，无法讨论 | 能提炼几条建议 | 可变成一个当代人能检验的问题，并有现代场景 | /5 |
| **E. 边界与反例** | 只能歌颂 | 有争议但难以公平处理 | 观点的条件、争议和局限可被诚实呈现 | /5 |
| **F. 资料可信度** | 关键事实无可靠来源 | 部分可核验 | 有一手文本/作品/完整表达、正式出版物或演讲、可靠采访或学术资料交叉支持 | /5 |
| **总分** |  |  |  | **/30** |

## 选题组合规则（以一季 6 期为例）

- 不连续两期都围绕“效率 / 自律 / 财富 / 创业”。
- 至少包含一位中国语境中的人物；但不把其“东方性”当作卖点。
- 性别、地域、职业、代际和思想传统应当有真实差异。
- 人物影响力不必都来自商业成功：文学、艺术、教育、科学、公共伦理和社会行动都可入选。
- 有争议的人物可以做，但节目必须具备处理争议的资料能力，而不是把争议当点击诱饵。
