# 03｜研究与事实核查规范

## 目标

让每一期都能清楚区分：**发生过什么（事实）｜人物亲自说了什么（引述）｜我们如何理解它（编辑判断）｜我们借助什么解释它（背景）**。

人物节目最容易在“好故事”面前牺牲准确性。本规范规定：没有核验的细节，不得为了戏剧性写进旁白。

---

## 1. 来源层级

| 层级 | 可用来源 | 使用方式 |
|---|---|---|
| **P1：一手材料** | 原书、完整演讲、正式文章、本人完整访谈、演讲文字稿、公开档案 | 核心观点和直接引文的首选 |
| **P2：正式自述/机构资料** | 本人官网、出版社作者页、所属机构、作品官方资料 | 可核实书目、职位、官方自述；须标注其自述性质 |
| **S1：可靠独立报道** | 有编辑流程的媒体、正式传记、可靠长访谈 | 交叉核验经历、争议与影响 |
| **S2：学术/专业背景资料** | 学术百科、同行评审研究、大学课程资料、权威学会 | 解释思想传统、历史背景与术语 |
| **C：评论/批评材料** | 可信评论、同行观点、人物争议的不同立场 | 用于边界与反例；不可单独支撑生平事实 |
| **不可单独采用** | 金句图、营销转载、百科条目、AI 摘要、无来源短视频、论坛帖子 | 只作线索，不作播出依据 |

### 最低取证要求

- **关键生平节点：** 至少 1 个 P1/P2 + 1 个 S1 或第二份独立来源。
- **作品出版、书目、正式职务：** P2 可作为主证，但优先交叉核验。
- **思想主张：** 至少 1 段 P1；禁止只引用“别人说他主张什么”。
- **销量、语言数、受众、榜单等影响力数字：** 必须写明是谁的口径；出版社或本人声称的数据不得写成独立审计事实。
- **争议、道德判断、违法或伤害性主张：** 至少两份独立可靠来源，并明确时间、证据状态和当事人回应；必要时不做。

## 2. 研究档案的必备字段

每期先建立一个来源编号表（如 `RH-P1-01`），再写笔记。每条重要信息都可回链到来源编号。

| 字段 | 示例 |
|---|---|
| Claim ID | RH-F-03 |
| 待验证主张 | Ryan Holiday 19 岁离开大学，师从 Robert Greene。 |
| 类型 | 生平事实 / 引文 / 出版信息 / 影响力 / 编辑判断 |
| 来源编号 | RH-P2-01 |
| 来源层级 | P2 |
| 原文摘录或页码/时间码 | 原文句子、章节、视频时间码 |
| 核验状态 | 已确认 / 待交叉确认 / 不采用 |
| 拟在成片中的表述 | “据其官网自述，他 19 岁离开大学，成为 Robert Greene 的学徒。” |
| 风险/备注 | 自述来源，避免扩展为“唯一原因”或“命运转折”。 |

## 3. 脚本标记法

在内部英文稿中使用以下标记，发布版删去标记：

- `[F]` 可核验事实；写明来源 ID。
- `[Q]` 直接引文；含原文、译文、出处、页码或时间码。
- `[E]` 编辑解释；不得伪装成当事人意图。
- `[C]` 背景知识；标明学术/专业来源。
- `[L]` 局限、反例或争议；标明不同观点来源。
- `[V]` 画面素材；标明版权/授权状态。

例：

```text
[F:RH-F-03] At nineteen, Holiday left college to apprentice under Robert Greene.
[E] That did not give him a philosophy. It gave him a front-row seat to ambition as a craft.
```

第二句是我们的解释，不能写成“这件事让他因此相信……”，除非有本人明确表述。

---

## 4. 引文与翻译规则

1. 引用以短为原则：单次建议不超过 25 个英文词，且必须说明它在原作中的语境。
2. 不得从不同段落拼接成看似完整的一句话。
3. 所有中文译文均标为“节目译”；已有权威中译时，先核对版本与版权，不直接抄长段落。
4. 经典文本需注明译本。不同译本若影响含义，应在制作笔记中保留比较。
5. 所谓“名言”若无法查到可靠出处，宁可不用。
6. 引文不应替代解释：每 1 句引文，至少配 2–3 句自己的白话阐释。

---

## 5. 影响力的表述规范

不要写：“他影响了全世界年轻人。”

应写成可追溯、不过度延伸的表述，例如：

- “据其出版方资料，其作品以四十多种语言出版；该数字属于出版方口径。”
- “他的作品在自我管理与现代斯多葛社群中拥有持续读者。”
- “这说明其传播范围很广，但不等同于所有读者接受其哲学解释。”

影响力可通过多个信号组合判断：持续出版、翻译、被引用的作品、读者实践社群、跨领域讨论、教学/创作影响。粉丝数量只是一种弱信号。

---

## 6. 有争议人物与敏感内容

- 先问：争议是否与本期核心思想有关？无关则不为制造戏剧性而插入。
- 相关时：呈现原始事实、不同解释、人物回应与未知部分；不替观众做事实以外的断言。
- 避免诊断人物人格、心理状态或动机。
- 对仍在世的人，使用可核验的措辞：`he said`、`the publisher describes`、`critics argue`，不要无证据断言意图。
- 遭到严重指控、涉及犯罪、医疗、政治冲突或弱势群体时，必须由第二位编辑完成事实复核。

---

## 7. 发布前事实闸门

以下任何一项为“否”，本期不得锁稿：

- [ ] 每个重要生平事实都有来源编号。
- [ ] 每条引文能回到原页、原书或原时间码。
- [ ] 所有销量/影响力数字写明口径和时间。
- [ ] 编辑解释与事实叙述被清楚区分。
- [ ] 至少一项边界、反例或学术异议进入成片。
- [ ] 画面、书封、照片、音频均有版权或合理使用判断记录。
- [ ] 链接、书名、人名、年份、译名经过最后核对。
