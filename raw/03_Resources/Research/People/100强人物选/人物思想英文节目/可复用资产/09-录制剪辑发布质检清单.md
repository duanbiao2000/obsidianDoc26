# 09｜录制、剪辑与发布质检清单

> 使用方法：每次进入下一阶段前逐项勾选。任何关键项未通过，优先修内容，不用音乐、特效或标题掩盖问题。

## A. 录制前：研究与脚本

- [ ] 用一句英文说清：`This episode is not about ____. It is about ____.`
- [ ] 人物矛盾、现代问题和结尾问题相互对应。
- [ ] 生平部分不超过成片 30%。
- [ ] 至少 1 份一手作品/完整演讲真正进入论证。
- [ ] 每个重要事实、数字、引文有来源编号。
- [ ] 人物自述、出版社宣传和独立事实被区分。
- [ ] 至少一项反例、局限或不同解释已写入正文。
- [ ] 直接引文短且语境准确；译文标为节目译或注明版本。
- [ ] 所有敏感事实、争议、法律/医疗/心理健康表达经额外复核。
- [ ] 英文稿已大声试读；语速在 115–125 WPM 范围内。
- [ ] 人名、书名、地名、术语发音已标注。

## B. 录制中：声音与表演

- [ ] 前 25 秒没有冗长片头、自我介绍或口号。
- [ ] 重点句后留有自然停顿；没有机械地逐句同速。
- [ ] 讲事实、引文、编辑判断和边界时，声音层次清楚。
- [ ] 不以夸张断言、情绪高涨替代证据。
- [ ] 音频无削波、明显底噪、口水音或音量剧烈变化。
- [ ] 录音环境、麦克风距离、背景音保持一致。
- [ ] 每一段至少保留一条无明显口误的完整备选。

## C. 剪辑中：叙事与画面

- [ ] 每 45–75 秒有信息或视觉节奏变化，但不为了变化而乱切。
- [ ] 画面帮助理解时间、因果、原作或现实案例。
- [ ] Life Map 只保留与思想形成有关的 3 个节点。
- [ ] 引文卡显示作者、作品/演讲与必要出处。
- [ ] `THE LIMIT` 是实质内容，非一秒免责声明。
- [ ] 所有图片、视频、音乐、书封、截图均有来源/授权状态。
- [ ] AI 生成画面没有伪装为史实影像。
- [ ] 没有未经验证的“历史现场画面”或误导性照片。
- [ ] 片头、章节卡、结尾问题使用统一栏目组件。
- [ ] 结尾回扣开场，而不是生硬总结或强制关注。

## D. 字幕：中英文与术语

- [ ] 静音看完整片，中文是否可以独立理解？
- [ ] 中文字幕是自然意译，不是逐词直译。
- [ ] 一屏不超过 2 行；阅读速度合理。
- [ ] 专有名词、书名、年份、数字与画面/简介一致。
- [ ] 同一术语前后一致，已记入术语表。
- [ ] 英文可切换字幕轨已校对（如提供）。
- [ ] 引文字幕与主持人解释视觉上可区分。

## E. 发布前：B站交付

- [ ] 中文主标题诚实、具体，英文副标题有识别度。
- [ ] 封面只表达一个问题或张力，不堆人物名和小字。
- [ ] 视频简介首两行能说明人物、问题和本期主张。
- [ ] 简介/置顶评论包含核心参考资料链接与更正方式。
- [ ] 置顶评论提出一个可讨论、不可用“是/否”回答的问题。
- [ ] 分区、标签、字幕轨、封面、发布时间、片尾卡均已检查。
- [ ] 不使用“改变人生”“真相”“必看”等超额承诺词。
- [ ] 导出文件完整观看一次；手机端检查字幕、字体和音量。

## F. 发布后：48 小时和 14 天

- [ ] 记录前 30 秒留存、平均观看时长、完播趋势和收藏/投币/转发等信号。
- [ ] 阅读高质量评论：观众理解了什么、质疑了什么、要求查证什么。
- [ ] 记录字幕、发音、节奏和画面理解问题。
- [ ] 若有事实错误，按更正规范处理，而不是静默修改。
- [ ] 把真正跨期可复用的经验回写到 `可复用资产/`。
