# 人物库｜目录说明

本目录保存**跨季度人物库的正式内容**。它不承担长期操作规则、实时项目状态或单集研究材料。

| 文件 | 唯一职责 |
|---|---|
| `100人候选名单-编排版-v1.4.md` | 当前唯一正式 100 人名单：人物、编号、章节、节目理由、比例检查和版本记录 |
| `计算机科学补位候选清单-已确认-v0.2.md` | 技术人物补位的已确认决定与未来观察池 |

## 相关入口

| 需要做什么 | 应打开的位置 |
|---|---|
| 确认当前名单基线、未决人名解释或当前优先事项 | `../00-项目交接与实时状态.md` |
| 新增、移出、重排或升级正式名单 | `../可复用资产/skills/person-pool-change/SKILL.md` |
| 执行人数、编号、保留/排除人物校验 | `../可复用资产/自动化/人物库硬约束.v0.1.json` 与 `check_people_list.py` |
| 为某一人物进行评分、资料采集和 ERP 判断 | `../可复用资产/skills/episode-readiness/SKILL.md` |

具体单集一旦立项，材料应放入 `../节目制作/EPxxx-人物名/`，不能写回本目录。
