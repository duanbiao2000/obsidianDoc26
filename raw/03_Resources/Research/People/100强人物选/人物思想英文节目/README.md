# 人物思想英文节目｜导航入口

> 本文件只负责**找到正确文件**。长期规则见 `AGENT.md`；当前状态见 `00-项目交接与实时状态.md`；具体内容以对应正式文件为准。

## 开始顺序

```text
AGENT.md
  → 00-项目交接与实时状态.md
  → 本次任务的正式内容文件
  → 对应 Skill 与自动化校验
```

## 去哪里找什么

| 如果需要…… | 打开…… |
|---|---|
| 确认长期协作规则、编辑底线、阶段闸门和收尾方式 | `AGENT.md` |
| 确认当前名单版本、活跃 EP、阻塞项和下一步 P0 | `00-项目交接与实时状态.md` |
| 查看正式 100 人名单、章节、人物理由和名单版本历史 | `人物库/100人候选名单-编排版-v1.4.md` |
| 查看人物库目录和当前文件入口 | `人物库/README.md` |
| 选择通用规范、模板或任务 Skill | `可复用资产/README.md`、`可复用资产/skills/README.md` |
| 运行名单、版本、EP 阶段或会话收尾校验 | `可复用资产/自动化/README.md` |
| 处理某一期的人物研究、事实、脚本、字幕或素材 | `节目制作/EPxxx-人物名/` |

## 导航维护

文件路径、当前正式版本或目录结构变化时，只更新本导航页的相关入口；不要把规则、实时状态、名单正文或研究材料复制到这里。
