若你要做“**每日财报 / 研报提炼**”，建议把来源分成两层：**财报以交易所/监管披露为准，研报以聚合平台和券商渠道为主**；前者是原始事实，后者是分析观点。

## 财报：优先官方源

| 市场   | 首选入口                                    | 可获取内容                                                                                                         |
| ---- | --------------------------------------- | ------------------------------------------------------------------------------------------------------------- |
| A 股  | **巨潮资讯网（CNINFO）**                       | 年报、半年报、季报、业绩预告、公告、问询函等；覆盖深市、沪市、北交所披露信息。 [[cninfo.com](http://www.cninfo.com.cn/)]                             |
| 港股   | **HKEXnews / 港交所披露易**                   | 上市公司公告、业绩报告、通函等，可按公司、时间和公告标题检索。 [[www1.hkexnews](https://www1.hkexnews.hk/search/titlesearch.xhtml)]          |
| 美股   | **SEC EDGAR**                           | 10-K（年报）、10-Q（季报）、8-K（重大事项）及其他申报文件；免费、可全文搜索，也提供实时/每日申报列表和 API 数据。 [[sec](https://www.sec.gov/search-filings)] |
| 全球公司 | 公司官网的 **Investor Relations / 投资者关系** 页面 | 通常可直接获得财报 PDF、业绩演示稿、业绩电话会材料与新闻稿；关键数字仍建议回到监管文件核验。                                                              |

如果你只是想知道“**今天有哪些公司发业绩**”，用财报日历筛选国家、时区和日期会高效得多。TradingView 的 Earnings Calendar 支持按地区、时间段和时区筛选，并显示 EPS、预期与实际值；富途也提供港美股公司的财报披露日期与相关表现。[[cn.tradingview](https://cn.tradingview.com/earnings-calendar/)]

## 研报：聚合与原始渠道

- **专业终端**：Bloomberg 等适合高频、全球化和机构级需求，整合公司申报文件、业绩记录、行业研究及众多第三方研究内容，但一般成本较高。[[bloombergchina](https://www.bloombergchina.com/solution/analyst/)]

1. **公告原文核验**：A 股进巨潮，港股进 HKEXnews，美股进 EDGAR；先保存原始链接而非只存二手解读。[[cninfo.com](http://www.cninfo.com.cn/)]
