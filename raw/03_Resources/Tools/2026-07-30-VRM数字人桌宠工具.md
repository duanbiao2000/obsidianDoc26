**Warudo** 是一款 Windows 上可直接通过 Steam 安装的 3D VTuber/虚拟角色工作台，个人使用免费。它可导入 VRM 角色，内置摄像头/iPhone 面捕、手部追踪、口型同步、场景与互动逻辑，定位比 Persona 更偏专业直播、录屏与可视化角色控制。[[store.steampowered](https://store.steampowered.com/app/2079120/Warudo/)]

## 适合你的用途

它很适合将 `.vrm` 形象变成你视频或 AI 教学演示中的数字角色：

- 用摄像头驱动头部、表情和手势
    
- 用麦克风音频让角色张嘴说话
    
- 配置背景、灯光、道具、镜头，再经 OBS 录制或推流
    
- 使用 **Blueprint** 可视化逻辑系统，将热键、表情、动作、Twitch/YouTube 事件或外部控制连接起来。[[youtube](https://www.youtube.com/watch?v=AERvgciIRzk)][[store.steampowered](https://store.steampowered.com/app/2079120/Warudo/)]
    

例如，做英语口语讲解视频时，你可以将你的麦克风设为口型输入，摄像头驱动角色表情，把 Warudo 的透明背景画面送入 OBS，叠加在 PPT、网页或屏幕录制画面之上。Warudo 支持由麦克风输入做音频口型同步，并可对元音口型进行校准。[[note](https://note.com/haradaa07/n/n4f3fe7e388c7?hl=en)][[youtube](https://www.youtube.com/watch?v=blIU1OLBLN4)]

## 安装与最低配置

在 Steam 搜索 **Warudo**，点击安装即可，无需 Node.js、Python 或 C++ 编译环境；其 Steam 页面说明个人用途为免费。[[store.steampowered](https://store.steampowered.com/app/2079120/Warudo/)]

公开的最低系统要求信息显示其需要 Windows 10、约 6 GB 磁盘空间、Intel Core i5-9400F 和 NVIDIA GTX 1660（6 GB 显存）级别配置，因此它明显比 Persona、VSeeFace 这类轻量角色查看器更吃显卡。[[systemrequirementslab](https://www.systemrequirementslab.com/cyri/requirements/warudo/23461)]

## 导入 VRM

最直接的流程是：

1. 下载一个有明确授权的 `.vrm` 人物模型。
    
2. 安装并启动 Warudo。
    
3. 在启动/角色配置中点击 **Open Character Folder**。
    
4. 将 `.vrm` 文件复制到打开的角色目录。
    
5. 回到 Warudo，在角色下拉列表中选择该模型并加载。[[youtube](https://www.youtube.com/watch?v=V6ILzbbUeo0)][[note](https://note.com/haradaa07/n/n4f3fe7e388c7?hl=en)]
    

首次加载后，建议进入角色的 **Motion Capture Settings**：

- 摄像头方案可选 MediaPipe 等
    
- 不需要身体追踪时，把 Pose Tracking 设为 `None`
    
- 将 Lip Sync 设为 `Always Enabled`
    
- 选择正确的麦克风设备
    
- 若口型不对，进入 Lip Sync 设置对 `A / I / U / E / O` 进行校准，并映射到模型实际拥有的 BlendShape。[[youtube](https://www.youtube.com/watch?v=blIU1OLBLN4)][[note](https://note.com/haradaa07/n/n4f3fe7e388c7?hl=en)]
    

## 与 Persona 的差异

|维度|Warudo|Persona|
|---|---|---|
|安装|Steam 直接安装。 [[store.steampowered](https://store.steampowered.com/app/2079120/Warudo/)]|当前偏向源码安装、依赖 Node 和原生构建环境|
|驱动重点|摄像头/iPhone 面捕、手捕、麦克风口型。 [[store.steampowered](https://store.steampowered.com/app/2079120/Warudo/)]|监听特定应用的**系统播放音频**并让角色响应。|
|角色表现|场景、灯光、道具、动作、复杂逻辑和直播集成。 [[warudo](https://warudo.app/)][[youtube](https://www.youtube.com/watch?v=AERvgciIRzk)]|轻量桌面角色与实时语音呈现。|
|资源消耗|中等到较高，适合独显电脑。 [[systemrequirementslab](https://www.systemrequirementslab.com/cyri/requirements/warudo/23461)]|相对轻量。|
|自动化潜力|Blueprint 与 SDK/扩展生态更强。 [[youtube](https://www.youtube.com/watch?v=AERvgciIRzk)]|MCP 是其特点之一。|

## 是否值得装

**值得安装**，若你希望得到一个成熟、免编译、能做面捕和录制的 VRM 工具。尤其你做内容和教学演示，Warudo 可以成为“数字人出镜层”，将角色画面输出给 OBS 或后期软件。

但如果你真正要的是“ChatGPT/AI 的系统语音一播放，桌面角色就自动说话”，Warudo 默认以**麦克风输入**口型同步为主，不直接等同于 Persona 的“按应用进程监听系统音频”。这种场景可通过 Windows 的 Stereo Mix 或虚拟音频线把播放音频路由成一个录音输入来实现，但会增加额外的音频路由配置。[[note](https://note.com/haradaa07/n/n4f3fe7e388c7?hl=en)][[youtube](https://www.youtube.com/watch?v=blIU1OLBLN4)]
