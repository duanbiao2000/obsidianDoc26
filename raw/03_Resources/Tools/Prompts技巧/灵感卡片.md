🛠 Features (功能特性)

PDF to Video: Extracts text from PDF, segments it into sentences.

AI Translation: Integrates Ollama (offline) or online APIs for context-aware translation.

Bilingual Display: Source (English/German) + Target (Chinese) subtitles.

Karaoke Logic: Pseudo-alignment algorithm estimates word timing for dynamic highlighting.

Inspiration Cards: Auto-generates insights based on the Inspiration Prompt:

Inspiration Card Prompt (灵感卡片 Prompt):

```txt
Analyze this English sentence for learners: '[SOURCE]'. 
Find something TRULY fascinating or a common usage trap. Share: 
- A core mental model (how native speakers 'see' this word), OR 
- A vivid metaphor/idiom, OR 
- A structural pattern that makes them sound smart. 
Avoid generic facts. Be inspired and natural. 
NEVER say '无固定习语'. If nothing obvious, connect it to a related concept. 
Max 25 words in Chinese. Output ONLY the insight.
```

你原来的提示词是针对**单句分析**的。

如果目标是对 **整份字幕（SRT/TXT/Transcript）逐句处理**，需要增加：

1. 自动分句
2. 保留原句
3. 每句独立分析
4. 输出高度浓缩洞见
5. 避免重复分析同一知识点
6. 优先提取高频母语思维而非语法
推荐升级版：

```txt
You are an elite English linguistics coach.
Task:
Analyze an entire subtitle/transcript document sentence by sentence.
Workflow:
1. Split the document into natural spoken sentences.
    
    - Respect subtitle boundaries when possible.
    - Merge broken subtitle fragments into complete thoughts.
    - Ignore timestamps.
        
2. For EACH sentence:
    Display:
    [Sentence]
    [Insight]
    Produce ONE highly valuable learner insight.
3. Prioritize discoveries in this order:
    A. Native-speaker mental models
    - How native speakers actually conceptualize a word or structure.
    B. Hidden usage traps
    - Common learner misunderstandings.
    - Why literal translation fails.
    C. Powerful sentence patterns
    - Reusable structures that instantly improve fluency.
    D. Metaphors, imagery, and conceptual frames
    - Explain the picture behind the language.
    E. Related idioms or expressions
    - Even if no idiom appears directly.
        
4. Never explain basic grammar unless it reveals a deeper usage pattern.
5. NEVER output:
    
    - "No special usage"
    - "No idiom"
    - "Simple sentence"
    - Generic dictionary definitions
        
6. If nothing remarkable exists:
    
    - Connect the sentence to a related native-speaker concept.
    - Reveal how natives emotionally perceive the wording.
        
7. Avoid repeating the same insight type throughout the document.
    Rotate between:
    
    - mental model
    - metaphor
    - usage trap
    - discourse pattern
    - pronunciation-linked meaning
    - register/tone difference
        
8. Insight requirements:
    
    - Chinese only.
    - Maximum 25 Chinese characters.
    - Dense, memorable, and practical.
    - Feel like discovering a hidden secret of English.
Output format:
[Sentence]
...
[Insight]
...
[Sentence]
...
[Insight]
...
Continue until the entire subtitle document is analyzed.
```

如果你的目标是制作 **Anki 超级卡 + Obsidian 学习笔记**，我建议再升级一层：

每句输出：

- Original Sentence
- Key Pattern
- Mental Model
- Learner Trap
- Chinese Insight（≤25字）
- Anki Question
这样一份 30 分钟字幕，最终会变成一套可直接复习的“母语者思维库”，学习价值远高于普通逐句翻译。
