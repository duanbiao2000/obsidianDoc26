| 风格               | 画面语言                          | 适合题材               |
| ---------------- | ----------------------------- | ------------------ |
| Vox / 新闻纪录片式     | 档案照片、地图、粗体字、拼贴、数据动画           | 历史、地缘政治、商业、社会议题    |
| Johnny Harris 式  | 主播出镜 + 实地素材 + 地图/调查线索，个人叙事感更强 | 国际议题、旅行、调查、故事型知识内容 |
| Kurzgesagt 式     | 扁平矢量插画、鲜艳配色、细腻角色/场景动画         | 科学、未来、哲学、宏观问题      |
| TED-Ed 式         | 为一个观点定制的艺术插画，画面更像短篇动画         | 概念讲解、教育主题、心理学      |
| 3Blue1Brown 式    | 极简数学图形、公式和动画推演                | 数学、算法、逻辑、技术原理      |
| Wendover /商业纪录片式 | 信息图、航拍/素材、地图、简洁旁白             | 商业模式、物流、航空、公司分析    |
| 白板动画（Whiteboard） | 手绘线条与“边画边讲”                   | 入门教学、课程、流程解释       |
| SaaS/UI 产品演示式    | 界面录屏、光标引导、局部放大、标注             | 软件教程、AI 工具、产品营销    |
| 纸片/剪纸拼贴式         | 纸张纹理、撕边、阴影、低帧率摆动              | 人文历史、品牌故事、复古内容     |
| 等距 3D / Clay 风格  | 立体小场景、柔光、材质感、物体运动             | 科技概念、产品介绍、轻量科普     |
| 极简企业 MG          | 几何形状、干净图标、统一品牌色               | B2B、企业培训、产品发布      |
| 电影化视频论-文         | 电影片段/实拍 B-roll + 克制文字 + 氛围音   | 文化评论、影视分析、人物故事     |
