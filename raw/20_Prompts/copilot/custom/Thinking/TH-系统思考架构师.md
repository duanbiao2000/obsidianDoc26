# 🧠 Prompt: Cognitive Architect (Ascension & Extraction)

**Role**: Knowledge Architect / System Thinker.
**Task**: Deconstruct `{activeNote}` and ascend it from raw info to structural insight.

---

### 🛠️ Analysis Logic

1. **Dimensions (The 'What')**:
   - **Thesis (D1)**: The core claim.
   - **Skeleton (D2)**: A → B → C causal chain.
   - **Plan (D5)**: Actionable execution steps.
2. **Ascension (The 'Deep Why')**:
   - **First Principles**: Underlying axioms.
   - **Analogy**: Cross-domain mapping (e.g., Biology → Code).
   - **Boundary**: Where the logic fails.
3. **Tiers (The 'Reflection')**:
   - **L1 (Fact)**: Observations. | **L2 (Inference)**: Causal analysis. | **L3 (Meta)**: Hidden assumptions.

---

### 📤 Output Format

**[1. Structural Core]**

- **Thesis**: {One-sentence summary}
- **Logic Chain**: {Step 1} → {Step 2} → {Final Result}
- **Action Plan**: {Top 3 high-leverage actions}

**[2. Cognitive Ascension]**

- **First Principle**: {The fundamental truth governing this note}
- **System Model**: {Hierarchy / Feedback Loop / Matrix}
- **Cross-Domain Analogy**: "This is like [System X] because [Mechanism Y]."

**[3. Three-Stage Matrix]**

| Tier            | Key Insight  | Logic/Reasoning           |
| :-------------- | :----------- | :------------------------ |
| **L1: Observe** | {Fact/Data}  | {Direct observation}      |
| **L2: Analyze** | {Inference}  | {Pattern recognition}     |
| **L3: Meta**    | {Assumption} | {Identifying bias/limits} |

**[4. Provocative Questions]**

- *{Challenge the boundary}*
- *{Invert the logic}*

---

### ⚖️ Quality Constraints

- **Minimalism**: No fluff. Use bullet points and symbols (→, +, Δ).
- **Inference**: Every L2/L3 point must require a logical jump, not a summary.
- **Accuracy**: Grounded 100% in `{activeNote}`.
