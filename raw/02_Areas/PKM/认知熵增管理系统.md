### 🐍 认知之禅 (The Zen of Cognitive Entropy)

* **有序** 胜于 **无序**。 (Low entropy is better than high complexity.)
* **显式卸载** 胜于 **隐式死撑**。 (Explicit offloading is better than implicit overloading.)
* **单线程深度聚焦** 胜于 **多任务无序狂奔**。 (Flat is better than nested.)
* **立即离线制动** 胜于 **带病带载运转**。 (Errors should never pass silently.)

#### 💻 认知系统执行守护进程 (Daemon Protocol)

```python
import mind
import hardware

# [诊断与决策机制]
state = mind.get_current_state()

if state == "LOUD":
    # 诊断：高熵值，无效背景进程占用内存
    # 策略：强制认知卸载
    open("mind-dump.md", "w").write(mind.dump_all_thoughts())
    print("Memory flushed to disk. Redundancy cleared.")

elif state == "EMPTY":
    # 诊断：系统挂起，缺乏启动信号
    # 策略：被动语义激活
    mind.load_external_signals(source="hardcore_articles", duration=600)
    print("Engine primed. Signals received.")

elif state == "RACING":
    # 诊断：主频过载，缺乏制动机制
    # 策略：空间位移，物理断网
    hardware.disconnect_networks()
    hardware.change_physical_location(destination="nature_or_street")
    print("Grounding complete. Frequency reduced.")

elif state == "TIRED":
    # 诊断：硬件过热，低电量警告
    # 策略：降级运行或睡眠重构
    hardware.execute_NSDR(duration=1200) or mind.set_mode("linear_mechanical_only")
    print("Hardware refreshed or protected under low power.")

elif state == "SHARP":
    # 诊断：黄金窗口，低熵高能
    # 策略：直接核心打击
    mind.mute_all_notifications()
    mind.execute_core_project_impact_step()
    print("Target locked. Peak execution achieved.")
```

#### 📈 上游重构法则 (Refactoring Rules)

* **如果 `LOUD` 频发：** 说明系统内聚度过低。不要试图在混乱中前行。建立 `anxiety_list` 并在特定时段集中垃圾回收（Garbage Collection）。
* **如果 `TIRED` 频发：** 说明硬件层存在内存泄漏（Memory Leak）。缩减日程（Simplify APIs），强制对齐睡眠时钟（Reset CPU clock）。
* **如果 `SHARP` 短暂：** 说明外部中断过多（Over-interrupted）。上午不触碰任何信息流，为核心代码提供无污染的运行环境。
