## 费曼式学习法

|原则|常见错误|实际练习|
|---|---|---|
|**好奇优先**|为完成任务而记忆，几乎不提问|每次学习前先列出三个真正想弄明白的问题。|
|**从做中理解**|看教程、读笔记，却不操作|先做一个粗糙实验、原型或题目，让失败决定下一步要学什么。|
|**用多种表征**|只读文字或只背定义|同一个概念分别画图、举例、写公式、口头解释。|
|**把问题拆小**|一开始就被复杂度压住|将问题拆为变量、部件、条件、约束和最小可测试步骤。|
|**跨界探索**|只在专业舒适区内学习|选一个相邻领域找类比，例如用产品实验理解科学假设。|
|**允许不知道**|急于显得懂，直接填补空白|明确写下“我不知道 X”，把它变成下一轮检索或实验问题。|
|**让现实裁决**|迷信名人、理论或直觉|事先写下预测与衡量方式，再以结果修正模型。|

这些原则与本书强调的理解、科学探究、提问、假设、图示、类比、实验与好奇心相一致。[[en.zlib](https://en.zlib.bz/book/n1ydZjZjw8/richard-feynmans-mental-models.html?dsource=recommend)]

## 一个实用模板

用这张“费曼问题卡”处理一本书、一个观点或一个项目：

text

`问题： 我想真正理解什么？ 事实： 我亲自观察到或可靠来源确认了什么？ 模型： 我目前认为它为什么发生？ 简化解释： 我能否用150字、一个例子和一张图讲清？ 预测： 若模型正确，接下来应出现什么现象？ 反例： 什么会证明我错了？ 最小测试： 我能在7天内做什么来验证？ 更新： 测试后，我保留、修改还是放弃哪一部分假设？`

## 对你的应用

你正在系统读学习、AI、心理学和思维模型书。费曼式方法最能防止一种风险：**把别人的框架迅速总结得很漂亮，却没有建立自己的可验证理解。**

例如读到“精益学习”时，不只记住“少学多做”，而应追问：

- 对什么类型的任务，少输入确实更有效？
- 哪些任务需要先扎实打基础，不能只靠即时学习？
- “有效”如何衡量：完成率、迁移能力、收入、长期记忆，还是主观满意度？
- 用自己未来一周的学习项目如何测试它？

本书最值得留下的不是某个花哨的 mental model，而是一种纪律：**宁可诚实地说“我还不懂”，也不以术语、权威和熟悉感伪装理解。**[[en.zlib](https://en.zlib.bz/book/n1ydZjZjw8/richard-feynmans-mental-models.html?dsource=recommend)]


| 任务类型           | “少学多做”通常更合适                              | 为什么仍要打基础                                                                                                                                                |
| -------------- | ---------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 有明确产出的项目       | 做一条视频、写一篇文章、用 API 自动化一个流程；遇到障碍再补相应知识     | 项目会持续暴露真实知识缺口，学习与使用紧密相连                                                                                                                                 |
| 高频且反馈快的技能      | 剪辑、提示词设计、英语口语表达、代码调试                     | 快速尝试—纠错—再尝试，本身就是练习；但要有质量反馈                                                                                                                              |
| 高风险或强依赖前置知识的领域 | 不宜直接“边做边学”，如数学证明、统计推断、医学、复杂编程架构、正式写作语法体系 | 缺失核心概念会使错误难以诊断，也无法判断自己是否真的做对                                                                                                                            |
| 追求远迁移或专业能力的领域  | 仅靠完成眼前任务往往不够                             | 迁移通常更容易发生在与练习情境相近的任务；远距离迁移相对罕见，因此需要抽象原理、多样例子与刻意变式练习。[worklearning](https://www.worklearning.com/2020/01/06/major-research-review-on-learning-transfer/) |
