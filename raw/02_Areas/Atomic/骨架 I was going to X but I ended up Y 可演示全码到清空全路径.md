# 骨架 I was going to X but I ended up Y 可演示全码到清空全路径

核心：以一个"原计划 vs 实际结果"的句型骨架，演示全码→隐藏全码→清空的完整练习路径，可直接当第一张 Full 卡。

为什么 / 证据：
> 句型：`I was going to X, but I ended up Y.` 重音：*I was GOing to…, but I ENded UP…*。步骤：先看卡片完整说10次 → 遮住中/英一侧说 → 用真实内容造3句。熟手输出：*I was going to work out after dinner, but I ended up working late. By the time I got home, I was too tired to do anything.*（其中 *I was going to…*、*ended up…*、*By the time…*、*too … to …* 即高频"简码"）

边界 / 反例：
- 该骨架仅覆盖"计划变更"一类叙事，不能泛化到所有口语场景。
- 高频套用易显得套路化，需配合其他骨架与自由表达。

我的判断（个人层 / 应用）：
- 我把它作为第一张 Full 卡录入，并在熟手输出里把自然带出的 *By the time…*、*too…to…* 单独收进简码库——骨架是入口，顺带的块才是资产。
