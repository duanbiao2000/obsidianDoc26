# 显性知识是文档规则事实、默会知识是行动依赖的隐性模型

**核心**：显性知识是文档、规则和事实；默会知识是选择、排序、判断和行动时所依赖的隐性模型。优秀的知识系统不能只收集信息。

**为什么 / 证据**：
> 显性知识是文档、规则和事实；默会知识是选择、排序、判断和行动时所依赖的隐性模型。
> 优秀的知识系统不只是收集信息，还应该记录：为什么采纳这个观点；为什么舍弃另一个方案；什么信号说明一个项目值得继续；哪些经验可以迁移；哪些判断只在特定上下文有效。

这一定义把"默会"从"神秘直觉"还原为"隐性模型"，是可显性化、可记录的对象（见 [[用六问模板把默会感觉转为可观察判断标准]]、[[判断性知识是经验压缩后的快速判断而非神秘直觉]]）。

**边界 / 反例**：
- 并非所有默会都能完全显性化；有些身体性、情境性知识显性化后失真或失效。
- "记录判断"本身也可能变成新的教条，若不复盘就会僵化。

**我的判断**（个人层 / 应用）：
- 这正是我建第二大脑的方法论底座：每条笔记的"我的判断"层，就是把这个隐性模型从脑子里搬到纸上。只收藏不写判断，等于只攒显性材料、没攒默会。
