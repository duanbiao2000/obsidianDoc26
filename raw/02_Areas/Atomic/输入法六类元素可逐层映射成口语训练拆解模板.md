# 输入法六类元素可逐层映射成口语训练拆解模板

**核心**：把小鹤音形的六类元素逐一映射到口语训练层，得到一套稳定的"发音线索+表达结构+完整复现+高频块+场景脚本+强制自动化"拆解模板。

**为什么 / 证据**（六层映射）：
- **双拼音码 → 音节/重音/连读**：建立声音运动路径
- **双形拆字 → 句子骨架/搭配/语义角色**：建立可组合的表达结构
- **单字全码 → 完整句型或语块**：能解释、能准确复现
- **简码 → 高概率块状表达**：低负荷脱口而出
- **词库候选 → 个人表达库/场景脚本**：降低临场检索成本
- **隐藏全码词库 → 不看稿不翻译不逐词拼装**：强制自动化与流利度

**边界 / 反例**：
- 这是类比而非等价：输入法是离散符号系统，口语是连续声学+语用系统，不能直接搬运所有机制。
- "隐藏全码词库"在输入法靠软件强制，口语需人为设计训练条件才成立。

**我的判断**（个人层 / 应用）：
- 拿到新材料我先按这六层自查缺哪层，优先补"声音路径"和"场景脚本"两层——这两层是我过去最容易跳过、却最影响实战的。
