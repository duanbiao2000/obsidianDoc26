# 口语训练应照全码到简码逐步撤支架

**核心**：用输入法「先全码、后简码、逐步撤支架」的设计来安排口语训练——先建可解释的发音与表达路径，再撤掉辅助，逼出更短、更自动化的产出。

**为什么 / 证据**：
> 先用"全码"建立可解释的发音与表达路径，再逐步撤掉支架，逼出更短、更自动化的产出。小鹤的"全码字/词 → 简码"不是单纯提速，而是把学习模式切到实战模式；口语训练也可以这样分层。

小鹤音形本身就是"先练拆分（全码），熟练后删辅助候选（简码）"的成熟产品，其训练节奏可作口语设计的参照原型（见 [[输入法六类元素可逐层映射成口语训练拆解模板]]）。

**边界 / 反例**：
- 该框架假设材料有清晰"全码"（完整句型+重音）；纯单词记忆、发音习惯养成可能不需要完整三阶段。
- 对已有强语感者，"先全码显性"可能是冗余。

**我的判断**（个人层 / 应用）：
- 落地时我默认：任何新表达都先走"全码可见"再谈撤支架，不跳步；但只对我真要"自动化"的表达才走到清空全码库，其余停在 Frame 即可，避免为不常用表达过度投入。
