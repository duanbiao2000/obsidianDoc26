# 口语流利度来自整体提取的高频语块而非单词拼装

**核心**：口语里的"简码"不是缩写，而是能整体提取的高频语块（chunks），像输入法高频词一击命中——流利度来自"块"的库存与提取速度。

**为什么 / 证据**：
> 英语的"简码"不是缩写，而是**高频语块（chunks）**。例如 *What I mean is…*、*The thing is…*、*It depends on…*、*I ended up…*、*I'm not used to…*。它们在口语中可以整体提取，类似输入法里高频词一击命中。

"逐词拼装"的认知负荷是流利口语的核心瓶颈，整体提取的块能压低该负荷（见 [[口语材料应用 Full Frame Prompt 三库并按自动化晋级]] 中 Prompt 库设计）。

**边界 / 反例**：
- 过度依赖块会致表达"模板化"、句法灵活性下降。
- 低频或高度专业场景，硬塞通用块反而增加检索与适配成本。

**我的判断**（个人层 / 应用）：
- 我建简码库时只收"我真实会脱口"的块，不收"看起来高级但用不上"的块；优先覆盖高频场景（计划变更、表态、解释、拒绝），而非广撒网。
