# 精英学术环境传递的七类默会知识

**核心**：精英教育环境可能培养或传递的默会知识，可归为七类；它们不是"人人具备的特质"，而是通过讨论、办公室交流、同伴反馈被强化的隐性互动能力。七类按"主功能"分三组，避免扁平清单的隐含重叠。

**为什么 / 证据**（七类，以哈佛学生群体为 illustrative 例；按主功能分三组）：

### 主功能一 · 评估判断（evaluate）：判断质量与价值
- **1. 什么问题值得被认真讨论**：区分是否只是信息检索/有理论价值/能产生新研究/流行但无深度/值得投入数年。成熟提问从"如何提高效率"变为"在什么约束下哪些策略有效、代价是什么"。
- **4. 如何判断机会的真实价值**：公开信息给名称/截止日；默会判断项目是否真有指导、负责人可靠否、是否空有声誉无实值、能否带来下一次机会与网络。
- **7. 什么样的失败是有价值的**：不把失败等同"无价值"；追问假设错还是执行不足、排除哪些可能、能否转成新问题、是否值得继续。

### 主功能二 · 人际互动（relate）：与他人有效协作
- **2. 如何表现出"值得交流"**：展示如何思考而非只展示知道什么；不把观点说满；承认不确定；准确回应他人论点；提让讨论深入的问题；不把异议当攻击。
- **3. 如何接近重要的人**：邮件多长、首段说什么、如何表明读过对方工作、何时提请求、具体到什么程度、被拒后如何维持关系、如何通过熟人进圈子。

### 主功能三 · 自我建构（construct self）：构建叙事与容纳不确定
- **5. 如何把经历包装成有意义叙事**：从罗列经历，到形成"观察到问题→为何关心→尝试了什么→失败暴露什么→形成什么新问题"的解释链；也是一种理解自我的方式。
- **6. 如何与不确定性相处**：奖励提尚无答案的问题、证据不足时暂缓判断、区分事实/推测/价值判断、承受长期无结果、失败后重定义问题。

**边界 / 反例**：
- 这七类是"环境可能传递"的，不是某群体天生拥有；换环境优势未必平移（见 [[精英优势来自环境与网络而非天赋且换环境未必有效]]）。
- 模仿外在符号（腔调、术语）而无对应判断，是舍本逐末。
- 看似重叠（1/4/7 都含"判断"、2/3 都涉"与人互动"、5/6 都涉"自我"）是因为把它当**扁平七清单**；一旦改为**主功能（评估/人际/自我）× 子对象**的正交结构，组内靠"被判断/互动/建构的对象"区分，重叠自然消失——与 Agent 技能路由的裁决原则同构（见 [[Agent 应按触发条件动态路由到最匹配的技能画像]]）。

**我的判断**（个人层 / 应用）：
- 我把这七类当"可训练行为清单"而非"精英特质"：按三组主功能分别找场景练、找反馈。尤其第1类（好问题）和第4类（机会判断）直接决定我投入产出；第6类（与不确定相处）是我长期研究的底层耐性。
