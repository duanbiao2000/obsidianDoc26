# 口语材料应用 Full Frame Prompt 三库并按自动化晋级

**核心**：用 Full/Frame/Prompt 三类卡片库承载口语材料，并设明确晋级与移出规则，避免"永远背稿"或"模糊流利"。

**为什么 / 证据**：
### 三库定义
- **Full**（初学库）：完整句子、音频、重音标注、中文意思、3 个替换例句
- **Frame**（常规库）：只留句型骨架 + 一个语义提示，如 `I ended up + V-ing`
- **Prompt**（熟手库）：只留场景标签，如 `plan changed / overtime / weekend`
### 晋级规则
> 能跟读复述准确 → Full→Frame；3秒内造3个不同个人句 → Frame→Prompt；陌生话题自然用出≥3次 → 移出复习库，只在真实对话维护。

**边界 / 反例**：
- 三库若不做定期"移出"，会变成囤积而非训练系统。
- 晋级标准（"自然用出≥3次"）较主观，难量化。

**我的判断**（个人层 / 应用）：
- 我每周做一次"移出"审计：把能自然用出的 Prompt 卡从复习流里删掉，只留真实对话维护；库不是收藏夹，要有进有出。
