### 🏛️ 核心架构：CLAUDE.md 是什么？

CLAUDE.md 是 Claude Code 的**项目记忆文件**。它是一个纯 Markdown 文件，在每次会话开始时被自动读取并加载到上下文中，为 Claude 提供关于项目的**持久指令**和背景信息。

可以把 CLAUDE.md 想象成你给一位新队友的入职简报，包含了团队工作方式、需要避免的坑以及项目的关键部分。

#### 1. 加载机制与层级

CLAUDE.md 的加载遵循**从通用到具体**的层级原则，不同层级的文件会被合并加载：

| 层级 | 位置 | 范围 | 用途 |
| :--- | :--- | :--- | :--- |
| **托管策略** | `/etc/claude-code/CLAUDE.md` (Linux) 等 | 组织内所有用户 | 公司级编码标准、安全策略等 |
| **用户指令** | `~/.claude/CLAUDE.md` | 当前用户的所有项目 | 个人代码风格、工具偏好等 |
| **项目指令** | `./CLAUDE.md` 或 `./.claude/CLAUDE.md` | 当前项目 | 项目架构、通用工作流、团队共享的约定 |
| **本地指令** | `./CLAUDE.local.md` | 仅当前项目（个人） | 个人特定的沙箱URL、测试数据等，通常不提交到Git |

此外，**子目录中的 CLAUDE.md 文件是按需加载的**。例如，当 Claude 读取 `app/api/` 目录下的文件时，才会加载 `app/api/CLAUDE.md`，而不是在会话开始时加载。

#### 2. 文件内容与编写原则

一份优秀的 CLAUDE.md 文件通常包含以下核心内容：
*   **项目背景与目标**：项目是什么，核心目标是什么。
*   **技术栈与架构**：使用了哪些框架、库，项目的目录结构是怎样的。
*   **常用命令**：如何构建、测试、运行项目。
*   **编码规范与约定**：代码风格、命名约定等。
*   **关键约束与“坑”**：需要避免的架构模式或已知问题。

编写时应遵循以下原则：
*   **保持精简**：官方建议将文件控制在 **200 行以内**。每一行都会消耗上下文窗口，因此要确保每一条信息都至关重要。
*   **具体明确**：使用具体的例子和量化的描述（如“函数不超过50行”），否定句式（如“不要使用 X 模式”）通常更有效。
*   **结构清晰**：将最重要的规则放在文件开头，并使用 Markdown 标题进行分层组织。

#### 3. CLAUDE.md 在扩展体系中的定位

CLAUDE.md 是 Claude Code 众多扩展机制中的一种，与其他机制分工明确：

| 扩展机制 | 核心作用 | 加载时机 |
| :--- | :--- | :--- |
| **CLAUDE.md** | 提供**始终在线**的项目级上下文和背景信息 | 会话开始时加载，并持续整个会话 |
| **Rules (规则)** | 提供**硬性约束**，如必须遵守的安全策略 | 按路径或文件类型作用域加载 |
| **Skills (技能)** | 封装**可复用的工作流**和知识 | 按需调用 |
| **Subagents (子代理)** | 将复杂任务**委派**给专门的子代理处理 | 按需调用 |
| **Hooks (钩子)** | 在特定事件（如工具执行前/后）进行**确定性自动化**控制 | 事件触发时执行 |
| **Output Styles** | 控制 Claude 的**回答风格** | 全局生效 |
| **System Prompt Append** | 在系统提示词**末尾追加**全局指令 | 全局生效 |

简单来说，**CLAUDE.md 负责“告诉 Claude 项目是什么”**，而其他机制则负责“在特定场景下指导 Claude 怎么做”。

### ✨ 新增特性：CLAUDE.md 的演进

随着 Claude Code 的迭代，CLAUDE.md 也引入了一系列新特性，使其更加强大和灵活。

*   **🤖 自动记忆 (Auto Memory)**：除了你手动编写的 `CLAUDE.md`，Claude 现在可以**自动**从你的更正和偏好中学习，并将这些学习成果写入 `MEMORY.md` 文件。`CLAUDE.md` 是你给 Claude 的指令，而 `MEMORY.md` 则是 Claude 自己的“记忆笔记”。

*   **📂 规则 (Rules) 与按需加载**：为了保持根目录 `CLAUDE.md` 的精简，可以将特定于某些文件类型或子目录的指令拆分到独立的**规则文件**中。这些规则只有在 Claude 操作相关文件时才会被加载，实现了更精细的上下文控制。

*   **📥 条件加载与导入语法**：`CLAUDE.md` 支持更丰富的功能，如**条件加载**和**导入语法** (`@path`)，可以引用其他的上下文文件。这使得将大型文档拆分为模块化结构成为可能。

*   **⚡ 提示缓存 (Prompt Caching)**：为了优化成本和性能，Claude Code 对 `CLAUDE.md` 应用了提示缓存技术。在会话中，除了第一个请求外，后续请求会命中缓存，按更低的费率计费。这意味着你无需为了节省成本而过度精简文件。

*   **🚀 `/init` 命令一键生成**：现在，你可以在任何项目中输入 `/init` 命令。Claude 会自动分析你的代码库，并为你草拟一份 `CLAUDE.md` 文件，涵盖构建命令、测试命令、项目结构等。

*   **📈 模板化与最佳实践演进**：社区和官方都在不断总结最佳实践，并以此更新 `CLAUDE.md` 模板。例如，出现了采用**双重记忆架构 (Dual-Memory Architecture)** 和**渐进式披露 (Progressive Disclosure)** 原则的新模板。

*   **🧩 `CLAUDE.local.md` 与个人配置**：引入了 `CLAUDE.local.md` 文件，用于存放你个人在特定项目上的偏好，且该文件不会被提交到版本控制系统。
