掌握 PptxGenJS

从零到一生成 PowerPoint


一个纯 JavaScript 库 · 跨平台 · 功能全面

浏览器 · Node.js · 任何前端框架

⚡ 环境搭建与 Hello World


                    const pptxgen = require('pptxgenjs');
                    let pres = new pptxgen();
                    pres.layout = 'LAYOUT_16x9';
                    let slide = pres.addSlide();
                    slide.addText('Hello World!', {
                        x: 1, y: 1, fontSize: 36, color: '363636'
                    });
                    pres.writeFile({ fileName: 'MyFirst.pptx' });

坐标单位：英寸 · 原点在左上角

🧩 核心概念

  • 演示文稿 (Pres)：整体容器
  • 幻灯片 (Slide)：通过 pres.addSlide() 创建
  • 元素 (Elements)：文本、形状、图片、表格、图表...
  • 布局 (Layout)：LAYOUT_16x9、LAYOUT_4x3

📚 开发环境与资源

  • 安装：npm install pptxgenjs 或 CDN
  • 官方文档：gitbrent.github.io/PptxGenJS
  • 在线示例：基础示例 · 完整展示

✍️ 文本与格式

  • addText('内容', { x, y, w, h, fontSize, color, bold, align })
  • 富文本：使用数组混合样式
  • 项目符号：bullet: true 或 bullet: { type: 'number' }
  • 换行：breakLine: true，边距：margin: 0

🔷 形状与样式

  • addShape('rect', { x, y, w, h, fill, line })
  • 可用形状：rect, oval, line, roundRect
  • 幻灯片背景：pres.background = { fill: 'FF0000' }

🖼️ 图片与图标

  • addImage({ path: 'path_or_url', x, y, w, h })
  • 裁剪模式：sizing: { type: 'contain' } 或 'cover'
  • 图标管线：react-icons → sharp → base64 → 嵌入

📊 表格


                    slide.addTable([
                        ['Header1', 'Header2'],
                        ['Data1',   'Data2']
                    ], {
                        x: 1, y: 1, w: 8,
                        colWidth: [4, 4],
                        rowHeight: 0.8,
                        border: { pt: 1, color: '888888' },
                        fill: { color: 'F0F0F0' }
                    });

📈 图表

  • 类型：bar, line, pie, scatter
  • addChart(pptxgen.ChartType.bar, data, options)
  • 建议：自定义颜色，隐藏图例，圆角

🎨 幻灯片母版

  • 定义统一风格（Logo、背景、占位符）
  • pres.defineSlideMaster() → addSlide() 引用
  • 保证品牌一致性与效率

⚠️ 常见陷阱与规避

  • 颜色：十六进制不要带 #，否则文件损坏
  • 透明度用 opacity 属性，而非颜色编码
  • 选项对象：不要在多个 add* 调用间复用同一个对象
  • 实例管理：每份演示文稿用新实例，避免状态污染

📤 输出与集成

  • 导出方式：writeFile, base64, Blob, Buffer, 流
  • 与 AI 结合：AI 生成 JSON → PptxGenJS 渲染
  • HTML 转 PPT：支持 HTML 表格一键转换

📝 实战项目：“我的学习笔记”

  • 目标：创建一份 PptxGenJS 学习总结 PPT
  • 结构：标题页 → 目录 → 核心 API → 总结

🔧 分步实现（代码构思）


                    const pres = new pptxgen();
                    pres.title = '我的学习笔记';
                    pres.author = 'Your Name';
                    const sections = ['标题页', '目录', '核心API', '总结'];
                    sections.forEach(title => {
                        const slide = pres.addSlide();
                        slide.addText(title, { x: 1, y: 0.5, fontSize: 32 });
                        // 添加内容...
                    });
                    pres.writeFile({ fileName: 'MyNotes.pptx' });
