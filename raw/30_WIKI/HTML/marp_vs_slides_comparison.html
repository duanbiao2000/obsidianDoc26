🎯 产品定位一句话

⚡

Marp Extended

文档转换器

将标准 Markdown 转换为符合出版规范的幻灯片文档，强调版式一致性与跨平台可移植性。

核心价值：写完即走，一键导出 PDF / PPTX，适合需要纸质或邮件分发的正式场景。

🎨

Slides Extended

演示引擎

基于 Reveal.js 的浏览器原生演示平台，强调视觉动效与交互叙事，将 Markdown 转化为网页级体验。

核心价值：在浏览器中呈现电影感过渡与分步动画，适合线上直播、现场演讲与视频录制。

⚠ 关键澄清：两者均为 Obsidian 插件，安装后均可即装即用；Marp CLI 仅用于高级自动化导出，非日常必需。

📝 Markdown 语法支持深度

Marp Extended

遵循 Marpit 规范，对标准 Markdown 支持极佳，但部分 Obsidian 扩展语法需适配。

语法支持
标准 MD（标题/列表/链接）✅ 完整
代码块高亮✅ 完整
Obsidian 内部链接 [[ ]]✅ 自动转换
Obsidian Callout⚠️ 需 CSS 适配
Mermaid 图表⚠️ 需开启 HTML 渲染
Dataview 查询❌ 不支持

Slides Extended

基于 Reveal.js 的 HTML 渲染管线，几乎完整继承 Obsidian 的解析能力。

语法支持
标准 MD（标题/列表/链接）✅ 完整
代码块高亮✅ 完整
Obsidian 内部链接 [[ ]]✅ 原生支持
Obsidian Callout✅ 原生渲染
Mermaid 图表✅ 自动初始化
Dataview 查询✅ 支持（需刷新）

💡 结论：如果你的笔记重度依赖 Obsidian 专属语法（Callout、Mermaid、Dataview），Slides Extended 能最大程度保留原格式；若笔记为标准 Markdown，两者差异不大。

📦 导出能力与格式兼容性

PDF

🏆

Marp 原生支持高质量矢量 PDF 导出，分页精准，适合印刷。

Slides 依赖浏览器打印，分页控制较弱。

PPTX

🏆

Marp 可导出可编辑的 PowerPoint 文件，便于团队协作二次加工。

Slides 无原生 PPTX 导出能力。

HTML

🏆

Slides 的 HTML 是自包含的交互应用，可部署到任意静态托管。

Marp 的 HTML 为静态页面，无交互能力。

格式Marp ExtendedSlides Extended适用场景
PDF原生导出，矢量质量浏览器打印，位图打印、邮件、存档
PPTX原生导出，可编辑不支持企业协作、模板复用
HTML静态页面交互式应用网页嵌入、在线分享
PNG/JPGCLI 支持批量截图需手动截屏社交媒体、缩略图

🚀 性能与资源占用

Marp Extended

  • 渲染在 Obsidian 主进程内完成，无额外浏览器实例
  • 内存占用低（约 50-80MB 增量）
  • 大文件（>100 页）预览无明显卡顿
  • 导出速度取决于文档复杂度，通常秒级
优势：轻量、稳定、适合长文档。

Slides Extended

  • 预览时启动 Chromium 内核（或调用系统浏览器）
  • 内存占用较高（约 150-300MB 增量）
  • 动画与过渡消耗 GPU 资源，低配设备可能掉帧
  • 大量 fragment 页面首次渲染有延迟
注意：建议关闭不必要的动画以保证流畅度。

测试环境：macOS 14 / Obsidian v1.8 / 16GB RAM · 100 页标准 Markdown 文档

扩展性对比

Marp 的扩展主要依赖 CSS 自定义与 Marp CLI 的引擎替换，适合有设计系统需求的团队。

Slides 可完整利用 Reveal.js 生态：Chart.js 图表、MathJax3 公式、Markdown 插件、Zoom 插件等，扩展天花板更高。

📚 安装配置与学习曲线

⚡

Marp Extended

1. Obsidian 社区插件安装
2. 书写标准 Markdown
3. 点击导出

日常零配置，CLI 仅为可选高级功能

🎨

Slides Extended

1. Obsidian 社区插件安装
2. 配置 Reveal.js 选项（可选）
3. 学习 fragment / transition 语法

基础使用简单，但高阶动画需学习 Reveal.js API

📌 关键结论：两者安装均为一键完成。Marp 的上限低但下限高；Slides 的下限低但上限极高，精通需投入更多时间。

🎬 视频制作场景专项分析

针对"将 Markdown 笔记转为讲解视频"这一典型工作流的客观评估

维度Marp ExtendedSlides Extended
录制方式 导出 PDF → 全屏播放 → 录屏软件捕获 导出 HTML → 浏览器全屏 → 录屏软件捕获
动画捕获 ❌ 无原生动画，需后期在剪辑软件中添加 ✅ 原生支持过渡与 fragment，录屏直接捕获
音频同步 后期配音，时间轴需手动对齐画面切换 可内嵌 Web Audio API 实现点击自动播放旁白
输出画质 矢量 PDF，任意缩放清晰 依赖浏览器渲染，建议固定 1920×1080
后期工作量 高（补动画、补转场、对齐音画） 低（动画已内嵌，仅需粗剪与调色）
推荐度 ⭐⭐⭐ 适合静态讲解、课件存档 ⭐⭐⭐⭐⭐ 适合动态叙事、自媒体内容

工作流建议：若追求极致效率且接受平面风格，Marp + PDF + 录屏是最短路径；若追求视觉感染力且希望减少后期时间投入，Slides Extended 的自带动效能显著降低制作门槛。
