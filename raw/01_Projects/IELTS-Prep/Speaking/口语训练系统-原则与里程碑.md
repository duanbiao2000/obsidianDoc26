# 口语训练系统 · 原则与里程碑

> 本 SOP 是「雅思口语系统升级」决策的落地执行文件（关联 [[2026-08-03-决策-雅思口语系统升级]]）。基线 B2，**目标口语 7.5+**，**瓶颈 = 回答的逻辑 / 连贯 / 完整性 / 深度**（词汇非瓶颈，维持即可）。

## 1. 每日结构（4 小时 = 4 个单元 × 60 分钟，每单元含听说读写，口语 40%）

| 单元 | 练习 50 分钟（听说读写） | 思考 10 分钟 |
| :--- | :--- | :--- |
| 单元 1（精力高峰） | 口语 24m（Part 1）→ 听力 8m → 阅读 6m → 写作 12m | 四科快检 + 计分卡 |
| 单元 2 | 口语 24m（Part 2）→ 听力 8m → 阅读 6m → 写作 12m | 同上 |
| 单元 3 | 口语 24m（Part 3）→ 听力 8m → 阅读 6m → 写作 12m | 同上 |
| 单元 4 | 口语 24m（综合复述）→ 听力 8m → 阅读 6m → 写作 12m | 同上 |

铁律：
- 每单元 = 50 分钟练习 + 10 分钟思考；每日 4 单元 = 200 分钟练习 + 40 分钟思考 = 4 小时；
- **口语每天 4×24 分钟 = 96 分钟（占 40%），是本系统的优先投入**；四段覆盖 Part 1 / Part 2 / Part 3 / 综合；
- 写作每天 4×12 分钟 = 48 分钟（占 20%，口语让出的 10% 归写作）：日常做结构 / 句式 / 段落训练，**完整 Task 每周 2-3 次或模考日**；
- 听力每日 32m、阅读每日 24m；
- 口语时间必须用于真实输出（录音 / 对话），阅读听力不得冒充；4 个单元独立结算。

### 1.1 风险隔离规则

- 每个单元独立结算：失败 / 中断只损失该单元，不牵连其余；
- 同日 ≥2 个单元失败 → 当晚 10 分钟诊断（精力 / 难度 / 环境）；
- 连续 3 天 ≥2 单元失败 → 降总量或换时段，不硬撑。

## 2. 口语 24 分钟段（每天 4 段，覆盖全部题型）

| 段 | 内容 |
| :--- | :--- |
| 段 A（单元 1） | 材料吸收 + 拆解 6m（用[[可复用提示词-雅思真题级材料生成]]产出示范，拆 C-R-E-D，跟读 2 遍）→ Part 1 快答 10m（3 题 × 三查）→ Part 2 结构预热 8m |
| 段 B（单元 2） | Part 2 独白 ×2 轮：准备 1m → 说 2m → 三查 → 复录 1 遍（24m） |
| 段 C（单元 3） | Part 3 深度问答 ×3 题：C-R-E-D + 三查（24m） |
| 段 D（单元 4） | 综合复述 + 本周高频问题专项 + 自由对话（24m） |

### 2.1 沉浸吸收规则

- 吸收 = 输入 + 当日转化：拆解的高分示范必须**当天**复述 / 仿写 / 应用 ≥1 个表达块，否则不计入有效时间；
- 吸收对象优先：口语问答与写作高分示范（当前瓶颈所在），阅读听力材料次之；
- 材料用[[可复用提示词-雅思真题级材料生成]]产出，保证与真题一致。

## 3. 高分回答骨架：C-R-E-D

- **C**laim 观点：直接回答问题，1 句
- **R**eason 理由：1-2 个，说清"为什么"
- **E**vidence 证据/例子：具体、个人化、可验证
- **D**epth 深化：影响 / 对比 / 条件限定 / 反向思考（Part 3 推荐）

**禁用清单（无效答案）**：单独使用 `It depends.` / `It's important.` / `I think it's good.` 不构成答案，必须跟理由 + 例子。

## 4. 实时反馈：三查清单（每题后 ≤3 分钟）

1. **完整性**：问题所有部分都答了吗？（Part 2 所有 bullet points；Part 3 正面回答 + 延伸）
2. **逻辑连贯**：观点 → 理由 → 例子链条是否清晰？连接词是否自然（非机械堆砌）？
3. **深度与冗余**：有"为什么 / 例子 / 影响"吗？有没有车轱辘话或空话？

反馈规则：**只改 top 1 一件事，然后复答那一题**；不要一次性改 5 件事。

### 4.1 单元思考清单（每单元最后 10 分钟 = 四科快检 + 计分卡）

- 口语（2 分钟）：三查清单 + 只记 top 1 问题；
- 听力（2 分钟）：记 1 个发音 / 跟读点，明天口语段试用；
- 阅读（2 分钟）：记 1-2 个表达块，标注可套用话题；
- 写作（2 分钟）：记 1 个逻辑句式，迁移口语 Part 3；
- 计分卡（2 分钟）：更新当日每日进步计分卡。

## 5. 同步节奏

- **每 2-3 天**（5 分钟 mini 同步）：汇总高频问题 top 3，检查错误表达是否复现。
- **每周**（30 分钟周同步）：回听 2-3 段本周录音，按六维评分；核对 4 小时结构执行率；更新下周重点。
- **每 2-3 周**（周期末）：官方标准口语模考 + 行为指标审计。

## 6. 里程碑

- **M0 基线周**：官方标准模考（六维基线 + 目标 7.5+）+ 4 小时构成记录 + AI 范文抽查 5 条。
- **M1（周期 1 末）**：六维对比基线，目标 = 连贯 / 完整性维度提升；无提升 → 换反馈方式（自评 → AI / 真人对话反馈）。
- **M2（周期 2 末）**：全科模考 + 结构审计；口语无进步 → 砍低价值输入，喂给口语。
- **M3（考前 4-6 周）**：冲刺模式，全真模拟为主、探索性学习归零。
- **M4（考前 2 周）**：全真环境模拟（一次过、计时、不重录）。

## 7. 纠偏触发器

- 连续两次周期检查同维度无提升 → 停掉该训练线，先做瓶颈诊断；
- AI 内容被指出错误 / 不地道 ≥2 次 → 降权该生成源，改用语料库来源；
- 每周单元复盘执行率 < 80%（4 个单元中 <3 个完成 10 分钟思考）→ 下周优先补复盘，不补量；
- 考前 2 周低于保底分 → 现实调整目标，而非加量硬冲。

## 9. 每日进步计分卡（5 分钟，每天填）

| 指标 | 今天 | 目标 |
| :--- | :--- | :--- |
| 口语有效输出分钟 | /80+ | ≥ 80 |
| 单元复盘执行率（完成思考的单元数 / 4） | /4 | = 4 |
| 三查达标率（达标题数 / 总题数） | / | ≥ 70% |
| 新掌握表达块（拆解后当日应用） | 个 | ≥ 1 |
| 错误复现次数 | 次 | ↓ |
| 范文逻辑拆解篇数 | 篇 | ≥ 1 |

趋势规则：**每周看趋势，不看单日**；连续 3 天三查达标率 < 50% → 该训练线降量并诊断；连续 5 天达标 → 提高题难度或换话题域。
