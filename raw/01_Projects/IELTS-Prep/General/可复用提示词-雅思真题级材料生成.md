# 可复用提示词 · 雅思真题级材料生成

> 目标：让 AI 生成尽可能接近真实真题的听说读写材料 + 高分示范答案。**可变参数用 {{}} 标注**，每次使用只改参数，正文不变。

## 使用说明

1. 把「提示词正文」整段粘贴给 AI（Copilot / Claude / 任意 LLM）；
2. 替换 {{…}} 参数（主题、难度、数量）；
3. 默认是吸收版（题目 + 示范 + 逻辑拆解）；想要纯练习版，加一句"只出题，不给示范答案"；
4. 生成后先按「真题一致性守则」自检，再按三查清单吸收（见 [[口语训练系统-原则与里程碑]]）。
5. 日常训练默认单元版；考前冲刺（M3/M4）说"全真模考版"，按真实考试节奏出整卷。

**默认生成 1 个 50 分钟单元的量（口语 24m / 听力 8m / 阅读 6m / 写作 12m）；要一天的量就说"生成 4 个单元"。**

## 变量参数

| 参数 | 示例 |
| :--- | :--- |
| {{主题范围}} | 工作与职业 / 科技与生活 / 环境 / 教育 |
| {{目标分}} | 7.5+（词汇灵活、复杂句可控、几乎不卡顿） |
| {{题量}} | 默认 1 个单元：口语 1 段（P1×3 或 P2×1 或 P3×2-3）、听力 1 段、阅读 1 篇、写作 1 题；可要求 4 个单元 / 天 |

## 提示词正文

```text
# 角色
你是资深雅思出题官，同时是 8.5 分高分考生与雅思考官的混合体。你生成的材料必须经得起检验："这像不像真实真题？"

# 任务
生成一个训练单元（50 分钟练习）的雅思材料（听力 / 阅读 / 口语 / 写作），主题范围：{{主题范围}}，目标分：{{目标分}}，题量：{{题量}}。语言水平对齐目标分，不得明显过高或过低。

# 真题一致性守则（生成时逐条自检，做不到就重写）
1. 题型严格来自官方真实题型：听力 4 个 Section、阅读（判断 / 匹配 / 填空 / 选择）、口语 Part 1-3、写作 Task 1+2；不得发明题型。
2. 话题限于题库常见主题域（工作、教育、科技、环境、媒体、生活方式等），不得出怪题、偏题。
3. 口语示范必须像真人说话：有缩略形式、自然停顿、适度不完美；禁止 AI 腔（"moreover/furthermore" 堆砌、万金油例子、过度对称的排比句）。
4. 写作 Task 2 必须展示完整逻辑链：立场 → 论点 → 论据 / 例子 → 让步或深化；示范后附 1 行结构拆解。
5. 口语 Part 3 每题示范使用 C-R-E-D：观点 → 理由 → 证据 / 例子 → 深化（影响 / 对比 / 反向思考）；示范后附 1 行逻辑拆解。
6. 范文用词地道：优先常见搭配与表达块，不堆砌生僻词。
7. 输出量约束：材料量必须能在 50 分钟单元内完成（口语 24m / 听力 8m / 阅读 6m / 写作 12m）。宁可少出题，不可出做不完的量。
8. 听力结构真实：Section 1 = 双人对话（表单 / 笔记填空），Section 2 = 单人口播（地图 / 多选 / 配对）；不得用一文本混多种题型冒充多个 Section。
9. 多选题命题校验：正确项与干扰项不得同时直接出现在原文；干扰项必须是"被提及但不符合问题限定"的内容。
10. 判断题答案口径：陈述相对原文做无根据的绝对化 / 去限定 → 按官方口径判 FALSE（与原文限定冲突）或 NOT GIVEN（原文无信息）；答案必须附定位句 + 一句命题逻辑。
11. Part 2 cue card：提示点必须完整以 4 个 bullet 给出（含 explain why）。
12. 口语与写作统一 C-R-E-D 结构（观点-理由-证据-深化），不引入 PEEL 等平行术语；口语示范后附 1 行逻辑拆解，并按禁用清单检查（不得以 It depends / It's important 作结）。
13. 总量硬约束：生成后必须自报总时长；一天 4 单元 = 240 分钟（练习 200 + 思考 40），**口语每天 ≥ 96 分钟（40%）**，写作 ≤48 分钟（20%，含结构 / 句式 / 段落训练；完整 Task 每周 2-3 次或模考日），听力 ≤32 分钟，阅读 ≤24 分钟；超量必须削减，不可超时。

# 输出格式（按单元时间预算）
## 口语（24 分钟段，一次只给一个段）
- Part 1 段：3 题，每题 30-45 秒示范
- Part 2 段：1-2 条 cue card（覆盖全部 bullet points）+ 2 分钟示范 + 逻辑拆解
- Part 3 段：3 题，每题 C-R-E-D 示范 + 1 行逻辑拆解

## 听力（8 分钟段）
- 1 段录音原文（≤2 分钟文本）+ 一组题 + 答案

## 阅读（6 分钟段）
- 1 篇短文（≤300 词）+ 一组题 + 答案与定位句

## 写作（12 分钟段）
- 结构 / 句式 / 段落训练（开头段、论点句、衔接句等）；完整 Task 每周 2-3 次或模考日生成

# 生成后的质量控制（必须执行）
1. 对照官方评分标准（FC / LR / GRA / P）给本段材料各写 1 条提升建议；
2. 指出本段材料中"最不像真题"的 1 处，并当场重写；
3. 输出「学习重点清单」：3 个值得吸收的表达块或逻辑句式，并注明适用 Part / 题型。

# 模式
- 默认：吸收版（题目 + 高分示范 + 逻辑拆解）
- 若我说"练习版"：只出题，不给示范答案
- 若要一天的量：说"生成 4 个单元"
- 若要全真模考版（单科大块、模拟考试节奏）：说"全真模考版"（仅 M3/M4 冲刺使用）
```
