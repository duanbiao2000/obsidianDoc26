## 各题型考什么 & 最关键技巧

| 题型                                                            | 考察核心                                          | 最核心答题技巧                                                                                                 |
| ------------------------------------------------------------- | --------------------------------------------- | ------------------------------------------------------------------------------------------------------- |
| Matching Headings（段落标题配对）                                     | 提取段落主旨、区分主旨 vs 细节、把具体内容抽象成概念。ieltsliz+1       | 只看段首段尾 + 转折处，先自己一句话写出段落大意，再去匹配；绝不被例子/数字带偏；先排除明显不相关的 heading。ieltsliz+1                                  |
| TFNG / YNNG 判断题                                               | 区分“原文明确说了/说反了/根本没说”；精细理解陈述和原文的逻辑关系。ieltsliz+1 | 先在原文定位，逐词比对“意思”而不是单词；True = 基本同意，False = 明确相反，Not Given = 关键信息缺失或范围不同；看到“所有、唯一”等绝对词要特别警惕。ieltsliz+2     |
| Matching Paragraph Information（信息配对段落）                        | 扫读能力、在多段中定位特定信息、识别同义改写。ieltsliz+2             | 把题干关键信息先用自己的话“改写一遍”，再去文中扫同义；答案不按顺序出现，一条一条在文中找；一条信息只匹配一段，别贪心想塞进两个段落。ieltsliz+1                           |
| Matching Features（人物–观点/术语–解释 等）                              | 归类能力：把多条信息分配给不同人名/术语等；比对细节差异。ieltspodcast+1   | 先给每个人名/术语在原文旁边做“人物小档案”笔记，再去看选项往里放；特别关注说话动词（claim, argue, suggest 等）和态度词；允许重复使用同一个字母，注意说明。ieltspodcast+1 |
| Matching Sentence Endings（句子结尾配对）                             | 逻辑衔接、语法完整性、含义一致性。ieltspodcast+1               | 先用语法排除：主句 + 结尾要构成语法完整的句子；再用含义检查是否合理；通常先看主句在文中位置，再在附近比较几个选项结尾。ieltspodcast+1                             |
| Multiple Choice（单选/多选）                                        | 全文结构理解 + 细节比对；识别干扰项。imsindia+1                | 先看题干和选项，圈关键词，再回原文定位；优先排除明显不对的项，“同词不同意”是高频陷阱；多选题建议最后做，因为信息分散、耗时长。imsindia+1                              |
| Summary / Note / Table / Flow-chart Completion（摘要/笔记/表格/流程填空） | 整合一段或多段的信息、把细节放进结构里；同义替换、词性判断。ieltsliz+3      | 先读 summary 本身，预测每个空的词性和大致意思；答案通常按顺序出现在某一小段范围内；在原文中找“同义表达”，不要只盯原词；严格遵守字数限制。ieltsliz+3                    |
| Sentence Completion（句子填空）                                     | 句子级别的精细理解；语法、搭配和同义替换。ieltsliz+1               | 先用语法判断空格需要什么词（名词、动词、形容词）；再在原文附近找意思匹配且词性一致的词；注意题目要求“用原文中的词”。ieltsliz+1                                   |
| Diagram / Label Completion（图示标注填空）                            | 读图能力 + 方位/结构理解；把文字信息对应到图上。ieltsliz+1          | 先搞清图示结构和方向（left/right, above/below 等），再回原文找描述空间关系的句子；按顺序填空，通常沿一个方向移动。ieltsliz+1                         |
| Short-answer Questions（简答题）                                   | 精确定位细节信息，用少量原词作答。ieltsliz+1                   | 读题干时先判断需要信息的类别（数字、人名、原因、结果等）；在文中快速定位后，直接从原文抄答案，注意单复数和字数上限；超一个词就错。ieltsliz+1                             |
| Choosing a title / main idea（选标题/中心思想）                        | 全文/段落的整体理解；区分主干 vs 细节。ieltsliz+1              | 做在最后：通读后先用一句话写出“这篇文在干嘛”，再去选最贴近的标题；警惕只抓住局部细节但不覆盖全文的选项。ieltsliz+1                                         |
| Categorisation（分类题）                                           | 把信息按标准分组；识别多个小差异。scribd+1                     | 先给每个类别做“标签”（比如支持/反对/中立），在原文看到相应态度或特征就归类；注意有些选项可能不使用。scribd+1                                            |

## 怎么用这些信息来规划训练

从命题方角度，所有题型背后其实就考几件事：定位（skimming/scanning）、理解（主旨 vs 细节 vs 态度）、整合信息、以及词汇同义替换。ielts+2

你的训练可以按“核心技能”而不是“题型名字”来走，比如：

- 一段时间专攻“细节定位” → 多做 TFNG、选择题、简答题。
- 一段时间专攻“主旨抽象与结构” → 多做 heading、title、matching paragraph info。
- 一段时间专攻“整合和改写” → 多做 summary/note/table completion。

# 🎯 雅思阅读高分操作系统 (目标 8.0+)

> [!abstract] 核心哲学
> 雅思阅读的本质不是“读懂文章”，而是 **“信息检索” + “逻辑对齐”**。
> 高分考生不做阅读笔记，只做 **“信息压缩”**。

---

## 一、 解题算法地图 (核心题型)

| 题型 | 考察本质 | 💡 第一反应 (算法) | ⚡️ 避坑指南 |
| :--- | :--- | :--- | :--- |
| **Heading** | 段落功能识别 | 扫段首尾/转折 -> 定义段功能 | 绝不看细节例子；排除法是王道 |
| **TFNG** | 逻辑边界判定 | 圈出“绝对词” -> 比对原文程度 | 找不到 = NG，说反了 = F，别脑补 |
| **Summary** | 语境/词性预测 | 预判词性 -> 锁定定位词 -> 找替换 ≈ | 严格遵守字数；注意语法对齐 |
| **Matching** | 细节/属性关联 | 建立“人物/信息档案” -> 扫读定位 | 答案不按顺序；可能重复选择 |
| **Choice** | 主旨与细节整合 | 排除极端项 -> 回原文找事实依据 | 别选“常识正确”但“原文未提”的项 |

## 二、 视觉导航系统 (Notation System)

*笔尖即思维：减少二次搜索成本，实现“秒回原文”。*

### 1. 结构与逻辑标记

- `|` : **Main Idea** (段落主题句，通常在首尾或转折后)
- `★` / `→` : **Logic Point** (转折、因果、结论处，通常是出题点)
- `Q[序号]` : **Question Found** (标记该处已被哪道题用掉，防止混淆)
- `~` : **Term** (不认识的术语，只需标出位置，不纠结语义)

### 2. 态度与程度预警 (针对 TFNG/Yes-No)

- `[+ / - / ?]` : **Attitude** (作者支持 / 反对 / 不确定/部分同意)
- `⚠` : **Absolute Trap** (看到 All, only, must, always 等词立即警觉)

### 3. 高阶定位锚点 (Advanced Anchors)

- `○ [类别]` : **Categorized Data** (不仅圈数字，要标性质。如：`○ 1995 (Exp)`, `○ 45% (Data)`)
- `⇄` : **Mapping** (发现题干与原文的替换对应关系)

---

## 三、 深度建模：从“读文章”到“拆逻辑”

### 1. 同义替换链 (Paraphrase Mapping)

这是 8.5 分的核心能力。记录替换时注意三种维度：

- **近义词/短语：** *limited* resources ≈ *scarcity* of materials
- **词性转换：** *rely on* (v.) ≈ *reliance* (n.)
- **正话反说：** *difficult* to achieve ≈ *not easy* / *challenging*

### 2. 段落功能识别 (Function Recognition)

将段落视为“乐高积木”，Heading 题选的是“积木的作用”：

- **Def** (定义) | **Exp** (实验) | **Data** (数据) | **Crit** (质疑) | **Sol** (方案) | **Comp** (对比)

## 四、 考场红线与“伪努力”避坑
>
> [!danger] 行为红线 (考试/训练严禁)
>
> 1. **严禁同步查词：** 练习时也不准查。标记 `~` 即可，做完题再统一复盘。
> 2. **严禁过度划线：** 划线超过全段 30% 意味着大脑没有进行结构化思考。
> 3. **严禁脑补推导：** TFNG 只看原文给没给依据，不看“按照常理是不是”。
> 4. **严禁匀速阅读：** 考场时间分配应为“读题(预判)-扫读(定位)-精读(解题)”。

---

## 五、 进化训练计划

- [ ] **Phase 1: 定位力 (Week 1)**
  - 重点：TFNG + 填空类。
  - 目标：100% 准确锁定出题句，熟练使用 `○` 和 `⚠` 标记。
- [ ] **Phase 2: 结构力 (Week 2)**
  - 重点：Heading + Matching Info。
  - 目标：不读全文，3分钟理清段落功能图 (Def/Exp/Crit)。
- [ ] **Phase 3: 预判力 (Week 3)**
  - 重点：全真模拟 + 替换链复盘。
  - 目标：看到题干，脑中自动浮现 2-3 个可能的原文替换词。
