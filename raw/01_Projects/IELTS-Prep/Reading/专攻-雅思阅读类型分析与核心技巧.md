# IELTS Reading Operating System (Band 8.0+)

The core of IELTS Reading is not comprehension; it is targeted search and logic alignment. High scorers do not take reading notes; they compress information.

## 1. Question-Type Quick-Ref
| Type | What It Tests | Core Algorithm | Trap to Avoid |
| :--- | :--- | :--- | :--- |
| **Heading** | Paragraph function | Scan first/last lines & turns → define function | Never read examples; use elimination |
| **TFNG** | Logic boundaries | Circle absolute words → match text degree | Missing = NG, reversed = F (no guesswork) |
| **Summary** | Context & grammar | Predict word class → anchor keyword → find synonym ($\approx$) | Strict word limits; grammatical alignment |
| **Matching** | Detail/attribute links | Build entity/info profiles → scan text | Answers are out of order; watch for reuse |
| **Choice** | Macro/micro integration | Eliminate extremes → find text-based facts | Reject "common sense" facts not in text |

## 2. Visual Notation System
*Pen is thought: minimize re-reading to instantly jump back to the text.*
- **Structure:** `|` (Main Idea), `★` / `→` (Turning point / Logic), `Q[#]` (Question used).
- **Attitude:** `[+/-/?]` (Pro / Con / Neutral), `⚠` (Absolute traps like *all*, *only*, *must*).
- **Anchors:** `○ [Type]` (Categorized data, e.g., `○ 1995 (Exp)`), `⇄` (Paraphrase mapping).

## 3. Paraphrase & Function Mapping
- **Paraphrase Chains:** *limited resources* $\approx$ *scarcity* | *rely on* (v.) $\approx$ *reliance* (n.) | *difficult* $\approx$ *not easy*.
- **Paragraph Functions:** Treat paragraphs as Lego blocks. Heading tests block function: **Def** (Definition) | **Exp** (Experiment) | **Data** (Data) | **Crit** (Critique) | **Sol** (Solution).

## 4. Hard Rules
1. **No live dictionary lookups:** Mark unknowns with `~`. Review after finishing.
2. **No excessive underlining:** If over 30% of a paragraph is underlined, you aren't thinking structurally.
3. **No outside logic:** TFNG relies strictly on text evidence, not real-world probability.

## 5. 3-Week Skill-Based Plan
- **Week 1 (Targeting):** TFNG + Completion. Drill accurate sentence location and attitude tagging (`[+/-/?]`).
- **Week 2 (Structure):** Headings + Matching Info. Map paragraph functions in under 3 minutes without reading line-by-line.
- **Week 3 (Prediction):** Full mocks + Paraphrase review. Train your brain to anticipate 2–3 synonym variants before scanning.
