18 Claude Chat Commands

Type these at the start of any prompt in claude.ai

“Forget everything above. Fresh start.”  
Resets context for a clean slate.

“Summarize what we’ve covered, then keep going.”  
Provides a recap and continues the dialogue.

“Bullet points only from here.”  
Restricts responses to bulleted lists.

“Use Opus for this one.”  
Switches the model to Claude Opus for the next prompt.

“Keep this short. I’ll ask for more if I need it.”  
Requests a concise answer first.

“Before you respond — what are you assuming?”  
Asks Claude to list its prompt assumptions.

“Think out loud before giving me the final answer.”  
Enables a detailed chain-of-thought process.

“Give me three versions. Different angles.”  
Generates multiple diverse responses.

“Now critique what you just wrote.”  
Instructs Claude to review its previous output.

“Pick up where you left off.”  
Resumes from the last completed point.

“For this whole conversation, you are [role].”  
Sets a persistent role-play persona.

“Remember this the entire session: [detail].”  
Pinpoints crucial information for the whole chat.

“Rewrite the last response but [one change].”  
Edits the previous answer with specific modification.

“What’s missing from my prompt?”  
Asks Claude to identify gaps in user input.

“Give me the uncomfortable version of this answer.”  
Requests the rawest, most direct response possible.

“What would you need to give me a better answer?”  
Inquires about necessary improvements.

“Flag every assumption you made.”  
Calls out all underlying presuppositions used.

“Now make it half as long.”  
Compresses the previous response to 50% length.
