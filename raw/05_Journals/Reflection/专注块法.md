# 专注块法

> [!abstract] 一句话主张
> 用 25–50 分钟的专注块，每块只定义一个产出，对抗碎片化。

## 为什么有用
固定的时间盒 + 单一产出目标，比"尽量专注"更可执行。

## 具体做法
- 每个专注块 25–50 分钟
- 每个块只定义一个明确产出 → 
- 开始前清空桌面和通知 → 
- 手机放到伸手拿不到处 → 
- 在黄金时段做高认知任务 → 

## 反例 / 常见误区
- 一个专注块里做三件事 = 没有专注
